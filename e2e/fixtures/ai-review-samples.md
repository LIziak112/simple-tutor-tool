::::question{type=solve difficulty=2 knowledge="有理数加减混合运算"}
（样本①：清晰错误——请把每一步分行写清楚，并故意在某一步保留符号错误，使最终答案错误）计算：$(-15)+7-(-8)$，写出完整过程与最终结果。

:::hint
先把减法统一为加法（减去一个数等于加上它的相反数），再从左到右依次计算。
:::

:::answer
0
:::

:::solution
$(-15)+7-(-8)=(-15)+7+8$；异号相加取绝对值较大的加数的符号：$(-15)+7=-8$；$(-8)+8=0$。最终结果为 $0$。
:::
::::

::::question{type=apply difficulty=2 knowledge="正负数的实际应用"}
（样本②：模糊歧义——请故意多次涂改叠写：写错后划掉、在原处叠写新算式，制造难以辨认的局部）某地清晨气温为零下 $3$℃，中午上升了 $8$℃，傍晚又下降了 $5$℃。求傍晚的气温，列式并写出计算过程。

:::hint
规定上升为正、下降为负，把各次变化写成有理数的和。
:::

:::answer
0
:::

:::solution
设上升为正：$-3+8-5=0$（℃）。傍晚气温为 $0$℃。
:::
::::

::::question{type=choice difficulty=1 knowledge="有理数乘法"}
（样本③：空稿——作答时不要写任何草稿，直接点选选项）$(-2)\times(-3)=$（　）

- [ ] $-6$
- [x] $6$
- [ ] $-5$
- [ ] $5$

:::solution
两数同号，积为正：$(-2)\times(-3)=6$，故选 B。
:::
::::

::::question{type=solve difficulty=2 knowledge="有理数乘方与混合运算"}
（样本④：只写最终答案——笔迹上只写最终得数，不写任何中间步骤）计算：$(-2)^2-4\times\left(-\frac{1}{2}\right)$，写出过程。

:::answer
6
:::

:::solution
先算乘方：$(-2)^2=4$；再算乘法：$4\times\left(-\frac{1}{2}\right)=-2$；最后相减：$4-(-2)=4+2=6$。
:::
::::

::::question{type=choice difficulty=2 knowledge="有理数除法与加减混合"}
（样本⑤：正确过程但误填——草稿纸上把过程完整写对，但交卷前故意点选一个错误选项）计算 $(-12)\div 3+(-2)$ 的结果是（　）

- [x] $-6$
- [ ] $-2$
- [ ] $2$
- [ ] $6$

:::hint
先算除法，再算加法；注意除以正数不改变符号。
:::

:::solution
$(-12)\div 3=-4$；$-4+(-2)=-6$，故选 A。
:::
::::

::::question{type=solve difficulty=3 knowledge="有理数乘方"}
（样本⑥：原稿错而订正对——第一遍把 $-1^4$ 当成 $(-1)^4$ 计算而做错；交卷后在结果页用「添加订正」把过程写对并封存）计算：$-1^4-(-2)^3$，写出过程。

:::hint
先想清楚 $-1^4$ 表示「$1^4$ 的相反数」还是「$-1$ 的四次方」，再看 $(-2)^3$ 的符号。
:::

:::hint
减去一个负数等于加上它的相反数。
:::

:::answer
7
:::

:::solution
$-1^4=-1$（先算乘方再取相反数）；$(-2)^3=-8$；$-1-(-8)=-1+8=7$。
:::
::::

::::question{type=judge difficulty=1 knowledge="相反数的概念"}
（样本⑦：多版本同 id——第一遍故意答错进错题本；再从错题本重练同题，第二遍独立做对）任何数的相反数都比它本身小。[[错误]]

:::hint
用 $a=2$、$a=-2$、$a=0$ 分别代入，比较 $a$ 与 $-a$ 的大小。
:::

:::solution
相反数与原数符号相反：正数的相反数比它小，负数的相反数比它大，$0$ 的相反数是 $0$。因此这句话不成立。
:::
::::

::::question{type=choice difficulty=2 knowledge="有理数混合运算"}
（样本⑧：长图切片——草稿分行写满约两屏再作答，触发多页切片；交卷后立即关页可顺带覆盖「缺图不重建」场景）计算 $(-36)\div 4-(-2)\times 5$ 的结果是（　）

- [x] $1$
- [ ] $-1$
- [ ] $19$
- [ ] $-19$

:::solution
$(-36)\div 4=-9$；$(-2)\times 5=-10$；$-9-(-10)=-9+10=1$，故选 A。
:::
