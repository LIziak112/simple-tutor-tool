# 整理材料为内容 DSL（simple-tutor-tool）

把用户给的任何教学材料变成「可直接导入 simple-tutor-tool」的 Markdown 文档。
产出物只有一种：符合 DSL v2 规范的 .md 文件（含 frontmatter）。

## 工作流（按序执行）

### 1. 读规范（必做，不可跳过）

通读同目录的 `规范.md` 与 `完整样例.md`。规范是唯一权威：指令清单里没有的
指令、语法一律不用；拿不准的写法回规范查表，不要凭记忆发挥。

### 2. 判断输出形态（frontmatter 的 kind）

| 材料形态 | kind | 要点 |
| --- | --- | --- |
| 讲解性内容（知识点、例题讲解） | `lecture` | 按「# 第X讲 …」切篇，例题用 `::::example` 包题面与解析 |
| 题目集合 | `practice` | 若干 `::::question` 顶层容器；frontmatter 写 `unit:` |
| 讲一段练一段 | `mixed` | 讲义段落与题目交替，导入时自动拆分并关联 |

### 3. 整理红线（最常翻车处，成文后逐条自查）

- frontmatter 以首行 `---` 开头，`kind` 必填；练习**显式声明 `unit:`**（不写则
  用文件名当单元身份，文件改名会断统计）；练习要挂到某篇讲义时写 `lecture:`
  （按讲义名在同文件夹匹配）。
- 题目容器 `::::question{type=…}`：type 七选一（judge/choice/multi/fill/solve/
  apply/find-error）；difficulty 1–5 缺省 2；knowledge 写考点。
- 判断题题干写 `[[正确]]` / `[[错误]]`（恰一个）；选择题用任务列表 `- [x]`
  标正确项（单选恰一个，多选至少一个）；填空 `[[答案]]`、等价答案
  `[[0.5|1/2]]`；手写题（solve/apply/find-error）可选 `:::answer` 最终答案
  与 `:::solution` 详解。
- 公式一律 `$…$`；**`[[…]]` 标记内绝对不写 `$`**——会被公式定界符从中间切开，
  空位识别不到且答案原文泄露（error 级，BLANK_MARKER_CONTAINS_DOLLAR）。
  要在算式中间留空时把公式断成两段，断点两侧用普通括号 `(` `)`。
- 所有容器必须写结束围栏 `:::`；嵌套时外层多一个冒号；H2/H3 标题不要写进
  折叠/提示/详解容器内部。
- 题目 id：同一道题的修订版**保持原 id 不变**（学情统计跨版本延续）；新题不写
  id，系统自动派生「单元slug-序号」。
- 不写原始 HTML（表格用 GFM 管道语法），不用外链图片 URL。

### 4. 图片

- 用户提供了图片文件：`::image` 的 src 直接写**图片的真实文件名**（保持原名，
  不要改名、不要编造路径），交付时提醒用户「导入时把 md 和图片（或整个文件夹）
  一起选择」，系统会自动上传并改写 src。
- 环境配置了 simple-tutor-tool 的 MCP 服务器：先调 `upload_image` 上传，用返回
  的 `blobs/media/…` 路径作 src。
- 两者都没有：图的位置写一句普通文字说明占位，不要伪造 `::image`。

### 5. 校验 → 修正循环（交付前必跑）

按环境选一条校验路径：

| 优先级 | 路径 | 适用 |
| --- | --- | --- |
| 1 | MCP `lint_markdown` | 环境已接入 simple-tutor-tool 服务器（自部署用户） |
| 2 | `pnpm tutor-lint <文件或目录>`（在 simple-tutor-tool 源码仓库内执行） | 本地有仓库源码 |
| 3 | 教师端「导入」页预览 | 兜底，人人可用：把文件拖进去即 lint 门禁 |

循环执行：校验 → 逐条按 issue 的 message / fix 修正 → 重新校验，**直至 0
error**。warning 逐条判断：能改则改（如补 `unit:`），确属内容意图的可保留并在
交付时告知用户。

### 6. 交付

- 只交付完整的 .md 文档（含 frontmatter），正文不夹带解释性文字。
- 文件名建议即单元名或讲义名；md 与其引用的图片放同一文件夹。
- 需要直接导入且环境有 MCP：调 `import_markdown`（多文件打包用 `import_zip`）；
  否则指引用户在教师端「导入」页上传。

## 乱输入处理

- Word / 扫描转写文本：先理顺段落与标点，再套 DSL；图片里的公式转写为 LaTeX
  写进 `$…$`（结果页按公式渲染）。
- 缺参考答案的手写 / 应用题：**不要编造答案**——省略 `:::answer`（该题导入后
  自动进入教师人工批改队列）。
- 材料里超纲、重复或有疑义的题：原样保留，整理完列表告知用户，不擅自删改
  内容语义。
