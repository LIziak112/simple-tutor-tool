# simple-tutor-tool

[![CI](https://github.com/LIziak112/simple-tutor-tool/actions/workflows/ci.yml/badge.svg)](https://github.com/LIziak112/simple-tutor-tool/actions/workflows/ci.yml)

[简体中文](README.md) · [English](README.en.md)

这是一个为线上一对一辅导老师做的**自部署、AI 原生**讲练工具——最初只是为了解决「讲义散在各个文档里、每个学生的做题情况全靠脑子记」的日常麻烦，后来在一轮轮真实使用中逐渐长成了现在的样子。

它想把一件事做好，并把整条链路串起来：老师（可以借助 AI）按规范写好 Markdown，导入即自动渲染成可互动的讲义与练习；学生打开链接就能答题，包括在题干上圈画、在草稿纸演算、用 Apple Pencil 手写作答；老师随后在后台看到每个学生逐题的作答、原始笔迹回放、草稿原稿、订正反思与学情总结；这些结构化数据与手写过程证据还能整包交回 AI，帮助复盘与准备下一节课。

**单进程、数据自持**：一个 Node 进程同时提供教师端、学生端与全部 API；数据就是本机 `data/` 目录里的一个 SQLite 文件加 blobs 目录（手写笔迹、草稿原稿、题干圈画、备份、共享内容都在内），不经任何第三方平台，备份 = 复制目录。

这条主线的核心资产是**贯穿两端的数据结构契约**（[`packages/contract`](packages/contract) 的 Zod schema）：上游，符合契约的 MD 能被自动转成讲义与练习；下游，作答数据与过程证据是结构化 JSON 与标准图片，AI 可直接消费。

```
AI 产内容（符合 DSL 规范的 MD）──→ 导入自动解析渲染 ──→ 学生互动答题（手写 / 草稿 / 圈画 / 订正）
        ▲                                                              │
        └──────── AI 诊断学情 / 逐题评析 / 生成针对性练习 ←── 结构化作答与过程证据 ──┘
```

### 用它可以做什么？

- **对老师**：告别散落的 Word/PDF 和靠脑子记学情。用 Markdown（或让 AI 辅助）快速产出互动讲义与题库，一键布置作业或组建课程；在后台用快捷键高效批改主观题、倍速回放学生手写推导过程、查看演算原稿与订正反思；通过掌握度矩阵、薄弱考点排行和讲义阅读地图，一眼看清下节课该讲什么。
- **对学生**：免安装 App、免注册，iPad 或电脑浏览器点开专属链接即用。看带公式和折叠解析的互动讲义，做题时可在题干上圈画重点、展开草稿纸演算、用 Apple Pencil 手写解题过程；交卷后对照解析做订正与错因反思，系统自动沉淀错题本与单题历次笔记本，随时一键重练薄弱题。
- **对 AI 协作**：不用把题目和学生作答手工复制粘贴给大模型。制作端有完整的 DSL 规范、提示词与离线校验包（[`dsl-kit/`](dsl-kit/)）；数据端可一键导出带手写原稿/订正图片与防幻觉提示词的「AI 学情数据包」或单题「AI 复习包」，也可通过内置 MCP Server 让 Claude 等客户端实时接入。

## 支持的模式

项目围绕一对一辅导的不同教学阶段，支持以下几类模式组合使用：

### 1. 内容组织模式（3 种文档 `kind`）

| 模式 | Frontmatter 标识 | 适用场景与行为 |
| --- | --- | --- |
| **讲义模式** | `kind: lecture` | 编写课程讲义，按 `# 第 X 讲` 自动切分成篇；支持公式、例题折叠（`:::example`）、分步推导揭晓（`:::steps`）、函数图像（`::graph`）、分栏与重点标记。 |
| **练习模式** | `kind: practice` | 编写纯题库或作业卷，自动拆题入库；支持 **7 种题型**：`judge`（判断）、`choice`（单选）、`multi`（多选）、`fill`（填空）、`solve`（计算）、`apply`（应用）、`find-error`（找错，后三者为手写题）。 |
| **讲练混合模式** | `kind: mixed` | 在同一份 Markdown 中同时编写讲义与配套题目；一次导入自动拆分为讲义篇目与配套练习单元，并在讲义底部自动关联本课练习。 |

### 2. 学生学习与练习模式（3 条作答通道）

- **课后作业模式**：老师从题库勾选一个或多个单元指派给学生，支持**「每个单元独立一份作业」**（推荐，各自独立作答与交卷）或**「合并为一份作业」**；答案公布时机支持**「交卷即公布」**或**「截止时间后公布」**（截止前严格隐藏对错、参考答案与详解）。
- **课程自主练习模式**：学生进入所属课程，按章节目录阅读可见讲义后，直接点击配套练习单元作答；交卷即公布答案与详解，支持**无限次重做**（每次从空白开始，历次得分与作答快照全部保留）。
- **错题重练模式**：错题本自动跨作业与课程收录错题，支持按「练习单元 / 时间 / 考点」三维分组及按课程筛选；学生可自定义攻克标准（默认**严格模式：连续做对 2 次**，可选**宽松模式：做对 1 次**），并从错题本或交卷结果页一键拉起错题重练卷。

### 3. 身份与访问模式

- **双登录模式**：学生支持**专属链接免密直达**（适合在 iPad Safari「添加到主屏幕」作为全屏 PWA 使用）与**登录名（默认同姓名）+ 密码登录**，老师可按学生独立开关或重置。
- **多教师隔离与共享模式**：支持单实例多教师使用，各教师的资源库、课程、学生、作业严格隔离；首位教师为管理员（可管账号与自助注册开关），教师可将优质讲义/单元发布到「共享中心」供其他教师预览并导入各自资源库。
- **同浏览器师生双身份并存**：教师会话与学生会话使用独立 Cookie，老师可在同一浏览器同时登录教师后台与测试学生账号，实时对照预览而不互相顶下线。

### 4. AI 协作模式（3 层接入）

| 模式 | 适用场景 | 工作方式 |
| --- | --- | --- |
| **离线技能包模式（`dsl-kit/`）** | 用本地 AI 工具（Claude Code / Cursor / 网页大模型）写讲义、整材料、出题 | 将 [`dsl-kit/`](dsl-kit/) 文件夹交给 AI，内含 DSL 规范、完整样例、提示词模板、「材料整理」技能 [`SKILL.md`](dsl-kit/SKILL.md) 及零依赖单文件离线校验脚本 `tutor-lint.mjs`（`node dsl-kit/tutor-lint.mjs <文件>`），AI 本地写完即自检到 0 error。 |
| **数据包导出模式（LearningPack v1/v2 & 单题复习包）** | 阶段性学情复盘、逐题手写过程评析、学生单题自查 | 教师端五步向导一键导出「AI 学情数据包」ZIP（支持化名脱敏、按阶段收录**手写原稿 / 订正 / 题干圈画图片**、内置 5 类提示词模板与防幻觉诚实口径声明）；学生或教师也可在结果页按题导出「AI 复习包」或静态合成图（PNG）。 |
| **MCP 实时连接模式（`/mcp`）** | 在 Claude Desktop 等支持 MCP 的客户端内直接对话操作 | 教师生成专属 API Token 并在客户端配置 `/mcp`，AI 即可调用 **14 个内置工具**：查看学生与课程、拉取学情包与题目统计、将诊断报告直接写回系统、读取 DSL 规范与能力清单（`describe_capabilities`）、校验并导入 Markdown / 图片 / ZIP 教学包。 |

## 已实现功能总览

### 内容引擎（MD 进，互动页面出）

- **导入即用与自动结构化**：讲义、练习或混合 `.md`（可连同本地图片一起选择）一次导入自动拆题分篇；练习自动抽取单元、题号、题型、难度、考点、答案、提示与详解。
- **互动渲染与公式支持**：Markdown、GFM 表格与数学公式（KaTeX 本地打包，不走 CDN）自动排版；例题解析默认折叠，分步推导（`:::steps`）逐步点击揭晓，函数图像（`::graph`）动态绘制。
- **指令注册表与能力化**：17 个指令由注册表统一管理，**已发布指令只增不改，旧内容永远可用**；宿主统一消费 Zod 类型化属性，注册表自动派生 `capabilities.json` 系统能力清单；教师可在设置页按需开关辅助能力（如分步揭晓、手写与草稿入口）。
- **教学包往返与在线编辑**：支持在 frontmatter 声明 `teachingPack` 能力依赖；资源库支持一键导出 `.zip` 教学包（含 Markdown、能力清单快照与引用的本地图片）并可原样重新导入；内置 CodeMirror 6 编辑器带实时 lint 诊断，单题编辑自动维护版本号（`version+1`）。

### 学生端（零负担阅读、作答与复盘闭环）

- **讲义阅读**：公式排版、自动大纲目录（滚动阅读时当前小节自动居中跟随）、例题折叠展开、底部直达本课配套练习。
- **全题型作答与手写**：判断 / 单选 / 多选 / 填空 / 手写题；数学答案可选 MathLive 虚拟键盘输入；手写题支持页内（Atrament）与全屏（Excalidraw）书写；支持可折叠答题卡快速跳题与分步提示按需解锁。
- **演算草稿纸与原稿冻结**：非手写题（选择/判断/填空）题卡内置**草稿纸**（支持白底/格线/横线、自动加高、全屏演算同时参考题干与选项、笔写/手指滚动防误触、本机 IndexedDB 持久化与服务端增量同步）；**交卷瞬间自动冻结本次演算原稿**，后续重练或修改绝不覆盖历史原稿。
- **固定底图题干圈画**：做题时可直接在固定宽度题干底图上圈画批注（横竖屏旋转或缩放不漂移，交卷后自动封存，结果页可保存订正圈画）。
- **结果回看、订正反思与题目笔记本**：交卷结果页每题提供单行操作栏（查看详解、本次原稿、订正、本题历史、更多）；支持空白或**复制原稿起步订正**，填写「我卡在哪里 / 我的错因」反思后封存为检查点；交卷后找回的本地未同步草稿明确标记为**补充稿**；**题目笔记本**（`/s/notebook/:qid`）跨轮次对照同一道题的历次原稿、订正、补充稿与题目版本。
- **作业列表、我的记录与错题本**：首页聚焦最新两份待完成作业与待办总数，独立「我的作业」列表支持按状态、北京时间自然日、标题搜索与分页筛选；「我的记录」跨作业、课程练习与错题重练汇总全部历史作答；错题本支持「待复习 / 已攻克」分区、多维分组与一键重练。

### 教师端（内容资产管理、高效批改与学情洞察）

- **资源库与统一导入向导**：文件夹归类、讲义库/题库/回收站管理；导入支持多选文件、选整个文件夹或直接粘贴，提供 dry-run 动作预览、跨文件冲突检测与一键「复制错误给 AI」。
- **课程、学生与作业管理**：课程章节编排、可见性与定时发布、学生视角只读预览、成员×单元进度矩阵；三步布置作业向导与名单动态增补。
- **待批队列与手写过程回放**：待批队列（`/t/data/pending`）支持键盘快捷键（`J/K` 切题、`1/2/0` 判对/判错/清空、`U` 撤销）连续批改；作答详情支持**手写笔迹按时间戳倍速回放（1×/2×/4× 与进度条拖动）**，同时查看学生演算原稿、题干圈画、订正反思，并支持对任意题改判与写评语。
- **三维学情分析（ECharts）**：
  - **总览**：待批计数、重做统计、周期内「下节课重点」薄弱考点卡、学生×作业/课程单元完成矩阵。
  - **学生画像**：正确率自然周趋势、薄弱考点条形图、用时异常题、**讲义阅读地图**（按小节统计停留与挂机时长）及 AI 诊断报告归档区。
  - **题目视角**：单题与考点正确率、高频错误答案聚合、平均与中位用时。
- **导出与备份恢复**：作答记录导出 UTF-8 BOM CSV（Excel 直接打开无乱码，含手写图链接）；五步向导导出 AI 学情数据包（v1/v2，支持预览时刻 `asOf` 锁定快照）；一键下载完整数据备份 zip，支持密码确认上传恢复（恢复前自动拍快照可回滚）。

## 如何使用

### 一、启动服务（按场景选择运行方式）

环境要求：Node.js ≥ 24、pnpm 12.6.0（容器部署仅需 Docker）。

#### 方式 1：Windows 双击脚本启动（最省心，适合本地日常教学或演示）

仓库根目录提供了两个批处理脚本（首次运行前请先执行一次 `pnpm install`）：

- **双击 `测试模式.cmd`（开发/演示模式）**：免构建直接运行源码，前端地址 `http://localhost:5173`（同一 Wi-Fi 下学生 iPad 可直接通过电脑局域网 IP 访问），后端端口 `8787`，数据固定保存在仓库 `data/` 目录；自带端口占用检测与关闭后残留进程清理。
- **双击 `启动服务.cmd`（本地生产模式）**：自动检查并执行 `pnpm build`，随后以单进程生产模式启动 `node apps/server/dist/index.js`，浏览器自动打开 `http://localhost:8787`。

#### 方式 2：命令行开发模式

```bash
pnpm install          # 安装依赖
pnpm dev              # 并行启动 server（8787）与 web（Vite，默认 5173，/api 自动转发；首次启动自动初始化数据库）
pnpm seed:demo        # 可选（需先启动过一次服务完成建库）：灌入演示数据，终端会打印新建 demo 教师的随机初始密码（演示学生密码均为 demo-pass-123）
```

#### 方式 3：云服务器 / 生产环境部署（详见 [docs/部署.md](docs/部署.md)）

- **Docker Compose（推荐，自带 Caddy 反代与健康检查）**：
  ```bash
  git clone https://github.com/LIziak112/simple-tutor-tool.git && cd simple-tutor-tool
  mkdir -p data && sudo chown -R 1000:1000 data    # 容器内以 uid 1000 的 node 用户运行
  docker compose up -d --build                     # 浏览器打开 http://localhost（云服务器用公网 IP）
  ```
- **GHCR 镜像快速运行**（免本地构建）：
  ```bash
  docker run -d -p 8787:8787 -v ./data:/app/data ghcr.io/liziak112/simple-tutor-tool
  ```
- **Node 裸机常驻**：执行 `pnpm build` 后运行 `node apps/server/dist/index.js`，配合 systemd 管理进程。

关键环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 服务监听端口 |
| `DATA_DIR` | `./data` | 数据目录（`tutor.db`、`blobs/`、`shared/`、`backups/`、`secret.key` 全在内，备份 = 备份此目录） |
| `PUBLIC_URL` | `http://localhost:8787` | 对外访问地址；为 `https://` 时自动启用 Secure Cookie 与 PWA Service Worker |

> 公网部署建议：在管理端（`/a`）关闭教师自助注册，并在「设置 → 备份与恢复」定期下载备份包。

### 二、五步跑通日常教学闭环

1. **初始化教师账号**：首次打开服务会自动进入设置向导（`/t/setup`），创建管理员教师账号与密码。想先看完整学情效果，可在服务启动建库后运行 `pnpm seed:demo`（按终端打印的随机初始密码登录 `demo` 教师账号，或加 `--teacher <你的登录名>` 播入指定教师域），也可直接导入 `samples/v2/` 下的样例文档。
2. **编写并导入讲义/练习**：
   - 把 [`dsl-kit/`](dsl-kit/) 文件夹发给你的 AI 工具，让它把现有讲义/试卷整理成符合规范的 `.md`，或点击教师端「导入 → AI 出题助手」复制完整提示词。
   - 在教师端「资源库 → 导入」选择 `.md` 文件、文件夹或直接粘贴文本；如有语法问题，点击「复制错误给 AI」让模型修正后确认导入。
3. **组建课程、添加学生与布置作业**：
   - 在「课程」中新建课程，从资源库添加讲义与练习单元并排好章节顺序；
   - 在「学生」中添加学生名单，一键复制学生的**专属登录链接**（或初始密码）发给学生；
   - 需要布置课后任务时，在「作业」向导中勾选目标学生、练习单元、组合方式与截止时间。
4. **学生线上学习、答题与订正**：
   - 学生用 iPad 或电脑打开专属链接，阅读讲义、完成作业或课程练习；
   - 答题过程中可点开题干圈画、展开草稿纸演算、手写解题过程；
   - 交卷后查看得分与详解，针对错题在结果页直接添加订正并写下「卡点与错因反思」，在「错题本」中按考点或单元一键重练直至攻克。
5. **教师批阅、学情复盘与 AI 备课**：
   - 在「数据 → 待批队列」用键盘快捷键快速批改填空与手写题，点开作答详情回放学生手写过程、查阅草稿原稿与订正记录；
   - 在「学情」查看掌握度矩阵、薄弱考点与讲义阅读情况；
   - 在「导出」生成 AI 学情数据包（或通过「连接 AI」配置 MCP 客户端），让 AI 分析薄弱点、评析手写过程并生成下一节课的针对性变式练习。

## 下一步迭代方向（Roadmap）

当前系统已完成「内容引擎 → 全题型与手写/草稿/圈画作答 → 批改与订正闭环 → 学情分析与 AI 数据包/MCP 接入 → 组件能力化与教学包」的主干建设。接下来计划沿着以下几个方向持续迭代：

1. **讲练一体模式（`kind: lesson`）与逐题即时反馈**
   - 面向课堂「讲一段、练一题」的实时带教场景：在讲义正文中原位嵌入练习题，学生每做完一题可**单题独立提交、当场展开对错判定与详解**，无需等到整卷交卷后才获得反馈；同时完整复用现有的草稿冻结、订正、错题本与待批队列机制。
2. **强过程训练与更多互动组件扩展**
   - **步进门禁与可探索讲义**：为 `:::steps` 分步指令增加可选的门禁校验（完成前序填空或互动后才解锁下一步推导）；为 `::graph` 函数图像增加可拖动参数滑块（`sliders`），让学生在讲义中直观探索参数变化对图像的影响。
   - **新展示指令与新互动题型**：基于已就绪的「注册表 → 组件 → 样例 → `gen:spec`」扩展管线，按需补充页签（`:::tabs`）、音频/视频（`::audio` / `::video`）、时间线（`:::timeline`）、抽认卡（`:::cards`）等展示组件，以及推导步骤排序（Parsons Problems）、拖词填空、连线配对、分类归类、图片热区选择等新互动题型。
3. **iPad 真机深度打磨与进阶手写体验**
   - 完成长篇演算草稿、静态合成图片导出（一图流）、固定底图题干圈画在 iPad + Apple Pencil 真机多场景下的手感定标与专项验收；根据真实教学反馈按需探索多页专注书写模式与低延迟笔迹预测渲染。
4. **内置 BYO-Key AI 助手（可选扩展）**
   - 在现有「不绑定特定模型、通过数据包与 MCP 开放接入」的基础上，提供可选的教师端自有 API Key 配置（支持 OpenAI 兼容接口与 Anthropic）：支持在工作台内一键流式生成学情报告、选择薄弱考点自动生成并自校验（自动 lint 修正）变式练习、以及利用多模态视觉模型对学生手写题提供 AI 预批改建议（仅作辅助参考，须经教师确认才写入判定）。
5. **可组合学习活动与智能复习计划**
   - 将「分步解方程」「错因归因辨析」等教学方法进一步沉淀为受约束、可观测的学习活动配置；结合学生历次作答与订正证据，在学生端演进出智能排序的「今日复习计划（Today）」与教师端的「课前简报」。

## 架构与仓库结构

```
┌──────────────────── 一个 Node 进程（apps/server） ────────────────────┐
│  静态资源：apps/web 构建产物（SPA + PWA + KaTeX 字体）                  │
│  /api/teacher/*（教师会话）       /api/student/*（学生会话/专属链接）     │
│  /mcp（教师 API Token，14 工具）  /api/public/spec/*（规范/Schema/能力） │
│  领域服务：内容与教学包 / 作答 / 草稿与圈画证据 / 学习痕迹 / 学情 / 导出  │
│  data/tutor.db（SQLite WAL）· data/blobs/（笔迹/草稿/圈画/媒体）· backups│
└───────────────────────────────────────────────────────────────────────┘
     ▲ 老师（电脑 / 平板浏览器）    ▲ 学生（iPad / 手机 / PC，PWA）    ▲ AI 客户端（MCP / dsl-kit）
```

所有契约来自 `packages/contract`，前端、后端、MCP 与导出文件共用一份 schema。

```
simple-tutor-tool/
  apps/
    web/        # React 前端（学生端 + 教师端 + 管理端，一个 SPA 按路由分区）
    server/     # Hono 后端（API + 静态资源 + MCP + SQLite）
  packages/
    contract/   # Zod 数据契约与指令/能力注册表（唯一事实来源）+ JSON Schema 导出
    md-dsl/     # DSL 解析器 + linter + 规范生成器 + CLI（tutor-lint）
    grading/    # 纯函数判分与服务端校验器注册表（服务端权威执行）
  docs/         # 架构、部署、DSL 规范、功能清单、精进方案、进度等文档
  dsl-kit/      # 一站式分发包：DSL 规范 + 完整样例 + 提示词模板 + 能力清单 + 材料整理技能 + 离线校验脚本
  samples/      # 样例 MD（v2 集合 + lint 反例），同时作为解析与渲染兼容性回归夹具
  e2e/          # Playwright E2E 测试套件
  启动服务.cmd   # Windows 本地生产模式一键启动脚本
  测试模式.cmd   # Windows 开发/演示模式一键启动脚本
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` / `pnpm build` | 开发（并行） / 全量构建 |
| `pnpm test` / `pnpm e2e` | 单元测试（Vitest） / E2E（Playwright，Chromium + WebKit） |
| `pnpm lint` / `pnpm typecheck` / `pnpm format` | Biome 检查 / 类型检查 / 格式化 |
| `pnpm db:generate` | 修改 Drizzle schema 后生成数据库迁移（禁止手改线上库） |
| `pnpm schema:export` | 导出内容契约与数据包 JSON Schema（改 contract 后须重跑并提交） |
| `pnpm gen:spec` | 从指令注册表生成 `docs/dsl/规范.md`、`提示词模板.md`、`capabilities.json` 并刷新 JSON Schema，同时同步 `dsl-kit/` 分发包并打包其离线校验脚本 `tutor-lint.mjs`（改注册表/lint/契约后必跑，CI 校验产物无漂移） |
| `pnpm tutor-lint <文件或目录>` | 校验 DSL 文档，有 error 时退出码 1 |
| `pnpm reparse [--dry-run]` | 解析器升级后从库内原文重抽取结构化字段（题目 id 不变） |
| `pnpm seed:demo` | 灌入演示数据 |

## 质量红线

- **防泄题**：学生端 API 永不返回未交卷题目的答案、详解、提示；新增学生端接口必须附泄露测试（`assertNoLeak`）。
- **判分只在服务端**执行（`packages/grading`），客户端结果不可信。
- **契约优先**：数据结构改动先改 `packages/contract`，禁止前后端各自手写同一类型。
- **DSL 兼容**：`samples/` 历史样例是兼容性回归测试，任何改动后必须仍能解析、渲染一致。
- CI（[.github/workflows/ci.yml](.github/workflows/ci.yml)）：lint / typecheck / 单测 / `gen:spec` 漂移校验 / build / E2E 全过才可合并。
