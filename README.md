# 线上答题系统（有理数辅导配套）

学生 iPad/电脑网页**看讲义、做题（支持手写）**，老师网页**直接查看做题情况与手写痕迹**。

## 快速开始

```bash
cd 线上答题系统
python server.py
```

按控制台打印的局域网地址访问：

- 学生端：`http://<电脑IP>:8787/`
- 教师端：`http://<电脑IP>:8787/teacher.html`

iPad 与电脑连同一个 WiFi，用 Safari/浏览器打开即可，无需安装任何东西。

## 使用流程

1. 教师端 → 内容管理 → 选择练习册 .md（按《有理数打磨/01_线上格式规范.md》书写）→ 导入为练习；讲义同理。
2. 学生打开学生端 → 输入姓名 → 练习 → 作答（判断/选择/填空自动判分；计算题手写）→ 交卷。
3. 教师端 → 提交记录 → 逐题查看答案与手写原图 → 批注正确/错误 → 导出 CSV。
