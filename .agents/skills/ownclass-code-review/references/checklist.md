# OwnClass 审查清单

## 简化

- 查仓库现有实现和调用方，合并确认的重复逻辑。核对新增抽象、配置和依赖是否有实际调用者。
- 检查热路径是否增加重复渲染、循环或查询，保留能说明收益的证据。

## 正确性

- 对照需求、入口、调用方和测试。检查边界输入、并发与失败路径。涉及保稿或账号切换时检查保存失败保护、冲突裁决和迟到回执隔离。
- 数据结构以 `packages/contract` 的 Zod 契约为准。核对前后端共用类型、生成产物、服务端判分和 drizzle-kit 迁移。
- DSL 指令保持向后兼容，新增属性有默认值，兼容样例保持解析与渲染行为。相关变更核对 `pnpm gen:spec` 产物。

## 安全

- **普通学生出口**按当前公布规则检查答案、详解和提示。逐题提交与整卷交卷分别核对，已交卷但未公布也须受保护。检查新增学生接口的防泄露测试及 `publicOfSnapshot`、`studentStemMd`、`assertNoLeak` 的边界。
- **AI 受控出口**按 [学生 AI 约定](../../../../docs/约定/学生AI伴学.md) 逐项检查。区分学生主动触发和允许的授权范围，核对创建、领取、读取与交付时的当前权限。整体复盘另查整卷已交卷、答案已公布、逐题授权和预览确认。允许场景核对实际外发内容，禁止场景核对无泄露。
- 核对鉴权、数据归属及撤权路径。AI 授权范围排除教师私注、其他学生数据、整讲义原文、内部账号 ID 和凭证。
