# v2.1.0：学习闭环——草稿原稿、订正与 AI 证据包

这是 simple-tutor-tool 的第二个正式版本。v2.0 把「讲、练、批」放进了一个工具；v2.1 补上闭环的后半段：**学生怎么写的（过程证据）、错了之后怎么改的（订正）、以及怎么把这些可信地交给 AI 复盘**。

## 这个版本交付了什么

### 题目草稿与交卷原稿（过程证据）

- 非手写题（选择 / 多选 / 判断 / 填空）题卡内置**草稿纸**：iPad 上用 Apple Pencil 演算，笔迹本机持久化 + 服务端增量同步（断网补传、并发冲突交给用户裁决）。
- **交卷即冻结原稿**：交卷时追平最终笔迹并固定版本引用——此后重练、改卷、清空都不改这一次的原稿；缺稿交卷必须学生明确确认。
- 学生结果页与教师详情页**同视角只读回看原稿**（标注轮次），缺图可一键重建分析图。

### 订正、补充稿与题目笔记本

- 结果页逐题「添加订正」：空白新开或**复制原稿起步**；「保存订正」即封存检查点，可附「我卡在哪里 / 我的错因」两栏反思（随封存冻结，再编辑自动新开一份）。
- 交卷后找回的本地草稿转存为**补充稿**——明确标注「不能证明交卷前已固定」，找回稿永不冒充原稿。
- 学生端**题目笔记本**按轮次对照同一道题：第一次原稿、看解析后的订正、找回的补充、第二次独立尝试，身份严格区分；教师端同样可读。
- 错题重练开新卷**零历史泄漏**：答题页不自动展示任何订正与历史答案（网络层测试锁定）。

### AI 学情数据包 v2 与 MCP

- 导出向导新增**手写证据（v2 数据包）**：按阶段收录原稿 / 已封存订正（含反思）/ 补充稿；**逐题评析**目标自动关联证据。
- **预览时刻固定选择（asOf）**：预览确认后，学生再交卷、再订正都不改变包内容——给 AI 的材料是「当时那一刻」的可复核快照。
- 包内引用一致（evidenceRefs → 证据条目 → zip 文件一一对应），缺失显式登记并给中文原因，不静默跳过；学生包剥除答案、解析与定位 id。
- MCP `get_student_learning_pack` 同参数同装配（v2 / 证据阶段 / 逐题评析），AI 客户端可直接拉取。

### 给 AI 的诚实口径（这个版本特别在意的）

- **辅助信息三态**：学生是否在交卷后回看过解析，区分「已知回看 / 已知未回看 / 未采集（未知）」——后两者都不能推断「完全独立完成」，提示词明文要求 AI 同口径表述。
- **订正正确 ≠ 独立掌握**：提示词要求原稿、订正、补充稿分别分析，不把正确订正当作掌握的证据。
- **缺证据就说不能确定**：缺图 / 无草稿的题，提示词要求表述为「证据不足，不能确定书写过程」，不编造过程。
- 长稿切片分页的**页间重叠**显式声明（重叠区笔迹属同一段内容，不重复计数）；分析图是可事后补传的渲染产物（非封存时刻快照）、讲义正文按生成时刻读取——都写进包内说明，不藏着。
- **AI 建议供人工核对，不进入服务端自动判分**：判分只在服务端；系统不内置模型、不自动外发任何学生数据。

## 已知限制

1. **合成图片导出未上线**：单题材料以 zip 交付（Markdown + PNG），暂无「题干 + 原稿」一图流。
2. **固定底图标画未上线**：暂不能在题干图上圈画标注。
3. **真实多模态客户端实测进行中**：8 类样本材料的 AI 实测由部署者本人执行与核对（材料与规程见仓库 `docs/审查报告/Phase6-AI材料验收.md`）。
4. **自动 GC 未接线**（有意保守）：草稿文件只增不减，回收由运维显式触发；备份引用与损坏快照的保留防线已内置。
5. **草稿不跨设备漫游**：跨设备以服务端稿为准（既定口径）。
6. v1 学情数据包的 `reviewedSolution` 字段语义放宽为可空（未采集时为 `null` 而非 `false`）；自定义解析脚本若断言布尔值需适配。

## 升级与回滚

按既有流程替换构建产物并重启即可（迁移随启动自动执行，幂等）。升级前建议在教师端「设置 → 备份与恢复」下载完整备份；应用内亦可从备份 zip 恢复（恢复前自动再拍一次快照）。细节见 [部署文档](../部署.md)。

## 工程质量

v2.1 全量 **3608 项单元测试（283 个测试文件）/ 86 项 E2E**（chromium + webkit 双内核，含「学生原稿 → 教师查看 → 双端冲突订正 → 同题重练 → 软删题 → 批量 v2 包 → MCP 实数据」全链用例）；学生端接口逐一挂泄露测试（未交卷不下发答案 / 详解 / 提示）；TypeScript strict、契约 Zod 单一来源、DSL 已发布指令只增不改。

---

**TL;DR for English visitors:** v2.1 closes the learning loop: every non-handwriting question now has a scratchpad whose ink is frozen into an immutable "original" at submission; students file corrections (with reflection) and recovered supplements that are clearly labeled as such; a per-question notebook shows every round side by side. The AI learning pack grew a v2 with staged handwriting evidence, preview-time snapshot pinning (asOf), and honesty notes — three-state "did they view the solution", corrections ≠ mastery, missing evidence must be stated as unknown. Batch export and MCP share one assembler. 3608 unit tests and 86 E2E cases, student-facing APIs leak-tested per endpoint.
