# 学情一年规模量测

在同一台 Windows 开发机上分别单跑 `pnpm exec vitest run --project node apps/server/src/services/analytics-growth.test.ts`。夹具有 60 名学生、24 门课程、52 周，每生每周两卷，每卷 20 题，共 6,240 卷、124,800 条作答。课程共用题库，用时样本因此跨课程。统计响应先预热一次，再取 12 次服务调用的 p95。计时包括 SQLite 与服务聚合，未包含 HTTP、渲染或网络。

| 入口 | SQL 次数 | 返回应用的行数 | p95 毫秒 |
| --- | ---: | ---: | ---: |
| 总览，全年 | 97 → 45 | 173,994 → 42,930 | 422 → 302 |
| 总览，单课程近 30 天 | 33 → 16 | 137,828 → 847 | 119 → 11 |
| 单个学生画像，全年 | 40 → 11 | 172,425 → 953 | 310 → 101 |
| 题目统计，单课程全年 | 24 → 8 | 138,885 → 1,525 | 120 → 106 |

四个响应的 SHA-256 与基线一致。执行计划显示教师归属使用学生索引、卷读取使用学生索引、作答使用卷与题的联合索引、条目使用课程与类型的联合索引。表中行数由 SQLite 返回值计量，执行计划用于确认访问路径，未量测物理扫描行数。总览课程条目从每课程一次改为批取，同一批待批计数供矩阵和总览复用。筛选后仍保留矩阵所需的历史卷，重点卡片复用已装载的作答，只补查额外日期范围。

全域中位数只在画像和题目统计计算，只读取当前请求所需题目，保留该教师在其他课程、统计窗外和重做卷中的已交样本。SQLite 按题号和秒数分桶，应用以桶计数取中间样本。实测后保留实时计算，提交和数据校正后的请求直接读取最新样本。该路径仍随实际全域已交样本增长，题目统计的延迟收益小于返回行数的降幅。
