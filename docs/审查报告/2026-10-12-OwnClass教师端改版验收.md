# OwnClass 教师端导航与配置改版验收

日期：2026-10-12。实施分支：`codex/teacher-navigation-settings-ui`；目标分支：`v2`。本次不发布 main。

## 最终行为

网站名称统一为 OwnClass，广告词为 **Your data. Your way. All for learning.**。首页、浏览器标题、PWA 名称及教师初始化、注册、登录入口同步品牌。技术仓库名与包名保持既有标识。

教师侧栏按教学、分析、系统分组，底部账号入口，管理入口仅管理员可见；原路由和导入高亮兼容。1024px 以下改为完整抽屉导航，支持 Escape、焦点返回，导航区独立滚动。

设置默认展示学生作答方式，备份和账号各自为 URL 分类。配置控制器持续挂载，切换、浏览器前进后退不丢未保存勾选。凭据管理集中到连接 AI 页，保留原重置确认；客户端切换只展示一份配置代码。最近快照默认三条，可展开全部。复制失败明确提示手动复制，加载失败支持重试。

## 质量闸门

本机未提供可调用的同名 simplify 与 code-review 技能，未宣称调用了它们。按顺序对完整 diff 执行人工简化审查，再执行正确性审查，最后运行真实命令和浏览器验收；未使用子代理。

### 简化与复用审查

- 桌面导航、抽屉和顶栏位置共用导航配置；资源库匹配逻辑保留，未增加新路由体系。
- 连接页复用原 ApiTokenSection，删除独立生成逻辑、Token 复制组件和第二份配置代码。服务端查询键、请求和凭据重置逻辑复用。
- Brand 与品牌常量复用于教师入口与 PWA；HTML 静态 title/description 保留必要的原生声明。
- 去掉无消费者的 Brand compact 变体；复制反馈关联当前内容，删除 Token 的两秒定时重置。
- 分类通过现有 React Router URL 状态表达，无新增状态库、依赖、契约或数据库迁移。

### 正确性审查及已修复发现

| 发现 | 处理与证据 |
| --- | --- |
| 凭据重置后沿用旧 Token 的“已复制”反馈 | 先补失败测试，再按复制内容关联反馈；ApiTokenSection 回归通过 |
| 部署地址加载失败持续显示加载状态 | 显示错误与重新获取入口；真实浏览器测试重试后恢复 |
| 抽屉减少动态效果的覆盖优先级不足 | 真实 Chromium/WebKit 复现，改为 motion-safe 启用动画；减少动态效果时 animationName 为 none |
| 配置重排可能卸载本地编辑状态 | 使用 hidden 隐藏持续挂载区；组件与真实浏览器切换、前进后退测试通过 |
| 最近快照过长 | 默认三条，明确展开数量、aria-expanded 与列表关联；空、加载、错误既有测试继续通过 |

凭据访问仍沿用教师认证与既有 API；学生载荷、答案投影、解析器、判分均未改动，未新增泄露面。配置码块仅在教师路由展示，重置确认取消不调用重置。本次没有修改学生数据或真实教师配置。

## 手动验证步骤

1. 打开首页，确认 OwnClass 和广告词；浏览器标签为 OwnClass。教师登录、注册、初始化页同步品牌。
2. 桌面查看三组导航；导入页资源库高亮、课程详情课程高亮；普通教师看不到系统管理。
3. 窄屏打开导航，Tab 访问入口，Escape 关闭并回到触发按钮；选择入口后关闭抽屉。短高度侧栏可滚动到系统入口。
4. 设置页修改一个开关但不保存，切换备份再返回；修改仍保留。浏览器前进后退也保留所选分类；未知 section 回落学生作答方式。
5. 备份区查看最近三条、展开全部并收起；恢复仍走既有密码确认流程。实际恢复请只在隔离测试环境操作。
6. 连接页切换通用客户端/Claude Desktop，始终只有一份 JSON；复制地址与配置有反馈，失败可手动选择复制。
7. 在隔离环境验证凭据重置弹层，取消不改变 Token；确认重置后配置使用新 Token，复制反馈不沿用旧凭据状态。
