## Frame API 与下一单接法

```tsx
<QuestionAnnotationFrame
  question={publicQuestion}
  layout={source.layout}
  scopeKey={scopeKey}
  onGeometryChange={setGeometry}
  inkLayer={inkLayer}
>
  <QuestionSurface question={publicQuestion} answer={ownAnswer} readOnly />
</QuestionAnnotationFrame>
```

1. `question` 必须是原冻结公开题目；先用 resolver 核验当前 questionRevisionId、正文坐标和只读事实。教师完整快照必须先取公开投影。不得用 ResultOptions/DetailOptions 等另一套 DOM 假装同模板恢复；参考答案与对照区仍放在框外，按原授权显示。
2. `scopeKey` 用部署、学生、attempt、题目、questionRevisionId、phase、resetVersion 组合。禁止包含每笔 docVersion 或完整 record/source 对象；也不加入首次上传时从未绑定到已绑定的 baseId。几何身份还包含公开内容和原 layout。`questionFrameIdentity` 可供调用者将回调结果与当前身份对应。
3. `onGeometryChange` 返回 `{status, identity, reason, preserveInk}`。首次只有 ready 才可显示同框墨层；checking/blocked 不能开笔。`preserveInk=true` 表示当前相同基准已有成功工作区，后续异步测量期间保留它；超限提示仍须显示、停止写入。不能把上一作用域的 ready 用给新题。
4. ref 暴露 `getSurface()` 和 `verify(layout, signal?)`。verify 等待资源稳定并 await questionSurfaceMatchesLayout；创建时会等待 React 提交对应逻辑框。它不授予写权，不代替持久化、封存或当前 session 复核。显式续画接 `prepareQuestionAnnotationContinuation`，被动只读不补写证据。
5. `onBeforeResize` 先结束在途笔。Frame 只观察真实尺寸变化与稳定几何身份，不按每笔正文重新测量。首次同 PNG/layout 的云端绑定回执不卸载画布；真正换源与 reset 仍受保护。
6. QuestionSurface 既有 readOnly 使用同一 Input DOM、禁用回调与原生控件；ordering 只读也保留操作区的禁用占位。mode="export" 始终剔除本人答案，即使调用方误传 answer；公开底图不因排除操作区几何而烧入本人 sequence。
