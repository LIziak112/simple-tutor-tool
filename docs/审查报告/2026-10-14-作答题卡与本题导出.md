# 作答题卡与本题导出实施与审查

## 范围与结果

分支 `codex/ongoing-question-export` 从 `v2` 的 `57de606` 建立。用户授权完成后只合并 `v2`，本轮不发布 `main`。

题卡元信息共用题头，更多菜单统一 Lucide 图标、分组、动作式文案。作答态新增「导出本题」语义，固定公开题面和当前笔迹快照，合成已有标画与草稿或正式手写作答；收起和隐藏不排除材料。长稿分页，每页重复题面。图片预览、逐页复制和全部下载共用固定 PNG。

无标画时直接生成公开题面，不建立新的标画底图绑定。已绑定底图保持原坐标域。草稿严格读取本机记录，有待传稿时保留本机版本，无待传稿时检查服务端版本；读取失败、保存失败或草稿冲突显式阻止导出。正式手写优先本机稿，落盘失败拒绝导出。

AI 复习包继续使用结果页既有服务端授权载荷与封存证据。本轮没有增加 API、依赖、契约字段、数据库迁移或 DSL 指令。

## TDD 与质量闸门

先执行失败测试复现资料行文案/位置、严格本机读取、纯题面不绑定底图、多页预览和预览失败后的下载禁用，再修改实现。

项目要求的 systematic-debugging、simplify、code-review、security-review、verification-before-completion 技能文件未在当前可用技能目录和项目技能目录中找到。本轮按其对应纪律执行根因定位、完整 diff 简化、正确性检查、安全边界检查和真实命令验证，未声称调用不存在的技能。

| 闸门 | 发现与处置 |
| --- | --- |
| 简化 | 复用题面底图、render-note、render-ink-snapshot、canvasToPngBlob、剪贴板与菜单组件；移除题头冗余 Fragment；文件名复用既有消毒逻辑并增加可选材料名称，保留原默认行为 |
| 正确性 | 严格本机读取不能吞错；补正式笔迹落盘失败检查；无标画导出不能创建底图绑定；多页复制明确当前页；预览解码失败禁用下载/复制；所有图片 URL 在关闭和卸载时释放 |
| 安全 | 只使用 AttemptQuestionPublic 和公开题面底图；不克隆整卡或提示；不复用结果页权限接口；生成过程检查标画/草稿会话与正式稿代际，迟到产物在弹窗关闭后不发布 |

## 手动验证

1. 学生打开作业/练习，更多 → 显示题目资料；宽屏难度/考点和题号同排，窄屏自然换行。
2. 检查每个菜单项都有图标；标画可见时为「隐藏标画」，隐藏后为「显示标画」；待检查标记可以添加、取消。
3. 分别验证无笔迹、只有标画、只有草稿、标画与草稿、正式手写；「导出本题」中题面始终存在。
4. 收起草稿、隐藏标画后导出，已有笔迹仍在；复制粘贴到 AI 的图片与下载图片一致。
5. 长稿查看全部页、逐页复制与全部下载，每页均含题面；遇到读取/保存/字体错误时明确提示并可重试。
6. 交卷后从结果页使用原有 AI 复习包，确认文字、ZIP、附件及合成图入口保持原语义。
