## 完整 diff 自审

依次进行了简化、正确性和公开数据边界检查；由单代理完成，未宣称运行未安装的工作流技能或独立验收。

- 简化：仅一个纯函数归一入口，复用既有数组模型和关联同步，无新依赖、字段、迁移或配置。
- 正确性：正则校验与 trim/去空语义一致；重复考点不重复入库或计数；无效值由既有 error 闸门阻断保存，保留原文和旧数据。
- 公开数据：未扩大任何学生接口的字段集合；答案、解析、提示与含题块讲义原文仍走原公开投影。相关既有回归包含在全量单测中。
- 无待修审查项。Pencil、系统缩放和生产业务数据未在本轮验收范围内。

## 手动验证

1. 教师导入或编辑一道题，填写 `knowledge=" 数轴 | 有理数加法 || 数轴 | "`，预览应显示两个独立标签；保存后详情应只包含两个考点。
2. 导出练习后重新导入，两考点仍存在；改成另两个考点，旧关联应消失；删除 knowledge 后应清空关联。
3. 将值改为 `" | | "`，预览或保存应给出 INVALID_QUESTION_ATTRS，已有题目与关联不被覆盖。
4. 学生作答并形成错题后，两个考点各计一次，任一考点均可筛到；归组不承诺按 Markdown 首项。
5. 用分发包 `node tutor-lint.mjs 文件.md` 校验上述合法/非法文档，退出码分别为 0/1。
