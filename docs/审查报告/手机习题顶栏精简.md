# 手机习题顶栏精简（2026-10-15）

## 范围与计划

用户确认：手机作答页顶栏只保留返回、单元名称、更多入口；保存状态与课程信息收进练习信息。新建 `codex/mobile-attempt-header`，基于远端 `v2`，隔离本机尚未发布的 AI 伴学开发；验收后推送 `v2` 并更新云服务器。

- `AttemptHeader.tsx`：小于 640px 隐藏顶栏元信息与保存状态，信息窗补上实时保存状态及原有操作；桌面布局不变。
- `AttemptSession.tsx`：从信息窗内保存详情定位题目时关闭外层弹窗。
- `AttemptHeader.test.tsx`、`student-workspace.spec.ts`：覆盖信息完整性、窄屏高度、保存详情定位、焦点、宽屏回归。
- `AGENTS.md`：同步交互约定。

## 根因与 TDD

原顶栏在手机端显式分三行放置标题、保存状态、课程信息；信息窗只展示课程信息，缺少保存状态。新增测试先失败：单测提示信息窗没有「全部已保存」；Chromium 和 WebKit 均在 320px 检测到顶栏保存状态仍然可见。修改后通过。

## 质量闸门

环境未提供 `/simplify`、`/code-review` 的可调用技能，依次按同名闸门目的检查本分支完整 diff：

1. 简化检查：沿用现有信息窗、状态与保存详情组件；使用一个关闭回调连接定位行为，无新增依赖、并行类型或保存实现。
2. 正确性检查：发现外层弹窗关闭后可能自动把焦点拉回顶栏，已用与保存详情一致的 `onCloseAutoFocus` 处理，并增加真实浏览器焦点断言；保留桌面来源行原有跨列范围。
3. 本次只改既有公开信息的展示位置，不改学生 API、载荷、答案投影、解析、判分或数据库；无需额外安全审查。既有工作区 E2E 防泄露监视仍执行。
