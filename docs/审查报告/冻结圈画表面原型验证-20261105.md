# 冻结圈画表面原型验证（2026-11-05）

## 范围与隔离

本实验位于独立分支 `codex/annotation-surface-validation`，基于 `af03a97e7b23994690d6bb4d040a579326882220`。原型只在开发路由 `/dev/question-base?frozenExperiment=1` 挂载；默认 `/dev/question-base` 保留旧夹具。实验代码在 `apps/web/src/pages/dev/test-support/`，内存快照 `version: 0` 仅通过开发页 textarea 手工搬运，不进入正式 API、契约、IDB 或服务器。E2E 使用合成的公开题目和材料夹具，接入真实 `QuestionSurface`、`renderQuestionBaseImage`、字体嵌入与 `annotation-surface` 笔迹引擎。没有调用服务端 `publicOfSnapshot` 或真实学生账号数据。

验证意图：如果同一原稿在另一浏览器恢复后图片/笔迹坐标变化、槽位必须重新探测目标 DOM 才能绑定、排序项目移动时仍把它当冻结图的一部分、材料需要超出 4096 的 canvas，方案即失败。正式生产改造没有在本轮实施。

## 结果

| 项目 | 状态 | 证据与边界 |
| --- | --- | --- |
| 公式与双填空题卡 | **通过原型验证** | 原题公开结构由真实 `QuestionSurface` 排版，冻结时同次捕获槽位框、生成 PNG，并核对前后槽位/布局证据。Edge Chromium → desktop WebKit → Edge、desktop WebKit → Edge → WebKit 双向恢复中，原 PNG、原 points 逐值保持；现有笔迹引擎完成续画、整笔橡皮和撤销。画布像素采样证实恢复及同 PNG 再导入后的笔迹变化。目标端强制修改字体和 KaTeX 字号，未重新测量旧控件位置。 |
| 答案控件 | **通过原型基础交互** | 填空控件每空一个，输入实际更新唯一 `StudentAnswer` 状态，Tab 焦点顺序及只读阻断通过。坏槽位清单只显示原稿和原笔迹，关闭控件及圈画输入。长公式选项测得真实换行高度，选项 B 更新单一答案状态，改字体后底图与槽位清单不变。真实中文 IME 和屏幕阅读器未测。 |
| 触控尺寸 | **缩小模式未通过** | 720 CSS px 原稿缩至 340 显示宽时，输入框实际高 **20.78 px**；开发页显式 1:1 放大后为 **44 px**，并可横向浏览。生产必须设计可到达的放大/输入方式，不能把捕获时 44 px 当作屏幕触控 44 px。 |
| 动态排序 | **边界验证通过** | 冻结的仅是公开静态题干；真实 `QuestionSurface` 排序板另行作答，移动项目改变答案，原 PNG 不变。笔迹跟随移动项目未实现，也未声称可自动推断跨节点箭头语义。 |
| 长材料七选五 | **局部分片通过，整体编辑未通过** | 合成五槽公开材料在一次稳定布局中按连续偏移裁成 4 片，真实 PNG 及每片真实笔迹 canvas 最大边长 3200，片缝两侧局部笔迹和邻近槽位可定位，同 PNG 导入新 doc 能刷新画布；几何损坏拒绝读取，材料身份不符仅可读原稿和笔迹。每片目前独立 `AnnotationDoc`，跨片一笔、统一橡皮/撤销、可视区按需挂载、长文内存上限和材料服务器同步均未实现。因此不能判定长材料圈画已完成。 |

长材料桌面浏览器实测：同一材料 CSS 高 **5018**、宽 **720**；4 片共 **14,451,840** 像素。Chromium PNG 总字节 **4,975,376**、生成 **628–681 ms**；WebKit PNG 总字节 **2,284,384**、生成 **1225 ms**。两浏览器观测到的背景生成及 ink canvas 最大边长均为 **3200**。若把全部片的图片解码与 ink 各估为一份 RGBA，约 **116 MB**，这只是像素量推算，**不是实测堆内存**。当前所有片同时挂载，开发 textarea 还会每笔 JSON 化全部 base64，性能数字不能外推到生产。

## 已有保护与原型简化

- 目标端只按冻结题目 ID、修订版、公开内容签名及稳定槽位键核对；不从目标 DOM 猜旧坐标。fill 的序号只在冻结修订版内有效，matching 用 `slotId` / `optionId`，React `useId` 不持久化。源布局缩放只测试未缩放捕获，任意源缩放尚无证据。
- 图片像素尺寸、笔迹文档尺寸和材料片连续偏移在导入时核验。未知控件、槽位缺失或身份不符不得编辑；旧协议 PNG + 矢量、无 PNG 的旧材料及账号切换路径未在本原型验证。
- 材料槽位在合成夹具里暂按 `strong` 的“（N）”文本定位；普通正文可出现相同文本，生产必须由材料渲染器提供稳定语义槽位。材料当前绑定单题身份，真实共享材料多题未验证。长公式/表格局部滚动的表面边界也未验证。
- 控件样式和可访问性仅验证了数量、名称、输入状态、焦点和只读的基本行为；未完成完整键盘、IME、触屏缩放和屏幕阅读器验收。答案、解析、教师私注未进入合成夹具，但服务端公开投影、防泄露测试仍需生产实现阶段验证。
- 未接入正式本机可靠落盘、CAS/mutationId、离线冲突、账号/阶段隔离、封存、旧客户端协议升级或材料云同步。原型通过只支持进入分阶段生产设计，不代表跨设备问题已修复。
