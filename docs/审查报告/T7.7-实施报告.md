## 二、实现要点

- **契约**（单一来源）：`capabilitySwitchSchema`（steps|ink——choice/fill 正式作答、none 无输入不设开关）、`capabilityProfileSchema`（strictObject，空数组=显式全关合法、重复拒绝）、`ALL_ENABLED_CAPABILITIES`、`EnabledCapabilityFlags`+`toEnabledCapabilities`（数组→布尔归一，md-dsl 与 web 共用）；attempt 详情草稿/结果两分支与 studentLectureDetail 增必填 `enabledCapabilities`。
- **存储与读取**：teachers 表单列 JSON（迁移 0028，NULL=未配置=全启用，存量行无需回填）；读侧 NULL/空串/坏 JSON/不合 schema 一律兜底全启用（兜底到「多给辅助」一侧，不触判分/答案路径）。
- **设置 API**：GET/PUT `/api/teacher/settings/capability-profile`（requireTeacher；PUT 过契约：未知开关名/重复/拼错键 400）；两教师互不影响。
- **学生端下发**：attempt 详情（attempt→student→teacher 域，无域异常行兜底全启用）与讲义详情（课程教师域）读时计算——生效方式=学生刷新页面（无推送、无冻结）。
- **lint**：`CAPABILITY_DISABLED`（warning）——steps 关→逐容器提示完整展开；ink 关→逐手写题提示隐藏入口（题号与 lintQuestions 同口径；手写题型集合从 questionCapabilityBindings 按 inputType=ink 派生）；无上下文（CLI/缺省）经归一为全启用自然零 issue；导入 preview/commit/批量/MCP 均传教师有效集（zip 批量整批查一次）。
- **前端**：`EnabledCapabilitiesContext`（无 Provider=全启用：教师预览/旧载荷/既有测试零改动；裸 Context 不导出）；steps 关=完整展开+无揭晓按钮（不伪造 reveal）；ink 关=HandwrittenControls 单一早退分支（无书写入口、已有笔迹 PNG 只读、最终答案照常）+题卡草稿纸入口隐藏；AttemptSession 顶层与讲义阅读页包 Provider。
- **边界保持**：开关不清答案/笔迹/草稿、不改提交规则、不参与判分；启用集不是安全边界（studentStemMd 投影与 assertNoLeak 独立保证）。

## 六、范围决策（记录）

1. 取卷端点（GET /assignments/:id/paper、GET /attempts/:id/paper）未加字段：无 web 页面消费方（作答页统一走 GET /attempts/:id 详情），加字段无 UI 受益。
2. AnnotationLayer（题干标注）与 CorrectionSection（订正）不受 ink 开关控制：清单枚举的手写辅助入口为 HandwrittenControls 与 NoteLayer；标注/订正属学习痕迹与订正流程，不在「作答辅助方式」语义内。
3. E2E 用专属乙教师承载开关翻转：开关是教师级全局状态，共享甲域会污染并发 spec（曾致 b-batch 草稿纸入口被关闭超时）。
