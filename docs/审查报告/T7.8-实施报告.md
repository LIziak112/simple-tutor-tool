## 二、实现要点

**契约**（8b97096）：`packages/contract/src/teaching-pack.ts` 新增 `teachingPackSchema`——`z.strictObject`，`formatVersion` literal 1 缺省 1、`name` 非空必填、`version` 非空缺省 `"1"`、`directives`/`validators` 非空字符串数组缺省 `[]`。strictObject 拒绝未知键（拼错字段 fail fast）。`frontmatterSchema` 增可选 `teachingPack`（z.object 未知顶层键仍剥离，沿既有口径）。无声明即普通 MD，解析输出零变化。

**lint 引用校验**（3259648）：`packages/md-dsl/src/lint/teaching-pack.ts`——`VALIDATOR_IDS` 模块级从题型能力表 `questionCapabilityBindings` 派生（不把 grading 引入 md-dsl）；无声明短路零开销；有声明时逐 ref 校验：directives 经 `getDirective` 归一（别名合法），validators 对题型能力表 validatorId 集合。缺失报 error：`DIRECTIVE_REF_NOT_FOUND` / `VALIDATOR_REF_NOT_FOUND`（rules.ts 登记），行锚 frontmatter 次行，文案含中文修法。经 `runRules` 末尾单点接线——preview / commit / 批量 / ZIP / MCP 同一分析入口，commit 重新分析，直接提交不可绕过。普通正文未知指令仍 warning + 降级，不受影响。

**存储**（46c6aa3、ef57c56）：units / lectures 各加可空 `teaching_pack_json` text 列（drizzle-kit 迁移 `0029_daily_blazing_skull.sql`，两条 ALTER 无回填；NULL=未声明）。`commitImport` 事务内单点计算 `teachingPackJson`，讲义/单元 × insert/update 四写入点统一携带：一次导入拆出的资源共享同一声明；重新导入按新声明覆盖；普通 MD 重导清空为 NULL；正文编辑（updateLecture / updateQuestion / reparse）不触碰该列。

**export.md 回写**（fae8a34）：`teachingPackYamlLineOf(column)`——NULL 无声明行；JSON.parse 失败或契约 safeParse 失败 `console.warn` 留痕后返回 null（外力破坏的存量不无声丢声明，也不炸导出）。值全部经 `JSON.stringify` 拼进固定键序的 flow 映射单行——引号/反斜杠/控制符全转义，产物恒为合法 YAML，可原样解析回读；不引入 yaml 序列化依赖（server 无该包，硬性规则 5）。

**ZIP 导出**（d0a3a9c）：`teaching-pack-service.ts` `exportTeachingPackZip` 六步——①exportUnitMd / exportLectureMd（域 404 在此，含在包语义内）→ ②lintDocument 重跑，error 级 422 `LINT_ERROR` 不生成包（含全删题单元 422 PRACTICE_NO_QUESTIONS，见范围决策）→ ③`readSpecFile("capabilities.json")` 当前系统清单快照 → ④`extractMediaImageSrcs` + `statMediaSrc`（resolveWithinRootOrNull 强边界）收集本地图片 → ⑤`zipBufferOf`：content.md + capabilities-snapshot.json + 图片按原 src 路径（`archive.file(absPath, {name: src, store: true})`，内容寻址幂等 src 不变）→ ⑥文件名 `.md`→`.zip`。路由 `GET /api/teacher/units|lectures/:id/export-pack.zip`（requireTeacher 组内，闭包工厂 `exportPackZipHandler(kind)`），specDir 从 app→teacher→library→service 四层透传（DI 同 dataDir 惯例）。`attachmentDisposition` RFC 5987 双段输出（ASCII 兜底段剥 CR/LF/引号 + `filename*=UTF-8''` 全百分号编码）——undici Response 头拒绝非 ASCII 字节，中文包名曾实测 500，此为根因修复；`noStoreBinaryResponse` 单选项 `attachmentFilename` 恒经它，markdownResponse 手写编码收敛到同一助手。

**web 入口**（d97eab8）：资源库讲义/单元列表行 Package 图标按钮（aria-label `导出教学包 ${title}`）+ 单元详情面板「导出教学包」按钮（导出中禁用、失败明细进面板错误区）+ 页头说明补一句。`downloadTeachingPack` / `downloadExportMd` 收敛至既有 `throwShellError` + `filenameFromDisposition`（升级为优先解码 `filename*`，坏 % 序列 try/catch 回退 `filename=` 段）+ `saveBlobAs`。

**E2E**（faab6ea）：`e2e/teaching-pack.spec.ts`——教师 API 造数（minimalPng 上传 → 含声明与图片的练习文档 commit）→ 学生 iPad 正式作答（判断题作答 + 图片可见 + 手写一划 + 最终答案交卷）→ 判分结果断言 + 泄露监控零违规 → 教师 export-pack.zip 解包三条目字典序断言（图片按原 src / capabilities-snapshot.json / content.md，声明与图 src 在场，快照含 `"formatVersion": 1`）→ content.md 再导入 → export.md 复核含 teachingPack。用共享甲教师（不翻教师级全局状态，T7.7 教训仍有效——教师级状态用例才需乙教师）。

## 六、范围决策（记录）

1. **全删题单元导出包 422（PRACTICE_NO_QUESTIONS）**：教师把练习题全部删除后导出，包内 content.md 无题目，重导入会被既有守卫拒绝。「导出前检查」的存在意义即拒绝不可再导入的包，故沿守卫 422 并在 `_issues` 附 lint 原文，不做放行特例。
2. **无声明资源也可导出包**：teachingPack 是可选命名空间，普通单元/讲义导出的 ZIP 就是不含声明行的 content.md + 快照 + 随行图片——「材料包」即教学包的退化形态，不强制先补声明。
3. **capabilities-snapshot.json 恒为导出时当前系统清单**：不是包声明能力的镜像——声明往返由 content.md frontmatter 承载；快照仅供归档与 AI 阅读（capabilitiesManifestSchema 可解析），重导入进 ignoredFiles 零处理、不注册能力、不覆盖运行配置（`getCapabilityProfile` 保持缺省全启用有测试锁定）。
