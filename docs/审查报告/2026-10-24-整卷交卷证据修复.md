# 整卷交卷证据修复审查与验证

日期：2026-10-24。目标分支：`codex/practice-experience-fixes`。

## 问题与修复

逐题提交后交卷，前端仍为全部题生成 evidence；服务端只接收尚未提交题的证据，因此严格集合校验返回 `NOTE_EVIDENCE_MISMATCH`。旧混合提交路由测试没有传 evidence，遗漏了真实前端请求的形态。

前端改用单题回执合并后的进度派生证据范围，确认弹层快览和实际声明共用范围；题目版本仍回传全卷。交卷提交所有剩余题（含空题），已提交题的答案、教师判定、提交时间及原稿证据保留。统一反馈列表原先仍展示无效的逐题提交按钮，本次按服务端 `canSubmitQuestion` 隐藏；学生在教师允许范围内继续自选反馈模式。

## TDD

- 新增列表和单题模式的本页逐题提交→交卷测试。修复前两项失败：预期 evidence 只含 q2/q3，实际多出 q1；修复后通过。三题中一题已提交与原现场十六题中四题已提交使用同一集合规则。
- 新增统一反馈模式不提供题级提交的测试。修复前列表用例失败、单题通过；修复后两种布局均通过。
- 路由混合提交测试改为真实 evidence 请求，另断言多项、缺项、重复、未知题仍拒绝；原先封存的证据行完整保留，剩余空题同样写提交时间。

## 质量闸门

当前环境未提供 `/simplify`、`/code-review`、`/security-review` 对应技能文件；按同样顺序完成以下人工审查。

1. 简化：不新建契约或协议，不复制服务端规则，复用现有协议判别和回执进度；用 Set 与 useMemo 派生集合，避免每次渲染逐题嵌套查找。确认弹层与实际提交共用同一证据范围。
2. 正确性：版本全集、材料恢复与全卷落盘保持原范围；只缩小本次证据范围。保留单题提交回执 overlay，防止本页刚提交的题再进入整卷 evidence。统一反馈隐藏入口时，已提交题的只读反馈仍保留。
3. 安全：未修改普通学生响应、答案投影、教师授权、判分或证据校验。未知/重复/多余/缺少的声明仍拒绝；已提交题证据不可覆盖。路由防泄露断言与双浏览器泄露监控继续覆盖。

未发现需要保留的未修复问题。无新依赖、契约或数据库迁移。

## 手动验证

1. 新开课程练习，自选「每题提交后查看」，分别使用列表与单题专注。
2. 提交首题，保留其他题为空，点击交卷并确认：进入整卷结果，首题结果保留，其余题一并提交。
3. 新开练习选择「交卷后查看」：不出现「提交本题」与「不会，提交并看解析」，可直接交卷。
4. 教师限制与作答中切换反馈后，同样不显示无效的逐题提交入口。

验证只操作临时隔离数据库及 8899/5199 端口，未提交或修改用户当前作答。
