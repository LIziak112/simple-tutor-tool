## 边界与发布条件

- 本批闭环是单张题卡。材料圈画仍是本机 `materialInks/materialInkBases`、1000 归一坐标，没有服务端 reader/writer。实验中的四片长材料仅验证同域裁片与局部恢复，未解决跨片一笔、统一擦除/撤销、按需挂载和内存总量；生产继续遵守单张底图像素边长 4096 上限，超限拒绝。
- 新客户端对**读到的**未知 API/IDB 布局、正文及待传记录 fail closed，零生成、零写回；v3 服务端拒旧 PUT。已部署旧 JS 与新 JS 共用 IDB 键、已运行标签页持旧内存快照时仍有并发覆盖风险。本批未引入双库或多版本运行时；生产启用须配合现有 PWA 安全更新流程更新/关闭旧页，并另验多标签场景。
- 当前适配器只支持静态填空输入。其他题型的动态答案区在唯一作答视图使用原有控件；自由笔迹跨动态排序、七选五全文插回或材料分片不承诺自动跟随。未知槽位保留原稿可读，不能猜坐标绑定。
- 没有用真实 iPad/Pencil、原生系统缩放或真实用户数据完成本批验收；浏览器 WebKit 不是设备验收。
