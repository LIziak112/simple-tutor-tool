# 学生设置与 AI 连接结构验收

## 范围与依据

范围：学生设置 `/s/settings` 与连接 AI `/s/settings/ai` 的总览、新增、详情、修改、加载、空状态、读取失败、保存失败、重置确认和窄屏。未修改题目旁 AI 伴学、教师设置和后端数据协议。

遵循 AGENTS.md、CONTRIBUTING.md、学生端 AI 伴学需求规格；沿用 React、Tailwind 4、Radix/shadcn、Lucide 与现有学生蓝色语义主题。不新增依赖。

借鉴 [Open WebUI 连接管理](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/) 的列表与编辑分离、[Cherry Studio 模型服务设置](https://www.cherryai.com/docs/en/pre-basic/settings/providers/) 的详情与模型测试分组。只借鉴信息结构，不复制第三方资源或引入供应商专属字段。

## 存储与范围决定

连接沿用服务端账号配置；API Key 不回读，MCP Token 沿用加密保存与哈希认证。表单草稿只用现有学生角色内存缓存，后台重取不覆盖草稿，登出清理；没有新增 localStorage 凭据副本、契约或数据库字段。

使用量统计暂不加入：适配器可解析供应商部分 usage，但没有完整的持久个人统计接口，MCP 与上下文链接也不能得知可靠 Token 用量。本次不以入队数、连接数或估算金额冒充真实使用量。

手动验收：

1. 进入学生设置，查看账号、手写当前配置和连接 AI 入口；展开快捷按钮，修改后收起，确认未保存提示和重新展开后的输入保留。
2. 进入连接 AI，先看到摘要；新增时仅可选择未配置方式；进入查看不出现可编辑的 API Key 表单。
3. 查看 MCP，优先复制完整配置，也能直接查看和复制 Token；重置与删除先确认，取消不写入。
4. 修改连接，制造保存失败，确认输入保留；取消编辑时确认放弃，成功保存回到总览。由原题进入时可返回原题，不自动发起求助。
5. 以键盘完成视图切换，在 320px 与 200% 缩放下查看所有操作，确认无横向页面溢出。
