# 学生 AI 连接设置改版验收

日期：2026-10-17。实施分支：`codex/student-ai-settings-polish`，起点 `55b2da8b`。用户已确认实施计划，并指定最终推送 `v2`，不推进 `main`。

## 交付行为

- `/s/settings/ai` 使用宽屏双栏、窄屏单栏，集中显示默认连接、我的连接和新增/编辑配置；已有用户的数据说明默认收起。
- MCP 卡片直接显示完整 Token 与已代入 Token 的完整 JSON，不设显隐开关，不再单列一次性凭据区域；刷新、重新进入或换设备可再次读取。
- 历史连接若只有哈希则保持原认证，不自动重置；手动重置一次后持续可见。复用既有凭据加密函数，在既有 `configJson` 保存可选密文，无表结构迁移。
- 本人连接设置以 `no-store` 返回 Token。API Key 仍只写不读；他人连接、普通学生出口、任务上下文、分享与日志不返回连接凭据。未修改全局 `assertNoLeak` 禁键规则。
- 上下文链接不再显示“建设中”。切换默认连接保留原连接行与未保存草稿；编辑已有连接时不能切到其他通道。
- 假 AI 服务的捕获、FIFO 剧本及重置改为按用例凭据隔离，凭据包含测试身份、worker 与 retry；保留真实零出站断言。
- Biome 排除本机工具目录，避免嵌套工作树 root 配置阻断；修复本次相关文件格式。

## TDD 与根因证据

1. 契约与服务新断言先运行：2 failed / 28 passed。失败分别为契约拒绝 MCP Token 字段、连接重读缺少完整 Token；实现后对应断言通过。
2. 页面新增刷新重读断言先失败；移除一次性状态并复用连接查询和 `CopyBlock` 后通过。
3. 假供应商隔离测试在旧全局队列下：B 重置清空 A 剧本，A 收到默认回信而非独占回信；按凭据隔离后通过。测试使用真实 HTTP 请求，不只断言内部实现。
4. 编辑通道约束先失败：编辑状态的 MCP 单选仍可选；加入编辑期间禁用并验证取消后恢复选择。
5. 全仓联调暴露首条 `beforeEach` 冷加载超出 10 秒，迟到环境覆盖导致下一例默认连接数为 0。临时计时证实服务器冷加载约 7.9 秒、后续环境约 0.13–0.17 秒；移除诊断输出后，将冷加载独立放入 `beforeAll`（60 秒预算）。真实连接失败探针可耗时 10 秒，为该联调组保留 30 秒交互预算，并在结束时清理查询与数据库。

## 手动验证

1. 学生打开 `/s/settings/ai`，创建 MCP 连接，查看完整 Token 和 JSON；复制配置、刷新或重新进入，确认同一 Token 仍可用。
2. 旧连接如显示无可查看 Token，点击「重置 Token」一次并更新外部客户端；确认新 Token 可持续查看，旧客户端凭据失效。
3. 配置页内 AI 或上下文链接、切换默认连接；原连接应保留。编辑页内连接时通道不可切换，取消后可重新选择。
4. 缩窄至手机宽度，检查复制、重置、保存与删除确认均可访问；剪贴板不可用时可选中文字手动复制。
5. 使用另一个学生账号，确认不能读取或重置前一个账号的连接。
