# 固定逻辑题面跨设备实测（2026-11-05）

本轮只验证用户指定的旧版路线：真实题面保持源逻辑尺寸，选项、输入框和圈画使用同一显示比例。不切换到题面图片，不实施新的生产方案。

## 结论

在本机 Windows Edge 与 USB 连接的真实 iPad Safari 上，已验证固定题面可以同时保留标画、续画和直接作答。屏幕或题列变窄本身没有导致所测选择题、填空题重新换行。不能再以“屏幕变窄必然换行”为由否定整题缩放路线。

但本轮没有证明跨端每个文字像素完全相同，也没有证明所有生产旧稿、离线同步和封存链路已经兼容。现有排序交互和部分视口断点仍会改变框内内容，属于实测发现的独立问题。

## 真实 Pencil、触摸、输入法和旋转

第一轮由用户手动操作选择题：记录到 140 条可信事件，含 `pointerType=pen`、touch 和选项操作；留下 22 笔真实 Pencil 笔迹。恢复到电脑后，22 笔全部字段和点序列、选项答案逐值一致。两端墨层像素包围框只有最大 1 个底图像素差，不能称像素输出完全相同。用户反馈“没问题”。

第二轮由用户手动操作填空题：记录到 107 条事件，其中有真实 Pencil、`compositionstart/input/compositionend` 中文输入法事件和 34 条 resize 采样；屏幕宽度实际经历 1112 → 834 → 1112。用户填写两个空并留下 7 笔，操作中实际出现约 97.22%、52.78% 和 100% 三种显示比例。旋转采样中的已有笔迹均为最终稿的原样前缀，没有重新计算旧 points；输入框和题面未发生可测的块重排。用户反馈“没问题”。

该 7 笔稿和两个填空答案恢复到电脑后逐值一致；电脑通过真实鼠标续画一笔，再传回 iPad，8 笔逐点一致、答案一致。截图已目视核对，没有看到缩放或旋转造成的整体笔迹平移。此结论限于本轮样例和已执行操作，不扩展为所有题型的手感或手掌防误触验收。

## 实测发现的问题

### 1. 原有严格兼容门槛确实会拒绝这份可操作原稿

使用同一份真实填空稿，分别调用生产 `measureQuestionSurface`，再调用原有 `compatibleSurfaceEvidence`：返回 `false`。规范化后的字体元数据相同，两端均有 26 个文本行框，但块框和文本框最大差均为 2 CSS px，超过原有 0.75px 判据。

这是对“为什么旧版跨端可能退到其他显示路线”的直接证据。尚未把 2px 差异逐项区分为 WebKit/Chromium 的 Range 测量口径、字形或基线差异，因此不能简单放宽阈值，也不能把它直接当成发生了换行错位。本轮没有修改保护条件。

### 2. 视口媒体查询仍能改变固定框内部排版

电脑补测在逻辑宽始终 720 的情况下，将真实浏览器视口从 1440 缩至 500：

| 题型 | 内容高度变化 | 结果 |
| --- | --- | --- |
| 单选 | 274 → 约 274 | 不重排 |
| 填空 | 152.546875 → 约 152.546875 | 不重排 |
| 配对 | 402 → 450 | `sm:` 视口断点改变槽位行的排列 |
| 排序 | 556 → 约 688 | `sm:` 视口断点改变板/池条目内部排列 |

固定容器宽度不会自动禁用 CSS 的视口媒体查询。这属于可定位的样式适配问题；不能归因于整题 transform 失败。真实 iPad 本轮横竖屏宽度都未跨过 640，相关窄视口结果仅为电脑补测，不冒充 iPad 分屏实测。

### 3. 排序操作本身会移动内容，单靠整体缩放不能让自由笔迹跟随

当前真实排序组件完成加入和移动后，内容高度由 556 变成 378；iPad 单次加入也由 556 变成约 494。旧 points 虽然仍完全不变，但被标画的正文可能已经移到另一个位置。

因此，“固定逻辑框 + 等比缩放”可以解决显示比例变化，不能单独解决“被圈的对象主动移动”。本轮未改变排序交互，也未推断笔迹语义。普通选择、填空、配对和开放正文输入没有测到同类块几何变化；开放题字数提示文字变化不作为正文几何漂移。

### 4. 缩小后的触控目标也会一起缩小

44 CSS px 的控件按 380/720 显示时只约 23.22px。这不妨碍真实控件的坐标命中，但不能凭此宣称所有窄屏手指操作均舒适可达。实际手工验证通过不替代全尺寸触控验收。

### 5. 墨层放置必须与现有绘制引擎的坐标口径一致

实验初版把现有 canvas 直接放进 transform 后代，发现其内部 CSS 坐标与 Atrament 使用的 offsetWidth 换算会重复受比例影响。最终验证沿用旧版 Overlay 的兄弟墨层结构：题面 transform，墨层以相同显示宽高适配，逻辑坐标共用。无需切换题面，也不需要改存储点。

另一个实验工具错误是同题同高度导入未重新加载画布；补上显式加载代次后重新执行。首轮混用旧画布的结果不计为通过证据，最终汇总来自修正后的完整重跑。
