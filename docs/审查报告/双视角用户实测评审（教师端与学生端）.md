## 一、总体结论

**核心闭环已经成型且质量高于预期**：

```
导入（AI 提示词桥接）→ 课程目录组织 → 三步布置作业
  → 学生作答（手写板 / 数学键盘 / 离线保护 / 分步提示）
  → 自动 + 人工批改（键盘流队列）→ 学情总览（下节课重点 + 完成矩阵）
```

这套循环对一对一辅导场景**有真实的差异化竞争力**。「下节课重点」（自动聚合薄弱考点 + 代表错题）和键盘流批改队列（J/K 翻卡、1/2/0 判定、U 撤销）是很多商业平台都没有的干货功能。

但实测发现：

| 级别 | 数量 | 说明 |
|---|---|---|
| **P0** | 2 | 学生直接可见的正确性缺陷，均已定位到根因，可低成本修复 |
| **P1** | 3 | 口径 / 逻辑疑点，影响师生对数据的信任感 |
| **P2** | 6+ | 体验打磨项 |
| **缺失功能** | 4 项低成本 | 补上后「专业感」提升明显（错题重练、通知红点、题号导航、打印） |

## 三、P0 问题：学生直接可见的错误（建议立即修）

### P0-1 题目内容把原始 LaTeX 泄露给学生（红色代码显示）

**现象**：「练习六 乘法与倒数」第 8 题（2）小问，在**学生作答页、错题本、教师批改页**三处都显示了未渲染的 LaTeX 原文（红色）：

```
原式 = +\left(\frac{3}{4} \times 8 \times \frac{5}{6}\right) = +\left( ▢ \times \frac{5}{6}\right) = ▢
```

**根因（已查实）**：`data/tutor.db` 中 `p6-q8` 的 `source_md` 原文为：

```markdown
原式 $= +\left(\frac{3}{4} \times 8 \times \frac{5}{6}\right) = +\left($[[6]]$ \times \frac{5}{6}\right) = $[[5]]。
```

内容作者在填空标记两侧手工交替 `$`，把一个完整公式切成了两段数学片段；后段 `\right)` 无配对 `\left`，KaTeX 渲染失败回退为红色原文。这正是 lint 规则 `BLANK_MARKER_CONTAINS_DOLLAR`（105f47a 引入）要防的模式——**但该规则只拦新导入，存量内容没有回溯巡检**。

**波及面**：错题本中同题卡片、教师端「参考答案」同样显示裸 LaTeX（如 `− 5/4 或 -5/4` 的混排回退）。

**修复建议**：
1. 修正该题 `source_md`：把该小问拆成独立完整公式（如 `原式 $= +(\frac{3}{4} \times 8 \times \frac{5}{6}) = +(\,$ ▢ $\,\times \frac{5}{6}) =\,$ ▢），或把过程改为行内短横线，保证每个 `$...$` 片段自洽；
2. 对库内全部单元跑 `pnpm tutor-lint` 做存量巡检并修复所有 error；
3. 产品层：在单元信息抽屉与导入预览界面把 lint error 用红色角标顶出（目前需要主动跑命令才能发现），形成「内容带病上线」的拦截。

### P0-2 题型标签显示英文内部代码「find-error」

**现象**：学生端单元页（`/s/courses/:id/units/:title`）题型统计显示：

```
判断 4 · 手写解答 5 · 应用题 1 · find-error 2 · 填空 4
```

**根因（已查实）**：`apps/web/src/pages/student/StudentCourseUnitPage.tsx:37` 的 `TYPE_LABELS` 映射表用了 camelCase 键 `findError`，而真实题型是 kebab-case 字符串 `"find-error"`，查表落空后回退显示原始值。

**修复**：键名改为 `"find-error"`（一行），顺带对照 `Question.tsx:17` 的权威映射（`"find-error": "找错题"`）补一个快照测试防回归。

## 四、P1 问题：口径与逻辑疑点

### P1-1 「未作答」与「做错」混为一谈

- 批改结果页头部「答错 6 题」中含**未作答被自动判错**的填空题；逐题卡片对未作答题也挂「答错」徽章。对学生而言「没做」和「做错」是完全不同的复习信号，也会让家长误读。
- 错题本出现自相矛盾卡片：**「首次做对」+「我的最近答案：未作答」+ 仍列在待复习**（练习五的判断题）。怀疑与 5e741ca「填空题改全人工批改」口径切换后的历史数据、或跨作业同题判定的聚合口径有关。

**建议**：
1. 判定状态增加「未作答」独立展示（统计与徽章都区分）；
2. 错题本对未作答题给「去补做」动作而非「待复习/已攻克」语义；
3. 专项核查错题本判定链路在批改口径切换前后的数据一致性（存量数据迁移是否需要补偿）。

### P1-2 得分口径不统一

- 「我的记录」页显示「得分 25」无分母；结果页有「自动判分得分（满分 100）」说明；教师端显示「自动判分：25 / 最终得分：未批」。
- 自动判分 25 实为「已判定题正确率」，8 题待批后还会变。学生/家长极易把中间分当最终成绩。

**建议**：统一为「暂定 25/100（8 题待批）」类写法；批改完成后明确给出最终分与变化。

### P1-3 资源库侧栏计数与分区不一致

侧栏「全部 11」是讲义(8)+单元(3)的混合总数，但当前「讲义库」分区只列 8 条、「题库」只列 3 条，切分区时计数与列表对不上，第一观感像 bug。

**建议**：文件夹计数跟随当前分区，或明确标注「全部资源 11（讲义 8 · 单元 3）」。

## 六、学生视角：复习闭环分析

**结论：主路径完整，但「复习效率」上有三个断点。**

已覆盖的主路径：首页三卡（作业/错题数/课程进度）→ 讲义阅读（目录/跳转/公式渲染良好）→ 单元练习（历次记录、首次/最近/最高分）→ 结果页（对错/参考答案/详解/笔迹回看/提示回看/老师评语）→ 错题本（考点筛选）。

| 断点 | 现状 | 影响 | 补齐难度 |
|---|---|---|---|
| **错题本只能看不能练** | 只有「查看详解」，无「错题重练」 | 复习闭环缺最后一环；消错题只能整单元重做 | **中**（见下方方案） |
| **长卷无题号导航** | 16 题平铺，仅吸底进度条 | 定位某题靠滚动，iPad 上尤其累 | **低**（吸底条上方加题号 chips，点击滚动定位 + 已答态着色） |
| **无任何通知** | 老师批改完/布置新作业，学生无感知 | 学生需主动逛，反馈延迟 | **低**（首页红点 + 角标；自部署无推送渠道，站内提示即可） |

### 错题重练的推荐实现方案

attempt 绑定在 unit 上是现有架构约束。推荐「**隐藏重练单元**」方案，可复用全部既有设施：

1. 学生在错题本按考点筛选/勾选题目 → 点「重练这些题」；
2. 服务端将所选题目克隆为一个 `hidden` 标记的重练单元（不进资源库、不进课程目录）；
3. 走既有 attempt 创建 → 作答 → 判分 → 批改 → 错题本消题 全流程；
4. 做对后按现有「最近一次做对 → 已攻克」口径自然闭环。

工作量集中在：unit 表加 hidden 语义、一个「错题建卷」接口、错题本入口改造；判分/批改/统计零改动。

## 七、教师视角：减负与提质分析

**结论：减负与提质两条线都有实打实的功能支撑，亮点突出。**

### 减负（效率）

- **键盘流批改队列**（`/t/data/pending`）：J/K 翻卡、1 标对 / 2 标错 / 0 清除、U 撤销（实测通过，撤销后进度正确回退）、课程/作业/学生三维筛选、逐卡评语随判定一并提交。19 张卡的批量处理效率远超逐题滚动。
- **三步布置作业向导**：对象（选课程自动带出成员）→ 内容（本课程练习/资源库双来源，勾选顺序即作答顺序）→ 确认（标题/截止/答案公布时机）。心智负担低。
- **完成矩阵**：谁没做、进行中、待批数一屏看清，直接点击进入对应作答。

### 提质（一对一质量）

- **下节课重点**：按周期自动聚合薄弱考点（判错数/正确率）+ 代表错题原文 + 直达作答详情——直接生成备课起点，这是本产品对一对一场景最有价值的差异化功能。
- **进度矩阵**：成员 × 可见单元，首次/最近/最高分 + 待批数 + 重做数，展开历次记录。
- **导出给 AI**：五步向导（范围/内容/目标/隐私化名/预览）产出可交给任意 AI 的学情数据包，与「AI 原生」定位自洽。

### 教师端待改进

见 P2-1 / P2-2 / P2-3；另建议：批改详情页头部增加「上一份/下一份作答」快捷切换（批改队列之外的单份浏览场景）。

## 九、优先级路线图

### P0（正确性，立即）

1. 修 `find-error` 标签（一行 + 快照测试）；
2. 修练习六第 8 题（2）内容 + **全库 `pnpm tutor-lint` 存量巡检**；
3. 在单元信息抽屉 / 导入预览暴露 lint error 角标（拦截带病内容上线）。

## 十、值得肯定的设计（对标商业平台的差异化优势）

| 设计 | 说明 |
|---|---|
| 下节课重点 | 自动聚合薄弱考点 + 代表错题，直接生成备课起点；商业平台普遍只有冷冰冰的正确率图表 |
| 键盘流批改队列 | J/K/1/2/0/U 全键盘批改 + 撤销 + 三维筛选，效率接近专业阅卷系统 |
| 分步提示（限量） | 每题提示按条解锁、剩余数可见、结果页可回看「做题时看过哪些提示」——教学痕迹完整 |
| 离线作答保护 | 断网不断答、本机暂存、恢复自动补发、离线时禁用交卷并明示原因 |
| 答案防泄露架构 | 学生端接口不下发未交卷答案（assertNoLeak 泄露测试）、答案公布时机策略（交卷即公布 / 截止后公布） |
| 双通道学生登录 | 专属链接（低门槛）+ 登录名密码（正式），可分别开关/重置 |
| 安全细节 | 登录防爆破锁定、删除保护（有作答禁删改归档）、题目软删除 + 回收站 |
| 导出给 AI 数据包 | 化名隐私 + 五步向导，与 AI 原生定位自洽，不锁定任何 AI 供应商 |
