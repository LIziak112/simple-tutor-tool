## 根因与修复

1. 回放画布由 Atrament 构造后残留 `touch-action:none`。虽然外层输入 div 是 `pan-y`，实际命中 canvas 时浏览器仍禁止手指滚动。材料中的纯显示 canvas 改为不参与命中，输入 div 继续负责状态机与坐标；不改共享绘制引擎或笔迹数据。
2. 材料 pointerdown 无条件 `preventDefault`，连状态机拒绝落墨的手指也被取消。现在只在状态机接受落笔时拦截。原生 touchstart/touchmove 以 `passive:false` 监听，核对 changedTouches 与 touches，仅阻止 stylus 原生平移，覆盖笔先落和手掌先落的顺序。
3. 冻结框和整段 `.material-reading` 各自创建横向滚动口，纵向计算值也变为 auto。材料适应宽度时改为无滚动裁剪；分栏正文交给外层材料列管理滚动。窄屏上下排列仍沿用原有横向防溢出，表格、代码及块级公式保留原有局部滚动。
4. 粘性材料直接成为整单元网格项，缺少题组自己的实体包含块。新增占满本组题行的常驻外框，再把滚动材料及中缝放进各自的边界，粘性定位随本组结束退出。题级独立材料同步处理；不改变题卡 key、作答状态、材料版本键或保存流程。
5. 分栏材料列增加可见外框；包含激活圈画层时高亮，使用 ring 避免改变正文几何。
