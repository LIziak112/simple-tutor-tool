### 下达提示词

```
阅读 AGENTS.md、docs/技术架构与实施方案.md、docs/开发任务清单.md（§0 全局约定）、docs/Phase5任务清单.md。
执行任务 <Txx>，只做该任务范围内的事。

2. 确认后实施。完成后运行 pnpm lint && pnpm typecheck && pnpm test（涉及 E2E 时加 pnpm e2e），贴出结果。
3. 逐条对照该任务的「验收」自查，说明每条如何验证。
4. 文档未覆盖的设计决策，停下来问我，不要自行假设。
```

### T5.1 AI 设置
- 产出：设置页：提供商类型（OpenAI 兼容 / Anthropic）、Base URL、模型名、API Key（加密存库，密钥来自 secret.key）；"测试连接"按钮；未配置时隐藏所有 AI 按钮。
- 验收：Key 不出现在任何接口响应与日志中（测试断言）。

### T5.2 一键学情报告
- 依赖：T5.1、T4.3
- 产出：以 LearningPack + 提示词调用模型，流式显示，存入 `reports`。
- 验收：🧑 生成报告质量可用。

### T5.3 变式练习生成
- 依赖：T5.2
- 产出：选择学生/考点 → 生成 DSL → 自动 lint，有错误自动让模型修正（最多 2 轮）→ 进入导入预览页由老师审核后导入 → 可一键布置为作业。
- 验收：🧑 生成的练习导入无 error。

### T5.4 手写题 AI 预批改
- 依赖：T5.1、T3.2
- 产出：待批队列中"AI 建议"：将题干、参考答案、手写 PNG 发给视觉模型，返回建议判定与理由；**仅作建议，老师确认才写入**。
- 验收：🧑 抽查 10 题，建议合理且未经确认不改变判定。
