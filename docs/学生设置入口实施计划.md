# 学生设置入口与手写手感归位计划

日期：2026-10-13。分支：`codex/student-settings-entry`。状态：待用户确认。只合入并推送 `v2`，不修改或推送 `main`。

## 目标

将学生顶栏头像与姓名合成一个清晰的设置入口，移除顶栏单独的「手写手感」链接。新增学生设置页，集中展示账号信息与手写手感；保持现有学习导航和退出行为。调整仅涉及前端入口与展示，不改配置契约、云端保存接口和笔迹渲染。

## 文件与步骤

1. `pages/student/StudentLayout.test.tsx`：先补头像/姓名进入设置、顶栏不出现手写手感、导航与退出仍可用的失败测试。新增学生设置页测试，覆盖账号信息、手写设置入口及未登录守卫。
2. `pages/student/StudentLayout.tsx`：头像和姓名统一为至少 44px 点击区域，明确可访问名称与键盘焦点状态；移除独立手感入口，收紧顶栏账号区域间距。
3. `pages/student/StudentSettingsPage.tsx`、`App.tsx`、`pages/InkFeelPage.tsx`：新增 `/s/settings`，用简洁配置行展示账号与「手写手感」。手写调整归入 `/s/settings/ink-feel`，提供返回学生设置入口，复用现有试写、命名配置与设备选择能力；原 `/s/ink-feel` 跳转新地址，`/dev/ink-feel` 和教师入口保持可用。
4. `CompactInkToolbar.tsx`：纸面工具栏的手感链接指向设置内的新地址。同步 `AGENTS.md` 与页面功能清单。
5. 浏览器测试验证点击头像进入设置、进入手感页并返回、旧地址跳转、命名配置保存与切换；桌面、平板和手机宽度检查无溢出、导航可达与焦点清晰。执行复用简化/正确性审查、相关测试、lint、typecheck 与 build，通过后仅合入并推送 `v2`。

## 设计边界

沿用学生蓝色主题与现有组件，不增加顶栏设置文字链接。账号信息不显示内部 UUID。未保存调整的离开确认保持有效，配置重取不覆盖编辑；不新增依赖，不改变答题、草稿或标画行为。纯间距与配色调整不单独编写样式测试，交互与路由按 TDD 验证。
