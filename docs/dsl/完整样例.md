## 一、练习（kind: practice）

覆盖全部七种题型、`:::hint`（多个）、`:::answer`、`:::solution`、显式 id、`:mark` 行内标记。

```markdown
---
kind: practice
unit: 完整样例练习
topic: 有理数混合运算
---

::::question{type=judge difficulty=1 knowledge="有理数的概念"}
$0$ 既不是正数，也不是负数。[[正确]]

:::solution
$0$ 是整数，是正数与负数的分界点。
:::
::::

::::question{type=choice difficulty=1 knowledge="相反数"}
$-5$ 的:mark[相反数]{color=red}是（　）

- [ ] $-5$
- [x] $5$
- [ ] $\frac{1}{5}$
::::

::::question{type=multi difficulty=2 knowledge="有理数加法"}
下列运算结果为正数的有（　）

- [x] $(-3)+7$
- [ ] $(-2)+(-5)$
- [x] $0+4.8$
::::

::::question{type=fill difficulty=2 knowledge="有理数加法"}
计算：$(-3)+7=$ [[4]]；$\frac{1}{2}$ 写成小数是 [[0.5|1/2]]。

:::hint
同号相加取相同的符号；异号相加取绝对值较大的加数的符号。
:::

:::solution
$(-3)+7=4$；$\frac{1}{2}=0.5$（填小数或分数均可）。
:::
::::

::::question{type=solve difficulty=3 knowledge="有理数混合运算" id=sample-q5}
计算 $-2^2+(-3)\times\left(-\frac{1}{3}\right)$，写出过程。

:::answer
-3
:::

:::solution
先算乘方：$-2^2=-4$；再算乘法：$(-3)\times\left(-\frac{1}{3}\right)=1$；最后相加：$-4+1=-3$。
:::
::::

::::question{type=apply difficulty=3 knowledge="有理数加减应用"}
水箱水位初始 $1.2$ 米，上午上升 $0.4$ 米，下午下降 $0.7$ 米。请用加减混合运算求最终水位。

:::hint
规定上升为正、下降为负，把各次变化写成有理数的和。
:::

:::answer
0.9
:::
::::

::::question{type=find-error difficulty=2 knowledge="有理数加法"}
下面的解答有一处错误，请指出从哪一步开始出错、说明理由并写出正确过程：

> 计算 $(-8)+(+3)$。
> 第一步：$(-8)+(+3)=11$（同号相加，取相同的符号）。

:::hint
先回顾异号两数相加的法则。
:::

:::hint
逐项检查每一步的符号与绝对值是怎样得来的。
:::

:::answer
第一步开始出错：$-8$ 与 $+3$ 异号相加，应取绝对值较大的加数的符号，得 $-5$。
:::
::::
```

## 二、讲义（kind: lecture）

覆盖 H1 切分两讲、`:::tip`、`:::warning`、`:::box{.样式类}`、`::::example`、`::::steps`/`:::step`、`:::fold`、`::::columns`/`:::col`、`::graph`、`::image`、`:mark`。

```markdown
---
kind: lecture
lecture: 有理数
---

# 第1讲 正数与负数

## 一、相反意义的量

用正负数表示:mark[相反意义的量]{color=blue}：气温零上 $3$ ℃ 记作 $+3$ ℃，零下 $2$ ℃ 记作 $-2$ ℃。

:::tip{title="记法"}
符号相反、数值相同的两个量，表示一对相反意义的量。
:::

:::warning{title="易错点"}
$-2^2 \neq (-2)^2$：底数带不带括号，意义完全不同。
:::

## 二、例题

::::example{title="例 1"}
计算 $(-3)+7$。

:::solution
异号相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值：$(-3)+7=4$。
:::
::::

::::steps
:::step{title="第 1 步：判断类型"}
$(-3)$ 与 $7$ 符号相反，属异号相加。
:::

:::step{title="第 2 步：选法则"}
异号相加，取绝对值较大的加数的符号，绝对值相减。
:::

:::step{title="第 3 步：计算"}
$7-3=4$，取「$+$」，得 $4$。
:::
::::

:::fold{title="拓展：在数轴上看加法"}
把 $(-3)$ 看作从原点向左走 $3$ 步，再向右走 $7$ 步，最终落在 $4$ 处。
:::

# 第2讲 有理数的加法

## 加法法则

同号两数相加，取相同的符号，并把绝对值相加；异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值；互为相反数的两数相加得 $0$。

:::tip
先判断「同号还是异号」，再选法则，最后定符号。
:::
```

## 三、混合（kind: mixed）

讲义段落与题目交替出现，导入时自动拆成讲义 + 练习单元并建立关联。

```markdown
---
kind: mixed
unit: 随堂练习
lecture: 第1讲 正数与负数
topic: 相反数
---

# 第1讲 正数与负数

## 概念

大于 $0$ 的数叫做正数，在正数前面加「-」号的数叫做负数；$0$ 既不是正数也不是负数。

:::tip
相反数只有符号不同：$5$ 的相反数是 $-5$。
:::

::::example{title="例 1"}
求 $-5$ 的相反数。

:::solution
只有符号不同的两个数互为相反数，故 $-5$ 的相反数是 $5$。
:::
::::

::::question{type=choice difficulty=1 knowledge="相反数"}
$-5$ 的相反数是（　）

- [ ] $-5$
- [x] $5$
- [ ] $-0.5$
::::

## 随堂练习

::::question{type=fill difficulty=1}
$0$ 与它的相反数之和为 [[0]]。
::::

::::question{type=solve difficulty=2 id=mixed-q3}
计算 $(-2)+(-5)+7$，写出过程。

:::answer
0
:::

:::solution
$(-2)+(-5)=-7$；$-7+7=0$（互为相反数的两数相加得 $0$）。
:::
::::

:::fold{title="本节小结"}
互为相反数的两个数相加得 $0$。
:::
```
