# 三期 3.1 结果事实与分组统计

按原迭代计划 §2.3.1、§2.3.5 和 Phase 3 验收实施，已由主人授权完整开发。

- 契约先行：和 UI 无关的题级事实、判定显示与聚合纯函数放在 contract，原判定优先级与未做语义保持；旧前端助手兼容转接。
- 学生与教师使用同一事实适配器，量表读取复用 rubricReviewOf，不新建判分逻辑。缺少的历史字段保持 null；不从题型猜测手写存在。学生私有随笔序号不下发给教师。
- 五种分组：单元、批次、题型、材料、考点。材料/考点多归属可重叠，跨组计数不能求和；未归批独立成组。单单元只有一次 final 结算不算分批，默认隐藏；多个单元优先单元，否则实际多批按批次。
- 分组提供完成数、客观正确率、量表各项有效档位平均与样本数、用时及按当前组的专项重练。量表 Agent 意见不替代本人自评/裁定，不折成对错分数。
- TDD 覆盖判定优先级、分组/未知数据、两端真实服务一致性与分组切换。整体完成后由根代理另派独审，不自审冒充独立验收。
- 没有真实样卷，不将 fixture 自动化报成真机或真实考试验收。3.2 在本包本地收口后另开工作树与 PR。
