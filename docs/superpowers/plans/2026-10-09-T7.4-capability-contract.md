## 一、调查结论（已核实）

- **zod 4.6.5**：`z.record(enumSchema, v)` 为穷尽 Record（缺键/多键都报错）——题型桥接表用它保证"七型齐全、键来自契约"。
- **schema:export 覆盖面**：export-schema.ts 只导出 content/learning-pack/review-pack 三组 schema；能力面不在其中 → **预期零漂移**。capabilities.json 是 T7.6 交付，本任务不新增产物文件。
- **gen:spec**：从注册表读 name/kind/description/example/attrDocs/syntax 生成规范与提示词模板——capability 字段不被读取 → 规范产物预期零变化（tutor-lint.mjs 本机重排噪声按既有口径丢弃）。
- **注册表机制测试**在 directives.registry.test.ts（t-test- 前缀临时注册 + 文件级模块隔离），标注一致性断言在 directives.test.ts（首发清单文件）。
- **index.ts** 无导出面枚举测试；新增 capability.ts 按字母序插入导出即可。

## 二、设计

### 新文件 `packages/contract/src/capability.ts`

- 词表（三面）：`directiveInputTypeSchema = z.enum(["choice","fill","steps","ink","none"])`、`evidenceFormatSchema = z.enum(["snapshot","ink-strokes","none"])`、`validationShapeSchema = z.enum(["exact","partial","rubric","unverifiable"])`（partial 仅词表保留，本阶段无实现无声明）。
- `directiveCapabilitySchema`：strictObject，三面各可选、面内单字段（interaction.inputType / evidence.format / validation.shape）——strict 拒绝拼错键；`DirectiveCapability = z.infer<...>`（单源）。
- 题型桥接表：`questionCapabilityBindingSchema`（strictObject：inputType / evidence.format / validatorId(min 1) / validation.shape）+ `questionCapabilityBindingsSchema = z.record(questionTypeSchema, binding)` + `questionCapabilityBindings`（模块加载期 parse，fail fast）：
  - judge/choice/multi → choice + snapshot + 同名 validatorId + exact；
  - fill → fill + snapshot + fill + rubric；
  - solve/apply/find-error → ink + ink-strokes + 同名 + exact。
  - evidence.format 是"可采集形式"（手写未书写不视为错误——行为语义属 T7.5 判分链，本任务只声明）。

### `directives.ts` 接线

- `DirectiveDefinition` 增 `readonly capability?: DirectiveCapability`（注释：只标注已实现行为，未声明行为不变）。
- `directiveDefinitionMetaSchema` 增 `capability: directiveCapabilitySchema.optional()`。
- 新增 `assertCapabilityConsistent`：**唯一明确冲突**——`evidence.format === "ink-strokes"` 时必须 `interaction?.inputType === "ink"`，否则注册期抛错（错误文案风格随既有 assert）。`none + snapshot`（折叠遥测）合法；不设计组合矩阵。
- 按 §4.3 标注表标注五个指令（均不标 validation）：blank=fill+snapshot；hint/fold/solution=none+snapshot；steps=steps+snapshot。question/answer/example/step 与 12 个纯展示指令省略整个 capability。

### index.ts

- `export * from "./capability.ts"` 按字母序插入（backup-api 之后、content 之前）。

### 红线对照

不把 choice 当注册指令（题型名 ∩ 指令主名 = ∅ 测试锁定）；answer 不是学生输入（无 capability）；blank 判分取所在题型（题型表声明，不在指令上标 validation）；不改证据格式/CAS/冻结；不新增通用证据调度；无 API/载荷变化。
