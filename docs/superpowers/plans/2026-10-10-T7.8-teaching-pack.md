# T7.8 教学包导入、保存与导出往返

> 依据：docs/Phase7任务清单.md T7.8、docs/组件渲染核心精进方案.md §4.6、AGENTS.md 硬性规则。
> 固定边界：复用既有文档与资源模型；教学包只声明依赖，不改判分、不新增执行代码或版本管理系统；
> 能力快照仅归档不注册。不触学生端载荷（导出不含学生作答/笔迹/快照），但触及导入链与教师域资源，仍按需跑 security-review。

## 关键设计（决策记录）

1. **YAML 回写不引依赖**：server 无 yaml 依赖（硬性规则 5），声明行用固定键序 flow 映射 + JSON.stringify 值
   （合法 YAML，yaml 包可解析往返）。
2. **图片在 zip 内保留原 src 路径**（blobs/media/<hash>.<ext>）——zip 导入配对规则①（相对路径完全一致）精确命中，
   内容寻址幂等使重导 src 不变；「导入→导出→再导入」字节稳定。
3. **导出前检查的实现**：对 content.md 重跑 lintDocument，error 级（含两新引用码）即 422 拒绝——不单查引用，
   与导入同口径（清单一处要求、两处受益）。
4. **无声明资源也可导出包**（content.md + 快照 + 图片）：清单未要求声明必须存在，md 重导合法；
   入口语义是「导出可分享包」。
5. **能力快照不进运行面**：解包侧 capabilities-snapshot.json 落 ignoredFiles（非 md/图片），仅归档；
   重导后教师能力配置与判分行为不变。
6. **commit 不可绕过**：直接提交走 commitImport → analyzeImport 重分析，两新 error 码天然阻断（清单要求）。
