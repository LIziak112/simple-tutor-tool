## 二、设计要点

- `types.ts` 拆为 `DirectiveBaseProps`（name/directiveClass/index/docIndex/children）+ `DirectiveProps<TAttrs>`（base + attrs）。
- `index.tsx` 新增 `withTypedAttrs(definition, component)` 泛型工厂：注册行上泛型具体化，`safeParse` 输出类型与组件 attrs 类型由同一 schema 推导，无 any、无强制断言；返回 `DirectiveRenderer`，失败返回 `null` 由宿主降级。`directiveComponents` 表保持该名与显式维护（方案 §六.6 不变量措辞），值变为渲染器绑定。
- 不读 attrs 的组件（hint/answer/solution/steps/columns/blank）props 用 `DirectiveBaseProps`（更少要求的组件可被传入更多 props，类型安全）。
- Question.tsx 删除手抄 `QUESTION_TYPE_LABELS` 与 `parseDifficulty`，标签改用 contract 既有 `QUESTION_TYPE_LABELS`（Record<QuestionType,string>，穷尽性由类型保证）。

## 五、测试点（typed-attrs.test.tsx，经 RichMarkdown 全管线）

缺省值（经 schema 通道，防迁移回归）：
- question 合法 type 缺 difficulty → 难度徽章「难度 2」；difficulty="3" 字符串 coerce → 「难度 3」。
- step 缺 title → 「第 1 步」；带 title → 显示标题不显示「第 1 步」。
- mark 缺 color → bg-yellow-200；color=red → bg-red-200。

非法属性降级（正文完整，非只断言不抛错）：
- question difficulty=abc → 无题卡、正文在、出现「未支持指令：question」。
- mark color=purple → 行内降级且文字保留。
- graph 缺 fn / image 缺 src → 降级（不再渲染占位提示框）。
- `:::hint{color=red}`（白名单键跨指令串用）→ hint schema strict 拒绝 → 降级、正文保留。

合法语义回归：
- image src="blobs/…" → `/blobs/…`、alt、width 样式不变。
- box `.warning` 样式类变体不变；fold 缺 title → 「详情」。
- 其余由 T7.9 样例门禁（3676 测试）、telemetry、E2E 全量覆盖。
