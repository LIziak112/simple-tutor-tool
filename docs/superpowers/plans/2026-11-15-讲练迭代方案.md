# 讲练迭代方案（回看讲义 · 主动结束 · 先做后看 · 学习闭环）

> 依据：[docs/约定/讲练.md](../../约定/讲练.md)（讲练专题 SSOT，基线 v2 d02f90ab）。本方案只给方向、分期与待定口径，不含逐任务实施步骤；每期开工前另写实施计划。
> 来源：合作方产品对话（麦吉兔频道 #34139、#34151、#34163、#34166）。

## 0. 一句话目标

讲练要成为一条完整的学习闭环：**读（或先做）→ 做 → 结束 → 回看（带讲义）→ 错题回到知识点 → 重练**。现在断在三处：没有主动结束、回看看不到讲义、错题回不到讲义。

## 1. 现状断点（详见 SSOT）

| 断点 | 现状 | 影响 |
|---|---|---|
| 收尾 | 只有最后一题提交时自动收尾 | 跳过题的卷永远「进行中」；跳过的题不算未做，统计失真 |
| 回看 | 只有最新一份卷的完成视图带讲义；结果页、落地页历次、我的记录都进 `/s/attempts/:id`，只有题 | 想看讲义只能「再做一次」 |
| 讲义版本 | 讲义正文不冻结，每次现切当前版本 | 老师重导后，旧卷回看的讲义和题对不上 |
| 顺序 | 只有先讲后练 | 不支持「先做后看」这种真实学习习惯 |
| 错题 | 讲练错题已进错题本，但只链到结果页 | 订正时回不到对应知识点 |

## 2. 分期

### 第一期：回看能看讲义 + 主动结束（优先，解决当前痛点）

**1A. 讲练视图回看（R1）**
- 结果页 `/s/attempts/:id` 对 `sourceType = "lesson"` 的卷加切换：「题目」（现有结果页）/「讲练」（讲义段 + 只读题卡 + 对错与详解）。
- 讲练视图复用现有 `LessonCompletedView`，改成按 attemptId 取数，不再只认最新卷。
- 落地页历次、我的记录、错题本里的讲练卷链接都能直达讲练视图（带 `?view=lesson` 之类的参数，默认值待定）。
- 服务端：新增或扩展「按卷取讲练回看数据」接口，只下发切段 + 冻结题公开投影，沿用防泄露约束（讲义 md 原文不下发）。

**1B. 主动结束（R2）**
- 作答页加「结束本次讲练」：有未提交题时二次确认，列出未做题数。
- 结束时同事务收尾：未提交题按「未做」记分，进分母；草稿答案不提交、不判分。
- 记录、错题本、落地页最佳表现按收尾后的口径统计。
- 中途离开不自动结束（保持可续作），是否加「N 天未动自动结束」待定。

**验收**：任一轮已完成讲练卷都能看到讲义；跳过题的卷能结束并显示「做对 X / N，未做 Y」。

### 第二期：讲义版本冻结（R3，回看正确性的地基）

- 开卷时记录讲义版本（讲义修订号或正文哈希 + 快照），回看用开卷时的讲义切段。
- 方案二选一（待定）：A. 每卷存切段快照（简单、占空间）；B. 讲义按版本存档，卷只存版本号（省空间、要加版本表）。建议 B。
- 当前进行中卷遇到重导：继续用开卷版本，还是提示「讲义已更新」——待定。

**验收**：老师重导讲义后，学生打开旧卷的讲练视图，看到的仍是当时的讲义，题目位置对得上。

### 第三期：先做后看（R4）

- 开卷时选模式：「先讲后练」（现有）/「先做后看」。模式记入卷（`attempts` 新增字段）。
- 先做后看：作答页只显示题目（讲义段折叠或隐藏）；结束后讲义展开，进入讲练视图对照。
- 单题释放：先做后看模式下，是否仍每题提交后立刻释放答案，还是结束后统一释放——待定（建议结束后统一释放，更接近「做练习」）。
- 模式由谁定：学生自选 / 老师在讲义 frontmatter 指定默认 / 两者都有——待定。

**验收**：选「先做后看」做完并结束后，回看页讲义与题目交错展示，可切回纯题目视图。

### 第四期：错题回到知识点（R5，闭环最后一环）

- 错题卡、本题历史上，讲练来源的轮次加「回到讲义」，打开讲练视图并定位到该题所在段落（锚点用题目 id）。
- 错题分组名显示讲练页标题（现状未核实，需先确认）。
- 错题重练卷（`sourceType = "wrong"`）的结果页也可链接回原讲练段。

**验收**：在错题本点一道讲练错题的「回到讲义」，能直接看到这道题前面的知识点段。

### 第五期：学习数据（R6，可选）

- 讲义事件（展开、段落聚焦、目录跳转）与题内用时关联到卷。
- 能按模式（先讲后练 / 先做后看）对比正确率与用时，供老师调整讲义。

## 3. 需要产品拍板的口径（开工前确认）

1. 结果页默认显示「题目」还是「讲练」视图？
2. 主动结束时，草稿里写了但没提交的答案：丢弃，还是按未做保留草稿只读？
3. 是否需要「长时间未动自动结束」？多久？
4. 先做后看：答案是逐题释放还是结束后统一释放？
5. 先做后看的模式由学生选、老师定，还是都可以？
6. 讲义冻结用快照还是版本表？
7. 进行中卷遇到老师重导，是锁定旧版本还是提示更新？

## 4. 依赖与顺序

- 第一期可独立先做（1A 不依赖冻结，但重导场景下旧卷回看会有偏差，需在说明里标注，第二期修正）。
- 第三期依赖第一期的讲练视图和主动结束。
- 第四期依赖第一期的讲练视图和第二期的冻结（否则锚点可能落空）。
