# OwnClass 教师端完整视觉重设计方案

状态：用户已确认，已在 `codex/ownclass-teacher-visual-redesign` 分支实施并通过验收。日期：2026-10-12。

实施结果、真实命令与截图见 [验收记录](../../审查报告/2026-10-12-OwnClass教师端视觉重设计验收.md)。第 2 节保留实施前评审依据。

## 1. 结论与设计目标

上一版完成了导航分组和配置拆分，但视觉仍接近默认组件拼装。设置页以两项配置承载两层竖向导航、重复标题、多层边框；侧栏广告词消耗高度；AI 连接页将操作、说明、帮助同时铺开。继续局部调圆角、换颜色，无法解决这些结构问题。

推荐方向：**清晰、克制、有品牌识别的浅色教学工作台**。白色导航与内容表面、冷灰页面底色、靛蓝主操作；使用页面网格和文字层级建立秩序，减少独立卡片。保留教学工具需要的信息密度。OwnClass 的品牌表达来自字标、选中态、主操作与统一排版。

方案交付包含完整评审、尺寸与色彩规范、页面结构、交互状态、响应式规则、实施文件清单、测试与合并流程，以及可点击的独立概念稿。确认后按第 9 节完成产品实现。

## 3. 全局框架与导航

### 桌面外壳

- 侧栏 224px；上下内边距 20/8px，左右 16px；≥1024px 显示。极短屏允许导航自身滚动，账号区固定可见。
- 品牌区：34px 图标，20px OwnClass 字标，12px“教师工作台”。现有 GraduationCap 可先沿用并统一主色；概念稿的 O 只是占位，不代表最终更换 logo。
- 广告词完整保留：**Your data. Your way. All for learning.** 放在登录/入口页和账号页页脚，工作侧栏不显示多行广告词。
- 导航行触控区域至少 44px，图标 18px，文字 14px/500；高亮为浅靛蓝底＋深靛蓝文字＋600 字重，保留 aria-current。无需在末端再放黑色小圆点。
- 教学：资源库、共享资源、课程、学生、作业。分析：学情分析、作答记录、导出中心。系统：连接 AI、设置。
- 底部保留单一账号入口；账号分类内管理员专属“系统管理”，普通教师不展示。保持 /a 路径与服务端权限；实施时同步修改现有 AGENTS UI 约定并测试入口可达。
- 顶栏 56px，使用低强调的工作台/当前位置；详情页提供有效的返回层级。账号信息不重复出现。保留移动导航触发器，不加入未实现的搜索框、通知或“连接正常”状态。

### 页面网格

| 页面类型 | 内容宽度与结构 |
| --- | --- |
| 设置、连接 AI | 可用内容最大 880px；外围容器最大 1000px，桌面水平留白 40–48px；在工作区居中 |
| 资源/学生/作业列表 | 最大 1280px，左右 32px；标题与主动作同一行，筛选与结果同一轴线 |
| 详情/编辑 | 根据已有业务，保留材料宽度；辅助信息仅在有足够空间时分栏 |

1440×900 与 1280×720 下验证完整导航不因装饰留白产生滚动；两项设置、说明与保存动作在首屏。1024px 左右不得把固定侧栏和固定内容宽度相加造成溢出。

## 4. 视觉规范

### 颜色 token

最终沿用项目 oklch 声明方式，将下列 sRGB 目标值转换成教师主题语义 token。使用现有主题挂载/Portal机制，保证弹窗、菜单、学生页与管理页不会被误着色。不要把全局 :root 直接替换成教师主题。

| 语义 | 浅色目标 | 用途 |
| --- | --- | --- |
| 页面底色 | #F5F6F8 | 工作区 |
| 表面 | #FFFFFF | 侧栏、表单与弹窗 |
| 正文 | #202938 | 标题与正文 |
| 次级正文 | #596579 | 说明、元信息 |
| 结构边界 | #E2E6EC | 行间分隔；不能直接当输入控件唯一边界 |
| 控件边界 | #7C879A | 必须辨识的输入/未选中控件 |
| 主操作 | #414FC4 | 主按钮、焦点和选中导航 |
| 选中背景 | #EDF0FF | 当前导航与强调说明 |
| 危险正文 | #B42332 | 重置与恢复影响说明 |
| 危险表面 | #FFF9FA | 恢复区域 |

| 实测候选色对 | 比值 |
| --- | --- |
| 正文 / 白表面 | 14.63:1 |
| 次级正文 / 白表面 | 5.90:1 |
| 次级正文 / 页面底色 | 5.45:1 |
| 白字 / 主按钮 | 6.69:1 |
| 主色文字 / 选中背景 | 5.89:1 |
| 危险正文 / 危险表面 | 6.25:1 |

暗色候选：页面 #171C27、表面 #202633、正文 #E8ECF4、次级 #A7B2C6、主操作 #5364DC；正文/表面 12.79:1，次级/表面 7.09:1，白字/主操作 4.97:1。实施时仍须对实际选中态、半透明状态、focus与Portal重新测量，不以这些候选值替代暗色验收。

### 排版、间距、表面

- 不更换字体依赖：沿用本地 Geist；明确中文回退到设备可用中文 UI 字体，不使用 CDN。先验证实际中文字体与 400/500/600 字重。
- 页面标题 30px/600/1.25，移动端 26px；分区标题 18px/600/1.4；配置标题 15px/600；导航、按钮与正文 14px/1.5；说明 13px/1.6；元信息 12px。在实现里以 rem 定义，移动输入至少 16px。
- 间距步长 4/8/12/16/24/32/40/48。组内 8–16px，独立分区 28–32px；不要逐个组件随意写尺寸。
- 配置行 padding 24px 28px，移动端 20px；行高随文案增长，不锁高度。描述最大约 54ch，长 URL/ID 可断行。
- 表面 12px 圆角、按钮与选择态 8px、徽标 5px。普通页面不使用重阴影；弹窗/下拉层才使用轻层叠阴影。
- 每个视图明确一个主动作；静态状态不能只靠颜色表达。危险主确认按钮放在确认弹层中，页面入口为危险色描边按钮。
- 交互背景/透明度不超过150ms；页签立即响应；不加列表整页飞入、按钮弹跳或装饰渐变。抽屉沿用项目实现并遵循 reduced-motion。

## 5. 设置页完整结构

```text
设置
简短用途说明
学生作答方式 | 备份与恢复 | 账号与会话  ← 横向分类链接

辅助作答
简短范围说明
┌──────────────────────────────────┐
│ 逐步揭晓      说明           开关 │
├──────────────────────────────────┤
│ 手写辅助      说明           开关 │
└──────────────────────────────────┘
生效时间与已有数据保留说明
未保存/已保存状态             保存更改
────────────────────────────────────
AI 简短说明                  管理 AI 连接
```

### 学生作答方式

- 两项设置共享白色表面；去掉每项的小卡片和重复笔图标。标签在左，控制器在右。
- 控制器使用现有 checkbox 数据语义，视觉可绘制为开关；不要为了外观增加依赖。这是暂存选择，仍需“保存更改”，不改成即时自动保存。
- 初始“当前设置已保存”；变化显示“有未保存的更改”；提交“正在保存…”；成功“更改已保存”；失败在动作附近说明失败并允许重试，保留本地选择。
- 分类仍为 `?section=teaching|backup|account`；采用语义链接和 aria-current，不只加 role=tab 而不实现键盘规则。
- 所有控制器持续挂载，切换分类不重置。现有后台数据同步是否会覆盖本地 dirty 状态需用失败测试核实，再决定修复；不假定持续挂载能解决所有状态冲突。
- 保留正式作答始终可用、已有答案/笔迹不清除、重新打开生效的真实语义。

### 备份与恢复

1. 分区“数据备份”：自动快照频率和保留数量短说明；完整备份范围写在下载动作旁。
2. “下载完整备份”为该视图主操作，下载前创建快照的说明保留。
3. “最近快照”：时间与大小对齐，完整文件名放在次级行；默认三条，展开全部与收起保留。不要把截断的文件名当作唯一信息。
4. “恢复备份”单独危险区域，置于快照之后；说明整体替换当前数据。点击选择文件后进入现有密码确认流程，展示文件名、数据覆盖范围、恢复前快照与会话影响。
5. 恢复中防止重复提交；失败保留必要上下文；成功以恢复结果引导重新登录。不在概念稿或演示中调用真实恢复。

### 账号与会话

- 账号信息用简单信息行展示；长登录名允许换行。
- 会话说明与退出动作独立分区，不包装成多个同等重量的大卡片。
- 管理员入口放在账号信息附近并明确命名“系统管理”；保留权限保护。
- 页脚出现 OwnClass 与完整广告词，既提供品牌落点，又不挤压日常操作。

## 6. 连接 AI 页完整结构

- 顶部：标题、一句用途、真实凭据状态。“已生成凭据”与“已连接 AI”必须区分；没有客户端心跳/握手依据就不显示后者。
- 第一步：凭据。无凭据显示单一“生成 Token”；生成后展示掩码、查看/复制和次级重置入口。保留确认重置、旧凭据立即失效及复制反馈；查看后是否默认掩码属于实施前需要验证的交互，不改 API。
- 第二步：选择客户端＋服务器地址＋完整配置。客户端切换只展示一份配置；代码面板的标题栏固定“复制配置”，地址保留单独复制。可保留“通用客户端/Claude Desktop”的现有真实说明，不能为了稿子简洁删除必需配置步骤。
- 未生成凭据时显式标注占位符；复制按钮应清楚提示复制的是示例，避免让用户以为是可直接连接的配置。
- 第三步：客户端确认说明。说明在客户端查看工具，不新增没有后台能力的“测试连接”按钮。
- 帮助随对应步骤出现；较长故障排查使用可发现的“连接排查”展开区。取消常驻 220px 文字侧卡，给代码与操作完整宽度。
- 配置字段和 MCP 协议保持现状；品牌更名不等于协议键名强制迁移。概念稿仍使用现有 `tutor` 配置键。

## 7. 教师端其他页面的统一延伸

以下是规划，执行前需逐页实际检查业务与状态：

| 页面 | 结构与动作分布 |
| --- | --- |
| 资源库 | 标题＋一个主创建/导入动作；搜索/类型/筛选单行；资源结果使用同一标题、标签、元信息和操作轴线；空列表给创建入口，筛选空结果给清除筛选 |
| 共享资源 | 与资源库共用基础结构，突出来源/共享状态；普通教学操作和发布管理动作分清 |
| 课程 | 优先清晰的课程名、资料/练习信息和进入入口；删除装饰性大图标、重复统计，真实计数才显示 |
| 学生 | 列表优先姓名、教学上下文和可用操作；详情页身份区、学情区、记录区分层；报告状态与更新日期同组 |
| 作业 | 筛选栏与状态明确，标题、对象、进度和日期对齐；布置动作唯一突出；长标题有查看完整内容方式 |
| 学情分析 | 先关键结论和依据范围，再图表与明细；无数据给原因与可执行下一步；不增加假数据图表 |
| 作答记录 | 使用稳定列表/表格密度；筛选与返回上下文保留；状态同时用文本和图标表达 |
| 导出中心 | 范围选择 → 导出动作 → 结果/下载；进度与失败贴近相应任务，不用多个主按钮竞争 |

详情/结果页保留现有单行操作栏、控制器持续挂载和返回来源约定。学生端现有布局与答案泄露保护不在这次外观重设计的变更范围内。

## 8. 响应式与交互状态矩阵

| 情况 | 规定 |
| --- | --- |
| ≥1024px | 完整侧栏；设置横向三分类；主操作与状态同一行 |
| 768–1023px | 现有 Sheet 抽屉；内容24px留白；不用只有图标但无文字提示的迷你侧栏 |
| 320–767px | 内容20px，320px必要时16px；三个分类缩短为“作答方式/备份恢复/账号会话”并保留完整可访问名称；配置说明可换行 |
| 手机配置行 | 控制器44px触控区，文字min-width:0；长文自然增长，不能遮挡控制器 |
| 低高度桌面 | 常用入口优先；nav内部可滚动且有滚动提示；不隐藏设置/账号操作 |
| 200%字体/缩放 | 内容重排，不锁标题/行高度；分类必要时换行；不靠横向滚动承载必需正文 |
| 加载 | 保留标题、分区和布局；局部骨架或文字，不整页闪烁 |
| 获取失败 | 保留当前页面定位；说明失败对象和重试动作；区分获取失败与保存失败 |
| 未保存 | 显示明确状态，分类切换保留；离开设置且会丢失时提供继续编辑/放弃处理 |
| 成功/失败 | 保存/复制反馈靠近原控件；状态通过稳定live region播报；错误不依赖短暂toast |
| 空数据 | 快照为空解释生成时机；业务列表为空给下一步；筛选为空给清除入口 |
| 键盘 | 跳到内容、所有导航和控件可操作；抽屉Escape关闭并还焦；分类导航符合链接语义 |
| 暗色/高对比 | 所有角色token映射完整；实际色对复测；forced-colors保留边界与焦点 |
