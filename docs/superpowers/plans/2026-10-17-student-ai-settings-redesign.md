# 学生 AI 配置流程重做

用户已于 2026-10-17 确认实施。分支：`codex/student-ai-settings-redesign`。

## 目标与顺序

1. 先检查现有连接、供应商出站守卫、上下文链接与测试，定位实际缺口。已有工作区改动不纳入本任务。
2. 契约先行：在 `packages/contract/src/student-ai-api.ts` 定义未保存配置的连接测试与模型列表请求、响应，先补失败测试。编辑配置可复用本人已保存密钥，但禁止把旧密钥发往不同地址。
3. 服务端：`provider-client.ts` 增加受出站守卫保护的 GET models，`connection-service.ts` 增加无持久化诊断，`routes/student-ai.ts` 增加本人授权端点。固定测试探针不带题目；错误脱敏；超时、重定向、响应上限沿用既有机制。获取列表成功不等于模型可用。
4. 前端：重做 `StudentAiConnectionPage.tsx`、`AiConnectionManager.tsx`，拆出页内配置组件，调整 `ai-connection-queries.ts`、`lib/api.ts`。以选择使用方式、地址与密钥、模型、测试、保存组织流程，明确显示最终接口、恢复建议、未保存状态；请求迟到不得覆盖新输入。MCP 保留完整配置复制，API Key 不回显。
5. 上下文链接：核对每链接一题与多链接独立语义，修改链接复制流程及分享正文提示，要求本次逐个重新读取，失败须说明；每次返回重新校验授权、禁用缓存，保留冻结快照语义。第三方 AI 的联网能力无法由本站保证，不能显示虚假的已读取/已连接状态。
6. 同步使用文档，按完整 diff 顺序做简化、正确性、安全审查，完成验证后小步提交并按项目流程合并。

## 测试与验收

- 契约：新建/编辑诊断，非法地址、缺少凭据、超长模型 ID、响应字段边界。
- 供应商：真实 GET 装配、模型 ID 筛选与去重、空列表、401/403/404、非法响应、超时、重定向、SSRF；不泄露响应原文或密钥。
- 路由/服务：未登录、跨账号与已删除连接；诊断不写配置；不同地址不得复用旧密钥；固定探针无学生资料。
- 界面：获取后选择或手填、未保存测试、失败重试、输入保留、修改参数清除旧结论、迟到响应隔离、编辑沿用密钥、保存与验证状态分离。
- 链接：不同题票据独立、重复读取重新授权、撤销/策略/快照变更立即生效、成功和失败响应禁缓存、复制提示要求逐链接重新读取。
- 纯布局与文案按项目规则豁免 TDD；交互、契约和服务先 RED 再 GREEN。
- 执行定向测试、全仓测试、typecheck、lint、build、schema:export、gen:spec；Playwright 使用隔离的 8899/5199 与临时库，不改用户 5173 数据。验证桌面和 320px、键盘焦点、加载/空白/失败状态，保留截图和手动步骤。

## 约束

不新增依赖、不改数据库结构、不扩大普通学生端答案可读范围。服务端只返回模型 ID、诊断结果等安全字段。不会在用户账号执行真实付费探针，自动化使用假供应商。
