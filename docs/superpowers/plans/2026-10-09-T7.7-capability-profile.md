# T7.7 教师级辅助能力启用集（capability profile）

> 依据：docs/Phase7任务清单.md T7.7、docs/组件渲染核心精进方案.md §4.5、AGENTS.md 硬性规则。
> 边界（用户已确认）：正式作答始终可用；仅 steps/ink 两项教师级辅助开关；不做课程覆盖、实时推送、配置冻结。
> 触及学生端载荷：security-review 必跑。

## 范围枚举（清单要求：枚举实际涉及的响应契约、页面与共享组件）

- 响应契约：`attemptDraftDataSchema` / `attemptResultDataSchema`（GET /api/student/attempts/:id，两分支都加）+ `studentLectureDetailSchema`（GET /api/student/lectures/:id）。取卷 `/paper` 端点无 web 页面消费方，不加（记为范围决策）。
- 页面：StudentAssignmentAttemptPage / StudentAttemptPage（经 AttemptSession）、StudentLectureViewPage、教师 SettingsPage（新增设置区）。
- 共享组件：StepsDirective、HandwrittenControls、AttemptQuestionCard（内含 NoteLayer 挂载判定）。
- 不动：AnnotationLayer（题干标注，学习痕迹功能非作答辅助，清单未列）、CorrectionPanel（订正流程）——记为范围决策。

## 关键设计

- 存储语义：NULL=全启用（缺省）；显式空数组=全关（合法）；读侧坏 JSON 兜底全启用（写侧已过契约）。
- 生效方式：学生重开/刷新页面（attempt 详情与讲义详情读时计算），无推送、无冻结。
- 回退不删数据：已有笔迹/草稿保留，开关只影响入口渲染；不改提交规则、不参与判分。
- 启用集不是安全边界：泄露守卫仍由 studentStemMd 投影 + assertNoLeak 独立保证。
