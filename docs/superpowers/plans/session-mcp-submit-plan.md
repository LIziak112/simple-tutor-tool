# 学生 MCP 提交增强（2.2 A2）

依赖 MCP 读取包；任务起点 6188d153。保留旧工具名字及无 responseVersion 时的必填幂等键和 `{success:true}`，只在显式 responseVersion=2 时增加题序定位、可省略键及安全事实回执。HTTP 请求契约不变。

1. 先写版本分支和真实 SDK 失败测试，再实现 strict object 与同源 JSON Schema 分支；旧缺键与未知字段仍拒绝。
2. 拆开普通与讲练提交，原路径兼容导出；摘要原样共享。省键从原规范摘要派生 UUID，不从最新草稿或笔记头补参数。
3. 首写内部回调在原重放裁决之后、写入之前执行 AI 门和冻结题序校验；来源仅从服务端鉴权依赖注入，客户端不得声明。
4. v2 回执白名单为本题身份、提交时间、实际结算序号、幂等键、已提交数及下一未提交题，不含答案解析或判定；自动收尾后重读实际行。回执按当前进度读取，重试不重写事实。
5. 班级与个人端真实 SDK 覆盖旧壳、省键/显式键、错配、首写拒绝、成功重放、最后一题和 tools/list JSON Schema；按工程验证入口收口并集中独立审核。

本包不包含当前题候选、分批提交、随笔幂等与关联、用时统一。未合并、未部署；物理设备及外部第三方客户端验收另列。
