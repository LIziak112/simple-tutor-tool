## 性能根因与修复验收

- 回归先失败：同一题面重新打开触发两轮资源等待；题面相同属性重渲染时，原生 radio 发生 6 次属性写入；AI 内容更新后题级作答回调引用改变。
- 根因一：标画几何观察器依赖选中状态，显式打开核对完成后因开合重新安装并等待。观察器改为依赖题面、布局、缩放等几何条件，通过当前选中引用决定输入；几何核对期间切工具仍保持输入保护，新的几何通知立即推进代次。
- 根因二：后台状态更新带来新的 AI 节点，题行随之渲染，临时作答函数令题面重新渲染。新增稳定题级作答回调，题面采用 React 默认属性比较；回调、答案、题目和显示模式变化按原语义更新。真实浏览器记录到的其他题目 radio 属性更新由 3096 次降至 0。

## 全量验证发现的设置保存问题

- 教师 AI 设置原先直接使用系统毫秒作为编辑版本；同毫秒连续保存时版本可能重复，系统时钟回调也会让版本回退。全量测试中的旧编辑保护用例因此偶发失败。
- 先补固定时钟回归：同一毫秒连续保存、时钟回调 1000ms 两例均先失败；实现改为当前时间与旧版本加 1ms 的较大值，沿用既有 ISO 时间契约。
- 修复后服务、教师路由与策略裁决 3 文件 38 项通过，旧编辑获得 `AI_SETTINGS_STALE`，最新教学设置保持原值。
- 简化与正确性审查：在既有保存入口推进版本，默认设置的空行语义和教师归属条件保持原有行为；学生数据边界审查确认策略配置读取和三种受控 AI 出口沿用原规则。
