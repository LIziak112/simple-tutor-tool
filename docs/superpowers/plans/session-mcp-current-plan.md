# 二期 MCP 当前题候选

依据原迭代计划 §2.2.3 与二期验收，在现有学生 MCP 读题和版本提交基础上补齐定位闭环。

- 兼容：无版本请求保留原求助任务状态；显式 responseVersion=2 返回任务状态与独立定位状态。
- 多窗口：同一题去重，异题返回规范上下文候选；焦点溢出、失权或来源失效不猜题。过期焦点只退到最近进行中练习，不伪称当前题。
- 安全：每个候选重查本人归属、AI权限、canonical来源；讲练按真实讲义正文排序并验证当前讲义可见性，普通练习按试卷顺序。只返回公开元数据，不返回题目答案、判定、正文或教师私注，不创建求助或激活学习记录。
- 验证：班级与个人真实SDK覆盖旧兼容、去重/候选、过期/溢出、权限、元数据字节预算；讲练题序与隐藏讲义独立红绿回归。生成两遍零漂移、类型及规模检查后，整体独立简化/正确性/学生出口安全审核。

当前包不取代外部真实客户端及物理设备验收，不合并或部署。
