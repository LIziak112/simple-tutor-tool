# 三期 3.3：范围复盘与分片报告

原迭代计划 §2.3.4、§3.3 的完整工作包，依赖已开发的分批结算及结果事实。旧 v1 快照、报告与工具继续原路径可读；新 v2 采用显式版本接口，避免旧客户端将新分节报告当成旧五段报告。

1. 先契约与失败测试：范围为整卷、已结算批次、单元或讲练已提交阶段。快照版本2带材料正文、量表/自评和封存用时；报告按预设profile的分节清单校验。每片仍最多30题且256KiB，不提高旧常量；超大单题明确拒绝，不截断。
2. 独立run/part表记录分片图：按冻结单元/结算分区，超过30题再细分；每片独立任务，所有片有报告后才能领取汇总任务。汇总快照只有子报告，不含题面或答案。幂等键和摘要持久化，分片与总任务一次IMMEDIATE事务创建，任一步失败全回滚。
3. 每次预览、创建、领取和报告读取复验本人归属、当前公布和逐题AI权限，范围外数据不进入批次快照；领取有租约/代次/CAS，迟到或取消不能覆盖报告，续租有总时限。配额与已有任务统一计数；未知状态不放行。
4. 新学生HTTP路由与学生/个人MCP工具接真实服务；结果页可创建范围复盘、查看分片进度与分节报告，批次结果和讲练阶段有入口。旧报告入口继续可读；证据题号按原卷显示序，不因分片重编号。
5. TDD覆盖105题、批次隔离、权限收紧、幂等/并发/全回滚、租约/证据越界、汇总无原题、旧v1读取；新增学生出口泄露测试；类型/lint/规模/生成两遍；完整任务后独立简化/正确性/安全审查。真实样卷、物理设备及外部真实客户端未到位的验收据实单列。

迁移独立生成，与用时/随笔新增迁移最终按依赖顺序重生成后集成；不修改生产库，不合并或部署，不开启任何清除任务。
