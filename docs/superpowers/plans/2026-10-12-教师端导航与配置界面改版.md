# 教师端导航与配置界面改版

日期：2026-10-12。状态：用户已确认，实施与验证完成，目标合并 v2。

补充确认：网站更名 OwnClass，广告词为 “Your data. Your way. All for learning.”。最终实现与验证见 [验收报告](../../审查报告/2026-10-12-OwnClass教师端改版验收.md)。导出导航最终采用“导出中心”；保留原中性色系统。两倍文本大小已验收，原生浏览器 200% 缩放未冒充已验证。本次用户明确只要求合并 v2，未发布 main。

## 目标与边界

让教师更容易找到教学功能与配置，并改善侧边栏、设置页、连接 AI 页的信息分布和视觉层级。第一阶段覆盖 `TeacherLayout`、`SettingsPage`、`ConnectPage` 及配置子组件；其他教师业务页只检查导航兼容，不逐页重做。后续建议另列，不混入本次交付。

沿用 React 19、React Router、Tailwind CSS v4、shadcn/Radix、lucide-react，复用现有本地字体与语义颜色。已读取 `AGENTS.md`、架构文档技术栈与 `docs/审查报告/UI与功能设计改版建议-2026-10-05.md`，并读取 better-interface 及其六个领域技能。

审查结论：**Block（限本次范围的静态审查）**，改版交付前解决动态效果约束，并补充响应式和键盘验收；未检查的其他教师业务页面不在结论范围内。

## 布局与视觉规格

桌面侧栏宽 232px、固定在视口内，品牌区在上、分组导航居中、账号与管理区在下。导航区可独立滚动，小高度窗口也能访问底部；导航项最小高度 44px、图标 18px，选中态采用底色、字重与可见标记，继续设置 aria-current。分组间距 20px，组内间距 4px。

窄于 1024px 时使用顶部“打开导航”按钮加现有 Radix Sheet 左侧抽屉，替换目前十一项横向长导航。抽屉与桌面共用条目数据，点击路由后关闭；支持 Escape、焦点圈闭和返回触发按钮。复用 Sheet 时检查减少动态效果，避免扩大到编辑器等无关组件。

页面背景使用现有浅中性色 token，白色配置表面，保留黑灰主操作。标题建议 24px/600，分区标题 16px/600，正文与导航 14px，补充说明 13px、行高 1.5。使用现有圆角与间距；可选调整只限定教师布局容器，避免改变学生主题。页面边距窄屏 16px、桌面 24–32px。

设置页最大宽约 1040px；桌面左侧 180px 分类导航，右侧配置内容，窄屏为可换行的分类链接。采用 `/t/settings?section=teaching|backup|account`，默认 teaching，未知值回落默认，浏览器前进后退保留所选分类。

三个配置区持续挂载，仅切换可见区域，避免丢失未保存开关和恢复文件状态；非当前区不参与 Tab 顺序。退出登录移到“账号与会话”内。设置中的 AI 区域改为清楚的 `/t/connect` 入口，Token 查看、生成、重置集中到连接页，复用 ApiTokenSection，避免两套凭据管理界面。

连接 AI 页最大宽约 1040px：顶部说明与三步进度，主体一列完整连接步骤，宽屏右侧简短帮助。展示“尚未生成 / 已生成凭据”，不显示未经真实连接测试的“已连接”。只提供当前客户端的一份配置代码；可切换“通用客户端 / Claude Desktop”说明。技术路径保留于客户端操作指导，不塞进主标题。长 URL、JSON 可选择并完整查看。

备份区将下载完整备份与恢复数据分开排布，继续保留现有恢复确认和登录失效提示；危险操作有明确后果说明。最近快照默认三条，全部记录可展开。

## 实施顺序与测试点

1. 用户确认本计划后，检查工作区，在独立 `codex/teacher-navigation-settings-ui` 分支实施。当前已有 README、截图和其他未跟踪文件，保留并排除出本次提交；不从其他任务分支继承无关实现。
2. 先写行为失败测试：分组导航与权限、资源库导入高亮、窄屏抽屉、设置分类 URL、未知分类回退、跨分类保留未保存开关、凭据重置确认、复制失败反馈、快照展开。
3. 实现 TeacherLayout，运行对应测试；再实现设置分类与配置卡片，运行对应测试；最后精简连接页并复核凭据重置行为。纯间距、圆角、背景与文案修改可豁免 TDD，以截图和语义检查验收，交互不可豁免。
4. 对完整 diff 依次完成 simplify 与 code-review 闸门，修复确认问题。当前可用技能目录未提供这两个同名技能；执行前查找本机其他技能，若仍缺失明确记录，并与用户确认可用的等价审查方式，不假称调用成功。
5. 执行 `pnpm test`、`pnpm lint`、`pnpm typecheck`、`pnpm build`，保存实际结果；仓库现存无关失败需明确区分并处理，不宣称全绿。
6. 执行 `pnpm e2e e2e/teacher-navigation-settings.spec.ts --workers=2`，使用仓库隔离数据库与 8899/5199 端口。Chromium/WebKit 验收 320、390、768、1024、1440px；核对 200% 缩放、长登录名、长 URL、快照空态/加载/错误、键盘、焦点及 reduced-motion。静态教学样例解析和渲染继续通过既有测试。
7. 手动验证：从课程详情与导入返回导航；普通教师无管理入口；切换设置分类后开关不丢；配置复制反馈准确；凭据重置保留确认；恢复流程继续要求既有确认。仅在隔离环境测试写操作。
8. 提交代码、测试及约定文档，在 PR 描述附手动验证步骤；全部闸门通过后按项目流程合并 v2，再发 main。具体发布方式遵循仓库当前流程，不覆盖未提交的用户工作。

## 后续如何精进

第二阶段统一资源库、学生、课程、作业的页头、筛选和列表操作。通过实际宽度测试决定各页面密度，避免把表格页强行收进配置页的窄栏。

第三阶段串联“学生 → 学情 → 布置练习 → 批改”：优先保留学生与来源上下文，减少反复重新筛选，再评估工作台和批改工作区；新增数据聚合或待办数量时先修改 contract 并补服务端测试。

本次验收重点：配置可由一个明确分类直接找到；窄屏所有一级导航可见可达；AI 页只出现一份当前配置代码；备份历史能展开；重排不丢状态。后续可观察完成配置的点击次数、操作错误与任务耗时，再决定是否需要新的工作台或更多快捷入口。
