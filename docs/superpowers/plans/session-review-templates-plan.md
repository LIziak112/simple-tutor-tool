# 三期 3.2 模板与预设

基于3.1完整事实层，按原计划§2.3.2–2.3.3、Phase3与D7授权实施四套预设和一级自定义。

- 模板契约先行，四套预设与分区名单只维护一份；声明适用条件、版本、分区选项和Agent profile（objective/essay）。不扩题型枚举。
- 单元practice.reviewTemplateId > 课程显式模板 > 课程考试标签 > 内容构成。未知/冲突配置回落客观题默认并给原因，不擅自挑一个单元模板。
- 课程增加可空考试类型/模板列，已有课程为null；新增迁移，不改旧迁移。考试类型有建议清单且可自填。模板只推荐展示，不改变判分、权限、公布门。
- 结果页同一数据切换模板、分区显隐和顺序；不重新请求题目。已显示分区暂时隐藏后保留组件状态。材料复用已有context；随笔摘录独立读取现有本人随笔接口，不外发私有内容。
- 内置分区：汇总、分组、逐题、量表、材料对照、作答/参考对照、用时分布、Agent报告、随笔摘录。Agent任务仍由用户显式创建；本包只传模板profile供3.3集成。
- 不做二级账号模板保存、用户编写组件或生产发布。没有真实样卷，仓内fixture和自动化不冒充真机/真实考试验收。
- 大文件按职责搬迁：courses表到course-schema；课程CRUD契约到course-metadata；删除条件到course-attempts。结果新逻辑到ReviewTemplateFrame/内置分区，旧ResultView只接已取数据与原节点。
