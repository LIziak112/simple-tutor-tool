## 接口与版本门

- `GET /api/student/attempts/opened`：严格的来源查询（course + courseId/unitId；assignment + assignmentId；lesson + lectureId/courseId可选）。返回`{attempt: AttemptSummary|null}`。权限同来源入口；不创建、不重冻。
- `POST /api/student/attempts/:id/activate`：请求`{expectedFrozenAt: string|null}`，null只匹配null。返回四字段`{attemptId,activatedAt,phase,frozenAt}`，没有题面、参考答案、学生身份。409表示快照变化，404表示卷不存在，403/作废/失权遵从原权限门。
- 摘要与MCP公开元数据使用共享`attemptSessionFields`；新服务端始终下发，字段可选兼容旧缓存。status仍三值。缺新增列的历史对象维持原进行中语义，只有显式null表示opened。
- 题内容版本`questionVersion`与冻结行身份`questionRevisionId`分开。重开新卷的行id不同，不能据此认定内容变更。答案新端可发送questionRevisionId进行精确校验。
- 重冻token为`max(now, oldFrozenAt+1ms)`，同毫秒与固定测试时钟都不会复用旧token。正式写事务取得写锁后再核对原冻结token，防止外部文件预处理期间另一入口重冻。

## 历史回填与清除

回填在runBackfills中，数据标记`attempt_activation_v1`同事务防重跑。完成卷、已有实质证据的draft、已开始计时的历史卷取startedAt；只浏览无证据保留null。证据覆盖答案/改答版本、提交、提示、标记、非空正式手写、笔记版本、圈画版本、AI任务、本人随笔锚或完整context、结算、用时账本与复盘任务。没有猜测首次动作时间。历史已保存的草稿/标注版本按旧协议保守视为动作证据；新协议首次零笔空正文同步不激活，后续清除/重冻只看实际笔画证据与激活事实。

清除`ATTEMPT_OPENED_PURGE_ENABLED`缺省false，天数缺省7。候选在同一immediate事务重新核验activatedAt/status/作废/证据；暂存上传分片保守保留。foreign_keys始终开启；事务内defer_foreign_keys，先删父卷让既有append-only的整卷删除保护按原规则生效，再移除无级联的空响应/上下文/事件/空笔记与底图，提交时FK统一核验。活动ledger、review audit保护触发器不修改；0076另外禁止改写既有activatedAt或删除活动卷冻结标记。

仅具备能力，不开启清除、不写删生产。启用前仍须按计划观察一发布周期并核对历史聚合证据。
