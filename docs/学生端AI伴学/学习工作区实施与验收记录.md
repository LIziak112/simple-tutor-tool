# AI 学习工作区：实施与验收记录

2026-10-19 · 分支 `codex/ai-learning-workspace` · 基线 `v2@7dcedb10`

## 交付行为

- 初问和追问输入使用按作答/题目或任务隔离的学生角色内存缓存，切换连接设置后恢复；退出、换账号清理，不新增浏览器持久化副本。设置返回自动恢复对应编辑或阅读视图，零自动发送。
- 初问使用默认提示，可直接发送；自定义问法作为独立意图保存，切换不替换学生自写文字。发送前展示题目、当前作答和选定材料；未采集的页数不虚报，发送时仍走既有收笔、恢复核对、固定矢量重绘和上传流程。
- 读反馈后可「回题试一试」，恢复进入前的位置；题后保留「再看回复 / 检查新步骤」。检查只进入准备态，附选定材料或写出步骤后才发送新任务。旧稿追问继续使用原快照。主动换稿退出旧链接结果、放弃旧失败动作，不撤销旧票据；普通失败重试继续沿用原幂等键与冻结材料。
- 当前回复优先，原提问、旧回复和旧任务按需展开；「这一步没懂」预填可编辑问题，选中当前回复文字时附上引用，不覆盖已有追问草稿。
- 读到的内容保留正文版本，新回信不自动追加；其他设备改成已读也不会把当前输入替换成长回复。专注阅读与题下区只有一份活动正文和编辑框；目录来自真实标题，退出恢复焦点和阅读位置。
- 求助记录不再重复拉正文或提前记已读；同卷原地打开对应题与任务，保存失败留在列表。跨卷使用任务所属作答，核对任务、题目及作答归属后消费一次定位字段，保留来源返回。
- 数学兼容覆盖明确的 `\(…\)` / `\[…\]`，代码与普通方括号不猜测转换；规范化后重新校验字节、公式和节点预算。超限提供每段最多4000字符的纯文本阅读，仍不执行HTML、图片或链接。
- 更新未自定义的默认回答模板，帮助学生明确下一步并使用兼容数学格式；教师自定义模板和已冻结的历史提示词不被改写。

## 根因与先失败证据

1. 原快捷问法直接调用 `setText(button.prompt)`，覆盖自写问题；新的保留测试先失败，改成题级独立意图后通过。
2. 原队列返回仅含attempt地址，队列自己展开全文并直接记opened；新的指定任务打开测试先失败，改为同卷回调与跨卷题/任务定位，正文授权读取成功并可见后才记交付。
3. 对原走查回信只读核对，确认存储中确有LaTeX圆括号/方括号定界符，包含截图所见等式，且没有美元定界符。原受限Markdown入口只接remark-math，反斜线定界符会被作为普通转义消费。新增兼容测试及KaTeX渲染回归覆盖此链路，不改写存储原文或普通题面渲染。
4. 首次连接保存后的状态仍可能命中全局十秒新鲜缓存，保持“未配置”而不再自动刷新；状态查询改为打开时重核对，连接新增、更新或删除同时失效AI状态缓存，回归使用人工预置的新鲜旧缓存验证。
5. 原超限分支只有失败文字；增加有预算的纯文本恢复。兼容后的超长公式仍必须被拒绝进入KaTeX。

## 手动复核步骤

1. 作答题旁打开助教，不填文字直接请求提示；检查只在最终发送时出站。输入自己的问题再切换问法，文字应保留。
2. 发送时选择实际草稿或圈画；材料读取或落盘失败时应保留输入并明确重试，不得静默省略。等待期间继续写题，新回复不得改变焦点、滚动或纸面。
3. 主动读回复，查看材料依据；选一句话点「这一步没懂」，修改或发送追问。进入专注阅读再退出，检查只有一个活动编辑器、草稿和阅读位置保留。
4. 点「回题试一试」，在原位置补写一步；点「检查新步骤」，确认材料或写出文字步骤后发送。旧回信不能悄悄换成新稿。
5. 等第5题回复时去做第6题，从求助记录点第5题，检查同卷没有重新路由或重挂题面；回题后检查原阅读现场。再从我的记录打开队列，检查跨页直达正确任务。
6. 在iPad Safari上复核横竖屏、分屏、Pencil、软键盘、文字放大和VoiceOver；特别检查发送与交卷按钮、焦点返回及长公式。

最后一项仍需真机和目标学生试用；浏览器设备模拟、测试全绿和人工编写的示例均不能替代学习体验验收。尚未做3–5名目标学生的无指导任务试用，也不宣称减少摩擦已有统计数据。
