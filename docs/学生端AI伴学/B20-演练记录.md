## 3. 对发布的含义

- **恢复可靠**：从备份 zip 恢复后，AI 侧只有「备份时点已存在」的状态继续；
  备份窗口内产生的任务/票据/凭证轮换全部失效，迟到回执只留审计事实不写正文
  ——不存在「恢复后旧会话继续写新库」的路径。
- **降级不拖垮核心**：AI 四类故障（密钥丢失/文件缺失/GC/整体禁用）下普通
  作答、交卷、判分、结果证据全部照常；缺件显式报错不假成功。
- 密钥与数据同包：备份 zip 含 `secret.key`，恢复后页内连接 Key 解密封照常；
  若单独丢失 secret.key（未随备份），页内连接转 needs_rekey、学生重填即恢复
  （场景 A 语义），其余功能不受影响。
