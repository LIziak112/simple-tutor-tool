# 学生端 AI 伴学使用指南

适用版本：v2.2.0（学生端 AI 伴学首发）。面向教师与学生两类用户，描述**已实现**的行为与边界；需求全文见[需求规格](需求规格.md)，能力支持范围与限额总表见[发布说明](../releases/发布说明-v2.2.0.md)。

先记住一句话边界：**AI 伴学是平台唯一会把当前题「已有答案与解析」发给外部 AI 的功能，是否发送、以什么尺度回答由教学模式决定**。普通的取卷、结果页、错题本、导出不因此放开答案。

---

## 一、教师篇

### 1. 三种教学模式

在「设置 → 教学 → AI 伴学」设置你的默认模式；也可以在学生编辑、作业编辑里单独指定（覆盖关系见 §2）。

| 模式 | 学生作答中 | 本题完成后 |
| --- | --- | --- |
| 开放伴学 `open_study`（默认） | 可求助；按学生诉求启发、纠错、讲概念或完整讲解 | 可自由复盘 |
| 仅启发 `guided_only` | 可求助；提示词要求 AI 不直接给最终结果、填空答案或正确选项，着重下一步与当前错误 | 自动按开放伴学复盘 |
| 完成后可用 `post_submit_only` | 所有通道均不可新建或领取本题求助 | 自动开放复盘 |

**「仅启发」的真实边界（重要）**：它是写给 AI 的输出要求，**不是保密模式**——发送的内容与开放伴学相同，仍包含本题已有答案与解析；外部 AI 或学生自己掌握的其他工具可能读到原始答案，模型也可能不遵守提示词。需要作答期完全不接触答案的测验，请选「完成后可用」。

**「本题完成」的判定**：普通作业=交卷成功；自由练习/错题重练=本次练习提交成功；讲练=当前题提交成功（按题生效，一题提交不开放整份讲义）。填完答案、点交卷失败、收起纸面、到截止时间都不算完成。

**与答案公布时间的关系**：AI 伴学不沿用普通结果页的公布时间设置。开放伴学/仅启发在作答中就把答案解析提供给 AI（即使结果页还没公布答案）；「完成后可用」在提交后即开放复盘（即使作业设置为截止后公布）。设置「截止后公布」不会自动限制 AI——设置页会在你选择时同步提示当前 AI 策略的影响。

### 2. 多处设置如何合并

合并分两步，保证「关闭某个学生/某份作业」无法被另一处绕过：

1. **先判可用性**：学生或作业**任一处**明确设为「完成后可用」，本题未完成时即不可用；
2. **再判回答尺度**：明确的作业模式 > 明确的学生模式 > 教师默认 > 开放伴学。

设置页会显示**有效模式及原因**（如「本学生作答中不可用，来自学生设置」）；学生与作业都显示继承时，展示实际继承到的值。

### 3. 提示词模板

三种模式各一个模板（开放/启发/复盘），不写就用内置默认；可预览、可恢复默认。模板正文不下发给学生端（学生只看到模式名）。修改模板只影响之后的发送；历史任务保留当时有效模式与提示词，便于回溯。

### 4. 动态变更会发生什么

- 改模式**立即对后续操作生效**（学生刚刷新就遇到新规则，不需要等什么同步）。
- 开放/启发 → 完成后可用：未完成题的新发送、领取、链接正文与附件读取都会被拒绝；未外发任务停为「当前不可用，完成后可继续」，学生的问题和快照不丢弃。
- 已出站的内容无法追回。尚未展示的旧回信会收存，但在本题完成前不再向学生交付；已展示的内容不会假装被撤回，记录保留。
- 改回允许后，未完成任务由学生点「继续发送」，不会因你切换而自动外发。
- 改默认或模板不会覆盖学生自己自定义的快捷按钮。

### 5. 督学记录（怎么看学生用没用 AI）

批改详情页（教师端题目数据）的题卡上有 AI 状态标签，点开「记录」抽屉可看每题的求助事实：

- 事实包括：任务创建、外发（页内通道）、外部领取（MCP）、链接生成与读取、回信到达与展示、交卷前/后等——**只记录平台可确认的事实**。
- 「作答中求助·未处理」= 仅入队尚未外发，**不等于**已获得帮助；「无 AI 求助记录」**不能证明**独立完成（学生可用自己的工具）。
- 外部链接被读取时平台记录「外部读取」，但无法确认是谁读的、是否已辅导——如实显示「平台无法确认」。
- 缺失材料（如历史 PNG 已不可读）会显示明确的缺失原因，不静默跳过。

## 二、学生篇

### 1. 首次连接（设置 → 连接 AI，`/s/settings/ai`）

三种通道可同时配置，选一个默认：

| 通道 | 怎么配 | 适合 |
| --- | --- | --- |
| 页内 AI | 填外部 AI 的 OpenAI 兼容地址（baseUrl）、模型名、API Key；可选「模型能否看图」（未知/能/不能） | 想在作答页里直接问答 |
| 远程 MCP | 页面生成专用端点 + Token（点「重置」换新） | 用 Claude Code、Cursor 等客户端攒题批量处理 |
| 上下文链接 | 选默认有效期（最长 72 小时） | 把题目做成一次性链接粘给任意 AI |

- **首次使用前有一步知情确认**：平台会告知「本题已有答案和解析会一起提供给 AI」。确认一次即可，之后不再重复问。
- 页内 AI 的 Key 加密保存在你的部署服务器上，任何页面只显示指纹（前 8 位），不再显示明文；MCP Token 只在创建/重置时显示**一次**，请当场复制保存。
- 「模型能否看图」选**不能**时，带手写材料的发送会被拦截并提示（不会偷偷丢图）；选**未知**时发送前会有说明，允许只发文字。
- 连接测试按钮用 10 秒超时试连；Key 换填后验证状态重置，需重测。

### 2. 作答页求助（右侧伴学栏）

作答页题卡上的「AI 助教」按钮打开伴学栏（宽屏右侧栏；窄屏为可开合面板）。开关栏、改布局**不会**打断你正在写的字或丢草稿。

伴学栏从上到下：题目绑定（题号/快照时间）→ 通道与当前模式 → 快捷按钮 → 材料选择与补充问题 → 主操作按钮 → 本题对话 → 追问输入。

- **快捷按钮**：默认四个——「启发下一步」「查当前步骤」「讲核心概念」「完整拆解」，可在设置里自定义（最多 12 个）。仅启发模式下「完整拆解」会锁定并说明原因。
- **材料**：可勾选本题的圈画标注、草稿、正式手写（多页长稿逐页采集）；发送前能看到将发送什么。
- **发送**：页内通道点发送后任务进入队列并由服务器代发；MCP 通道是「加入队列」等外部客户端来领取；链接通道生成一次性票据 URL（复制给外部 AI）。
- **发送失败**：材料上传失败会明确提示并允许重试（重试只补材料，不会重复建任务）；断网/超时显示「发送结果待确认」，提供核对与显式重试——**重试前会提示可能重复计费**，平台绝不自动重发。

### 3. 追问

收到回信后在输入框继续提问即可：追问携带本题此前的对话与**你最初发送的那份材料快照**（不重新采集），同题最多 20 轮。

### 4. 助教队列（顶栏「队列」按钮）

两个角标含义分开：**待处理**（还没获得回信）与**新回复**（有未读回信）。面板里按 待领取/处理中/已回信/失败/暂停/取消 分组，可从任务跳回对应题目。任务可以取消（仅未领取的），但已出站的内容无法追回、不保证退费。

### 5. 结果页批量复盘

结果页头部有「AI 复盘」入口：默认勾选**明确判错**的题（待批题可手动加选，判对题不可选），一次最多 30 题。发起前页面明示费用语义：**N 道题 = N 次 AI 调用**（MCP/链接通道平台不会自动收到回复）。部分失败时只重试失败的那几题，成功的不重发。未公布成绩的作业整卷不可用（不泄露对错）。

### 6. 分享链接的注意点

- 链接**本身可读**（外部 AI 没有你的登录态）：获得链接的人可以读到题面、你的作答、答案解析与你选定的材料，**只发给可信的 AI 服务**。
- 默认 24 小时有效（可自选，最长 72 小时），可随时撤销；撤销/过期/题面变更后旧链接立即失效。
- 复制失败（如 HTTP 部署环境）会提供手动复制文字与材料下载的降级方式；外部 AI 是否真的读取了链接，平台只能记录「已被读取」，无法确认读取者。
- 当前版本刷新页面后不保留已生成的链接（防泄露设计：token 只存在内存），需要时在任务上重新生成。

## 三、常见状态与错误

| 你看到的 | 含义与处理 |
| --- | --- |
| 未连接 / 请先连接 AI | 没有可用连接（`AI_SETUP_REQUIRED`），去 `/s/settings/ai` 配置 |
| 老师暂不可用 / 当前不可用，完成后可继续 | 教学策略为「完成后可用」且本题未完成（`AI_POLICY_DISABLED`）；交卷后自动开放 |
| 发送结果待确认 | 出站超时等不确定态（`uncertain`）：先核对是否已有回信，再决定是否重试（重试可能重复计费） |
| 材料缺失或未成功上传 | 该页材料历史上传失败或文件已不可读；可重试上传，历史缺失如实显示 |
| 模型不支持图片 | 连接的「能否看图」设为不能又勾了手写材料；改为仅文字或更新连接设置 |
| 连接需要重新填写 Key | 服务器密钥变更导致无法解密（`needs_rekey`）；重填 Key 即恢复，不影响其他数据 |

## 四、数据与删除

- 任务、对话、留痕事实（谁在何时求助/外发/回信）**永久保留**用于教学回溯，本期没有删除入口。
- 材料图片随任务保留；正式手写作答证据（原稿）与 AI 功能无关、不受任何 AI 设置影响。
- 删除连接 = 该通道不可用；重置 MCP Token 后旧 Token 立即失效。
- 教师关闭 AI 功能不影响普通作答、交卷、结果查看（见发布说明「降级行为」）。
