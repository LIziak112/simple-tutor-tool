# AI 助教三种布局实施与验收记录

2026-10-21 · 实施分支 `inx` · 对应《AI助教三种布局与阅读交互方案》

## 已实施行为

- `/s/settings` → AI 求助偏好 → 助教显示方式：题下阅读、侧边对照、独立弹窗。卡片暂存、保存生效；取消不影响当前配置，失败保留编辑，跨标签修改不覆盖草稿。
- 本地偏好契约先行，来源／student角色／账号隔离。持久化内容仅为版本与布局；账号切换、退出重置内存身份，旧账号的迟到保存拒绝。
- 题下继续为兼容默认。侧边基于实际容器预算打开，空间不足保存本机稿后临时转弹窗，本次阅读不自动弹回。放大与还原不写偏好。
- 三种壳共用一份会话、活动正文及输入。侧边／弹窗的输入位于限高底区，正文独立滚动；弹窗适配 visualViewport，背景纸面保活，交卷栏不穿透。
- 分节基于完整文档解析、公式渲染及清洗后的顶级标题生成。首节展开，标题原地开合，支持展开全部／收起其余；引言、嵌套标题、代码与跨节引用定义不被切坏。
- 阅读状态保存在学生角色 Query 缓存中的内存容器，按任务、消息版本隔离。布局重挂恢复展开节及相对锚点，退出清角色缓存；输入继续使用既有草稿控制器。
- 工作区设置入口收笔落盘后进入设置，提供受限的「返回本题」来源；中文题目 ID 保留，未知参数与外站地址剔除。

## TDD 与真实问题处理

契约／存储／设置测试先执行失败（缺少实现），实现后 8 项通过。分节测试先执行失败（没有分节），实现后与现有安全渲染合计 19 项通过。展示集成测试先执行失败（弹窗、偏好及放大入口不存在），实现后 16 项通过。

## 质量闸门

本会话可用技能中没有 simplify、code-review、security-review 或 verification-before-completion 的对应入口，按仓库要求的顺序执行人工完整 diff 审查与真实命令验证，不声称调用了不存在的技能。

1. 复用与简化：会话与输入控制器复用；分节只在 AI 专用渲染链发生；来源过滤复用作业列表的已有过滤器；三种布局没有三份聊天状态或并行编辑器。
2. 正确性审查：核对默认兼容、身份与存储失败、降级锁定、焦点返回、布局切换前落盘、消息版本和中文题目定位。修复放大期间空间不足时还原仍为弹窗的焦点标志残留。
3. 安全审查：无新增接口和数据库结构；仅本地展示偏好持久化；渲染仍先全量预算与清洗后分节；不执行 HTML，不加载外部图片，不放宽链接协议、普通学生投影或三教学模式。来源路径受限，参数有界，不携带凭据。

纯视觉修改（标题合并、行距与材料说明字号）按规则豁免先写样式断言，由真实截图与窄屏流程检查。

## 手动验收路径与限制

学生设置保存三种布局，回原题分别打开；在侧边时缩窄到390px，确认转弹窗，拖宽后不反复搬动；关闭重开重新按偏好计算。读取包含至少三节的回复，展开第二节，输入半句追问，放大还原，关闭重开，再去设置更换布局并返回，核对题号、材料轮次、文字与阅读位置。新回复只提示，主动查看才切版本；布局操作不得创建 AI 任务或采集材料。

浏览器验证覆盖 320px、390px、768px、1024px、1440px，使用真实页面与假 AI 供应商。Pencil 真机、iOS 实际软键盘、VoiceOver 及系统200%缩放尚未实测，不能用浏览器模拟结果宣称这些项目通过。
