## 完整 diff 审查

环境没有提供 `/simplify`、`/code-review`、`/security-review` 对应可用技能，按相同目标依次进行了人工审查；未虚称调用技能。

1. 简化：复用已有出站目标守卫、错误归一、契约类型和 HTTP 可用的 UUID 生成器；链接复制共用单一说明生成入口；连接列表移动时保持节点身份。
2. 正确性：补齐空回复不能判测试成功、改模型清除验证状态、迟到探针拒绝写回、MCP 不提交链接专用字段、正文中断不悬挂等用例；均先失败再修复。

已知边界：本站可保证每次收到请求时重新校验、禁止缓存，不能强制第三方 AI 发出请求或清除其缓存；页面如实说明，并要求核对题号/题干。实际供应商测试使用隔离 fake provider，未动用用户密钥或产生付费调用。

## 手动验证

1. 学生进入设置 → 连接 AI，填写服务商 API 根地址和 Key；核对页面列出的最终 GET/POST 地址。
2. 点击获取模型列表，搜索/选择模型；不支持列表时手填。点击测试当前配置，确认收到回复与耗时，再保存。
3. 修改模型或 Key，确认旧成功结论消失；改地址后不填新 Key 不能复用旧凭据。错误时输入保留，可修正重试。
4. 保存后测试连接，刷新确认状态持续存在；取消修改后切换 MCP，核对完整配置复制及 Token 重置确认。
5. 为不同题目分别生成链接，一起发给支持联网的 AI；确认复制内容要求逐条重读。查看访问统计，再撤销链接确认公开读取立即拒绝。
6. 在 320/820/1280px 检查无横向溢出，键盘依次访问字段和按钮；测试网络中断后可重试。
