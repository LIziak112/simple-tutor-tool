## 手动验证

1. 学生进入设置 → 连接 AI，填写服务商 API 根地址和 Key；核对页面列出的最终 GET/POST 地址。
2. 点击获取模型列表，搜索/选择模型；不支持列表时手填。点击测试当前配置，确认收到回复与耗时，再保存。
3. 修改模型或 Key，确认旧成功结论消失；改地址后不填新 Key 不能复用旧凭据。错误时输入保留，可修正重试。
4. 保存后测试连接，刷新确认状态持续存在；取消修改后切换 MCP，核对完整配置复制及 Token 重置确认。
5. 为不同题目分别生成链接，一起发给支持联网的 AI；确认复制内容要求逐条重读。查看访问统计，再撤销链接确认公开读取立即拒绝。
6. 在 320/820/1280px 检查无横向溢出，键盘依次访问字段和按钮；测试网络中断后可重试。
