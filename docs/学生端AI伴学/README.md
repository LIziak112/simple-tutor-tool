# 学生端 AI 伴学：需求与开发入口

日期：2026-10-15。当前范围：默认开放、单题上下文、三种督学模式、三种连接方式、右侧伴学栏和客观求助留痕。

本文件夹是本扩展唯一的现行文档入口。需求、任务分解和验收材料分工如下，不保留旧决策或另设一份相互竞争的计划。

1. [需求规格](需求规格.md)：定义产品行为与边界。
2. [开发总清单](开发总清单.md)：36 项任务、21 个推荐会话批次、执行纪律及派单模板。
3. [批次目录](批次/)：每批完整任务说明，包括输入、实施步骤、测试、停止条件和交接。
4. [验收记录](验收记录.md)：当前进度、实际提交与验证结论。未验证不得勾选通过。

GLM 新会话从开发总清单选择一批，只加载需求规格相关章节、当前批次、依赖的验收结论及本批涉及代码。不要让它一次实现全扩展，也不要把一批中几个任务压成一个无法分别验收的大改动。

B00 只调查并产出技术设计。B00 审核后再固定契约名称、接口和限额；后续批次不重新发明这些约定。技术实现方案应保存为本文件夹内的“技术实施方案.md”，目前尚未生成，也不代表本轮已经执行 B00。

所有任务尚未开始。本文档整理未修改业务代码、数据库或项目规范，未调用外部 AI 发送数据。
