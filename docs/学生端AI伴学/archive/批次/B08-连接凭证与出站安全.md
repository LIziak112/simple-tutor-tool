## SAI-16

**连接凭证与出站安全**。前置：05、13、15。

### 目标与文件

独立安全会话，建立连接配置和外发能力，不在本任务开发 UI 或真实收费调用。读 B00 端点/Key/认证/恢复设计、现有 config/secret.key/backup 白名单、API token 和日志中间件。

新增 connector、credential、outbound-target 相关模块与测试，按需生成契约/迁移；不能把凭证随手加进 app settings 明文 JSON。

### 实施步骤

1. 账号可保存多个已批准通道配置，指定默认；连接元数据、模型图像能力与验证状态各自明确，不凭 token 存在宣称在线。
2. 按技术设计实现 Key 生命周期：保存/更新/撤销、认证加密与版本、恢复缺 key 的可操作状态；异步承诺与 key 可用生命周期匹配。
3. MCP/分享凭证高熵、分用途、哈希存储，首次明文创建响应与普通列表分开；不能用学生登录链接 Token 复用。
4. 出站端点按批准目标范围、协议/端口/URL 用户信息限制，重定向与实际连接地址受控。一次 DNS 校验不能替代连接级防护。
5. 内网/localhost 仅管理员显式批准场景，不推断云服务器能访问学生设备。
6. 日志屏蔽 Authorization/Key 与含 share secret 的 path；异常响应不透传供应商请求头/堆栈。
7. 删除连接停未执行任务并保护历史事实；还原备份后对旧外部凭证采取已批准失效/重连策略。

### 攻击/故障用例先写

| 类别 | 断言 |
| --- | --- |
| secret | list/detail/error/log/URL 均无明文 Key，只有创建响应允许一次 token |
| 鉴权 | 跨学生、跨教师、Cookie/外部 token 混用不能管理连接 |
| SSRF | localhost/私网/IPv6映射/link-local/云元数据、重定向、DNS 重绑定按真实连接策略拒绝 |
| key | 错密文/缺解密材料可解释，不能无限重试或泄露 |
| restore/revoke | 旧凭证不复活，迟到任务不能恢复删除的连接 |
| capability | 未验证不当图像支持，测试连接不自动带题面 |

### 完成条件

- [ ] 保存配置不发送学生题目；真实测试调用需要另有授权。
- [ ] 已确定可用供应商/自定义端点范围明确，不宣称支持任意 Webhook。
交接威胁表、连接/凭证 API、密钥备份语义、错误与限额；停止 B08。
