# B15 上下文链接闭环

同一会话范围：SAI-28 → SAI-29 → SAI-30。先读[总清单](../开发总清单.md)、[需求规格](../需求规格.md)、技术实施方案和[依赖验收](../验收记录.md)，提交准确计划等确认。每个任务单独测试/提交，通道闭环后停止。真实客户端缺环境时保留待人工，不用mock冒充完成。

## SAI-28

**分享票据生命周期**。前置：15、16。

### 输入与文件

读需求§10、SAI-15/16，新增分享票据服务与测试，必要结构改动先contract再生成迁移。

### 实施步骤

1. 创建票据只能由本人已登录、当前有效模式允许的主动操作发起，绑定一个不可变题目/材料快照。
2. 票据高熵、哈希保存，区分MCP/登录Token；有效期、撤销和重建遵循B00限额。
3. 一个旧链接永远不无提示改指新题；重建新票据保留本次问题，旧链接状态明确。
4. 读取不领取队列、不切当前题、不视为学生已读/AI已回复；不做“第一次GET就销毁”，兼容预览和图片重取。
5. 每次正文/附件读取核对票据、作答、当前禁用与作废；不能只在创建时核权限。
6. 访问事实与任务创建事实分开，对预览/本人/AI来源无法确认时只记未知。

### 先测

- 猜票据、过期、撤销、跨账号/题/附件、重开后旧卷、老师中途关闭全部拒绝。
- GET重复、HEAD、链接预览不消耗任务或生成回复事实。
- 重建后原链接仍旧快照或失效，不悄悄返回新稿。
- share secret无法兑换MCP/管理连接/列出本人其他任务。

### 完成条件

- [ ] 创建、复用/重建、到期、撤销的状态和副作用都有测试。
- [ ] 票据不无期限公开个人全部作答。
交接票据API、生命周期、读取授权服务，供下一任务只通过该入口访问。

## SAI-29

**分享正文及附件**。前置：09、11、28。

### 输入与文件

在SAI-28票据与SAI-09/11快照之上提供外部AI可读内容。新增分享正文/附件路由与测试，检查app中间件、PWA/反代缓存和日志。

### 实施步骤

1. 输出题号/快照时间/有效模式、题文、参考、学生问题和选定材料；只装配该票据快照，不从最新题库重新拼。
2. Markdown/简洁HTML的实际选择按B00实现；公式原文可用，图片链接只指向本票据授权附件。
3. 本文授权答案解析可出现；学生姓名/内部ID/绝对路径/教师私注/其他题不能出现。
4. 正文和每张附件独立调用票据当前权限校验，过期/撤销后直连图片也拒绝。
5. 设置不缓存/不索引/Referrer策略，PWA不缓存该路径；检查服务端以及反代的path脱敏，不能只清查询参数。
6. HEAD不记正文已读取；GET成功只记未知来源读取，图片缺失有明确说明，不用空白图假成功。
7. 错误用安全内容，不能在异常页打印快照、secret或文件路径。

### 先测

- 正文过期、附件仍被直接请求：同样拒绝。
- 同题答案媒体可用，私注/邻题媒体不在清单或错误里。
- 应用日志捕获无token/path secret；缓存配置匹配请求方式。
- 图片路径穿越/替换ID/错页号不能读其他文件。
- 多次预览/附件读取不导致重复求助题数或AI已读。

### 完成条件

- [ ] app.request/HTTP测试验证实际headers与二进制权限。
- [ ] 原media/blobs访问规则不被全局放宽。
交接实际URL模式、headers、反代/Service Worker配置和泄露测试。

## SAI-30

**链接发送与降级**。前置：20、23、29。

### 目标、文件与入口

让链接通道与单题侧栏统一。修改侧栏主动作/连接说明，新增链接查看撤销与复制下载组件；复用合规材料导出，不新建无门禁下载路径。

### 执行步骤

1. 选链接通道后主动作只有“复制AI链接”；快捷按钮按本次意图创建同题快照/票据，成功复制真实反馈。
2. 生成成功但复制失败时保留已生成链接，提供手动复制，重试复制不再新建任务/事实。
3. 显示题号/生成时刻/有效期与获得链接者可读答案解析说明，不以“仅AI可看”误导。
4. 过期/撤销后可主动生成新链接；仍需当前权限，不因为上次创建过而永远开放。
5. 外部读取失败提供复制本题文字、下载所选图片/材料；同一AI外发策略与留痕适用，不替换原有普通导出行为。
6. 目标AI实测可读/图片能力写兼容记录；若只有外部回复，平台不显示回信内容也不标已收到。
7. 从侧栏复制/下载不能影响草稿/圈画工具或退出编辑，失败保留输入。

### 必须先测

- 剪贴板失败/权限拒绝/HTTP不支持，与生成失败区分。
- 仅完成后可用未完成时，复制文字/下载AI包同样拒绝。
- 复制成功无抓取、被预览抓取、真正外部读取均不冒充AI已回信。
- 换题/换账号不复制上一题新链接，旧票据不自动切换内容。
- 缺图/超限先减选确认，不用下载静默缺件材料。

### 完成条件

- [ ] 单题链接与降级可端到端使用，所有成功文案有实际操作依据。
- [ ] 用户仍需把链接交给外部AI，不承诺一句“看题”必刷新缓存。
交接真实读取限制、复制/下载测试与人工待验；停止B15。
