# B09 页内AI与连接设置

同一会话范围：SAI-17 → SAI-18。必读[总清单](../开发总清单.md)、[需求规格](../需求规格.md)、B00 技术方案和[依赖验收](../验收记录.md)。先出本批准确文件/步骤/测试计划等确认；批内分别 TDD 与提交，结束停止审核。

## SAI-17

**页内AI异步执行**。前置：09、11、12、16。

### 输入与文件

首条完整模型执行链路。读已确认 provider 协议、SAI-12/15/16。新增 provider adapter、worker、fake provider/HTTP fixture 测试；在 `index.ts` 启停接入，不在 app.ts 导入时启动后台任务。

### 执行步骤

1. adapter 接收服务端批准的单题上下文/选定图片，不直接按客户端 messages 原样代理。
2. 统一请求格式、图像能力、回复/usage 与错误归一；供应商异常只暴露受控错误。
3. worker 仅领取页内类型任务，有界全局/学生并发和超时，事务外 fetch；领取/发送/事实/写回走共享服务。
4. 429/临时 5xx 有限退避并尊重供应商指引，Key 无效/策略变化不重试；网络失联可能已收费时明确状态不明。
5. close/restore/revoke/cancel 可中止后续交付，并验证 lease/context/generation 后才落结果。
6. 先保证完整回复入库和安全展示语义；如采用流式，明确部分输出/失败/禁用后的行为，不在流式路径绕过模式校验。
7. 暴露可注入时钟/transport/worker runOnce 供确定性测试；生产调度由单入口管理，不能开发热更重复启动。

### 必测

- 正常文字与多图、provider 结构损坏/超大响应、模型不支持图且学生未减选时阻断。
- 429→按时重试→成功；401 直接需重配；Retry-After 不导致失控长阻塞。
- 两 worker 不重复交付，过期 lease 写回拒绝；未知收费状态不自动无限重发。
- 页面关闭仍按承诺执行；重启恢复；恢复库旧回执/取消后回信不越权展示。
- 作答保存请求仍可及时处理，无同步阻塞 Hono 主线程。

### 完成条件

- [ ] fake provider 走实际 HTTP/装配/队列链，而不是直接改 DB status。
- [ ] 模型结果不能改变 answerJson/判分或提交状态。
- [ ] worker 停止/启动测试无悬挂定时器和重复实例。
交接首发协议、实际支持能力、worker 生命周期与故障测试；真实模型人工留 B19。

## SAI-18

**学生连接设置**。前置：08、16、17。

### 输入与文件

把已可用页内连接变成学生可配置体验。修改 `StudentSettingsPage.tsx`、实际前端路由，新增 AI connection page/queries/components 与测试；使用 Hono 端到端类型，复用 TanStack Query。

### 实施步骤

1. 在 /s/settings 增加连接 AI，页内选择批准端点/模型、录入 Key、测试、保存/删除、默认通道。
2. 首次说明发送目的地、默认已有答案解析、材料可能含姓名、费用；说明确认与通道偏好保存到正确账号。
3. 连接测试只做批准的无题面探针；已配置/验证成功/暂不可用分开显示。
4. 删除/重配 Key 不回显旧明文；复制敏感凭证功能未来由对应通道接入，不留假按钮。
5. 从题卡进入设置保留来源题与未发送输入；设置成功回题后由学生再次主动发。
6. MCP/链接配置尚未完整可用时明确说明进度，不显示“已连接”；B14/B15 在同页补真实引导。
7. 保留其他手写设置和学生路由守卫，不把账号内部 UUID 暴露到界面。

### 先测

- 新账号默认未连接，不默认已同意向任何目的地发送。
- 首次设置失败/测试失败/保存失败保留输入与可操作错误；Key 字段只显示安全状态。
- refetch 不覆盖脏编辑，版本冲突不吞改动，换账号缓存立即隔离。
- 配置成功返回原题，不自动发半成品；普通导航放弃确认正确。
- 复制失败有反馈，HTTP 剪贴板不支持时可手动处理，不虚报成功。

### 完成条件

- [ ] 真实设置路由 get/save/test 可联调，组件用例覆盖失败/返回流程。
- [ ] 已授权连接知情后不逐题重复确认，但数据外发仍需主动操作。
- [ ] 学生设置和墨感页回归通过。
交接页面路径、query keys、首次知情状态与路由测试；停止 B09。
