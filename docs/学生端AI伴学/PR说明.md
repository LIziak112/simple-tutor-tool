## 问题 / 结果行为

一对一辅导场景里，学生希望在作答中向 AI 求助，但教师必须能控制「谁能用、什么时候能用、AI 以什么尺度回答」，且平台不能因此放开普通接口的答案保护。本 PR 交付：

- **三种教学模式**（open_study 默认 / guided_only 仅启发 / post_submit_only 完成后可用）：两步合并裁决（任一处「完成后可用」即关死；尺度按 作业>学生>教师默认），出站/领取/票据读取前按**当前**模式与完成态实时重校验——教师刚改设置立即生效。
- **受控 AI 出口（唯一授权例外）**：允许时把当前题题面、已有答案解析、本人作答与选定材料发给**学生自己配置的外部 AI**；教师私注、其他学生数据、内部 ID 与凭证结构上不进装配。普通学生接口的防泄露投影（assertNoLeak 族）零放宽。
- **三通道**：页内（OpenAI 兼容非流式，服务端代发）/ 学生 MCP（`/mcp/student`，Bearer+Streamable HTTP，四工具攒题领取写回）/ 上下文链接（一次性票据 URL，短有效期+可撤销+读取留痕）。
- **可靠队列**：幂等创建、配额、租约、代际 CAS——迟到回执只留审计事实不覆盖；备份恢复后旧代回执拒写新库（B20 真实演练实证）。
- **督学留痕**：只记服务端可确认事实（外发/领取/读取/回信/交付），「无记录≠独立完成」「仅入队≠已获帮助」如实呈现。
- 普通作答、交卷、判分、结果、导出**行为零变化**（AI 关闭/故障时全链路照常，演练实证）。
