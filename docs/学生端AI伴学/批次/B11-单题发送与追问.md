# B11 单题发送与追问

同一会话范围：SAI-20 → SAI-21。按[总清单](../开发总清单.md)先确认本批计划，读取[需求规格](../需求规格.md)、技术实施方案和[验收记录](../验收记录.md)。逐任务独立验证/提交，本批完成停止，不进入下一批。

## SAI-20

**单题发送控制**。前置：13、15、19。

### 输入与文件

读需求 §4、§5.2、§6、§7.4，SAI-13/18/19。新增 panel/session 输入控制器、按题草稿状态与 queries，题卡入口接入真实服务。

### 顺序实施

1. 打开 AI 只绑定账号/attempt/response，载入历史与默认通道，不发送；滚动题目不自动重绑。
2. 按题保存未发送文字、附件选择和选中的 preset；主动点别题 AI 才切换，回来恢复该题输入。
3. 顶部显示题号、模式原因、通道、当前快照，主按钮按通道显示发送/加入队列/复制链接，不出现两个同义按钮。
4. 快捷点击用其 prompt/附件默认即发；单次改附件只影响这次，不回写预设。
5. 发送前检查连接与首次知情；需要设置时保留全部输入和来源，回题不自动出站。
6. 正式发送调用固定材料采集及任务 API，以一次动作一个幂等键；重复点击复用它，采集/请求失败不清输入。
7. 仅启发的完整拆解说明完成后可用，学生自定义 prompt 不能改变服务端模式；当前禁用给原因并刷新状态。
8. 通道变更不重发，已在途任务保持原通道；来源/账号变化取消当前本地采集回调。

### 先测

- 只打开、滚动、看历史、换通道没有 create/provider调用。
- A题打字→点B题→回A：两题文字与附件不串。
- 连接未设→完成设置→返回：输入在、调用数仍为0。
- 连续点三次只建一任务；失败重试不生成重复收费动作。
- 刚写后发送包含最后正文，材料失败保留所有状态。
- 模式被老师关闭、换账号或讲练重开途中迟到结果不进入新题。

### 完成条件

- [ ] 真实 task API 联调，非静态演示按钮。
- [ ] 任务进入待处理后输入清理/保留策略明确，失败不会丢。
交接输入隔离键、发送状态图、幂等键生命周期和测试。

## SAI-21

**安全回信与追问**。前置：14、17、20。

### 输入与文件

把回信/追问接成可用本题对话。读需求 §7–9、SAI-14/17/20；复用本地 Markdown/KaTeX，但给 AI 回复专用受限模式。新增 feedback/history/追问组件与可复跑测试。

### 实施步骤

1. 同题消息按任务版本/发送时间呈现，显示材料时间和当时模式；只有收到反馈才显示真实回复。
2. 追问绑定同一题对话，允许主动采集新稿；未选更新时明确基于原发送材料，不悄悄附新笔迹。
3. 查询按账号/attempt/response隔离；页面可见时按 B00 限额增量查询，后台暂停/错误退避，不重解析整个题面。
4. 回信到达更新轻提示/未读，不抢焦点、不自动滚动主区或展开长文；学生打开时记一次查看事实。
5. 只渲染安全内容：禁原始脚本、危险链接、自动远程图片、可执行题块/工具等；公式/节点/字节超限给可解释失败。
6. 暂停/失败/取消/外部未知各有真文案；禁用期间不通过历史/轮询取得未获准交付的反馈。
7. AI建议不写 answerJson、不触发判分/提交；“不符合启发要求”可按批准需求记录反馈，若需新字段先改契约。

### 先测

- provider 回信入库后刷新可见，收到未打开与已打开可区分。
- 新稿追问前/后两任务的快照不覆盖，跨题历史不入模型。
- XSS/危险URL/远程像素/交互directive/超大公式不执行、不阻塞题面。
- 新回复期间学生正在画/打字，焦点、光标与画布 identity保持。
- 隐藏页无持续轮询，恢复只核对状态不重发。
- 外部链接没有平台回信时显示外部未知，不伪造已完成。

### 完成条件

- [ ] 一个真实 fake-provider 页内闭环可演示发送→回复→追问→刷新保留。
- [ ] 原普通 Markdown交互语义不被全局禁用。
交接受限渲染范围、query策略、追问上下文规则；停止 B11。
