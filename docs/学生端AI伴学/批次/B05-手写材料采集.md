## SAI-10

**手写材料采集**。前置：03、09。

### 目标、必读与文件

这是独立高风险会话。读需求 §4.2、§7.2，根 AGENTS.md 手写/标画约定，当前 `ongoing-question-export.ts`、`render-ink-snapshot.ts`、`AttemptEditorContext.tsx`、notes/annotation session 与 sync 代码。

从现有导出抽取共用材料采集，不重写绘图算法。拟新增 AI capture 控制器及测试，保留已有单题导出入口。

### 精确执行顺序

1. 发送动作锁定账号/session epoch、attempt、response、阶段、材料选择；采集全过程检查这些标识未变化。
2. 对选定题当前正在进行的笔画收笔，只等待相关题/阶段本机落盘；不能等待整卷全部同步，也不能跳过本机保存失败。
3. 确认材料恢复完成、没有待裁决冲突；本机旧键迁移仍走现有归属流程。
4. 读取固定矢量/底图/布局与当前本人答案，收起或卸载画布仍从持久材料读取，不把“没挂载”当空。
5. 分别走草稿/正式手写与圈画的正确重绘入口，长稿完整分页；圈画保持原底图 CSS 几何，预测点不入图。
6. 输出含版本、页序、尺寸、来源类别和字节的快照草案；不改变正式稿/交卷证据指针。
7. 任一步失败或账号/题变化则停止并给明确缺件原因，保持原稿/undo/输入；明确仅发文字才可减选重来。
8. 同一采集重试不在后台再抓最新稿冒充原稿；是否主动更新由发送控制器决定。

### 必须先测的真实风险

- 最后一笔尚未落盘点击发送，输出包含已收笔正文，预测段不存在。
- 本机比云端新、材料收起、画布已释放：仍取正确本机固定内容。
- 本机写入失败、恢复失败或冲突：不发送、不清稿、不显示空附件成功。
- 圈画已保存底图和当前题面换行不同：仍用配套底图，不拉伸笔迹。
- 长稿多页、草稿+圈画同时展开、正式手写题：页序/类别不混。
- 采集中换账号/切题/讲练重开：迟到图片被丢弃，不能进入新题。
- 字体/图片读取失败：明确失败可重试，不生成空白假成功图。
