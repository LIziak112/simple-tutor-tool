# B03 师生设置界面

同一会话推荐顺序：SAI-07 → SAI-08。必读[总清单](../开发总清单.md)、[需求规格](../需求规格.md)相关章节、B00 技术方案和[依赖验收](../验收记录.md)。本批先列准确文件/步骤/测试，经确认后逐任务实施；绿色检查点后继续同批，结束停止等审核。

## SAI-07

**教师设置界面**。前置：06。

### 输入与修改范围

读需求 §3、§5.1、§11，SAI-06 实际路由，现有教师 `SettingsPage.tsx`、配置控制器、学生管理、作业布置/编辑和 Portal 主题实现。

在实际设置组件接入三模式/模板，在学生与作业编辑加继承单选及来源说明；新增 AI 子组件与对应测试。不要重建一套教师导航或把所有配置压进巨型页面。

### 执行步骤

1. 查询原始和有效配置；显示“继承（当前：…）”，区分从哪里关闭。
2. 模式与模板只修改本地草稿，点击保存才调用接口；服务器重取不覆盖脏草稿。
3. 模板可预览与恢复指定默认；恢复前说明替换范围，保存失败保留编辑。
4. 学生/作业编辑显示另一对象明确关闭的影响，不把“我选开放”误称最终开放。
5. 与 answerRelease/dueAt 放在可看见的关联位置，说明 AI 复盘可能早于普通公布。
6. 复用离开确认与设置控制器持续挂载，教师主题内弹层、键盘焦点与窄屏布局一致。

### 必须先测

- 模式默认开放、继承来源可见，学生关闭+作业开放仍显示关闭原因。
- 未保存切分类再回来仍在；后台 refetch 不覆盖；保存成功清脏，失败保留。
- 模板恢复只影响当前模板；版本冲突不自动用服务器覆盖输入。
- 非管理员普通教师可管理本人教学配置，不能借 UI 进入系统管理或其他教师范围。
- 1024px 以下、长模板/中文标签和键盘操作可用；说明不依赖 hover。

### 验收与交接

- [ ] 用真实路由联调一次 get→暂存→save→refetch，不只 mock 一个静态页面。
- [ ] 原 teaching/backup/account 分类与现有未保存保护无回归。
- [ ] 不新增课程提示词分类，不展示内部 UUID。
交接实际页面路径、组件测试名、相关浏览器步骤和截图/待人工项。

## SAI-08

**学生快捷按钮管理**。前置：05、06。

### 输入、文件与目标

读需求 §5.2、SAI-02 的预设契约及现有学生设置守卫。新增学生 preset service/route 和 `apps/web/src/features/student-ai/` 下管理组件，接入账号设置；当前发送行为留给 SAI-20。

### 执行步骤

1. 无配置时返回一个契约来源的四个默认预设，不每次查询写四条记录。
2. CRUD/排序/启用与附件偏好归属当前学生；所有更新通过同一契约并采用 B00 并发编辑规则。
3. label 与 prompt 分开编辑；附件分别区分圈画、草稿、正式手写，不用一个 includeCanvas 混淆三类材料。
4. 支持删光，仍保留自由输入说明；恢复默认前列明将替换个人修改。
5. 跨设备重取反映已保存配置；有本地未保存编辑时不覆盖，离开给放弃确认。
6. 仅启发下预设元数据可以编辑，但界面预览说明实际发送仍服从教师模式，不删除学生自定义内容。

### 先测

- A 学生无法读取/更新 B 学生预设，学生请求不能带 teacherId 更新教师模板。
- 新账号默认值一致；删除全部后刷新仍空，不偷偷回填。
- 添加、改名、改提示词、改附件、禁用、重排均保存并恢复。
- 空白/超长/重复 ID 与过期版本有明确错误，不部分写入损坏列表。
- 恢复默认取消无副作用；确认后四项和顺序正确，其他连接偏好不被重置。
- 长中文名称换行/截断有完整可查看内容，不撑破管理页。

### 验收与交接

- [ ] 服务与页面真实往返，有错误及空状态。
- [ ] 不把老师不允许的操作通过隐藏按钮当唯一控制。
- [ ] 发送前单次改附件不自动持久改全部 preset，契约能区分两者。
记录新增路由、默认来源、账号隔离与管理测试；停止 B03 等审核。
