# B06 材料存储与任务队列

同一会话推荐顺序：SAI-11 → SAI-12。必读[总清单](../开发总清单.md)、[需求规格](../需求规格.md)相关章节、B00 技术方案和[依赖验收](../验收记录.md)。本批先列准确文件/步骤/测试，经确认后逐任务实施；绿色检查点后继续同批，结束停止等审核。

## SAI-11

**AI材料存储与引用**。前置：05、10。

### 输入与文件

把 SAI-10 输出变成可供异步处理的固定材料。读 B00 文件/DB一致性、留存设计、现有 blob I/O、note/ink/annotation GC 和备份引用。拟新增 `student-ai-materials.ts`、受控读取服务与临时 DATA_DIR 测试。

### 执行步骤

1. 服务器验证上传与选择属于当前账号/attempt/response/阶段；客户端 PNG 只作“学生材料”，不作可信判分。
2. 校验格式、字节、页数/尺寸及约定摘要，不能信任 Content-Length 或客户端路径。
3. 用不可变目标和安全写入顺序保存文件，核对成功后一次登记完整清单；失败不产生可访问半成品。
4. 引用原有不可变材料时添加引用保护；需要复制时放 DATA_DIR 约定命名空间，不读任意文件路径。
5. 每次取附件再验证归属、当前教学策略/分享票据；主任务不可读时附件也不可读。
6. 明确缺件/超限给调用方，保留可重试信息；不自动把缺失材料视为“不存在”。
7. 清理按留存安全窗口和全部当前/备份引用判定，不能删正式证据或还被任务引用的版本。

### 先测与验收

- 伪造 source ID、跨题/阶段、路径穿越、无效 PNG/超大 chunked 请求拒绝。
- 第二张文件写入失败时任务不能读到一张就假称完整；孤儿安全可回收。
- 上传后源本机继续编辑，原任务内容仍固定。
- 删除/取消任务后，仍被其他任务、正式稿或备份引用的文件不能删除。
- 当前禁用、作废或票据撤销时原附件 URL 不再可访问。

- [ ] DB/文件一致性故障测试使用真实临时文件，不只 mock 成功。
- [ ] 暴露清单没有绝对路径和不属于本题的私密媒体。
交接命名空间、引用/清理规则、故障测试和备份接入点。

## SAI-12

**可靠任务队列**。前置：04、05、11。

### 输入与文件

在 SAI-11 固定快照之上实现可靠队列，供 worker 和 MCP 共用。拟新增 `student-ai-queue.ts` 与临时文件 SQLite 多连接测试；遵循 B00 已确认状态表，不在本任务重新造另一套状态。

### 操作与语义

1. 创建：同学生相同 requestId、相同内容返回同任务；同键内容不符冲突。不同题/账号不能互相去重。
2. 列表：本人、按题/作答范围、稳定游标；查看/归档时间与处理状态独立。
3. 领取：短事务筛选符合时间/通道/权限的任务，条件写 lease/代次；网络、大图编码都在事务外。
4. 续租：校验当前持有者、代次、任务状态与总时长；不能无限占用。
5. 写回：核对任务、租约、contextVersion、反馈幂等键；首次成功后不被迟到回执覆盖。
6. 重试：仅可重试错误按有界次数/nextRunAt 执行，鉴权/策略错误不盲重试；失联过期可再次领取。
7. 更新 pending：必须是明确更新动作，产生新上下文版本；已领取拒绝替换。
8. 取消/暂停/恢复：保留请求与事实，取消不能承诺撤回出站；重新开放不自动发送。
9. 配额：单学生/教师积压与频率、分页/领取数遵守契约，超额不无限创建。

### 必须先测

- 两个实际 SQLite 连接同时领取同任务：只有一个有效 lease；同批重放不会抢新一批。
- 超时再领后旧 lease 不能回信/续期；同反馈重放成功、不同正文冲突。
- 取消与完成、更新 pending 与领取、重试与重复创建竞态均有唯一合法结果。
- 进程关闭/重开后就绪/过期任务可恢复，已完成任务不重复执行。
- 一学生大量排队不长期饿死另一学生；领取 MCP 类型不被 API worker 抢走。
- 当前权限在领取前校验，事务不因 mock 时钟或持锁等待挂死。

### 完成条件

- [ ] 状态转换集中实现，路由/worker/MCP 不能直接 set status 绕过。
- [ ] 不把 archived/opened 当任务终结状态覆盖 replied。
- [ ] 所有并发用例有可复跑证据。
交接操作 API、状态图/错误码、重试/幂等规则与测试；停止 B06。
