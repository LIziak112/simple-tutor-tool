# AI 回信格式检查器

用于 #54 的数学公式格式纠错。检查格式和 KaTeX 可渲染性，不判定数学结论正确与否。

## AI 的操作步骤

1. 调用 `claim_ai_task`，读取 `replyFormat.instructions`、规则版本和 `manifestUrl`。
2. 获取清单，对照平台下载文件，校验清单中的 SHA-256。文件地址为清单同目录下的 `<version>/<name>`。
3. Windows x64 运行 `ownclass-ai-check.exe reply.md --json`。其他已有 Node ≥24 的环境可运行 `node ownclass-ai-check.cjs reply.md --json`。无需源码或 node_modules。
4. 按 `issues` 的行列、错误码和建议修改，再检查；不要自行修改检查器或删除检查规则。
5. 无 error 后，将同一文件的正文传给 `submit_ai_reply`。warning 需自行复核；检查后若又改正文，重新检查。
6. 无本地执行环境时调用 `check_ai_reply({ replyMarkdown })`；它不领取、不保存、不续租、不标记已回复。
7. 最终提交仍执行服务端检查。error 返回 `AI_REPLY_FORMAT_INVALID`、`_issues` 和版本，不结束当前租约，可修正重提；临近租约到期调用已有 `renew_ai_lease`。

规则版本不匹配时重新获取当前清单。程序不自动联网升级，不向检查器传认证凭据。普通学生接口不因检查工具开放题目答案。

## 公式写法

行内：`结果为 $-\frac{1}{2}$。`，不要跨行。

独立公式：

```text
$$
\lim_{x \to 0} \frac{\sin x}{x}=1
$$
```

兼容 `\(...\)`、`\[...\]`；代码区域的内容不参与数学检查或规范化。字面美元符号写为 `\$`。

诊断的行列从 1 开始，字符位置以原文 UTF-16 码元计（CRLF 保留；CLI 去除文件开头 BOM）。error 是明确损坏的公式或超过预算；疑似裸 LaTeX、含义不明的美元符号以及疑似误配中文的公式给 warning。边界可疑的公式在页面按文字显示，不猜补。最多返回 50 条诊断，超过诊断预算要求分段整理。

退出码：0 无 error，1 正文格式错误，2 调用或文件读取错误。`--version` 查看规则版本，`--help` 查看用法。只读指定文件，不自动改稿或提交。

## 截断与历史回信

服务器保留既有 `AI_REPLY_MAX_CHARS` 截断规则（32×1024 个 UTF-16 码元，并非 UTF-8 字节）。原始输入先校验；截断后的实际内容再检查，截断导致的公式损坏返回 `TRUNCATED_MATH` 警告。页面隔离坏片段，原始已保存正文不被修改。

历史及页内 AI 回信同样使用显示兜底。能识别的独占行裸公式继续兼容；不完整或不可渲染的片段显示为代码文本，无法可靠分割时扩大到受影响行或块。正常公式继续显示；原文按有界纯文本查看。既有字节、公式、节点预算、图片禁用、链接和 HTML 清洗保持有效。

## 构建与部署

- `pnpm checker:build`：生成独立脚本及清单到根 `dist/ai-reply-checker/`。
- Windows x64 使用固定 Node 26.13.0 的内置 SEA 打包：设置 `OWNCLASS_SEA_NODE` 为该 `node.exe` 的绝对路径，再运行 `pnpm checker:build --exe`。CI 的专用 Windows job 使用此版本；应用继续用 Node 24 检查。
- `pnpm checker:smoke --exe`：比较源码、脚本和 exe 的诊断、退出码、版本、哈希；exe 在临时目录和空 PATH 下运行。
- CI 的 `ownclass-ai-checker` artifact 包含 exe、脚本、清单及 exe 对应脚本的指纹。构建服务器产物前将同一提交的 artifact 放到根 `dist/ai-reply-checker/`，服务器 build 自动复制到 `apps/server/dist/ai-reply-checker/`。
- exe 指纹与当前脚本不一致时不公布旧 exe；仅构建脚本的环境仍可分发脚本。正式带 exe 交付应核对清单含 `win32-x64`，并保持整个产物目录一起传输。
- 公开下载入口：`/api/public/ai-reply-checker/manifest.json` 和 `/<version>/<name>`。只允许清单白名单文件，不读取 DATA_DIR；未部署可用检查器时清单返回 503，使用远程检查工具。
- Linux/macOS 原生可执行文件不在首版范围；无需本地环境时使用远程检查。未引入 GUI 或额外模型审核。
