# 手写手感实验页

入口：`/dev/ink-feel`；原 `/dev/ink` 顶部有「比较手写手感」链接。生产构建也保留懒加载路由。实验只使用本机稿，不访问正式作答接口。

## 启动

正常 `pnpm dev` 后访问前端的 `/dev/ink-feel`，也可单独运行：

```powershell
pnpm --filter web dev:ink-feel
```

独立端口默认 5201，页面地址 `http://localhost:5201/dev/ink-feel`。若端口被占用，设置 `INK_FEEL_PORT` 后重跑；不自动接管其他任务的服务。

iPad 使用 HTTPS 才能充分测试增强采样与预测。已有合并 PEM 证书（同时含私钥和证书）时，通过 `INK_FEEL_TLS_PEM` 指定绝对路径，再运行同一命令；证书文件不提交仓库。此机可使用 ink-lab 已有的 `node_modules/.vite/basic-ssl/_cert.pem`。在 iPad 上访问终端打印的 WLAN 地址，按浏览器流程信任自签证书。

## 对照与手动验证

三组稿分别保存：当前 Atrament、低平滑 Atrament、perfect-freehand 自然手写。切换组、刷新、全屏和退出全屏都可继续测试。调整实验参数会重新绘制本组旧稿，不保留旧渲染规则。

1. 用同一设备、同一笔宽写「永、三、月」、小字、分数、根号、上下标与小数点；比较跟手度、转折、点号和快速连笔。
2. 自然手写切换硬笔、自然压感、等宽标画，分别比较预测关闭和开启；用鼠标时可单独尝试速度模拟压感。
3. 检查笔写/手指滚动、手指书写、手掌先后落屏、失焦与旋转；检查整笔擦除、撤销、重做与清空撤销。
4. 全屏、刷新、切换组后继续书写并导出 PNG，检查形状、颜色、位置。预测不进入正文、撤销历史或 PNG。
5. 记录设备、系统、浏览器、当前参数和主观感觉。采样率、绘制次数和最近一次绘制耗时只是诊断数据，不能等同端到端笔尖延迟。

## 依赖与实现

perfect-freehand 1.2.2（MIT）用于比较压力轮廓；替代方案是沿用既有 Atrament。它作为实验路由依赖随构建打包，不使用 CDN。正式作答默认值不变。实验适配器复用现有输入状态机、笔画契约、历史和擦除检测，湿/干画布分离，新笔增量绘制；预测最长 32ms、最多八点，超时自动移除。

本机键前缀 `ownclass:ink-feel:`，正文复用契约校验，配额和坏稿错误明确显示。浏览器数据不会自动同步到其他设备。

## 审查与验证

复用/简化审查：保持实验能力在独立目录，复用现有基础能力；低平滑调参不重建画布或丢撤销历史，橡皮批次共享包围盒，静止笔不持续绘制。

正确性审查：修复 raw/move 去重与预测采集争用、笔先落后手掌触摸保护；参数、工具和布局变化先收笔；预测与正式正文隔离。无新增学生 API 或答案载荷，不涉及判分与数据库迁移。可用技能列表没有 simplify/code-review 专用文件，本轮执行相应审查纪律，不宣称调用缺失技能。

回归命令：`pnpm test`、`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm e2e e2e/ink-feel.spec.ts e2e/ink-lifecycle.spec.ts --workers=2`。浏览器测试覆盖三组书写、调参后的撤销、刷新恢复、全屏画布身份、真实像素和 PNG 导出。模拟事件与自动化像素检查不替代真实 Pencil 手感验收。
