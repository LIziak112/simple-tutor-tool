# 手写手感与命名配置

入口：学生 `/s/ink-feel`，教师 `/t/ink-feel`，原 `/dev/ink-feel` 地址继续可用。旧 `/dev/ink` 已删除。页面只提供配置选择、试写、调整和保存；未登录可试写，登录后保存到账号。

## 使用

1. 选择「标准硬笔」「跟手硬笔」「自然压感」或「等宽书写」，在同一纸面试写汉字、连笔、分数、点号和转折。
2. 调整平滑、书写方式和默认笔色/粗细；自然笔感可展开更多选项调整压感变化、轨迹稳定、笔宽倍率、预测和模拟压感。试写支持全屏、整笔橡皮、撤销和重做。
3. 输入名称，例如「平板硬笔」，保存为新配置；选中已有配置后可以保存修改或改名另存。
4. 另一台设备登录同一账号，读取并选用配置，也可调整后另存为适合该设备的新配置。各设备当前选择独立记忆；草稿、正式手写和订正沿用本设备选择。标画沿用输入偏好，仍使用底图坐标域。
5. 后台刷新不覆盖未保存调整。两台设备修改同一份配置时，陈旧版本保存会被拒绝；刷新列表后「重新载入配置」，或换名称另存。每个账号最多 20 份配置，名称最多 40 字且不可重复。

保存成功表示服务端确认已写入账号。网络失败保留暂存调整，不能把本地试写误报为云端保存。设备选择按部署、角色与账号隔离，退出或换账号不会使用其他人的配置。

## 启动

正常 `pnpm dev` 后访问对应地址。独立试写端口：

```powershell
pnpm --filter web dev:ink-feel
```

默认 5201，可设置 `INK_FEEL_PORT` 改端口；后端代理通过 `DEV_API_PROXY_TARGET` 指定。`INK_FEEL_TLS_PEM` 可指定现有合并 PEM 证书绝对路径，用于 iPad HTTPS 试写，证书不提交仓库。保存命名配置需要启动本项目的新版本后端，服务启动时自动执行生成的数据库迁移。

## 实现

配置契约位于 `packages/contract/src/ink-profile.ts`，账号配置表由 drizzle-kit 生成迁移。师生端独立受保护的 `/api/student/ink-profiles`、`/api/teacher/ink-profiles` 提供读取、新建、版本更新与删除；所有归属从登录会话取得。

`ink-profile-store.ts` 维护本设备选用配置，共享手写引擎选择 Atrament 或 perfect-freehand。切换配置先收笔，保留同一笔画仓和撤销历史。新笔画包含可选渲染参数；PNG、草稿裁剪与回放复用相同绘制入口。预测只作为临时反馈，不进入正文或导出图片。草稿派生图渲染版本升级为 3。

未新增依赖。perfect-freehand 是项目已有依赖，全部资源本地打包。

## 验证

自动化覆盖账号与角色隔离、防泄露、同名与限额、更新冲突、设备选择、取消/失焦收笔、切换配置保留笔迹与撤销、草稿刷新恢复、PNG 内容与回放像素。真实 Pencil 的舒适度仍需真机试写确认，建议检查轻重、点号、快速连笔、手掌触摸、旋转与全屏。

命令：`pnpm test`、`pnpm lint`、`pnpm typecheck`、`pnpm build`、`pnpm gen:spec`，以及 `pnpm e2e e2e/ink-feel.spec.ts e2e/ink-lifecycle.spec.ts e2e/note-render.spec.ts e2e/note-layer.spec.ts --workers=2`。最终结果见 `docs/手写命名配置实施计划.md` 的验收记录。
