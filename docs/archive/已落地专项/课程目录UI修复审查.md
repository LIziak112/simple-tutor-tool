# 课程目录 UI 修复审查（2026-10-27）

## 范围与依据

针对用户标注的教师课程详情、目录排序/批量操作、从资源库添加侧栏和学生课程目录，按 `better-interface` 及其六个领域技能执行检查。对照文件夹改造前的页面层级与用户截图，保留原有组件样式，将文件夹融入现有界面。课程列表此前的紧凑化保留，本次不重做全站设计。

## 验证与审查

- TDD：先增加三条失败组件测试，覆盖没有逐行菜单、同级重排请求和批量隐藏；修复后通过。另先重现排序成功清除选择的问题，再修复并验证选择保留。纯样式与文案不写镜像测试，以实际截图和浏览器边界断言验证。
- 定向组件测试覆盖教师详情、资源侧栏、目录操作、学生目录；最终 quick、类型和 lint 结果同步到《课程嵌套目录与查找验收记录》。
- E2E 覆盖根目录与嵌套目录键盘拖拽、上移后保留选择、320px 选中操作栏和菜单、归档与学生搜索/阅读返回，以及侧栏加载中、失败重试、45 条长名称、320/640/1280px 和 200% 根字号。
- 侧栏断言资源滚动区下沿不越过底部设置区，设置区不越过视口；点击最后一条资源时发布设置与完成按钮仍可见。截图同时检查实际布局，不仅检查无横向溢出。
- 本地 5183 页使用原课程数据的独立数据库备份，复核教师未选/单选、长目录、资源侧栏与学生练习状态，保存截图。未更改原开发数据库。
- 简化审查：复用现有拖拽与菜单组件；使用同一套选中操作，删除逐行菜单和重复图标，没有增加树组件、依赖或另一套管理协议。
- 正确性审查：重排提交当前父级完整同级 ID 集；跨层移动仍走原服务；搜索中关闭拖拽；连续排序保留选择；切换课程重置目录组件状态；失败保留输入与选择。
- 安全审查：本次没有新增服务端或学生接口，没有改投影、判分、答案授权、发布门和 MCP 权限。学生 E2E 继续监听答案泄露；操作仍调用原有受教师归属校验的目录指令。

**未验证**：真实读屏、原生浏览器 200% 缩放、真实 iPad/Pencil、RTL 和本次页面的深色视觉截图。根字号 200% 测试不等同于原生浏览器缩放。全量构建与 WebKit 由 PR CI 执行；本机 Chromium 首轮及失败复跑结果见验收记录，不将首轮失败称为全绿。
