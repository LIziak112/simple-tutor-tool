## 4. 质量闸门

没有可直接运行的simplify/code-review/security-review本地技能或当前PR审查入口，本轮明确人工依次执行，不冒称工具调用。检查范围为`435127f`至本轮最终工作树及新文件。

- 简化：复用AttemptWorkspace、题目完整度、答案格式化、contract筛选schema；删除返回上下文重复校验，不新建业务控制器。
- 正确性：修复恢复竞争、CSS缩放、状态文案、填空空号和标题层级；导航不卸载稿件，详情返回不依赖浏览器历史步数。
- 安全：公布gate保护选项、对照、分数、范围；填空参考空数也只在公布后读取；结果重练继续消费finalCorrect；returnTo只接受`/s/records`及白名单字段；会话仓仅存ID，身份与来源隔离。
- 界面：按better-interface六领域说明检查键盘/焦点、结构、文案、换行、语义色和既有Lucide/Radix样式。没有宣称完整WCAG或全部主题对比验收。

无已确认且未处理的本轮阻断项。测试中发现教师作业列表既有超长不间断标题横向溢出，会影响共享夹具点击；本轮用独立教师隔离数据，教师端该问题不在本轮学生页范围，未修改。旧Excalidraw全屏用例仍出现未挂载setState控制台提示，本轮未改该控制器，不把用例通过等同于零控制台警告。
