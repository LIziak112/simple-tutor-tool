# 跨设备原位标画实施记录

日期：2026-10-15。实施分支：`codex/annotation-fixed-surface`。

## 最终行为

- 已有标画的题目按保存时蓝框内的排版固定逻辑宽高；题面与笔迹使用同一显示比例，桌面、平板和手机切换不重新换行。
- 顶栏「圈画」进入／退出编辑，退出保留已有笔迹。删除下方第二份题面及「查看／编辑／收起原标画」状态分支。
- 云端恢复的布局与矢量直接显示，不要求先点圈画，也不逐题额外请求正文或下载 PNG。首次显式编辑时才缓存原底图；缓存不创建待传笔迹版本，不覆盖下载期间新增的笔迹。
- 手机可「放大题面」横向浏览，再「适应宽度」；缩放先收笔，点集、笔宽与保存尺寸保持原坐标，画布不随真实 DOM 的 transform 再次变换。
- 不能复现字体／旧样式的历史稿在原位置显示历史题面，保留独立答案控件；隐藏笔迹不隐藏历史题面。图片失败提供真正重挂图片的重试入口，未就绪前不启用输入。
- 学生结果与教师批改的可见题自动呈现原稿，底图成功前保留普通题面；正文或图片失败保留题面并提示重试。原稿只读，学生答案和参考答案仍在既有对比区显示；文字题面保留供读屏读取。
- 无契约、数据库、依赖或判分改动。导出仍走原有固定底图与矢量合成，服务端授权及封存机制沿用。

## 根因与实施

布局匹配原先直接比较屏幕宽高与几何散列；尺寸变化后跳到独立 PNG 区，而其可见状态与顶栏编辑状态分离。现在分离保存的逻辑排版与显示尺寸，以逆变换后的几何继续严格核对签名，不放宽公开内容、版本和字体检查。

复用 `QuestionSurface`、`annotation-surface` 与现有存储／同步入口。旧稿的独立填空控件按现有 AST 空位计数生成，避免另写正则或猜测旧图空位坐标。学生／教师自动回看复用 `AnnotationView` 的授权读取和静态绘制。

## 质量闸门

当前环境未提供仓库要求的 systematic-debugging、simplify、code-review、security-review、verification-before-completion 技能文件；已按同名流水线的检查目标执行根因定位、完整差异简化、正确性／安全审查与真实命令验证，没有声称调用不存在的技能。

1. 简化审查：去掉独立 original 开合状态和第二套按钮；复用既有画布、空位计数和回看入口；恢复展示直接消费既有记录，取消重复下载与正文读取路径。
2. 正确性审查：修复下载缓存误制造编辑、下载快照覆盖新笔迹、空云端稿画布尺寸为零、图片重试未真正重载、切换题目后迟到读取回写等问题。确认隐藏、收笔失败、缩放、撤销、重进页面与保活共用原保存流程。
3. 安全审查：未新增接口，未扩大返回字段，未使用完整题目快照散列；正常题面继续使用公开投影。学生／教师 PNG 仍经原授权 URL，账号会话与底图绑定守卫保留；封存原稿和评分逻辑不改写。真实浏览器测试的泄露监视继续通过。

## 手动验收／PR 描述可用内容

1. 桌面打开带多行文字、公式、图片或表格的题，填写答案并圈画，退出编辑；确认仅一份题面、笔迹保留且答案控件可操作。
2. 同账号在无本机缓存的平板重开同一作答，确认笔迹自动出现；顶栏点一次直接续写，再点一次退出。刷新原设备确认笔迹和答案均保留。
3. 缩至手机宽度或旋转设备，观察公式、空位与笔迹保持相对位置；点「放大题面」横向查看，再点「适应宽度」，继续写、擦除、撤销并导出，确认无累计漂移。
4. 同时展开草稿，开合或切换布局；确认标画与草稿各自保留、保存失败不关闭原编辑者。
5. 教师修改题库后回看旧作答，确认仍为建卷冻结题面；教师批改与学生结果页不点标画入口即可看到原稿。
6. 模拟底图读取失败，确认题面／答案保留且可重试；旧布局无法复现时不在题面下方再复制一张图片。
