# 圈画与草稿交互修复报告

日期：2026-10-13。分支：`codex/annotation-scratch-fix`。目标：仅合并到 `v2`。

## 修改与根因

- 原题卡从唯一编辑模式推导纸面展开，开启圈画就隐藏草稿。现将纸面展开与标画模式分别保存，同题可同时展开、分别收起；切题和退出仍等待收笔、本机持久化，失败时保留原稿，迟到准备结果不能重新激活旧编辑者。
- 圈画激活区域增加淡蓝色外框，覆盖可标画的题面，排除草稿和外围操作；使用 outline 保持底图几何不变。
- 原位和固定底图标画都接入现有会话输入偏好，默认笔写／手指滚动。通过「手指书写」明确启用手指落墨，切换不重建引擎或历史。
- 清空失效由 Portal 菜单指针事件冒泡到题卡引起：退出标画早于清空命令。现只把真实题卡 DOM 内的外围操作视为退出；标画、草稿及其入口不相互关闭。清空先结束在途笔，迟到移动或抬笔不能恢复已清空正文；清空可撤销、重做、持久化。
- 题卡原先固定 below，并在协调器场景隐藏布局菜单。现复用现有自动／左右分栏／上下排列及设备偏好；显式布局优先，自动布局按题卡真正可用宽度判断，宽屏收起答题卡可腾出分栏空间。菜单按可用高度滚动，末尾项目不再超出屏幕。
- 补充回归发现旧 v2 的标画导出已有 10 像素偏差。Atrament 的平滑与自适应笔宽依赖 CSS 采样距离；原位导出现在按保存的 CSS 尺寸重放，PNG 像素尺寸不变。既有尺寸不兼容稿仍保留原底图入口，不向新题面强行套圈。
- 320px 标画工具栏将重做放入更多菜单，保留画笔、橡皮、撤销、更多、手指书写及作答；触控按钮均至少 44px。

未新增依赖、API、数据契约或数据库变更；最新 v2 自身的讲练功能更新已合入本分支进行集成验证。

## TDD 与质量闸门

先复现再实现：状态隔离、笔／手指模式、Esc 收起、在途清空和 CSS 尺寸重放单元测试都先观察到失败；浏览器先复现清空失效与手指误落墨，再验证修复。旧的「草稿始终下置」断言改为本次确认的自动分栏行为，仍保留子树身份和填空焦点断言。

对相对最新 v2 的完整 diff 先做复用／简化检查，再做正确性审查。保留已有偏好存储、输入状态机、工具栏与保活控制器，未另建一套手写系统。审查中发现并修复菜单超出视口、草稿入口误退出圈画、在途清空回写及 Esc 纸面收起回归；没有遗留确认发现。本次不改变学生端载荷或答案投影，现有泄露单元测试及 E2E 监测继续验证。

环境中未提供 systematic-debugging、simplify、code-review、verification-before-completion 的 SKILL.md；此处记录的是根因定位、两轮 diff 审查与真实命令结果，不声称调用了缺失技能。

## 手动验证

1. 在学生作业或讲练作答态打开客观题草稿，写一笔，再开启圈画。两区保持可见，淡蓝色框明确标画范围；两处均可用笔书写。
2. 分别收起圈画和草稿，再重新打开，确认另一部分状态与已有稿保留。切题、全屏及返回后检查草稿与正式纸面。
3. 默认模式用手指滑动题面，确认不落墨；打开「手指书写」后可写，再关闭，草稿和标画的偏好一致。
4. 标画后打开更多，执行「清空标画（可撤销）」，确认工具栏未退出；撤销恢复、重做清空，刷新后不恢复旧正文。
5. 草稿更多选择左右分栏／上下排列／自动，确认题面和笔迹保留。宽屏收起答题卡后自动分栏；收窄、旋转后自动回退下方。旧标画宽度不匹配时使用「查看原标画」。
6. 320px 窄屏检查标画工具与草稿菜单均可访问；导出原位标画，比较笔迹位置与笔宽。
7. 在真实 iPad 上比较 Pencil 起笔、手掌接触、手指滚动、中文转折、横竖屏和全屏。
