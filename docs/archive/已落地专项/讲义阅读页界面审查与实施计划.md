## 验证记录与边界

- 当前桌面宽度约 1144px：首屏标题重复；长目录标题省略；向正文下滚两屏后，返回按钮和讲义名均不在视口，全局导航和桌面目录仍在。
- 设置 390×844：目录展开占据首屏主要空间，正文主标题顶部约 571px。点击第一讲后成功滚到正文，返回和目录均不在视口；document.activeElement 仍为原目录按钮。
- 设置 320×720：首屏根文档 scrollWidth=314，innerWidth=320，未见整页横向溢出；目录长标题与更新时间被省略。此结果不代表整篇复杂表格均已验证。
- 浅色目录次级文字：计算颜色 oklch(0.5 0 0)，最近绘制背景 oklch(1 0 0)。中性 OKLCH 的相对亮度为 L³，(1+0.05)/(0.5³+0.05)=6.00。
- 检查结束恢复浏览器尺寸并返回页顶。
- 未验证：200% 真正浏览器缩放、暗色、屏幕阅读器完整路径、所有键盘焦点截图、减少动态效果系统偏好、触摸滚动串联、RTL、加载/错误运行时状态、无目录讲义、配套练习运行时状态。相关源码已检查，但不能据此宣称运行时通过。
- 这是审查和计划，尚未运行实现阶段的测试、类型检查与构建。

审查时结论：**Block**。两项 HIGH 已在下述实施中修复并验收；本节保留最初审查证据。

## 拟定界面

1. 常驻阅读栏左侧保留返回，中央显示讲义名，右侧提供“目录”入口。完整文档标题留在正文，课程和更新日期降为辅助信息。阅读栏高度与锚点偏移统一，避免新增 sticky 后遮挡正文标题。
2. 桌面侧栏宽度按正文空间调整，标题完整换行；一级章节默认可见，仅当前章的子节展开，其他章节允许独立展开。没有子节的章节不出现折叠按钮。收起桌面目录后正文回收空间。
3. 手机/平板窄屏首屏直接进入正文，阅读栏保留目录入口；目录使用现有可访问弹层，支持 Escape、焦点管理和独立滚动。跳转后关闭目录并将焦点交给正文目标。
4. 当前章节标记复用既有 useLectureSectionFocus，保留 lecture_toc_jump 与 lecture_section_focus 的索引语义，不另造一套跟踪体系。避免自动滚目录抢走学生手动浏览目录的位置。
5. 排版只作用于讲义阅读页，保留 RichMarkdown 的其他宿主表现。正文可考虑 16px，继续使用现有字体、颜色、圆角；先解决导航与层级，再做视觉微调。

额外建议（可后续处理）：记住阅读位置；把配套练习入口加到阅读栏的次级菜单；内容端缩短标题、把“原卷第 N 题”降为辅助信息。本样本里可见孤立 :::/:::: 与看似链接但实际为纯文本的 .md 文件名，应另做讲义材料和 DSL 校验，不作为本轮 UI 修改混入解析器修复。
