# 手写手感实验页实施计划

日期：2026-10-13。用户已确认在主项目增加实验页，实验稿不要求保留历史渲染规则。

## 范围

新增独立 `/dev/ink-feel` 懒加载页面，生产构建也可访问，便于 iPad 真机比较。三组对照：当前 Atrament、低平滑 Atrament、perfect-freehand。提供输入模式、工具、参数预设、预测开关、统计、本机保存与 PNG 导出，不访问学生 API，不修改正式作答的数据契约、判分和默认行为。

文件：`pages/dev/InkFeelPage.tsx`、`features/ink/lab/feel-*` 及测试、`App.tsx`、`InkDevPage.tsx`、Atrament 适配器的可选平滑参数、`e2e/ink-feel.spec.ts`、本页说明。新增直接依赖 perfect-freehand 1.2.2（MIT）：用于比较压力轮廓绘制；替代方案是继续使用既有 Atrament；依赖随本地构建打包，只在实验路由加载。

## 实施与测试

1. 先写失败测试：预测不落正文、raw/move 不重复且预测仍可采集、第二指针不丢已收点、失焦/取消/旋转收笔、工具切换收笔、静止不持续重绘、导出只含正式笔迹。
2. 实现实验适配器，复用现有契约、输入状态机、历史与擦除检测。湿/干画布分离，新笔增量绘制；参数变化可重新渲染实验旧稿。独立本机存储正文和实验参数。
3. 新增触屏可用页面及旧实验页入口，补真实浏览器的书写、恢复、撤销、导出、参数与模式切换测试。
4. 对完整 diff 做复用简化与正确性审查，运行单测、lint、typecheck、build 及 Chromium/WebKit E2E；真实 Pencil 手感由用户比较，不冒称自动化结果。
5. 分支验证全绿后小步提交；检查目标分支和工作目录状态后合并，避免混入正在进行的可靠性修改。

## 手动验证

进入 `/dev/ink-feel`，每组写“永、三、月”、分数、上下标、根号和小数点。比较笔尖跟随、小字与转折、轻重压感、快速连笔和停笔。分别测试笔写/手指滚动、手指书写、手掌先落、旋转、全屏、刷新恢复、擦除撤销及 PNG；HTTPS 能力以页面实际观测为准，不承诺固定采样率。
