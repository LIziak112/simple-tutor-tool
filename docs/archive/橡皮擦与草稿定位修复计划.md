# 橡皮擦与草稿定位修复

## 范围与步骤

用户已确认草稿定位方式并授权新分支修改，最终只发布到 v2。

1. 在 `codex/eraser-paper-position` 分支先补失败测试，复现擦除后的陈旧下标误隐藏、快速拖动漏擦、笔宽边缘命中及切换草稿后的题干移位。
2. 修改 `apps/web/src/features/ink/engine/erase.ts` 与测试：连续轨迹按线段扫过范围判定，计入笔宽；只删除空间命中的整笔，不比较形状。
3. 修改 `atrament-adapter.ts`、`annotation-surface.ts` 与各自测试：提交擦除前取出并清除预览下标，重绘使用删除后的正文；一次手势合并一次历史，撤销/重做与正文保持一致。
4. 修改 `AttemptQuestionCard.tsx` 与定位辅助函数、测试：记录操作前题卡位置，成功展开后待布局稳定再检查；只有位置变化且题干顶部已离开可见区域时对齐顶部，失败或用户先行滚动不抢位置。
5. 补真实浏览器回归测试，更新本文件与 AGENTS.md；对完整 diff 依次进行简化与正确性审查，执行测试、类型检查、lint、构建及相关 Chromium/WebKit E2E。
6. 分支全绿后合并并推送 v2，不发布 main。

## 测试点

- 相同形状的左右笔迹独立；右侧先写、左侧后写，擦右侧后左侧正文和最后一次重绘均保留。
- 多笔擦除、连续擦除、撤销/重做、取消/强制收笔后画面与正文一致。
- 快速移动的两个采样点之间穿过笔画仍命中；平行远处笔迹不受影响；粗笔边缘命中。
- 当前题位置没有变化、题干仍可见、保存失败、用户先行滚动均不自动置顶；上题收起导致当前题题干出屏时才对齐。
- 普通作答与讲练共用题卡；布局调整不重挂题面与纸面控制器。

## 手动验证

同一纸面先在右侧写根号式，再在左侧写同样公式，擦除右侧并抬笔，确认左侧保留；重复多次、撤销/重做、重新进入页面检查。用 Pencil 快速划过细笔与粗笔，确认经过的笔画被擦除、远处笔迹保留。

打开第一题草稿后滚到第二题并打开其草稿：若第一题收起使第二题题干出屏，应将第二题对齐到顶栏下方；题干仍可见或首次正常打开时不额外滚动。真机 Pencil 舒适度需设备试写，自动测试不能替代。

## 验证与审查记录

### 根因与修复

擦除没有形状识别逻辑。标准硬笔与标画在 `commitErase` 删除正文后，仍带着旧 `pendingErase` 下标重绘，导致后写且下标前移的远处笔迹被额外隐藏。修复为提交前清除预览下标、提交后按最新正文重绘。自然笔感原有提交顺序正确，同步补齐连续命中。

原命中只检查橡皮采样点，快速拖动时会跳过中间笔画；精筛也未计入笔宽。三种纸面统一使用点/线段扫过范围判定，加上半笔宽及自然笔感的宽度倍率。沿用整笔擦除，一次手势对应一个可撤销历史条目。

题卡使用唯一展开纸面，切换后上题高度减少使当前题卡上移。展开前记录题卡顶部，成功后等两帧检查实际位置和顶栏留白；位置变化且顶部出屏才对齐，不改变焦点。用户先行操作、收起或卸载取消迟到定位。

### 质量闸门

本机未提供 `/systematic-debugging`、`/simplify`、`/code-review`、`/verification-before-completion` 对应技能文件，按其规定的流程直接完成定位、简化、正确性审查与真实命令验证，没有声称运行缺失技能。

1. 简化：命中几何复用于全部三种纸面，不新增依赖/契约；移除逐笔线段临时坐标对象，单点命中保留直接距离路径；定位逻辑集中到题卡共用 hook。
2. 正确性审查发现并修复：两个既有测试辅助函数把 `x/y` 直接传给只读 `clientX/clientY` 的事件函数，实际测试全部在默认位置；现改成正确坐标。橡皮在途撤销/重做/清空会改变待删下标，标准硬笔和标画现在先收笔再变更历史。新增失败测试确认在途撤销恢复正文且迟到抬笔不能再次删稿。收起草稿取消待定位帧，避免晚到滚动。
3. 浏览器像素测试明确检查左右区域的墨迹存留，不用单个抗锯齿像素的精确数量比较（Chromium 重绘出现过 1 像素量化差异）。正文仍进行严格笔画内容断言。
4. 本次不触及学生 API、答案载荷、判分、数据库和 DSL；不需要修改契约、迁移或生成规范。
