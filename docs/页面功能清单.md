## 1. 数据模型现状（理解功能的前提）

```
courses（课程，可选组织层）
  ├── lectures（讲义）：courseId、标题、markdown 全文、排序
  └── units（练习单元）：courseId、可选关联 lectureId、标题、topic、排序
        └── questions（题目）：unitId、题型/难度/题干/选项/答案/提示/详解、
                              sourceMd 原文、version、deletedAt 软删

students（学生）：与 courses / lectures / units 均无关联 ←—— 当前关系缺口
assignments（作业）：unitId → assignment_students → students   ←—— 内容到达学生的唯一路径
attempts / responses / ink / events（作答域）
imports（导入留档）：每次导入的原始 MD + 报告
```

**导入落库规则（现状）**：
- 一次导入一份 Markdown（粘贴或选择单个文件），可指定目标课程，未指定时落到自动创建的**「默认课程」**；
- 练习按 **unit id** 匹配合并（同 id 再导入 = 更新单元信息，题目同 id 则 version+1）；
- 讲义按 **(课程, 标题)** 匹配：同标题替换 markdown，无则新增；
- 有 error 级 lint 问题整体拒绝写入；原文留档 imports 表。

**内容管理能力现状**：

| 对象 | 增 | 改 | 删 | 排序 |
| --- | --- | --- | --- | --- |
| 课程 | ✅ | ✅（改名） | ✅ | ✅ |
| 讲义 | 导入产生 | ✅（编辑抽屉改 markdown） | ✅（物理删除） | ✅（dnd 拖拽） |
| 练习单元 | 导入产生 | ❌ **无编辑**（改标题/topic 只能重新导入覆盖） | ❌ **无删除** | ✅（dnd 拖拽） |
| 题目 | 导入产生 | ✅（单题编辑抽屉，version+1） | ✅（软删，重导入同 id 可恢复） | ✅（单元内拖拽） |

## 2. 教师端功能明细（/t，侧边栏「辅导工作台」）

### 2.1 登录与设置（T1.9）
- 首次启动 `/t/setup` 设置教师密码（单人单密码，无用户名）；`/t/login` 登录；错 5 次锁 10 分钟；会话 7 天。
- `/t/settings` 当前**仅有退出登录**（改密码、API Token 属后续任务）。

### 2.2 内容页 `/t/content`（T1.11/T1.12）
- 左侧课程分组树：课程 → 讲义列表 + 练习单元列表；单元展开显示题目摘要（题号、题型、难度、考点）。
- 课程：增、改名、删、拖拽排序。
- 讲义：编辑抽屉（CodeMirror + 实时渲染预览 + lint 标注）、删除（物理删，二次确认）、拖拽排序。
- 题目：编辑抽屉（改该题 sourceMd 重新解析，id 不变 version+1；error 内容被拒保存）、软删除（列表消失，重导入同 id 恢复）、单元内拖拽排序。
- **练习单元本身：只能看和排序，无编辑、无删除入口**（见 §5-P2）。

### 2.3 导入页 `/t/import`（T1.11/T1.13/T1.7）
- **单文件模式**：粘贴 Markdown 或选择一个 .md 文件（多选不支持）。
- 流程：预览（左：CodeMirror 原文，lint 错误行标红；右：渲染预览；顶：单元数/题数/题型分布统计）→（有 error 时禁止导入）→ 选择课程（可选）→ 确认导入。
- 自动识别 v1/v2 文档；v1 自动转换导入。
- **「复制错误给 AI」**：把「**文档全文** + 错误列表（行号/CODE/中文说明）+ 修正要求」拼成一段提示词供粘贴给大模型（见 §5-P6：全文拼接的问题）。
- **AI 出题助手**（`/spec` 路由配套）：选文档类型与主题 → 一键复制「DSL 规范 + 完整样例 + 提示词模板」（约 2 万字）→ 交给任意大模型生成练习 → 粘回导入。
- `reparse` CLI（pnpm reparse）：解析器升级后从原文重抽结构化字段（命令行工具，非页面）。

### 2.4 学生管理 `/t/students`（T2.1）
- 列表：姓名、登录名、创建时间、备注、归档标记；默认隐藏已归档，可切换显示。
- 新增：姓名 + 登录名（默认同姓名、全局唯一）+ 可选初始密码（留空自动生成 8 位，一次性弹窗展示）+ 备注。
- 两种登录方式独立开关：专属链接 / 密码登录。
- 复制专属链接（`/s/{令牌}`）；重置密码（旧密码立即失效）；重置链接（旧链接立即失效）；归档/取消归档（归档后拒登录、会话失效）。
- **学生不隶属任何课程/班级**——与内容之间无关联（见 §5-P3）。

### 2.5 作业管理 `/t/assignments`（T2.2）
- 布置：选**练习单元**（下拉，只列有题目的单元）→ 多选**学生** → 可选截止时间；标题默认用单元标题。
- 列表卡片：标题、单元与实时题数、指派名单、截止、布置时间（倒序）。
- 编辑：改标题/截止、全量替换名单；删除：软删（学生端立即不可见，作答保留）。
- **作业 = 「单元 × 学生名单」的快照式指派**，是当前内容到达学生的唯一机制。
- 已交作业的批改/查看页面未实现（T3.1 起）。

### 2.6 占位区
- 「数据」「学情」为建设中占位页。

## 3. 学生端功能明细（/s/*）

### 3.1 登录（T2.1/T2.3）
- 专属链接 `/s/:token`：点开即登录（失效/被重置/被关闭时给中文提示 + 去密码登录入口）。
- 密码登录 `/s/login`：登录名+密码；错 5 次锁 10 分钟；会话 90 天。
- 顶栏「退出」登出。

### 3.2 首页 `/s/home`（T2.3/T2.6）
- 顶栏：姓名 + 导航（首页/讲义/我的记录）+ 退出；iPad 横竖屏自适应。
- 作业卡片：标题、单元与主题、题数、截止（北京时间或不限）、状态徽章（**未开始/进行中/已交卷/已批改**）；入口随状态变（开始练习/继续作答/查看结果）。
- 讲义入口（**当前学生能看到系统中全部讲义**，无按学生/课程过滤——见 §5-P3）。
- 「我的记录」占位（T3.5）。

### 3.3 答题页 `/s/assignments/:id`（T2.6 + T2.8–T2.12）
- 题卡：题号、题型徽章、难度、考点；RichMarkdown 题干（公式本地渲染；填空题的空位是**题干内联输入框**）。
- 作答控件：判断=对/错按钮；单选/多选=可点选项；填空=内联输入；计算/应用/找错=手写区 +「最终答案」输入框（可切 MathLive 数学键盘）。
- 手写：页内画布（Atrament：笔/荧光笔/橡皮/颜色粗细/撤销重做/清空确认/自动加高）与全屏作答（Excalidraw，题干固定顶部）；每笔结束防抖上传；刷新自动恢复。
- 分步提示：「给我一点提示（剩余 n 条）」逐条解锁；未请求的提示绝不下发（泄露测试覆盖）。
- 草稿防丢：每次改动/每笔即写本机 IndexedDB；10 秒与切后台增量同步；断网本地保存、恢复自动补传；顶栏三态（已保存 HH:mm / 保存中… / 离线，已存本机）；离线禁交卷。
- 交卷：确认弹层（未答数）→ **服务端判分**（判分只在服务端；题目快照冻结，之后教师改题不影响本次作答）→ 交卷前确保手写笔迹全部上传。
- 结果视图：得分汇总（可自动判分题正确率）、逐题 ✓/✗/待批、本人答案 vs 参考答案、详解折叠、手写笔迹缩略图（刷新仍在）、已解锁提示回看；手写无最终答案的题进「待批」（教师批改 T3.2）。
- 学习事件（T2.10）：作答全程埋点（聚焦/切走/改答案/提示/笔迹/页面隐藏），服务端按事件计算**每题有效用时**（页面隐藏期间不计时）。

### 3.4 讲义 `/s/lectures`、`/s/lectures/:id`（T2.3）
- 列表：全部讲义；阅读页：全文渲染（公式/折叠/步骤逐步揭晓/示例）、H2/H3 自动目录（点击跳转、可收起）、横屏目录左置双栏；折叠与步骤展开上报事件。

### 3.5 我的记录 `/s/records`
- 占位「即将开放」（历次作答/错题本 = T3.5）。

## 5. 已识别的设计问题（用户提出，2026-09-27，原样记录供架构讨论）

> 本节只记录问题，不给方案。后续以本节为输入做综合功能架构设计。

- **P1 批量导入缺失**：当前一次只能导入一份文件，需要支持批量导入多个文件。
- **P2 练习单元无法管理**：教师端不能删除练习单元，也没有编辑/管理入口（讲义可以删，题目可以软删，唯独单元是"黑洞"）。
- **P3 内容组织与分发模型不合理**：期望模型是「**讲义库 / 题库**（导入的内容先进库统一管理）→ 建课程 → 课程中添加讲义与练习单元 → **学生加入课程** → 学生自动可见课程内的讲义与习题」。当前实现：导入直接落进课程（或默认课程），学生与课程无任何关联，讲义对所有学生全量可见，作业是内容到达学生的唯一路径。
- **P4 作业功能保留**：作业机制仍需保留——限时测试、新题突击测试等场景仍靠「作业」来布置（即作业与「课程内容常规可见性」是并行的两条分发通道）。
- **P5**（伴随 P3 的语境）导入的内容无法合理管理：应先入讲义库/题库再挂到课程，而不是导入即最终位置。
- **P6 「复制错误给 AI」的复制内容错误**：当前把**文档全文**拼进提示词；正确做法是复制「**出问题的文件路径 + 错误信息**」，AI 按路径自己取文件（或后续经 MCP 读取），而不是把整份内容塞进剪贴板。
