## 1. 数据模型现状（理解功能的前提）

```
⓪ 教师（Phase 2B 多教师）：teachers（loginName 全局唯一、isAdmin、apiToken 预留），
   全部业务根表带 teacherId 域隔离（互相不可见，按 id 访问他人资源 404）
① 资源库（library）——导入内容的唯一落点
library_folders（一级文件夹，不可嵌套；folderId = null 即「未归类」）
  ├── lectures（讲义）：folderId、标题、markdown 全文、deletedAt 软删（回收站）
  └── units（练习单元）：folderId、可选配套讲义 lectureId、标题、topic、deletedAt 软删
        └── questions（题目）：unitId、题型/难度/题干/选项/答案/提示/详解、
                              sourceMd 原文、version、deletedAt 软删

② 课程（courses）——有序目录 + 成员
course_items（目录条目）：kind = 分节标题 / 讲义引用 / 单元引用（只存 refId，
                         引用而非复制）、排序、visible、publishAt 定时发布
course_students（课程成员）：主键 (courseId, studentId)，只由教师增删

③ 分发——学生看到内容的两条通道
常规通道：课程成员 → 自动看到课程内可见条目 → 课程练习（可重做，历次保留）
作业通道：assignments = 多单元（assignment_units）× 名单快照（assignment_students，
          布置后可增删）× 截止时间 × 答案公布时机（交卷即公布 / 截止后公布）

attempts / responses / ink / events（作答域）：sourceType 区分 assignment / course
两种来源，共用同一套作答接口；课程练习按 attemptNo 记历次。
判分链（Phase 3 定稿）：autoCorrect（未作答客观题 = false）→ teacherMark（批改
优先）→ finalCorrect（统计唯一口径，待批 ≡ 其为 null）→ scoreFinal（分母 = 全部
题）与 status（draft → submitted → graded），详见架构文档 §5.2/§5.6
imports（导入留档）：原始 MD + 报告 + 批量导入的 sourcePath / batchId / folderId
```

**导入落库规则（T2A.3，D17–D20）**：
- 单文件与批量共用一页（多选 .md / 选文件夹 / 粘贴三入口）；导入只进资源库（选目标文件夹，可选「同时加入课程」快捷项）；
- 练习按 **unit id** 全局匹配合并（命中保留原文件夹）；讲义按 **(目标文件夹, 标题)** 匹配；题目同 id 则 version+1，**文件中缺失的已有题保留**；命中回收站资源自动恢复并更新；
- 预览展示**动作清单**（新增/更新单元（题数细分）/新增/更新讲义/回收站恢复）与 warning（跨文件夹同名讲义、被未截止作业使用等）；
- 批量：跨文件冲突（同 unit id / 同文件夹同名讲义）视为 error；**每个文件独立事务**，有 error 的自动跳过，结束后汇总报告（成功 n / 跳过 n / 失败 n）；上限单批 50 文件、单文件 1 MB、合计 10 MB（413）；
- 有 error 级 lint 问题整体拒绝写入（422）；原文留档 imports 表。

**内容管理能力现状**：

| 对象 | 增 | 改 | 删 | 排序 |
| --- | --- | --- | --- | --- |
| 文件夹 | ✅ | ✅（改名） | ✅（内容移入未归类） | ✅（拖拽） |
| 讲义 | 导入产生 | ✅（编辑抽屉 + 单元详情改文件夹/配套） | ✅（软删 → 回收站，可恢复/彻底删） | 跟随课程目录 |
| 练习单元 | 导入产生 | ✅（详情面板改标题/topic/文件夹/配套讲义） | ✅（软删 → 回收站） | 跟随课程目录 |
| 题目 | 导入产生 | ✅（单题编辑抽屉，version+1） | ✅（软删，重导入同 id 可恢复） | ✅（单元内拖拽） |
| 课程目录条目 | ✅（从资源库多选，配套练习可一并） | ✅（可见/定时/分节标题） | ✅ | ✅（拖拽 + 上移/下移） |

## 2. 教师端功能明细（/t，侧边栏「辅导工作台」）

侧边栏定稿（T2A.9 + T2B + T3.1）：**资源库**（讲义库 / 题库 / 导入，共用 `/t/library`，URL `?tab=` 定位页签）· **共享** · 课程 · 学生 · 作业 · **数据**（已实装 `/t/data`）· **学情**（占位，Phase 4 实现）· 设置；管理员（`isAdmin`）末尾追加「管理」（`/a`）。「数据」自 T3.1 起为作答数据页（见 §2.8/§2.9），不再是占位。

### 2.1 登录与设置（T1.9 + Phase 2B）
- 首次启动 `/t/setup` 设置**登录名 + 密码**（多教师单表；首位教师必然 isAdmin=true 管理员）；`/t/login` 登录（登录名全局唯一）；错 5 次锁 10 分钟；会话 7 天。注册开关默认开（`POST /api/public/teacher/register` 自助注册，管理员可关闭）。
- `/t/settings` 当前**仅有退出登录**（改密码、API Token 属后续任务）。

### 2.2 资源库 `/t/library`（T2A.2）
- 页签：讲义库 / 题库 / 回收站（`?tab=` 定位，侧边栏直达）；左侧文件夹栏（未归类为虚拟项，显示讲义/单元计数）。
- 讲义库：列表（被引用课程数、更新时间）、编辑抽屉（CodeMirror + 渲染预览 + lint）、导出 .md、软删。
- 题库：单元列表（题数、题型分布、考点、被 N 个课程引用 · N 个作业使用），展开显示题目摘要（题目编辑抽屉 / 软删 / 单元内拖拽排序复用）；单元详情面板（改标题 / topic / 文件夹 / 配套讲义、使用情况、导出、删除）。
- 多选批量操作：移动到文件夹 / 加入课程（可见开关）/ 删除 / **发布到共享**；搜索（标题 / 单元 id / topic / 考点，前端过滤）。
- 删除 = 软删进回收站；确认弹层列出使用情况（引用课程 + 使用作业）；删除类 toast 带 5 秒「撤销」。
- 回收站：恢复 / 彻底删除（仅当无作答记录与作业引用，否则禁用并说明）。
- 导出的 Markdown 可原样重新导入（往返一致；已删题不导出）。
- 旧路径 `/t/content` 重定向到 `/t/library`。

### 2.3 导入 `/t/import`（T1.11 + T1.13 + T1.7 + T2A.3 + 内容模型与导入规范化）
- **统一待导入清单**：选择多个 .md / 选择文件夹（`webkitdirectory`，不支持的浏览器自动降级为多选）/ 粘贴，三入口往同一份清单加条目（文件名、相对路径、大小、可移除；同 path 重复 → 原位替换保持最新；粘贴条目文件名就地可改）；清单不显示正文，正文检查交给预览态。
- 规模预检实时化：清单一变立即重算，超限红字直接显示在清单区（与后端 IMPORT_TOO_LARGE 同口径）。
- 预览路由：1 条 → 单文件预览（可编辑、动作清单、错误面板、确认导入，粘贴与文件条目一视同仁）；≥2 条 → 批量预览：文件表格（相对路径、识别类型、内容列显示**「文件 → 存储名」实际名称**（如讲义「第4讲」/ 单元「练习四」· 8 题）、error/warning 数、动作摘要）+ 展开单文件预览（CodeMirror 标红 + 渲染 + 顶部统计条同样带实际存储名）+ 跨文件冲突检测。
- 目标文件夹选择（可就地新建）/「按子目录自动建文件夹」；可选「同时加入课程 X」（追加目录末尾，带可见开关）。
- 提交：逐文件独立事务（前端顺序调用 + 进度显示），有 error 的文件自动跳过，汇总报告可展开原因；批次可经 `GET /import/batches/:batchId` 回看。
- **「复制错误给 AI」新格式**（D21）：路径 + 错误列表（行:列、CODE、中文说明）+ 每个错误前后各 3 行的原文片段（相邻合并、超 200 行截断），**不附全文**；单文件与「复制全部错误」两种。
- **AI 出题助手**（`/spec` 路由配套）保留：一键复制「DSL 规范 + 完整样例 + 提示词模板」→ 交给任意大模型生成练习 → 粘回导入。
- `reparse` CLI（pnpm reparse）：解析器升级后从原文重抽结构化字段。

### 2.4 课程 `/t/courses`、`/t/courses/:id`（T2A.4 + T2A.6）
- 列表：课程卡片（名称、成员数、条目数、可见条目数、有作答标记）；新建（名 + 简介，创建后直达编辑页）；归档筛选（默认未归档）；归档/恢复；删除仅当无作答（否则 409 提示改用归档）；删除/归档不影响资源库内容。
- 编辑页页签：
  - **目录**：拖拽排序 + 上移/下移按钮；插入分节标题；每条状态标签（可见 / 隐藏 / 定时（北京时间）/ 已删除 / 无题目）与可见开关、定时发布；「从资源库添加」侧边抽屉（讲义/单元页签、文件夹筛选、搜索、多选、已在本课程置灰、D8 配套练习默认勾选一并添加）；「学生可见预览」开关（按 D5 只读展示成员此刻可见目录）。
  - **成员**：从学生中多选添加、批量移出（确认弹层说明影响：已交卷记录保留）。
  - **进度**（T2A.6）：成员 × 可见单元矩阵（次数、首次分、最近分、最近作答时间、待批数——Phase 3 起为共享谓词口径），点击单元格显示历次列表，**历次点击进作答详情**（T3.1 D8 衔接）。
- 课程页提供「布置作业」入口（带入该课程直接打开向导）。

### 2.5 学生管理 `/t/students`（T2.1 + T2A.4）
- 列表：姓名、登录名、创建时间、备注、归档标记 + **所在课程列**；默认隐藏已归档，可切换显示。
- 新增：姓名 + 登录名 + 可选初始密码 + 备注，**可选加入课程**。
- 两种登录方式独立开关；复制专属链接、重置密码/链接、归档/取消归档。
- 行操作「管理课程」（多选课程，调用成员接口——与学生页/课程页同一组接口）。

### 2.6 作业管理 `/t/assignments`（T2.2 + T2A.7 + T2A.8）
- **布置（三步向导）**：① 对象（选课程 → 名单默认带出全部成员可取消勾选；或不选课程直接选学生）② 内容（「本课程练习 / 资源库」双页签多选，含隐藏条目并标注状态；右侧已选列表拖拽排序、显示总题数与题型分布）③ 确认（标题默认「首个单元标题 等 n 个单元」、截止时间、答案公布时机「交卷即公布 / 截止后公布」、D15 已做过提示「张三：已在〈课程〉中做过〈单元〉n 次」仅提示不阻止）。
- 列表卡片：课程名、单元清单（含已删标记）、总题数、名单四态统计（未开始/进行中/已交卷/已批改）、内容锁定与「含已删除单元」标记；按课程筛选。
- 编辑：改标题/截止/公布时机；名单随时增删（新增立即可见；移出未开始直接移除，移出已开始/已交卷需二次确认，结果保留）；「补充课程新成员（N 人）」快捷按钮；任一学生开始作答后单元列表锁定（改内容 409，标题/截止/名单仍可改）。
- 删除为软删（学生端立即不可见，作答保留）。
- 已交作业的查看与批改见 §2.8 数据页 / §2.9 待批队列（名单状态点击直达该生作答详情，T3.1 D8）。

### 2.7 共享 `/t/shared` 与管理端 `/a`（Phase 2B）
- 共享页：浏览 `DATA_DIR/shared/` 下的快照与本地 `.md`（前 200 个、单文件 ≤1 MB）、预览渲染、「导入到我的资源库」（导入进自己的域）；教师删除自己发布的文件，管理员可删任意；资源库列表勾选后「发布到共享」生成独立快照。日常使用见 `docs/部署.md` §3.3。
- 管理端 `/a`（仅 isAdmin）：教师账号（创建 / 改登录名 / 重置密码 / 禁用启用 / 授予撤销管理员）、注册开关、共享文件管理；**看不到任何教师的业务数据**。

### 2.8 数据页 `/t/data`、`/t/data/attempts/:id`（T3.1，T3.2b/T3.3/T3.4 增强）
- **三视图**：按课程（默认，课程练习历次「第 n 次」+ 关联作业）/ 按作业 / 按学生（前端分组）；筛选 sourceType / status / studentId / from / to 全量同步 URL；分页（默认 50，最大 200）。
- **包含进行中草稿**（D5）：列表带「进行中」徽章；详情只读展示当前草稿（已答内容 + 笔迹），判定列显示「未交卷」，不实时自动刷新。
- 列表卡片：学生、来源（类型 + 课程/作业名 + attemptNo）、单元数/题数、状态、得分（`scoreFinal ?? scoreAuto`，D2 口径）、待批数（共享谓词口径）、时间与 activeSec；「待批 N」徽章入口直达待批队列。
- 详情页：来源头（「作业 · 课程名」或「课程：xx · 第 n 次」）、得分汇总（对/错/待批计数、scoreAuto、scoreFinal）、逐题列表（全卷连续题号 + 单元节标题、快照题干 `<RichMarkdown>` 渲染、本人答案、自动判定 / 最终判定 / 判定来源、activeSec、hintsUsed、changeCount、**参考答案与详解**〔已交卷才下发，教师端不受泄露约束〕）、每题「改判 / 评语」内联编辑（T3.2b，对自动判过的题亦可改判）。
- 手写：缩略图懒加载 + lightbox 放大；「快照 / 回放」切换（T3.3 `<InkReplay>`：atrament 按点时间戳重演、excalidraw 逐笔匀速近似；播放/暂停/进度条拖动/1×2×4× 倍速；矢量缺失降级 PNG + 提示）。
- 入口衔接（D8）：作业详情名单状态点击、课程进度矩阵历次点击 → 作答详情。
- 「导出 CSV」按钮（T3.4）：携带当前筛选（或详情页按来源定位）下载 `GET /api/teacher/export/csv`——全部来源、仅已交卷、每题一行 19 列、UTF-8 BOM（Excel 直接打开中文不乱码）、公式注入防护、手写笔迹 PNG 绝对链接。
- 接口：`GET /api/teacher/attempts`（列表，studentId/courseId/assignmentId/unitId/sourceType/status/from/to/limit/offset）、`GET /api/teacher/attempts/:id`（详情，draft 亦可用）；教师乙访问甲的 attempt → 404。

### 2.9 待批队列 `/t/data/pending`（T3.2b）
- 单题卡片连续批改：题干快照、选项、参考答案、学生最终答案（serializeStudentAnswer 口径）、手写 PNG 懒加载 + 放大、行为统计（用时/提示/改答案）、来源上下文（课程/作业/单元/第 n 次）、提交时间。
- 快捷键：J/K 上下题、1 标对、2 标错、0 清除判定、U 撤销上一题；顶部批改进度 x/y；乐观离队失败回滚；课程/作业/学生三筛选同步 URL；空态两分（「没有待批题」）。
- 接口：`POST /api/teacher/responses/:id/mark`（`{ mark: 'correct'|'wrong'|null, comment: string|null }` 一次提交；draft → 409 NOT_SUBMITTED；非本人教师 404）、`GET /api/teacher/pending-marks`（D4 口径：已交卷 attempt 中 `finalCorrect IS NULL`，submittedAt 升序先交先批）。
- 批改后各处联动（D2）：作业名单「已批改」统计、课程进度矩阵待批消除、各处得分切换为 scoreFinal 优先（缓存统一失效）。

## 3. 学生端功能明细（/s/*）

顶栏导航定稿（T2A.5/T2A.9 + T3.5）：**首页 / 课程 / 我的记录** + 退出；讲义为二级页面（主要入口是课程目录）。

### 3.1 登录（T2.1/T2.3）
- 专属链接 `/s/:token`：点开即登录（失效/被重置/被关闭时给中文提示 + 去密码登录入口）。
- 密码登录 `/s/login`：登录名+密码；错 5 次锁 10 分钟；会话 90 天。
- 顶栏「退出」登出。

### 3.2 首页 `/s/home`（T2.3/T2.6 + T2A.5）
- 作业卡片：「n 个单元（…）」、合计题数、截止（北京时间或不限）、状态徽章（未开始/进行中/已交卷/已批改）；入口随状态变（开始练习/继续作答/查看结果）。
- 我的课程卡片：课程名、进度条（至少交卷 1 次的可见单元数 / 可见单元总数）。
- 「我的作业」分区头带「我的记录」入口（T3.5，与顶栏导航同指 /s/records）。
- 移出课程或课程归档后立即不可见（D5/D7）。

### 3.3 课程 `/s/courses`、`/s/courses/:id`、`/s/courses/:id/units/:unitId`（T2A.5 + T2A.6）
- 我的课程列表（名称、简介、可见讲义/单元数、已完成单元数）；课程目录按 D5 过滤：分节标题、讲义项（阅读入口）、单元项（题数 + 状态徽章：未做 / 进行中 / 已完成（最近 xx 分 · 共 n 次）/ 有待批）。
- **隐藏/未发布/已删除条目对学生零信息**（连数量都不暴露）；非成员或课程归档 403。
- 单元落地页：题数与题型分布、历次记录列表（attemptNo、状态、得分、交卷时间）、首次/最近/最高分；开始练习 / 继续作答 / 再做一次（确认「将开始第 n+1 次，从空白开始」，新一次不预填上次答案与笔迹）；历次可逐次只读回看（各自快照）。
- 课程练习交卷即公布参考答案与详解（练习性质，可重做对照订正，D11）。

### 3.4 讲义 `/s/lectures`、`/s/lectures/:id`（T2.3 + T2A.5）
- 列表：**只含所在课程可见讲义**，按课程分组（同一讲义多课出现只列一次，带课程上下文）。
- 阅读页：全文渲染（公式/折叠/步骤逐步揭晓/示例）、H2/H3 自动目录、横屏双栏；课程上下文显示；底部「本课配套练习」（仅同课程中可见的配套单元，D8）。

### 3.5 答题页 `/s/attempts/:attemptId`（T2.6 + T2.8–T2.12 + T2A.6/T2A.7）
- 两种来源共用同一答题页（`/s/assignments/:id` 保留为入口）：顶部来源行「课程：xx · 第 n 次」或「作业：xx」。
- 多单元作业按单元分节（节标题 = 单元标题），题号全卷连续。
- 题卡与作答控件、手写（页内 Atrament + 全屏 Excalidraw）、分步提示（未请求的提示绝不下发）、草稿防丢（本机 IndexedDB + 增量同步 + 顶栏三态）、交卷（确认弹层 → 服务端判分 → 快照冻结）——同 Phase 2。
- 结果视图：得分汇总（大数字 `scoreFinal ?? scoreAuto`——全部批完标「最终得分（含老师批改）」，否则「自动判分得分」；待批计数为 summary.pendingCount）、多单元分节、逐题最终判定（finalCorrect 优先）与 ✓/✗/待批、本人答案 vs 参考答案、**老师批改块**（T3.5 D9：判对/判错/已评语 + 评语文本，公布后渲染）、详解折叠、笔迹缩略图、已解锁提示回看；作业答案公布时机为「截止后公布」时，截止前只显示已交卷与本人答案（不下发对错与详解，T2A.8）。
- 学习事件：作答全程埋点，服务端按事件计算每题有效用时；失去课程访问权（被移出）时草稿同步/交卷 403 且停止重试。
- 课程作答接口全部接入泄露测试（未交卷不下发答案/详解/未请求的提示）。

### 3.6 我的记录 `/s/records`（T3.5，D10）
- 本人**全部作答**（作业 + 课程练习混排）按最近活动时间倒序的索引；筛选 sourceType / courseId / assignmentId / status / from / to + 分页，全部同步 URL（刷新/返回不丢）。
- 卡片：来源徽章、状态徽章（进行中/已交卷/已批改）、来源标题（作业标题或「单元标题 · 第 n 次」）、得分（`scoreFinal ?? scoreAuto`；after_due 未公布显示「待公布」）、待批徽章、时间。
- 点击已交条目进单次结果视图（§3.5 结果视图，含老师批改块）；进行中条目即「继续作答」。
- 可见性：已移出课程的**已交卷**记录保留；已失权的进行中草稿不列出。
- 接口：`GET /api/student/records`（六筛选 + 分页 + total；泄露测试 assertNoLeak 接入）。
- 页头「错题本」入口（§3.7）。

### 3.7 错题本 `/s/records/wrong`（T3.5，D11）
- 聚合键 (学生, questionId)，跨全部来源（作业 + 课程练习）；只统计**已判定**作答（已交卷且 finalCorrect 非 null，待批不参与）；任一次判错即入本。
- 默认只显示「最近一次判定仍为错」；「显示已攻克」开关额外列出「曾错、最近一次已做对」；条目标注首次是否做对（最早一次已判定作答）。
- 考点 chips 筛选（服务端参数，选项从全量形态聚合）；条目：题干快照 `<RichMarkdown>`（[[答案]] 渲染为空框）、选项正确项标记、我的最近答案（serializeStudentAnswer 口径 / 未作答）、正确答案（公式管线渲染或「由老师批改后公布」）、详解折叠（复用结果视图 SolutionFold）、最近来源徽章 + 上下文 + 相对时间。
- after_due 未公布作业的作答**整体不参与聚合**（题目出现在错题本即等于泄露对错）。
- 接口：`GET /api/student/wrong-questions?knowledge&includeResolved`（assertNoLeak 接入）。
- 学生端笔迹回放不做（教师端专属；学生记录只看 PNG 快照，如需再立项）。
