# 手写与同步

本文件承接根 AGENTS.md 的专题约定；涉及本专题的任务必须在制定方案和修改前阅读。全局开发规则见 [AGENTS.md](../../AGENTS.md)。更新专题行为时同步维护本文件，不再向根文件追加实施细节。

## 作答圈画与草稿交互约定

- 题卡密度（2026-10-25）：作答题卡上下内边距 12px、横向 16/20px，题间距 12px；题头到题干 8px、题干到选项 12px。单选/多选选项最小触控高度 44px、上下内边距 8px、行间距 6px，字母在固定列内水平居中、在选项行内垂直居中；独立「0.」「1.」按正文显示，不解释为空有序列表。题面 Markdown 只移除首尾块外边距，保留内部段落与完整公式/图片，不截断长选项。正常题面与底图导出复用同一排版；旧稿继续经过布局核验，无法复现时保留原稿查看保护。

- 阅读空间（2026-10-25）：练习、纯讲义与讲练的顶栏在所有窗口宽度（含 iPad 横屏与电脑）随正文向下阅读收起、反向阅读展开，不设 1024px 分界；自动跳题、内层滚动、手写、输入与弹层不触发收起，键盘聚焦可找回，错误提示保持可达。导航平移不得改变题面布局或笔迹坐标。历史版本提醒随正文滚动。手机列表底栏以答题卡入口合并填写数；单题以题号入口合并跳题，与上一题及主动作共用一行，跳过题目通过答题卡；完整填写/提交进度与提前交卷在答题卡面板查看，更多菜单保留提前交卷。桌面保留侧栏与进度条，离线/保存失败等异常提示不随进度隐藏。

- 跨设备原位续写（2026-10-24，第二批）：新底图可携带版本化公开几何、字体与文本行框证据；固定逻辑宽度后逐块核对，允许字体序列化与最多 0.75 CSS 像素的内核基线差异，真实换行、题目内容或版本变化继续拦截。兼容稿自动在原题卡显示并从唯一圈画入口续写，复用原生作答控件与原笔迹坐标。历史稿只有哈希时必须命中原签名；显式续写可由已核验设备补充一次证据，服务端再次校验原内容、几何和字体哈希，原 PNG、旧签名、正文版本、待传标识、封存证据与活动时间不改。无法核验的旧稿仍保留原稿查看，不猜测排版、不要求清空或重开。
- 圈画底图本机持久化（2026-10-24）：IDB 同一条记录以 PNG 字节保存底图及矢量、布局与待传身份，避开部分 WebKit 的 Blob/File 写入失败；读取及前缀扫描恢复 Blob，兼容已有 Blob 记录。坏字节须报错保稿，不当作无稿；只在实际事务成功后解除保存失败保护。底图分键（2026-10-26 批次五）：底图 PNG 以字节内容指纹入独立键 `["annotation-base",…六元,指纹]` 只写一次（同引用或同字节不重写），每笔收笔只写不含 PNG 的小正文记录（localBase 携带指纹引用）；写序恒先底图后正文、旧内容键永不删除，中断窗口自洽；旧单键内嵌格式可读，下次落盘顺带拆键；读取按指纹复核字节，失配或缺失照坏字节纪律报错保稿。
- 非整数系统缩放（2026-10-24）：正常题面与导出副本共用稳定像素框，按真实 1px 边框测量修正原生像素取整，再抵消视觉缩放；不以模拟 deviceScaleFactor 代替原生缩放测试。补偿不得改变逻辑宽度、文档流高度或笔迹坐标，隐藏题显示后仍须适配；整数像素环境不额外测量题面或创建尺寸观察器。

- 跨设备原稿查看（2026-10-24）：查看保存时的底图与矢量笔迹不依赖当前浏览器的题面布局签名。作答页沿用唯一圈画入口；无 layout 的旧版底图打开只读原稿弹窗，布局不兼容但带 layout 的可读底图按下述固定底图续画规则处理，保留原生题面和唯一作答控件；原位编辑继续严格校验布局。布局不兼容但底图可读（本机 PNG 或云端 ready 底图带 layout）时，改为内联固定底图续画区块在保存底图上继续圈画，不自动弹只读弹窗、不改原生题面与作答控件；无 layout 的 v1 底图仍走只读弹窗。续画工作台挂载期间持有本题收笔注册，卸载后 overlay 重新注册，切题 flush 不落空。查看不重建底图、不创建待传空稿、不改写历史或封存证据；底图加载失败可重试，底图与笔迹坐标尺寸不符不得叠画。结果回看与作答态共用原稿绘制组件，换题、账号、重置代次或隐藏时关闭原稿弹窗。

- v1 旧版底图与编辑器横幅语义（2026-10-26）：打开圈画时发现 v1 旧版底图（本机缓存或云端回填，无 layout）直接进入只读原圈画查看并说明「此题标画为旧版」，不报错、不要求重新开始练习；导出合成对旧版底图明确告知暂不支持。编辑器全局横幅只承载「保存未完成」的收笔落盘失败（保留原编辑者、可重试，retry 重放同语义）；「打开失败」（prepare 前置条件不满足）不进横幅、不提供全局重试，由调用方（题目卡内 role=alert）就地呈现，错误原样抛回。云端底图 PNG 下载失败退避约 1s 重试一次（每次仍 15s 超时），取消与会话切换在等待间隙同样拦截，两次失败才报「下载失败，请重试」。

- 本机存储异常（2026-10-24）：事务返回空错误时显示可读原因；连接失效或事务中止后，下一次显式操作重新建连，不自动重放写入、不清理数据库或原稿。圈画重新打开和收笔时可重试原记录，必须保留底图、矢量、文档版本与待传标识；实际写入成功前不解除保存失败保护。编辑错误在标题正常布局内展示并提供重试，不另设高层悬浮条遮住标题。

- 学生对照自评（2026-10-24）：填空、解答、应用、找错等题，已提交且参考答案按当前规则公布后，学生可选择「对了／错了／暂不判断」，即时生效、无需教师再次确认。判定来源始终区分教师、自评、自动；教师判定优先，自评不得写 teacherMark，教师清除后依次回落自评和原自动结果。新协议卷与讲练的新冻结行使用自评策略，旧协议/历史冻结行保留原判分事实；待自评与教师待批分别计数。无实际参考答案（含仅有提示或解析、空白答案）不开放自评或逐题提交，随整卷交卷。自评不阻塞交卷、不改作答与原稿，修正自评更新错题集合，未判断不当作错。写入使用版本检查与幂等标识；错题和历史纳入已提交的单题时必须复用当前公布、课程可见性和作废守卫，不能仅删除 draft 过滤。

- 交卷始终提交全卷所有尚未提交的题（含未填写题）并结束整卷，不要求先逐题提交；已提交题保留原判定、提交时间和封存证据。整卷版本核验覆盖全部冻结题，本次证据声明只覆盖本次尚未提交题；前端使用含最新单题回执的题级进度派生范围。学生在教师授权范围内可自选「每题提交后查看」，只有该模式提供逐题提交；「交卷后查看」直接整卷交卷。

- 单题专注的题号与提交／填写进度仅在紧凑吸底栏展示，工作区不再常驻做题方式摘要行；「更多 → 做题方式」用弹窗承载唯一编辑器，关闭回更多入口。未作答只保留「不会，提交并看解析」，作答后同位改为「提交本题」；翻题为轻量箭头按钮，主动作承担下一题时隐藏重复翻题入口。列表模式保留行内摘要和原有交卷入口。
- 普通练习单题模式以服务端反馈工作流决定主动作：逐题反馈为提交本题／下一题／查看结果，整卷反馈为下一题／末题交卷。题级操作固定在吸底栏，提前交卷为次级入口；不重复呈现同目标的下一题或末题交卷。桌面答题卡侧栏与手机底栏弹层入口按空间互斥，本卷“更多 → 做题方式”复用摘要行的唯一编辑器。导航关闭回到实际入口，执行跳题时交给题目工作区聚焦。
- 已授权题级反馈的判定使用服务端 finalCorrect 优先、autoCorrect 兜底，两者均为空才显示待批；选择题保留原位只读选项与答案对照，不在反馈区完整重画选项。末题自动收尾后保留解析，详情轮询、重连及迟到响应不得替学生打开整卷结果；主动查看或离开重入才收敛。不放宽普通学生接口及未提交题的投影。

- 作答题卡外框跟随所在列表的可用宽度，不能按题型、草稿布局偏好或 AI 助教开合另设宽度上限；这些状态只控制卡内排版。无保存底图时题面填满当前题列；有保存底图时沿用其逻辑坐标尺寸并整体缩放，不用固定题面宽度掩盖外框差异。

- 手机端习题作答顶栏仅保留返回、单元名称与更多入口；课程、作答次数、题数和保存状态在「更多 → 练习信息」查看，保留保存详情、重试与题目定位。桌面端继续显示来源与保存状态。

- 首次圈画可在材料恢复成功后空闲预备可见题的公开底图：全局单任务，内存最多两份、总 PNG 两 MiB、三十秒过期；用户交互后重新计时空闲，指针按下或键盘操作立即取消在途预备，避免栅格化与显式打开争用主线程；隐藏、书写或会话切换时取消。预备不查云端、不创建本机稿、不上传空稿；显式打开仍核对云端、账号会话、题目版本、内容、布局与字体后才落盘。已有底图不被预备覆盖。稳定等待可返回已验证快照，生成后的真实题面校验不可省略。
- 圈画阶段耗时仅在开发模式用固定名称记录，不含题面、答案或账号标识；结果回看按需加载，加载失败提供重新加载入口。草稿同步的操作、材料恢复和完整状态分别订阅，恢复失败和冲突保护不能因优化失效。

- Markdown 渲染入口使用 React 默认属性比较跳过相同属性下的重复解析；不得用仅比较 source 的自定义比较器忽略回调、展示模式或样式，填空与指令上下文变化必须继续更新内部交互。

- 打开圈画、保存底图与编辑者收笔只等待当前账号、作答、题目和阶段的本机标画落盘；交卷继续等待全部标画落盘。材料恢复的本机读取与云端标画按最多四题一批执行，失败后等待本批在途任务结束再允许重试；草稿正文保留已有最多百题并发。所有材料核对成功前不解除作答保护，读取失败不得视为无稿。

- 作答跨设备同步按题目及材料独立合并：不同题目或不同材料的编辑自动保留并集，同一内容去重；同题同材料双方修改才要求选择「保留当前设备版本」或「采用云端版本」，不得以整卷覆盖代替裁决。答案使用逐题 `baseRevision` 与 `mutationId`；已采用版本协议的题目拒绝旧客户端无版本覆盖。新进入或重返作答先核对云端与本机材料，读取失败不视为无稿；未恢复、待传、本机保存失败或冲突时不得显示「全部已保存」。已核对的本机稿可离线续写。草稿纸工具栏不提供手感设置跳转，统一通过账号设置进入。

- 作答题卡展开的难度与考点与题号共用元信息行，空间不足时自然换行；更多菜单各项统一图标并使用下一步动作文案（显示/隐藏标画、显示/隐藏题目资料、标记/取消待检查）。
- 作答中的「导出本题」始终包含公开题面，并加入已有标画及本题草稿或正式手写；隐藏标画、收起纸面不排除材料。导出前收笔并确认本机落盘，从固定矢量重绘；读取/保存失败不得默默遗漏材料。长稿分页，每页重复题面，支持全部下载与逐页复制。结果页「AI 复习包」继续使用原有授权投影与封存语义。

- 橡皮按纸面坐标连续命中整笔，计入笔宽；擦除预览下标在正文删除前清除，抬笔、取消或强制收笔后不得隐藏未命中笔迹，一次拖动可一步撤销。标准硬笔、自然笔感和标画使用同一命中逻辑。
- 打开草稿或正式手写纸面后，仅在布局导致当前题卡位置变化且题干顶部离开可见区域时对齐至顶栏下方；正常打开、保存失败或用户先行操作不强制滚动。
- 同题圈画与草稿（或正式手写纸面）可同时展开；收起其中一个不隐藏另一个，切题仍先收笔并确认本机落盘，保存失败时保留原稿。
- 标画默认笔写、手指滚动，复用草稿的会话输入偏好；无笔设备通过「手指书写」明确启用。激活范围以淡蓝色外框标示，外框不改变题面几何。
- 草稿提供自动、左右分栏和上下排列；自动根据题卡可用宽度回退下方，显式选择优先。布局切换不重挂题面或草稿控制器；已有标画自动原位恢复，不再提供「查看／编辑／收起原标画」第二套入口。
- 草稿关闭时题干使用整行，不预留草稿列；仅实际展开且采用左右布局时分栏，上下布局不压缩题干。草稿开合保持外框宽度策略稳定，分栏宽度变化后先收笔再重新适配题面和笔迹，清除旧列宽下的手动放大状态。已有标画的题面固定保存时的 CSS 排版，真实题面与笔迹在同一区域等比缩放，窄屏可放大并横向浏览；尺寸变化先收笔，以逻辑坐标核对公开内容、字体与几何。不能仅拉伸笔迹覆盖重新换行的题面。无法复现的旧布局不再替换原生题面或生成独立答案控件；保持题干内作答，禁止将旧笔迹叠到新排版。经明确授权的维护重置使用按作答隔离的标画代次，旧本机稿先归档，旧代次上传须拒绝。
- 清空标画先结束在途笔，再清空正文，支持撤销；Portal 菜单操作不触发题卡退出标画。原位标画导出按底图保存的 CSS 尺寸重放，PNG 像素尺寸保持不变。
- 标画底图与回看合成图按已挂载的导出副本收集字体，不缓存 `document.body` 的字体 CSS 快照；仅缓存成功读取并校验的本站字体资源，失败须显式报错并允许重试。已有笔迹、绑定或封存的底图不得因字体修复自动覆盖。
- 底图布局冲突的裁决出口（2026-10-25，批次三 P0-2）：标画 409 冲突按 kind（revision/mutation/layout）落库，旧记录缺 kind 按有无云端摘要推导。layout 冲突「保留本机」＝本机保留、不再自动同步（retained 态，新笔画不排队上传，本机稿与底图照常查看导出），「采用云端版本」＝采用云端正文并把本机底图重绑为云端 PNG（下载失败保留冲突态可重试），「重新尝试同步」清保留态补传一次；revision/mutation 维持对齐/重铸重传。上传撞服务端已 ready 且同核布局的底图时直接采纳重绑，不再当冲突。服务端 pending 底图行超过 24h 未回传 PNG 允许后来设备接管（更新布局与身份三要素；行无 imagePath 无内容，不算改写历史）；ready 行永不接管、永不重生成。

## 学习记录与近似原位（2026-10-27，LR-PR4 / LR-PR5）

- 学习记录（LearningRecord）是服务端从既有表与 blob **现算**的只读聚合：草稿/正式手写/题干圈画三类材料的笔画、擦除墓碑、笔间停顿与时序覆盖度均从文档现算，不落新表。`GET …/record`、review-pack 的 `record.json`、教师 MCP `get_question_learning_record` 都是它的投影（记录是事实源，渲染/导出/AI 是投影）。
- 圈画跨设备（LR-PR4）：布局签名不兼容但锚全在时进「近似原位」——活笔画按语义节点重投影显示在当前题面上，新笔反向映射回保存底图坐标域；无锚旧稿仍走固定底图续画/只读。重投影与域换算单源在 `annotation-reproject.ts`。
- AI 上下文（LR-PR5）：claim/dispatch/share 三个受控出口新增可选 `record`——点序列经 RDP 简化（ε=坐标域宽×0.3%），单材料超 6000 点按笔均匀抽稀并置 `compacted:true`；任务创建把三类材料 `(revision, hash)` 钉进快照 `recordRefs` 并入 contextVersion。分享页的 record 序列化会清洗 UUID 形态字符串（SAI-29：不落内部标识）。
