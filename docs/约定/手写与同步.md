# 手写与同步

本文件承接根 AGENTS.md 的专题约定；涉及本专题的任务必须在制定方案和修改前阅读。全局开发规则见 [AGENTS.md](../../AGENTS.md)。更新专题行为时同步维护本文件，不再向根文件追加实施细节。

当前题卡圈画的模块入口、版本兼容、扩题型检查与排障顺序见 [圈画架构与维护指南](../圈画架构与维护指南.md)；本文件仍是行为约定。

## 作答圈画与草稿交互约定

- 材料圈画运笔时在现有画布逐帧追加新采样。橡皮、丢弃在途笔、替换草稿或画布尺寸变化时按矢量重建。收笔和更新保稿继续以完整采样及本机写入结果为准。
- 普通 Atrament 笔迹按绘制顺序回放时保留已画像素，停顿期间不重绘。回拖或换数据时重建目标画面。重叠时序、特殊笔刷和「看擦改」使用完整回绘以保持层叠与擦除语义。

- 材料分栏手势（2026-11-06）：笔写偏好下手指事件不取消默认滚动；只有状态机接受落笔时才拦截，Safari 原生触摸侧只阻止 stylus 平移。纯显示墨层不参与触摸命中，不把绘图库残留的 `touch-action:none` 施加给手指。冻结材料适应宽度时只裁剪横向溢出，分栏正文不创建内部滚动容器，纵向阅读由材料列独立承担；显式 1:1 放大仍保留横向滚动。材料与中缝各有占满本组网格行的外框，粘性元素受此外框约束，不侵入下一题组或普通题；开启圈画时材料列外框高亮。题目向上阅读时材料在本组边界内保持可见，普通滚动不重置材料阅读位置。

- 版本更新保稿（2026-11-04）：发现新版本不自动刷新正在使用的页面。用户选择保存并更新前，必须先结束在途指针与输入法组合输入；更新准备期间冻结新增输入，失焦后的最后一次答案变更纳入本轮保存，再逐编辑表面收笔并核验真实保存结果。普通答案、正式手写、草稿纸、题面与材料圈画、订正草稿均受保护；不能以“全部已保存”等展示字符串或吞错的 `flush` 返回成功代替本机事务与同步状态检查。
- 更新准备失败保留原页面、画布、正文和待传身份；读取失败、落盘失败、冲突、权限拒绝、仅保留本机稿或正文仍待传时阻止更新，并允许处理后重试。等待中账号、练习或材料作用域变化，旧的保存完成结果不能放行新会话。编辑器卸载后的在途本机队列由整页常驻末轮复核兜底，即使从学生端切到教师端也不能注销保护；显式退出后仍在内存的旧账号稿件必须成功落盘，但旧账号已落盘的待传稿不要求以新账号上传。检查仅涉及已加载记录，跟随新增队尾排干，不扫描历史稿，也不清理未同步材料。
- 更新只保存现有编辑，不代替交卷、逐题提交、订正封存或冲突裁决；订正反思等尚未保存的文字须由用户先完成原保存流程。其他页面引发的 Service Worker 接管也不得绕开本页保稿门禁直接刷新。多窗口更新采用保守策略：其他 OwnClass 页面先保存并关闭，旧版或未响应窗口不能当作安全放行。

- 纸面全屏时保留原画布及撤销历史，覆盖作答顶栏与底栏；背景不可交互，纸面中的菜单和确认弹窗仍可操作，退出后恢复背景与焦点。
- 普通题草稿和计算题正式手写共用纸面画布与工具栏，默认格线；两者继续使用各自的保存与提交语义，草稿不计作正式答案。
- 限时卷到达截止时收笔并锁定编辑。宽限内已写的正式手写继续补传，保留读取重试与版本裁决入口，离屏题有待传笔迹时恢复上传。宽限结束后只保留待传本机稿，学生确认按服务端已存作答交卷后，结果页仍保留本机稿。已确认封卷的本机作答仍须通过 PWA 本机落盘检查，之后可随版本更新保留。草稿纸的交卷证据仍走原有确认流程。

- 新题型可读性（2026-10-26）：配对题完整选项固定展示，原生下拉框以编号选择，选择前后题面高度稳定；开放题统一正文框保留旧标题文字。新建底图时核验公开投影与槽位几何；已存稿按原逻辑框恢复真实题面与同域笔迹，不能按目标设备活排版覆盖原基准。2026-10-27：下拉 option 正文采用共享保守清洗（`features/markdown/plain-text`，与错题摘要单源）——货币 `$`、字面下划线、乘号 `*`、全角空格等字面内容不改写，仅剥确定的装饰语法与无空白/CJK 的行内公式定界符。
- 材料题分栏工作区与协同标画（2026-10-27）：带材料题（题组共享材料与题级 ::ref 材料）在作答页提供左右分栏，中缝把手支持 35%~65% 拖拽与键盘步进（Home/End 极值），命中区与切换控件满足 44px 触控；「左右分栏 / 列表形式」为学生偏好，按部署、角色与账号隔离持久化（practice-preference 同模式），题组锚与题级材料锚提供同一切换入口，AI 对照激活等强制上下排布的语境不提供切换（控件状态恒与真实布局一致）。分栏网格生效（列表与单题同口径）：材料列为视口级粘性 + 独立纵向滚动端口（overflow-y:auto + overscroll-behavior:contain + isolate 层叠上下文），材料滚动不与页面/题卡列表争夺焦点，视觉范围严格裁剪在本组网格边界内不侵入相邻题卡；当前聚焦题（滚动侦测/跳题单源）切换时材料列平滑回顶。题卡头部窄列防坍塌：题号/题型徽标/作答状态禁逐字换行（整项换行、不逐字竖排），题卡声明命名容器（@container/question-card）后工具栏文字随题卡自身宽度折叠为图标（aria-label 恒可访问），极窄时工具栏间距一并折叠（触控目标恒 ≥44px），不再用视口断点。材料圈画与题面圈画共用引擎单源：笔色/笔粗（INK_PEN_COLORS/SIZES 逻辑单位）、整笔橡皮（INK_ERASE_RADIUS，半径内含半笔宽）、atrament 绘制原语与 pointer-machine 输入状态机（固定笔写，手指滚动不落墨）。材料笔迹按 1000 逻辑宽归一化存 attempt 本机草稿 `materialInks`，键含材料版本（QM-15 双版本卷互不覆盖）；交卷清稿保留材料笔迹供结果页只读回看（无服务端同步链路期间的本机唯一稿）。分栏宽度变化或窗口失焦时在途一笔先按已收采样收笔（一笔不混用两个排版基准）。材料已有基准时在阅读和圈画态持续保留固定逻辑框，分栏拖拽只整体等比缩放；退出圈画仍显示笔迹并允许阅读交互。不再使用活排版失配后隐藏笔迹及「按圈画时排版查看」切换。首次无基准须等字体、图片和尺寸稳定后落笔；已有基准按原宽高核验，10px 内正常放行，超限先收笔、保稿并停写。清空后可释放基准；无基准的旧非空稿不得自动重冻。材料仍只有本机存储，无题卡 PNG 或云端同步。
- 题卡密度（2026-10-25）：作答题卡上下内边距 12px、横向 16/20px，题间距 12px；题头到题干 8px、题干到选项 12px。单选/多选选项最小触控高度 44px、上下内边距 8px、行间距 6px，字母在固定列内水平居中、在选项行内垂直居中；独立「0.」「1.」按正文显示，不解释为空有序列表。题面 Markdown 只移除首尾块外边距，保留内部段落与完整公式/图片，不截断长选项。正常题面与底图导出复用同一排版；已存 v2/v3 稿按原逻辑框恢复真实组件并核验原几何证据，显示缩放不改变矢量坐标。

- 阅读空间（2026-10-25；2026-11-06 修订）：练习、纯讲义与讲练的顶栏在所有窗口宽度（含 iPad 横屏与电脑）随正文向下阅读收起、反向阅读展开，不设 1024px 分界；草稿与正式手写纸面仅展开时不锁定顶栏，纸面开合前后正文滚动规则一致。圈画模式、自动跳题、内层滚动、画布操作、输入与弹层不触发收起，键盘聚焦可找回，错误提示保持可达。导航平移不得改变题面布局或笔迹坐标。历史版本提醒随正文滚动。列表模式在所有窗口以底栏答题卡入口合并填写数，并在弹层内按已核对的作答与本题笔迹状态筛选。单题专注模式在所有窗口以底栏题号入口打开答题卡，与上一题、下一题及主动作共用一行，桌面另显示进度条；单题答题卡面板可查看填写和提交进度，提前交卷从更多菜单进入。离线与保存失败提示独立可见。

- 跨设备题卡圈画（2026-11-05 整题缩放修订）：真实题面、原生答案控件与同域墨层按原逻辑框等比缩放，退出圈画仍直接作答；无 PNG 主视图、图片控件恢复或作答切换。v2/v3 原布局、PNG、ready 身份与正文不改写，按原证据核验；v1 缺位置证据明确保稿，历史证据导出保留。
- 圈画底图本机持久化（2026-10-24）：IDB 同一条记录以 PNG 字节保存底图及矢量、布局与待传身份，避开部分 WebKit 的 Blob/File 写入失败；读取及前缀扫描恢复 Blob，兼容已有 Blob 记录。坏字节须报错保稿，不当作无稿；只在实际事务成功后解除保存失败保护。底图分键（2026-10-26 批次五）：底图 PNG 以字节内容指纹入独立键 `["annotation-base",…六元,指纹]` 只写一次（同引用或同字节不重写），每笔收笔只写不含 PNG 的小正文记录（localBase 携带指纹引用）；写序恒先底图后正文、旧内容键永不删除，中断窗口自洽；旧单键内嵌格式可读，下次落盘顺带拆键；读取按指纹复核字节，失配或缺失照坏字节纪律报错保稿。
- 非整数系统缩放（2026-10-24）：正常题面与导出副本共用稳定像素框，按真实 1px 边框测量修正原生像素取整，再抵消视觉缩放；不以模拟 deviceScaleFactor 代替原生缩放测试。补偿不得改变逻辑宽度、文档流高度或笔迹坐标，隐藏题显示后仍须适配；整数像素环境不额外测量题面或创建尺寸观察器。

- 题卡固定原稿流程（2026-11-05）：首次显式打开先稳定渲染公开题面，PNG、layout 与空文档先本机可靠落盘；无笔、无墓碑、无绑定/待传/冲突的预备不上传，题目 revision 改变时才可重建。首笔后按既有先 PNG、后正文的 CAS/mutationId 链同步。已有 ready、画后擦除稿、冲突或封存不得重冻。真实题面显示按来源、正文坐标与 DOM 几何核验，不依赖 PNG 解码；开笔继续要求可靠资产落盘和身份一致。来源 baseId 不同且正文归属不明时阻断叠画，待传或 retained 本机稿坚持本机 PNG+正文。读取失败不能当空稿。十题型共用唯一真实题面和原生答案控件，退出圈画先收笔落盘，再直接作答；笔态禁输入但保留值，缩小后可放大 1:1，不设置作答视图切换。

- 旧稿与编辑器横幅语义（2026-11-05 修订）：v1 无 layout 缺真实位置证据时，就地提示无法恢复并保留原稿，不再以图片替换真实题面；不要求重做题目，不新增专用恢复管线。历史证据仍可按原 PNG 与正文合成导出。编辑器全局横幅只承载「保存未完成」的收笔落盘失败（保留原编辑者、可重试，retry 重放同语义）；「打开失败」（prepare 前置条件不满足）不进横幅、不提供全局重试，由调用方（题目卡内 role=alert）就地呈现，错误原样抛回。云端底图 PNG 下载失败退避约 1s 重试一次（每次仍 15s 超时），取消与会话切换在等待间隙同样拦截，两次失败才报「下载失败，请重试」。

- 本机存储异常（2026-10-24）：事务返回空错误时显示可读原因；连接失效或事务中止后，下一次显式操作重新建连，不自动重放写入、不清理数据库或原稿。圈画重新打开和收笔时可重试原记录，必须保留底图、矢量、文档版本与待传标识；实际写入成功前不解除保存失败保护。编辑错误在标题正常布局内展示并提供重试，不另设高层悬浮条遮住标题。

- 学生对照自评（2026-10-24）：填空、解答、应用、找错等题，已提交且参考答案按当前规则公布后，学生可选择「对了／错了／暂不判断」，即时生效、无需教师再次确认。判定来源始终区分教师、自评、自动；教师判定优先，自评不得写 teacherMark，教师清除后依次回落自评和原自动结果。新卷按所属教师的自评设置冻结判分策略，历史冻结行保留原判分事实；待自评与教师待批分别计数。无实际参考答案（含仅有提示或解析、空白答案）不开放自评或逐题提交，随整卷交卷。自评不阻塞交卷、不改作答与原稿，修正自评更新错题集合，未判断不当作错。写入使用版本检查与幂等标识；错题和历史纳入已提交的单题时必须复用当前公布、课程可见性和作废守卫，不能仅删除 draft 过滤。

- 交卷始终提交全卷所有尚未提交的题（含未填写题）并结束整卷，不要求先逐题提交；已提交题保留原判定、提交时间和封存证据。整卷版本核验覆盖全部冻结题，本次证据声明只覆盖本次尚未提交题；前端使用含最新单题回执的题级进度派生范围。学生在教师授权范围内可自选「每题提交后查看」，只有该模式提供逐题提交；「交卷后查看」直接整卷交卷。

- 列表与单题专注共用「更多 → 做题方式」弹窗，关闭后焦点回到更多入口。允许逐题提交时，每题只显示一个「提交」，空白提交沿用服务端自动标记「不会」的规则。选中即提交开启时，单选的选项激活直接走同一条收笔、本机落盘、答案同步、证据和服务端提交链，正在提交的本题不可改选，其他单选的点选先保存并按顺序提交，失败保留作答并可重试。
- 单题专注的底栏显示答题卡入口与当前题号，以及上一题、主动作和下一题。桌面额外显示完整提交／填写进度。手机用图标，空间足够时加文字。逐题反馈时主动作依次为提交、下一题或查看本次结果，整卷反馈时为下一题或末题交卷。主动作已是下一题时只显示一次。答题卡关闭回到实际入口，跳题后聚焦题目工作区。
- 已授权题级反馈的判定使用服务端 finalCorrect 优先、autoCorrect 兜底，两者均为空才显示待批；选择题保留原位只读选项与答案对照，不在反馈区完整重画选项。末题自动收尾后保留解析，详情轮询、重连及迟到响应不得替学生打开整卷结果；主动查看或离开重入才收敛。不放宽普通学生接口及未提交题的投影。

- 作答题卡外框跟随所在列表的可用宽度，不能按题型、草稿布局偏好或 AI 助教开合另设宽度上限；这些状态只控制卡内排版。无保存底图时题面填满当前题列；有保存底图时沿用其逻辑坐标尺寸并整体缩放，不用固定题面宽度掩盖外框差异。

- 习题作答顶栏保留标题和操作。课程、作答次数、题数与截止时间集中在「更多 → 练习信息」。「更多 → 保存详情」独立提供逐题状态、重试和题目定位。正常保存摘要仅由辅助技术播报，保存失败等需要处理的状态在页面提示。

- 首次圈画可在材料恢复成功后空闲预备可见题的公开底图：全局单任务，内存最多两份、总 PNG 两 MiB、三十秒过期；用户交互后重新计时空闲，指针按下或键盘操作立即取消在途预备，避免栅格化与显式打开争用主线程；隐藏、书写或会话切换时取消。预备不查云端、不创建本机稿、不上传空稿；首次显式打开仍核对云端、账号会话、题目版本、内容、布局与字体后才落盘；已存原稿按保存身份、正文坐标和真实题面几何恢复。已有底图不被预备覆盖。稳定等待可返回已验证快照，生成后的真实题面校验不可省略。
- 圈画阶段耗时仅在开发模式用固定名称记录，不含题面、答案或账号标识；结果回看按需加载，加载失败提供重新加载入口。草稿同步的操作、材料恢复和完整状态分别订阅，恢复失败和冲突保护不能因优化失效。

- Markdown 渲染入口使用 React 默认属性比较跳过相同属性下的重复解析；不得用仅比较 source 的自定义比较器忽略回调、展示模式或样式，填空与指令上下文变化必须继续更新内部交互。

- 打开圈画、保存底图与编辑者收笔只等待当前账号、作答、题目和阶段的本机标画落盘；交卷继续等待全部标画落盘。材料恢复的本机读取与云端标画按最多四题一批执行，失败后等待本批在途任务结束再允许重试；草稿正文保留已有最多百题并发。所有材料核对成功前不解除作答保护，读取失败不得视为无稿。

- 作答跨设备同步按题目及材料独立合并：不同题目或不同材料的编辑自动保留并集，同一内容去重；同题同材料双方修改才要求选择「保留当前设备版本」或「采用云端版本」，不得以整卷覆盖代替裁决。答案使用逐题 `baseRevision` 与 `mutationId`；已采用版本协议的题目拒绝旧客户端无版本覆盖。新进入或重返作答先核对云端与本机材料，读取失败不视为无稿；未恢复、待传、本机保存失败或冲突时不得显示「全部已保存」。已核对的本机稿可离线续写。草稿纸工具栏不提供手感设置跳转，统一通过账号设置进入。
- 答题页的详情请求成功后才挂题卡和圈画层；首次详情请求超时、断流或离线暂停必须显示重试，不创建空答卷或空圈画稿。已有题卡的后台详情暂时失败保留当前笔迹引擎和画布几何，提示不得把在途一笔的坐标推移；权限撤销仍终止旧卷编辑。详情重试不改已保存的原稿身份、笔迹或本机待传稿。

- 作答题卡展开的难度与考点与题号共用元信息行，空间不足时自然换行；更多菜单各项统一图标并使用下一步动作文案（显示/隐藏标画、显示/隐藏题目资料、标记/取消待检查）。
- 作答中的「导出本题」始终包含公开题面，并加入已有标画及本题草稿或正式手写；隐藏标画、收起纸面不排除材料。导出前收笔并确认本机落盘，从固定矢量重绘；读取/保存失败不得默默遗漏材料。长稿分页，每页重复题面，支持全部下载与逐页复制。结果页「AI 复习包」继续使用原有授权投影与封存语义。

- 橡皮按纸面坐标连续命中整笔，计入笔宽；擦除预览下标在正文删除前清除，抬笔、取消或强制收笔后不得隐藏未命中笔迹，一次拖动可一步撤销。标准硬笔、自然笔感和标画使用同一命中逻辑。
- 打开草稿或正式手写纸面后，仅在布局导致当前题卡位置变化且题干顶部离开可见区域时对齐至顶栏下方；正常打开、保存失败或用户先行操作不强制滚动。
- 同题圈画与草稿（或正式手写纸面）可同时展开；收起其中一个不隐藏另一个，切题仍先收笔并确认本机落盘，保存失败时保留原稿。
- 题面圈画与草稿纸共用笔、橡皮、撤销和更多工具栏；Pencil 与鼠标可写画，手指只滚动，不提供「手指书写」。材料圈画沿用同一输入规则。正式手写仍可切换手指书写。工具栏只转发命令，圈画底图坐标、草稿逻辑坐标及各自保存流程独立。激活范围以淡蓝色外框标示，外框不改变题面几何。
- 草稿提供自动、左右分栏和上下排列；布局切换只改变固定原稿及笔迹的显示比例，不改 PNG、layout 或矢量坐标。窄屏可用「放大题面」按 1:1 横向浏览。已有题卡原稿不因当前 HTML 换行、字体或分栏变化重建；保存失败先留在编辑态，切题收笔需确认本机落盘。材料圈画当前仍使用独立的 1000 归一坐标与本机草稿，不由本轮题卡变更自动获得跨设备同步。
- 草稿关闭时题干使用整行，不预留草稿列；仅实际展开且采用左右布局时分栏，上下布局不压缩题干。草稿开合保持外框宽度策略稳定，分栏宽度变化后先收笔再重新适配题面和笔迹，清除旧列宽下的手动放大状态。已有题卡圈画按保存逻辑框整体缩放真实题面与笔迹，窄列可放大 1:1 横滚；尺寸变化先收笔，不改原坐标。题型控件复用唯一作答状态，不设置兼容作答切换。维护重置仍须明确授权并按作答隔离代次，旧本机稿先归档，旧代次上传拒绝。
- 清空标画先结束在途笔，再清空正文，支持撤销；Portal 菜单操作不触发题卡退出标画。冻结原稿标画导出按底图保存的 CSS 尺寸重放，PNG 像素尺寸保持不变。
- 标画底图与回看合成图按已挂载的导出副本收集字体，不缓存 `document.body` 的字体 CSS 快照；仅缓存成功读取并校验的本站字体资源，失败须显式报错并允许重试。已有笔迹、绑定或封存的底图不得因字体修复自动覆盖。
- 底图布局冲突的裁决出口（2026-10-25，批次三 P0-2）：标画 409 冲突按 kind（revision/mutation/layout）落库，旧记录缺 kind 按有无云端摘要推导。layout 冲突「保留本机」＝本机保留、不再自动同步（retained 态，新笔画不排队上传，本机稿与底图照常查看导出），「采用云端版本」＝采用云端正文并把本机底图重绑为云端 PNG（下载失败保留冲突态可重试），「重新尝试同步」清保留态补传一次；revision/mutation 维持对齐/重铸重传。上传撞服务端已 ready 且同核布局的底图时直接采纳重绑，不再当冲突。服务端 pending 底图行超过 24h 未回传 PNG 允许后来设备接管（更新布局与身份三要素；行无 imagePath 无内容，不算改写历史）；ready 行永不接管、永不重生成。

## 冻结原稿协议边界（2026-11-05）

- 用户在测试阶段明确停止扩展历史缺证据稿兼容：不新增 v1 无布局或原证据失配 v2/v3 的恢复模板。保留现有可用 reader、原 PNG、layout、正文及同步/封存保护；无法核验仍报错保稿，不清稿、不强行叠画，也不以旧稿自动恢复作为新版交付门槛。具体范围以[获批计划的后续调整](../superpowers/plans/2026-11-05-圈画统一整题缩放实施计划.md)为准。

- 整题缩放协议（2026-11-05）：新增 layout v4，固定 `renderProfile=whole-question-v1`，必须携带公开 `compatibility`，不接受 `controls`；v2/v3 原 schema、PNG、旧签名、正文坐标与 ready 身份继续保留。v3/v4 PUT 分别要求能力声明 3/4，并按底图保存版本核验，未知版本拒写保稿。首次新稿生成 v4；作答、只读回看、订正及当前题面导出接入同一真实题面框架。
- 真实题面兼容比较以保存基准的逻辑 CSS 四边最大偏差 ≤10px 为准；块 tag、已保存语义节点与顺序不变，Range 碎片仅在同结构块、连续且重叠的行内合并，字体字符串不独立阻断。原位来源判定与 PNG 解码分离：`resolveQuestionSurface` 只返回来源/正文坐标已核验、几何仍未核验的状态，调用方必须再用真实 DOM 执行 `questionSurfaceMatchesLayout`。账号/作答/题目/阶段仍由严格 store/session 键隔离，外层只读不绕过题目版本和坐标域核验。
- 缺 `compatibility` 的 v2/v3 仍须原签名精确命中；仅显式开笔调用 `prepareQuestionAnnotationContinuation` 补充经服务端确认的证据，不被动写回。请求在途收到封存或账号切换时不补写，不改变旧 PNG、核心 layout、points、待传身份或正文版本。v1 缺少真实题面位置证据仍明确阻断保稿，不能用图片主视图冒充整题恢复成功。

- v3.controls 为历史只读数据，不再捕获或恢复图片控件；真实 fill 输入按公开冻结模型渲染。公开底图不带本人答案、答案解析或教师私注。当前题面导出只读生成公开题面、完整本人答案与笔迹，历史证据导出保留原 PNG；两者不回写绑定或原稿。
- 题卡本批是单张 PNG（单边像素仍限 4096）与底图像素域 `AnnotationDoc`。未来材料可共用不可变像素资产、同域矢量、统一恢复门控和可靠保存原则，但共享材料须有独立的 attempt+冻结材料版本身份；超长材料要在同一逻辑坐标空间从稳定布局分片，并有有界笔迹绘制、跨片一笔/擦除/撤销的统一控制器及真实服务端 reader/writer。本批未实现材料服务端同步，也不把导出分页重新排版当作保坐标分片。
- v3 服务端 PUT 要求显式协议能力标识，旧上传被 403 拒绝；旧分类器按通用 403 停止自动重传并保留 pending，新客户端按专有码保留 pending mutationId 和本机 PNG、提示刷新后再试。已部署旧 JS 若与新页同机并行，仍可读改同一 `tutor-annotations` IDB 键，本批没有双库隔离或运行时迁移，不能承诺旧页本机稿安全；生产启用须配合现有 PWA 安全更新流程关闭或更新旧页面。
- 当前客户端读取未知 API/IDB 布局或正文协议时立即报错保稿，不按空稿生成底图或写回；这只保护实际读到未知版本的路径，已运行标签页持有旧内存快照的并发写仍需安全更新与多标签协调。封存事实单调保留；封存 GET 与在途一笔相遇时先收已采样点，本机记为 pending+retained 且停止自动上传，服务端已封存稿不改，封存后的普通写入仍拒绝。

## 学习记录与历史重投影（2026-10-27，LR-PR4 / LR-PR5）

- 学习记录（LearningRecord）是服务端从既有表与 blob **现算**的只读聚合：草稿/正式手写/题干圈画三类材料的笔画、擦除墓碑、笔间停顿与时序覆盖度均从文档现算，不落新表。`GET …/record`、review-pack 的 `record.json`、教师 MCP `get_question_learning_record` 都是它的投影（记录是事实源，渲染/导出/AI 是投影）。
- 圈画跨设备（2026-11-05 修订）：LR-PR4 的语义锚点、墓碑和重投影模块保留给学习记录及历史数据解释；题卡主恢复已改为保存原稿像素与同域矢量，不再用锚点近似重投影决定能否自动续画。任意跨换行自由笔迹没有可靠语义重投影保证。
- AI 上下文（LR-PR5）：claim/dispatch/share 三个受控出口新增可选 `record`——点序列经 RDP 简化（ε=坐标域宽×0.3%），单材料超 6000 点按笔均匀抽稀并置 `compacted:true`；任务创建把三类材料 `(revision, hash)` 钉进快照 `recordRefs` 并入 contextVersion。分享页的 record 按键定点投影（identity 的 responses 行 id 置占位、timeline detail 去 taskId），投影后契约 parse fail-closed；笔画 id 与 anchors 保留（锚语义）。

- 作答材料读取期限（2026-11-05）：盘点、标画正文、草稿头和草稿正文每请求含完整响应体设 30 秒期限；超时进入既有失败／重试流程，不初始化空稿，迟到响应不能替代新一轮结果。已核对基线的本机稿继续按原 verified 规则保留，提交及更新保护不放宽。

## 单题过程记录的保稿边界

- 圈画与草稿继续分别使用既有稿件仓和同步裁决。过程录制在有效编辑后保存事件，独立落盘和补传，任何过程错误不得改变当前稿、提交事实或封存证据。断网和恢复用分段及缺口说明，不能把上传先后当作书写先后。
- 本机落盘失败后保留待写批次，重试按原序落盘再上传。已保存且收到全部回执的过程恢复为已同步，丢失的事件仍标记为可能缺失。
- 同一作答在多个标签页打开时，答案、正式手写与材料圈画按题目或材料在 IndexedDB 同一读写事务中合并。同项从旧基线分别改过时保留各份正文，需在「本机稿件冲突」查看并选择。交卷清理只移除已确认同步的正文，保留未同步稿、待裁决稿及本机材料圈画与底图。
- 回放只将圈画叠在同题、同冻结版本、身份与几何均匹配的原底图上。草稿保留逻辑坐标。擦除、撤销、重做和清空用实际生效的笔画差量复现。
