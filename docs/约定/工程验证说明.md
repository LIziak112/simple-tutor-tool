# 工程验证说明

本文件保留原 AGENTS.md 的选测实现说明、历史性能测量与实验结论，供修改测试基础设施时查阅；测量数据只代表当时环境，不作为当前性能承诺。执行命令以根 [package.json](../../package.json)、[选测脚本](../../scripts/affected-lib.mjs) 与 [CI 配置](../../.github/workflows/ci.yml) 为准；日常执行入口见 [AGENTS.md](../../AGENTS.md)。

## 常用命令
pnpm dev / pnpm test / pnpm e2e（真实Playwright：Chromium/WebKit，隔离临时数据库与8899/5199端口；可追加spec路径或--workers=2，不复用用户5173作业）/ pnpm e2e:affected（功能面标签选测，仅 chromium，开发循环用；可传基线 ref 如 `pnpm e2e:affected HEAD`）/ pnpm e2e:full（全量 e2e 别名）/ pnpm lint / pnpm typecheck / pnpm format / pnpm build / pnpm db:generate / pnpm schema:export（导出内容契约 JSON Schema，改 contract 后须重跑并提交）/ pnpm tutor-lint <文件或目录>（lint DSL 文档，有 error 退出码 1）/ pnpm reparse [--dry-run]（解析器升级后从 questions.sourceMd / lectures.markdown 重抽取结构化字段，题目 id 不变；--dry-run 只输出不写库；库定位复用 DATA_DIR）/ pnpm gen:spec（从注册表生成 docs/dsl/规范.md、提示词模板.md 并刷新 JSON Schema，同时把规范三件套 + content.json 同步进仓库根 dsl-kit/ 分发包、并用 esbuild 把 tutor-lint 打包成 dsl-kit/tutor-lint.mjs 单文件零依赖校验脚本——规范与对外校验/材料整理技能的固定入口即 dsl-kit/；esbuild 系技术栈内既有依赖的扩展使用，server 构建同款；改注册表/lint 规则/契约/linter 或 CLI 后必须重跑并提交，CI 会校验 gen:spec 后 git diff 为空）

分层测试与 CI 单闸门（2026-10-25）：单测三档——`pnpm test:quick`（未提交改动相关用例，vitest `--changed HEAD`，修复循环用）、`pnpm test:affected`（相对 main 受影响用例，`--changed origin/main`，验证单用）、`pnpm test:full`（全量，等价 `pnpm test`）；配套 `typecheck:affected`（`pnpm --filter "...[origin/main]"`，改动包 + 反向依赖包）、`lint:changed`（只查变更文件，scripts/lint-affected.mjs 收集 diff+未跟踪后显式传给 biome——biome 原生 `--changed` 只看已提交差异、不含未提交改动，仅 CI 适用；vcs.defaultBranch=main 保留给 CI 与手动 `--changed` 场景）、`e2e:affected`（2026-10-25 升级为**功能面标签选测，本机仅 chromium**，webkit 与双浏览器全量归 PR CI 与每晚 schedule：全部 spec 已打 `@smoke/@teacher/@student/@annotation/@ai/@mcp/@export/@insights/@admin` 标签（登记表即 scripts/e2e-affected.mjs 的 SPEC_TAGS，含「e2e 下每个 spec 已登记」单测守卫）；scripts/e2e-affected.mjs 的显式映射表把 `apps/web/src/features/<面>` 与 `apps/server/src/routes/<文件>`（.test.ts 视同实现）变更映到标签——映射表不能省，应用源码不出现在任何 spec 的 import 图里，Playwright 自带 `--only-changed` 认不到它们（且它与 `--grep` 是 AND 关系，叠加会把未变动的冒烟 spec 滤掉，违背「任何选测恒含 @smoke」，故不使用）；兜底清单、`e2e/` 目录 default-deny（除已登记 spec 外一律全量）及映射表外的 apps/ 源码（features/markdown、shared、src/lib、services、public.ts 等跨功能面共享）→ 全量（仍仅 chromium）；无命中 → 只跑 @smoke；仅 spec 变动 → 文件参数直跑「变动 spec ∪ 冒烟 spec」；基线默认 `v2`——test:affected 的 origin/main 口径会让 v2 后代分支永远摊成全量，e2e 选测以 v2 为基线才有意义）。`scripts/affected-lib.mjs` 的兜底清单：pnpm-lock、vitest/playwright/tsconfig/biome
