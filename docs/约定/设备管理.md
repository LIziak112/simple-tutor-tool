# 我的设备

学生设置与教师设置的账号区共用设备列表，数据分别属于当前学习者或教师身份。个人账号学习与管理视角各自管理本视角的记录。

设备名优先使用本人自定义名，可以恢复自动名称。设备标识是本机随机UUID，类型和系统只是展示，不是硬件认证；清除网站数据、换浏览器或主屏幕应用可能产生新的记录。

合并以选择的设备为保留目标，旧来源默认不选，建议合并没有有效登录的旧记录。合并保留目标名称、保留历史别名；两个浏览器归到同一设备后，后续请求可能让另一浏览器的旧登录失效。活跃来源必须明确确认这一影响，不能把合并当成无副作用的改名。

新界面在合并请求中发送实际确认的规范来源、保留目标和是否允许活跃来源。服务端在同一个写事务内核对归属、确认前提并迁移引用；目标已归并到别处或未经确认的来源新出现有效登录时返回 `409 DEVICE_MERGE_STALE`，刷新列表并由本人重新确认，不自动跟随新目标或重试。原来源直接指向仍为规范记录的同一目标时可只读重放；目标后来再归并则旧确认失效。旧调用省略确认字段时保持原别名兼容语义，设备类型仍不参与授权。

移除登录记录会删除当前身份下对应设备的浏览器session，旧Cookie后续请求不再有效；不会删除设备历史或本机未同步内容，也不是永久封禁设备。回执显示实际删除条数，可能包括过期记录。清理未分配设备的旧登录会保留当前登录。

撤销当前设备会退出当前视角，并清理本身份查询缓存；个人账号另一视角独立保留。MCP、API token、AI分享链接属于独立凭证，本页不会撤销它们，需要到相应连接设置处理。
