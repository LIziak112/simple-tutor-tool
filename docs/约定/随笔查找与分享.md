# 随笔查找与逐条分享

随笔属于学习者，默认仅本人及本人授权的 Agent 可读。列表序号按本人递增，删除不回收；离线记录没有服务端序号时显示“尚未编号”。时间以 recordedAt 显示本设备时区的年月日时分与当日 UTC 偏移，辅助显示相对时间。设备改名复用“我的设备”，历史随笔显示当前设备名，Agent 未登记时显示 MCP Agent。

快捷标签统一定义在 contract 的 MEMO_PRESET_TAGS；本人常用标签从全部未删除记录 SQL 聚合，最多五个；快捷、常用和自由输入共享单条最多五标签约束。标签链接可筛选列表，关联条目通过原随笔序号链接查找；原文始终只追加或软删。

MCP `list_my_memos` 支持 seq、questionId、tag、parentMemoSeq 及既有分页过滤。`add_memo` 可传 UUID operationId：同一操作重试复用，返回同一条；正文、标签、关联父、来源坐标/显式说明或记录时间不同的复用返回 MEMO_OPERATION_CONFLICT。原请求摘要持久化且所有幂等命中路径复核：等价时区规范化为同一时间；省略时间和显式时间不同；未来时间在显示层收口前计入摘要；省略来源说明与显式说明不同，自动标题改名不改变重试摘要。缺少原请求摘要的旧 Agent 行不猜测补回，复用其键返回冲突。省略 operationId 保持旧客户端每次新增。parentMemoSeq 只能关联本人当前未删除条目；父删除后已有子条目保留，重试不会新增或复活父条目。

来源说明保留记录时快照。点击来源先由本人 memoId 解析当前可达目标，不接受外部 URL、不读取答案或创建作答：原冻结题仍可读则回原卷；原卷作废/失效后，仅在仍可见的同课程同单元内查本人已有作答的同题，再回单元或课程；不可访问统一显示来源不可用。解析只读，页面仍须再次鉴权。

分享设置按条确认分享给当前归属教师；分享授予该条正文、媒体、标签、本人序号、记录时间与来源说明，不授予来源题目、设备列表、上下文全量或父子关系。本人可随时撤回；软删、学生归档、教师停用或归属改变后立即拒绝教师读取。教师学生主页“学生分享的随笔”默认折叠，展开才请求，媒体 GET/HEAD/Range 每次校验当前逐条授权并返回 private, no-store。教师教学备注不进入学习者随笔。
