本文件承接根 AGENTS.md 的专题约定；涉及本专题的任务必须在制定方案和修改前阅读。全局开发规则见 [AGENTS.md](../../AGENTS.md)。更新专题行为时同步维护本文件，不再向根文件追加实施细节。

## 学生端 AI 伴学与受控 AI 出口（2026-10）

- 回复阅读列（2026-10-21）：材料摘要、正文与后续操作共用阅读列，题卡外框宽度不变；通道与当前模式收进面板标题区。段落标题原地展开，弹窗退出恢复入口焦点与阅读位置。

- 显示偏好（2026-10-21）：学生设置「AI 求助偏好 → 助教显示方式」提供题下阅读（兼容默认）、侧边对照、独立弹窗，保存后按部署来源、学生账号和当前浏览器隔离生效。侧边空间不足时临时用弹窗，本次阅读不随空间回补自动搬回；下次打开重新计算。题下／侧边的「放大阅读」仅改变本次呈现，三种布局共用唯一正文与输入；段落标题就地展开，不用目录瞬间跳转。布局偏好仅持久化版本和枚举，对话、材料、阅读位置及输入继续留在学生角色内存；不改变教学策略、普通接口投影或受控 AI 出口。

- 学习流程（2026-10-18）：AI回复默认在所属完整题卡之后自然阅读，不进入题面底图与采集副本；当前工作区只有一个输入框，旧材料追问与「带新稿另问」明确区分，后者只切编辑态，不出站。新回复不抢焦点、不自动追加长正文；收起/Esc回真实入口与原题锚点，保留按题和任务隔离的草稿。侧边空间不足时的呈现遵循上文显示偏好；普通接口、三教学策略和手写落盘/锁定规则不变。

- 学习工作区（2026-10-19）：默认提示允许不填补充文字；选择问法不覆盖自写问题，只有最终发送才出站；初问/追问草稿使用学生角色内存缓存，切连接设置后恢复同题编辑，退出或换账号清理，不另建浏览器持久化副本。发送前展示题目、当前作答与已选材料，页数未经核对不虚报。阅读结尾可回原位置尝试，再检查新步骤；检查须有选定材料或文字步骤，新稿仍新建任务、旧稿追问不重采。当前回复优先、历史按需展开；专注阅读只保留一份活动正文与输入，退出恢复阅读位置。求助记录在本卷原地打开对应题和任务，跨卷按任务所属attempt定位并核对归属，保存失败保留现场。数学定界符兼容只作用于AI回复且重新检查预算；超限可按段读纯文本，不放宽图片、HTML或链接清洗。

- 授权例外仅此一处：需求规格 §2.3 已明确授权「允许求助时向选定 AI 发送本题已有答案解析，启发模式也携带」，不需要再逐次确认。例外只覆盖 AI 伴学的三个受控出口——页内出站载荷、上下文链接票据读端点、学生 MCP 领取视图；普通取卷/结果/错题本/导出等学生接口的防泄露投影（`publicOfSnapshot`、`studentStemMd`、`assertNoLeak` 测试族）零放宽，不因 AI 功能统一开放答案。
- 三教学模式 `open_study`（默认）| `guided_only` | `post_submit_only` 只裁决 AI 可用性与回答尺度，与 `answersReleased`（普通答案公布）相互独立；「本题完成」（v1 逐题卷：该题行级 submittedAt，2026-10-23 起；其余 assignment/course/wrong：attempt 已提交；lesson：该题 submittedAt）后一律按 open_study 复盘尺度——完成态单源在 teaching-policy-service `phaseOfRows`，协议判别复用 practice-workflow-service/wiring 既有谓词，禁止各通道另写 sourceType 分支。「仅启发」是提示词输出约束、不是保密模式，需要作答期不接触答案的教师必须选 `post_submit_only`。
- 任务新建、MCP 领取、票据/附件读取、回信交付必须在出站或返回内容前按**当前**模式与完成态重校验（教师刚改设置立即生效）；教师私注（teacherComment）、其他学生数据、整讲义原文、内部账号 ID 与任何凭证永不在授权范围内。
- 学生端 AI 接口的泄露测试采用双断言：允许场景断言答案解析确实进入外发载荷（fake provider 捕获）；禁止场景与全部普通学生可读响应断言无 answers/solutionMd/教师私注哨兵。不得通过修改 assertNoLeak 的全局禁止键规则来掩盖泄露。
- 教师督学只消费服务端事实记录：无 AI 求助记录不能证明独立完成；仅入队未外发是「作答中求助·未处理」，不等于已获得帮助。
- 学生端 MCP 配置体验与教师 `/t/connect` 对齐：`/s/settings/ai` 提供完整 `mcpServers` 配置一键复制，两端共用 `apps/web/src/lib/mcp-config.ts` 生成（键名教师 `tutor`、学生 `tutor-student`，同一客户端并存不覆盖）；学生本人连接卡直接展示完整 MCP Token 与已代入 Token 的配置，刷新后仍可查看，不设显隐开关；Token 加密保存，认证沿用哈希。旧连接只有哈希时保持认证有效，明确提示手动重新生成一次后持续可见；不自动重置。API Key 继续只写不读，普通学生接口、AI 上下文与其他账号不返回凭据。
- 错题组卷两工具（2026-10 错题本迭代）：`list_my_wrong_questions`（只读）与 `create_wrong_practice`（建卷）。列表只给组卷决策元数据 + studentStemMd 脱敏题干摘录——**不是受控 AI 出口**，不带答案/详解/本人答案文本（assertNoLeak 集合恒适用）；筛选谓词单源在服务层（sinceDays=北京自然日含今天，与学生端「最近 N 天」一致；offset 翻页兜住超 limit 上限的存量错题）。建卷走 wrong-practice 服务层（与页面 POST /wrong-practice 同一校验、同一快照冻结、同一静默剔除口径、同一新协议起点 workflowVersion=1），**非幂等**（每次调用新建一份独立练习卷，工具描述要求 AI 先与学生确认）；范围快照 kind=ai 随卷落库（AI 的 label 展示在卷标题）；kind=ai 范围只由 MCP 服务端构造，页面请求契约拒绝之并校验 selection 题数与实际提交一致。学生 token 域内数据（本人错题本聚合），他学生的错题 id 天然不在聚合被剔除；建出的卷走普通 wrong 卷机制（草稿、记录可见、交卷进教师批改队列），无新出站面。
- 权威文档：docs/学生端AI伴学/需求规格.md 与 docs/学生端AI伴学/技术实施方案.md（B00 已验收，D1–D10 已定案，后续批次不得另起一套）。

- 本次练习整体复盘（2026-10-24，任务 1ef854c7）：与逐题批量复盘并行的**独立 MCP 任务类型**（契约 `student-ai-attempt-review.ts`，服务 `student-ai-attempt-review.ts`，表 `ai_attempt_review_tasks/results/facts`）。学生预览确认后创建一个 attempt 整体任务；可用门 = 已交卷 + 答案公布门 + 全部题当前策略裁决，任一不满足整卷统一拒绝（不借计数泄露对错）；范围/作答/判分/公布态参与 HMAC 预览版本锚，创建与领取不匹配即 409 重新预览（不静默发送新集合）；四桶互斥计数（作答态与判分态分离，无法核对的题按待批并单独计数，不假报未做）；整体快照为白名单内部视图（只进任务行与 MCP 领取视图，不进任何学生普通接口）；报告为 strict JSON + 证据题号归属复核，迟到/取消写回只记事实不覆盖；学生显式重试换新代次，旧报告保留；顶栏三计数由服务器聚合两类任务；报告不写回判分、错题本或学情评级；一次整体任务计一份配额（与逐题任务同事务合计），每 attempt 活动整体任务最多 1。逐题批量复盘、旧四 MCP 工具与页内/链接通道行为不变。
- 整体复盘修复（2026-10-25，PR #4）：报告写回、详情读取及打开也须通过当前交卷/公布/作废/逐题教学授权门；撤回授权不交付正文、不记已读。MCP 快照显式携带全部选项正文（不含正确性），实质题面/选项/参考内容也参与 HMAC；FIFO 暂停作废或失权任务并继续领取。两类任务在创建事务内共用待处理和北京自然日配额（起点含、终点不含），取消不退还当日额度；空白最终答案、全空填空和空多选不作为已答证据，正式笔迹存在仍算已答。
