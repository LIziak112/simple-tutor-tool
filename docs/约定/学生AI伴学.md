## 学生端 AI 伴学与受控 AI 出口（2026-10）

- 快捷问法的「更多问法」保留原生details，箭头随开合旋转、减少动画时即时切换；展开或选择仍不发送。AI提问、批量复盘、报告、出题和导出入口采用对应用途的Lucide图标，保留既有名称、教学策略、唯一活动输入和出站守卫。

- 回信格式检查（#54）：本地 Windows x64 exe、独立 Node 脚本、学生 MCP `check_ai_reply` 与最终提交共用 `@tutor/md-dsl` 检查核心及 contract 诊断类型。领取时提供格式说明和检查器清单入口；检查器只读、不联网、不代改、不提交，格式通过不代表数学正确。明确 error 阻止新的 MCP 写回且保留租约，warning 提示复核；同内容成功重放仍幂等。合法长回信仍截断并声明，截断损坏的片段返回降级警告。历史及页内回信只在显示时兼容或降级，不回写原文。详见[回信检查器使用说明](../学生端AI伴学/回信检查器.md)。

- 题下 AI 回复随题卡可用宽度排版；独占行的裸 LaTeX 按公式渲染。确定损坏的公式片段降级为代码文本并提供有界原文查看，不跨行猜补缺失内容；规范化前后均执行原有安全预算与清洗。

- 回复阅读列（2026-10-21）：材料摘要、正文与后续操作共用阅读列，题卡外框宽度不变；通道与当前模式收进面板标题区。段落标题原地展开，弹窗退出恢复入口焦点与阅读位置。

- 显示偏好（2026-10-21）：学生设置「AI 求助偏好 → 助教显示方式」提供题下阅读（兼容默认）、侧边对照、独立弹窗，保存后按部署来源、学生账号和当前浏览器隔离生效。侧边空间不足时临时用弹窗，本次阅读不随空间回补自动搬回；下次打开重新计算。题下／侧边的「放大阅读」仅改变本次呈现，三种布局共用唯一正文与输入；段落标题就地展开，不用目录瞬间跳转。布局偏好仅持久化版本和枚举，对话、材料、阅读位置及输入继续留在学生角色内存；不改变教学策略、普通接口投影或受控 AI 出口。

- 学习流程（2026-10-18）：AI回复默认在所属完整题卡之后自然阅读，不进入题面底图与采集副本；当前工作区只有一个输入框，旧材料追问与「带新稿另问」明确区分，后者只切编辑态，不出站。新回复不抢焦点、不自动追加长正文；收起/Esc回真实入口与原题锚点，保留按题和任务隔离的草稿。侧边空间不足时的呈现遵循上文显示偏好；普通接口、三教学策略和手写落盘/锁定规则不变。

- 学习工作区（2026-10-19）：默认提示允许不填补充文字；选择问法不覆盖自写问题，只有最终发送才出站；初问/追问草稿使用学生角色内存缓存，切连接设置后恢复同题编辑，退出或换账号清理，不另建浏览器持久化副本。发送前展示题目、当前作答与已选材料，页数未经核对不虚报。阅读结尾可回原位置尝试，再检查新步骤；检查须有选定材料或文字步骤，新稿仍新建任务、旧稿追问不重采。当前回复优先、历史按需展开；专注阅读只保留一份活动正文与输入，退出恢复阅读位置。求助记录在本卷原地打开对应题和任务，跨卷按任务所属attempt定位并核对归属，保存失败保留现场。数学定界符兼容只作用于AI回复且重新检查预算；超限可按段读纯文本，不放宽图片、HTML或链接清洗。

- 授权例外仅此一处：需求规格 §2.3 已明确授权「允许求助时向选定 AI 发送本题已有答案解析，启发模式也携带」，不需要再逐次确认。例外只覆盖 AI 伴学的三个受控出口——页内出站载荷、上下文链接票据读端点、学生 MCP 领取视图；普通取卷/结果/错题本/导出等学生接口的防泄露投影（`publicOfSnapshot`、`studentStemMd`、`assertNoLeak` 测试族）零放宽，不因 AI 功能统一开放答案。
- 三教学模式 `open_study`（默认）| `guided_only` | `post_submit_only` 只裁决 AI 可用性与回答尺度，与 `answersReleased`（普通答案公布）相互独立；「本题完成」（v1 逐题卷：该题行级 submittedAt，2026-10-23 起；其余 assignment/course/wrong：attempt 已提交；lesson：该题 submittedAt）后一律按 open_study 复盘尺度——完成态单源在 teaching-policy-service `phaseOfRows`，协议判别复用 practice-workflow-service/wiring 既有谓词，禁止各通道另写 sourceType 分支。「仅启发」是提示词输出约束、不是保密模式，需要作答期不接触答案的教师必须选 `post_submit_only`。
- 任务新建、MCP 领取、票据/附件读取、回信交付必须在出站或返回内容前按**当前**模式与完成态重校验（教师刚改设置立即生效）；教师私注（teacherComment）、其他学生数据、整讲义原文、内部账号 ID 与任何凭证永不在授权范围内。
- 当前题求助定位按学生 MCP 连接自愿开启，缺省关闭。浏览器只发送焦点身份与顺序，前台每 20 秒续期，隐藏、关闭或切题立即更新。服务端焦点在最后一次上报 60 秒后失效，短期序号用于拒绝迟到请求。定位代次绑定当前连接与运行实例，关闭定位、重置 Token 或恢复备份使旧代次失效。焦点不写学习事件，多个活动页面指向不同题时返回无当前题。`get_current_context` 只返回状态或本人已加入队列的任务 ID，仍须显式 `claim_ai_task`，定位和领取均按当前授权裁决。
- 学生归档、教师停用或所属教师域缺失时，停发相关页内任务并阻止读取现有分享。删除链接连接同时撤销该学生的有效票据。页内重试前重查连接、任务代次和发送规则；已外发的任务保留事实。账号或页内连接已撤权时，迟到回信只作内部事实留存。仅教学策略收紧时，在途回信可以收存，量表写回须有当前授权，学生可在当前模式允许该尺度时阅读本轮回信，已读的历史回信保持可见。

- 题序复用公开取卷序；讲练复用共享正文题序 helper，并检查实际来源课程的当前可见性。题目 id 与题序同时提供时须一致。目录和单题均先完成既有合法旧卷兼容读取，再校验整卷冻结成员的完整快照、题目身份和公开集合；坏、缺、错 id 或重复成员整卷拒绝，不改选健康题或返回替代提交参数。规范上下文使用共享 canonical projector，`view:null` 表示没有界面宿主，结算序号只来自实际行。
- 64 KiB 限制完整响应的元数据投影，包括所有重复 id、上下文、提交准备参数/证据、材料 id/标题/类型和图片来源/MIME/字节数。只扣除已知题干、公开选项文本、材料正文和本人作答正文；选择编号、匹配/排序 id 仍计入，新增元字段默认累计。合法长 id 不截断，合法长阅读和 essay 正文不受此元数据限额。收图前预检，取得真实文件信息后在读取原始字节前再验，交付前精确复验。
- `get_practice_question` 的 `submission.parameters` 是当前旧工具的只读准备数据，包含真实工作流/题目/答案版本和笔记证据。笔记事实取 `getStudentNoteHead` 的公开 `note.currentVersionId` 与 `note.revision`（数据库 `currentRevision` 仅内部映射），不伪造 `currentRevision` 字段，不将未知证据默认为 missing。服务端无法确认浏览器没有未上传稿，学生仍须核对题号、答案、稿件后另生成并保留 `submissionMutationId`，再调用原 `student_submit_practice_question`；旧工具仍返回 `{success:true}`。A1 不接受 `responseVersion:2`，不提供增强回执或免幂等键提交。
- 图片只从本题已授权公开题干、全部公开选项（含 matching/ordering 的可见干扰项）与本题公开材料正文提取，不按答案标记筛选选项，私有答案/解析/提示和邻题中的图引用不扫描。默认附图，原始字节合计超过 4 MiB 整次拒绝（等于上限允许），可显式传 `includeImages:false` 仅读文字；异步读文件在短同步数据库事务外执行，交付前再检查当前凭据、AI 策略、来源上下文与整卷冻结成员完整性，撤权后不交付已准备内容。新工具错误不透传任意内部 extra。

### 学生 MCP 提交 v2

读取 `get_practice_question` 后仍须向学生复述题目和答案并取得确认，再调用 `student_submit_practice_question`。不传 `responseVersion` 时仍须提供 `submissionMutationId`，成功壳保持 `{success:true}`。

显式传 `responseVersion:2` 可用 `questionNo` 定位，仍须原样携带读取时的工作流、冻结题目、答案版本与证据声明；同时提供 `questionId` 时两者必须一致。可省略幂等键，服务端从规范请求内容派生稳定 UUID；结果未知时重试原请求，不重新读取并替换草稿/证据版本。同显式键异内容返回冲突。

v2 回执仅含本题提交事实、实际结算序号、已提交进度与下一未提交题，不含参考答案、解析或判定。进度是读取时刻的事实；重放不重写提交、不重复记事件。MCP 首次写入重验当前 AI 权限，已成功请求的重放仍遵守原提交幂等裁决。服务端事件来源由鉴权连接注入，不信客户端来源字段。此增强尚不代表已完成当前题候选或分批提交。

## 范围复盘与分节报告（v2）

结果页的「范围复盘」可选整卷或单元；批次结果有「本批复盘」，讲练已提交题有「阶段复盘（至本题）」。阶段中存在未提交题时服务端拒绝创建，不默默跳过。范围由本人冻结行、当前课程可见性、公布门和逐题AI权限共同裁决；未公布的批外题不会进入快照。旧的v1任务、五段报告和原aiReview地址继续可读。

v2快照带所选范围的材料正文、量表、自评、统一用时事实和缺失说明。笔迹只传存在性，没有图像时不得推断书写过程。客观题与长文报告使用不同的固定分节清单；外部报告视为不可信输入，服务端校验分节键/标题/顺序、字节预算和原卷证据题号，Markdown沿现有安全渲染链显示，不回写判分或错题本。

大卷按冻结单元/结算边界分片，每片仍不超过30题和256KiB；单题无法容纳时明确报错，不截断。所有分片完成后才能领取汇总任务，汇总快照只有子报告，不重新附带原题或答案。每份子报告的UTF-8预算随分片数收敛，领取回执给出reportMaxBytes，为最终汇总预留空间；不能靠抬高原上下文常量换过关。

学生或个人MCP在向本人确认范围与诉求后调用`create_review_run_v2`（固定mutationId重试）；`list_review_runs_v2`只列元数据，`claim_review_part_v2`指定领取分片，`renew_review_part_lease_v2`续租，`submit_review_part_v2`回写。领取回执中的generation、snapshotVersion、leaseToken必须原样回传，证据题号保留原卷显示序。相同代次和相同内容重放幂等；异内容、过期/取消或旧代次不能覆盖已有报告，迟到回信只追加审计事实。

新任务图与创建幂等身份在同一IMMEDIATE事务落库，配额与既有AI任务统一计数，任一步失败全图回滚。每次预览/创建/领取/报告读取重验本人来源与当前权限；公布收紧后不返回旧报告正文，本人仍可取消排队。普通学生HTTP出口只给任务状态和经授权报告，不返回内部快照、租约或私有题库字段。真实样卷、物理设备与外部人工客户端验收仍单列，不用SDK自动化替代。
