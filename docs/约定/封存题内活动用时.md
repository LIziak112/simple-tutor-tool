# 封存题内活动用时

D4：新卷统一读题内活动账；历史卷不重算。旧 `activeSec` 和动态 `activity` 的含义保留，新的主展示、记录、批次、教师、CSV、Learning Pack、AI 快照读取 `time`。

`question_activity_sealed` 版本 1 表示首次成功提交事务封存的客户端活动证据，不代表注意力测量。时钟域是客户端 epoch 毫秒：跨设备时钟偏移可能影响重叠判断，receipt 只能证明接收顺序，不能证明物理同时。每题毫秒分别四舍五入，再把题秒数相加。

迁移只新增 profile、receipt、题账和占用区间。新卷创建事务由 trigger 写 profile；旧卷（含旧 draft）没有 profile，始终返回 `legacy_focus`，不依赖激活方案，也不回填事件收件顺序。旧焦点列、结算、历史 AI 快照均不修改。新 AI 快照 schemaVersion=2，旧版本 1 仍可解析和领取，重试使用原封存快照。

浏览器事件首插入和 receipt 同事务；相同 delivery 不增加收件序号。只有服务器真实提交服务创建 seal receipt；客户端 submit、hint、confirmed 或 view 信息都不能封存。提交事务只读取边界之前已经收到的证据；迟到和回看不会更新旧账。逐题、讲练、分批、整卷共用 writer，分批一次扫描，自动收尾只合计已封存行。

沿用可见/非 idle 的 episode：题级动作追认整段；隐藏与 idle 只扣一次，offline 不停表。服务器提交按 receipt 最近 focus 会话追认动作，不把服务器时钟插进客户端区间；尾端只到最后客户端事件。已封存 active、observed、unattributed 区间先占，后提交候选先扣占用；同批不同题重叠公平归未归属，同题多端取并集。首次封存可以导致提交先后影响后来题的归属，这是版本规则。

无客户端证据为 unknown；真实零秒为 available 0。总账带题数、已知数、未知数及已知部分，只有全部已知才给完整总秒数。零题 final 为零秒加法单位元。批账按不可变成员聚合，卷账按全部冻结成员聚合，读取不回放事件。CSV 原 19 列顺序保留，追加口径、版本、活动秒、观察秒与状态，未知留空、零写 0；原用时列明确标历史焦点。

学情按 metric/version 分 cohort 给平均、中位数、样本覆盖；slow 只比较同口径基准。旧 avgSec/medianSec 和离线指标继续保留焦点含义，离线分子与分母均不切换为活动秒。Learning Pack 的 time/timeCohorts 和 Markdown 主活动合计来自同一读模型，asOf 不读取未来封存行。

非限时作答顶栏显示服务端已收到的活动前缀估计（包括已封存与未提交候选），不延长到 now，不把回看加回旧题。最多每十秒刷新一次，五秒读取超时，卸载取消；离线显示等待同步。可隐藏并记住偏好。限时倒计时和宽限不变。提交仍使用原有有界 flush，不因计时新增等待。

实现模块：`attempt-time-schema` 定义存储；`event-write` 生成 receipt；`question-activity-replay` 复用旧回放；`attempt-time-attribution` 归属；`attempt-time-seal` 事务 writer；`attempt-time-projection` 批量读；`attempt-time-estimate` 估计。区间、摘要和 receipt 不出学生 DTO，学生只得到当前授权题的时间值与覆盖。

服务端提示和真实提交动作通过共同 evidence 层，按收件时最近收到的 focus receipt 身份追认对应 episode；即使之后同题重进或换 view，也不移到新 episode，不恢复 idle。封存与估计复用此入口。讲练开卷/续做 DTO 同样带 time/timeEstimate，作答顶栏复用显示与偏好组件。大域读取先去重并统一按 500 个 id 分块，所有计时查询都遵循同一分块边界。活动中位数明确 null 表示无可比样本，不能回落到历史焦点数值。
