# 界面与账号

本文件承接根 AGENTS.md 的专题约定；涉及本专题的任务必须在制定方案和修改前阅读。全局开发规则见 [AGENTS.md](../../AGENTS.md)。更新专题行为时同步维护本文件，不再向根文件追加实施细节。

## 学生设置与手写手感

- 学生顶栏头像与姓名统一进入 `/s/settings`，不单独展示手写手感链接；设置页展示个人信息与本设备书写配置，账号信息不展示内部 UUID。
- 学生手写手感位于 `/s/settings/ink-feel`，受学生布局登录守卫保护；原 `/s/ink-feel` 重定向新地址，`/dev/ink-feel` 继续提供未登录试写。
- 手写调整使用账号命名配置与设备选择，预测点不进入正文、历史或 PNG。真机舒适度仍须 Pencil 试写确认。

## OwnClass 品牌与教师端 UI 约定

- 教师设置不展示个人手写手感入口；学生通过账号设置自行调整。既有教师及开发手感路由暂保留兼容。
- 管理端使用教师端 OwnClass 品牌、靛蓝主题、内容轴线和标题样式，1024px 以下使用导航抽屉；管理导航和权限守卫保持独立，弹层继承教师主题。

- 手写配置（2026-10-13）：`/s/settings/ink-feel`、`/t/ink-feel` 提供用户试写与命名配置，`/dev/ink-feel` 保留为别名，旧 `/dev/ink` 移除。配置归属于当前登录师生账号，设备选择按部署/角色/账号隔离；保存到账号与在本设备选用是独立语义。草稿、正式手写、订正复用设备配置，新笔画携带可选渲染参数，PNG 与回放共用绘制入口。标画继续使用底图坐标域并沿用输入偏好，不能套用草稿坐标。
- 网站名称为 OwnClass，广告词为 “Your data. Your way. All for learning.”；两者为用户定稿的英文品牌文案，其余界面文案和代码注释继续使用中文。
- 教师导航按教学、分析、系统分组，原路径不变；资源库在导入流程保持高亮，系统管理位于账号分类，仅管理员可见。1024px 以下通过抽屉访问完整导航。
- 教师学生详情的页内导航位于筛选栏下方，滚动时吸顶，窄屏改用「跳至区块」菜单。跳转保留筛选和错题档位，焦点移至目标区块并为吸顶导航留出空间。讲义阅读地图可整体收起，默认只展示每篇讲义的摘要，逐节明细独立展开。
- 教师工作台使用独立靛蓝语义主题，Portal 弹层跟随教师主题；侧栏只展示紧凑品牌与单一账号入口，完整广告词保留在入口与账号页。
- 设置使用横向分类与配置行，选择为暂存，保存后生效；后台重取不覆盖本地编辑，普通导航离开时提供放弃确认。
- 设置分类使用 `/t/settings?section=teaching|ai|backup|account`，缺省与未知值回落学生作答方式；配置控制器持续挂载，切换分类不丢未保存状态。
- AI 设置使用独立分类；伴学模板与备课、复习提示词按用途默认折叠，收起保留草稿并提示未保存状态。同一分类仅一个「保存 AI 设置」入口，部分失败仅重试未保存部分，不误报全部成功。
- API Token 的生成、查看和确认重置集中在连接 AI 页；客户端切换仅展示一份当前配置，复制成功与失败都提供明确反馈。
- 备份最近快照默认显示三条，提供查看全部与收起入口；恢复操作保留密码确认和会话失效说明。

## 学生设置与 AI 连接信息结构（2026-10-17）

- `/s/settings` 按个人信息、学习偏好与 AI 求助偏好组织；快捷按钮编辑按需展开，收起不卸载、不清除未保存输入。
- `/s/settings/ai` 默认展示连接摘要总览；新增、详情、修改是互斥视图。新增仅允许尚未配置的方式，不通过选择方式暗中切换到编辑。
- MCP 详情优先给出完整配置，并直接展示完整 Token 与端点；总览不铺开凭据。重置与删除继续确认，复制失败明确提供手动复制说明。
- 编辑草稿沿用学生角色内存缓存，后台重取不覆盖输入；保存或确认取消后回总览，来源题返回保留。连接、凭据和统计不另建浏览器持久化副本。

## 学生设置的设备形态显隐（2026-10-28）

- 「自定义键位」分区与做题方式区的快捷键开关仅键盘设备渲染（`useKeyboardDevice`：pointer fine 直判，coarse 懒探测首个合格 keydown，详见 学生作答与讲练.md「键盘快捷键体系」）；纯触屏设备不出现。隐藏的快捷键开关沿已存值透传，保存载荷不受设备形态影响。
- 键位自定义沿用暂存-保存：录制式改键（Esc 取消，Ctrl/Alt/Cmd 与不可绑定键行内给原因）、冲突标红禁存（含撞固定 1–9 选项数字）、恢复默认 = 空覆盖表；跨标签保存后提示并可显式载入已保存值，后台重取不覆盖本地编辑。

## 课程选项缓存

- 导入页「同时加入课程」复用课程管理的未归档列表查询；课程创建、修改和删除同步刷新课程列表与内容树缓存。课程读取失败允许重试，选中项不在当前列表时阻止预览。

## 登录与账号缓存

- 师生登录成功先取消旧查询并清理当前角色业务缓存，再发布新身份；教师同时清理管理端缓存，师生并存会话互不清除。身份查询对象保持可订阅，退出后重置并重新确认未登录状态，不能让旧请求回写新身份。
- 缓存清理不删除本机未同步草稿、正式手写或标画；继续沿用账号绑定与迟到回执隔离。

## 个人账号：双视角与一枚 token（2026-11-09，个人学习迭代模块 0）

- 个人账号 = 一条 `teachers` 行（`accountKind='personal'`）+ 一条固定绑定的 `students` 行（`personalStudentId`），两行同事务创建、永不分离；不新增第三种会话或守卫——注册 / 登录（`POST /api/public/personal/register|login`）成功同时写教师、学生两枚会话 Cookie，`/t/*` 与 `/s/*` 既有布局守卫照常工作，退出两侧一起退。`GET /api/teacher/me`、`GET /api/student/me` 都带 `accountKind`，前端据此裁剪而不是复制页面。
- 教师入口登录个人账号时也返回两侧身份，切换浏览器会话后清理旧账号缓存、停止旧账号的同步队列并绑定新账号，已落盘的未同步稿保留。个人账号停用时，学习会话、管理会话和 MCP 都拒绝访问。
- 切换视角时，服务端按当前 Cookie 实时校验两侧是否属于同一绑定账号。另一侧已过期或属于其他账号时引导重登。退出时同事务结束当前会话及匹配的另一侧会话，保留独立的班级会话，并回到 `/p/login`。
- 注册走管理员配置的邀请码（管理端概览页「个人学习注册」卡；`app_settings.personalInviteCode`，清空即关闭）；`status.personalRegistrationOpen` 联动登录页「用邀请码注册」入口。限流与教师注册共用 `reg:ip:<IP>`，错邀请码也计数。
- 学习视角（`/s/*`）：导航去掉「我的作业」，顶栏多「管理视角」切换；管理视角（`/t/*`）：导航去掉 学生 / 作业 / 连接 AI，账号标签「个人账号 · 管理视角」，顶栏「学习视角」切回。班级能力的服务端闸门：添加学生、教师 API token 读写 → 409 `PERSONAL_ACCOUNT_RESTRICTED`；班级教师凭证走个人登录 → 403 `ACCOUNT_KIND_MISMATCH`。
- 一枚 token：个人账号唯一的外部凭证是绑定学习者的 AI 连接 token（学习视角「AI 伴学」里管理），端点 `/mcp/personal` = 教师白名单工具（`PERSONAL_TEACHER_TOOL_NAMES`，契约单源：内容管线 + 本人学情只读）∪ 学生全部工具；该 token 到 `/mcp/student` 401、班级学生 token 到 `/mcp/personal` 401、教师 apiToken 到两者都 401（同文案防探测）。白名单在注册时执行（`AllowListMcpServer`），不是 tools/list 层隐藏。
- 新建学习者的内部登录名基于学生 ID，存量按绑定 ID 读取，对外显示当前个人登录名。绑定学习者不能被归档或开启独立登录。若旧版本曾写入这类状态，验过个人密码后恢复绑定学习者并撤销旧学生会话。教师与学生会话 TTL 统一 90 天（Q10）。

## 版本更新与保稿（2026-11-04）

- 发现已就绪的新版本时显示非模态提示，不抢焦点、不打断书写；提供「稍后」与「保存并更新」。回到前台或恢复网络时检查更新，同一分钟的重复恢复事件合并，不做周期轮询。
- 用户选择更新后，先阻止新增交互、纳入输入框失焦时的最后一次修改，再执行已注册的作答和各类纸面保存，最后复核当前账号已加载材料的真实落盘及同步状态。不能根据「全部已保存」文案判断安全。读取失败、保存失败、待传、冲突、权限异常及账号/页面代次变化均阻止更新。
- 仍在书写或输入法组合期间不开始更新；未保存设置、其它打开的编辑弹窗也须先保存或取消。更新不会替用户提交、封存题目或自动保存教师设置。
- 保存进行中提示保持可见；失败、超时或激活被拒绝时恢复交互、显示中文原因并可原地重试，保留页面与稿件。其它窗口意外触发控制器切换时也只提示，不自动刷新当前页。
- 为覆盖旧版与挂起页面，等待激活的 worker 枚举作用域内全部窗口；只有请求更新的当前窗口是唯一窗口时才允许激活。否则提示先保存并关闭其它 OwnClass 页面，不把无响应视为已保存。
- 新版注册使用 `updateViaCache: "none"`；`sw.js` 与固定更新协作脚本使用 `no-cache`，避免缓存旧控制策略。静态资源更新不删除 IndexedDB、未同步材料或账号保稿。
- 首次发布迁移限制：仍运行旧应用的页面尚无上述提示与保稿门禁，不能对其强行激活。先让用户确认稿件保存，再完整关闭同站页面并重新打开；必要的人工切换也必须先确认真实保存状态。后续版本才由新流程负责。


## 嵌套课程目录与密度（2026-10-27）

- 课程内文件夹和内容名称全范围唯一，自动创建/加入时追加「（2）」等后缀；手动改名冲突报错。名称为课程内别名，不修改资源库原件。
- 目录按 `parentId` 嵌套；根目录使用空值，禁止跨课程和循环。默认单栏紧凑列表，学生预览按需打开；深层缩进设视觉上限，名称换行，移动目标显示路径。
- 搜索匹配名称和路径并展开祖先。教师保留原有同级拖拽排序（含键盘操作），跨文件夹使用移动；搜索中不开放拖拽。选中条目后才显示统一操作栏，支持移动、单项上/下移、隐藏/显示与「更多操作」，不在每一行重复下拉菜单或「可见」文字；排序成功保留选择，便于连续调整。移除默认解散文件夹，内容上移一级；移除子树也只删除课程引用。
- 文件夹融入原有目录视觉：学生保留彩色类型图标、卡片与练习状态层级，通过缩小间距提高密度。资源添加侧栏的目标、类型与资源列表在独立滚动区；发布设置和提交按钮在不遮挡内容的底部区域，窄屏和文字放大仍须可达。
- 资源库侧栏、资源库批量加入及导入页共用嵌套目录目标。导入可选保留来源目录层级，默认关闭；课程目标读取失败必须重试，不能当作根目录静默提交。
- 教师课程列表采用紧凑行；减少区块间距和卡片内边距，保留 44px 触控目标与可见焦点。禁止用压小字体掩盖密度问题。
- 学生筛选白名单 URL 参数为 `q`、`type`、`status`；折叠、筛选和最后阅读条目在学生角色查询缓存内保存，账号切换清理，返回课程恢复。教师目录和学生目录不共享查看状态。
- 完整实施与验收范围见 [课程嵌套目录与查找实施计划](../archive/已落地专项/课程嵌套目录与查找实施计划.md)。

## 共享界面反馈与手机学情（2026-11-07）

- 学习完成态的配色以 `components/learning-status.ts` 为单源：未开始为中性、进行中为蓝、已交卷为琥珀、已批改为绿。学生作业及侧条、师生作答记录、完成矩阵和作业名单共用含义；文字标签始终保留。题目对错、待批与自评提示继续使用各自语义。
- 保存按钮使用现有 Button 的 `busy` 呈现：原标签及图标维持占位，忙碌图标居中覆盖，通过 `aria-busy` 表达状态；调用方继续负责禁用、暂存、保存和错误重试。应用于师生AI设置与连接、教师教学设置、内容与单元编辑、课程编辑/发布时间和学生课程成员保存。加载、发送、删除及手写锁不因此改变。
- 普通 Button 的按压视觉内容缩放到0.96，100ms ease-out，按钮本身的热区保持原尺寸；菜单触发、禁用与减少动画偏好不缩放。该规则不用于画布、题面或笔迹坐标。
- Sheet 使用180ms的transform/opacity过渡，DropdownMenu仅用120ms的opacity过渡；中途反向从当前进度接续，退出仍由Radix管理卸载、焦点和滚动锁。减少动画偏好下立即切换。普通Dialog维持原动效规则。
- 导入新建文件夹、学生重开与教师/管理共享删除复用现有Dialog：打开后聚焦输入或取消，Tab限制在弹窗中，Esc取消并归还实际入口；请求期间禁止关闭，失败留在原处重试。已删除入口不存在时不强行聚焦已卸载节点。
- 单文件、批量导入和内容编辑抽屉中的复制降级窗复用 Dialog，打开即聚焦并全选只读提示词。Esc 或关闭按钮只关闭复制窗，焦点回到实际复制入口。
- 教师作答详情和待批队列的笔迹放大层使用全屏模态。打开聚焦「关闭」，Tab 留在放大层内，Esc、关闭按钮或点击背景退出后回到原缩略图。待批队列在放大期间暂停批改快捷键。
- 手机学情页（<640px）采用用户选择的B方案：默认展示当前时间/课程/重点周期摘要，以44px筛选入口打开现有Sheet；选择立即写入原URL，完成或Esc关闭并保留筛选。≥640px继续常显，始终仅挂载一份筛选表单。数据视图与学情视图区分名称，四个指标和统计口径说明保留。

## 课程资料：PDF / docx 原件上传下载（2026-11-10，个人学习迭代模块 6 第一步）

- 实体：`attachments` 一行 = 教师空间里的一份原件（个人账号即本人空间），可挂一门课程（`courseId`，无外键）或不挂；文件本体内容寻址存 `blobs/attachments/<sha256>.<pdf|docx>`，多行可共享一个 blob，软删不删 blob（纳入 blobs/ 整目录备份）。以后挂讲义 / 单元、预览副本、Agent 取件都在本表加列 / 加链接，不另起实体。
- 格式只认内容：PDF 看 `%PDF-` 文件头，docx 按 ZIP 包内关系与内容类型定位主文档，核对所需条目可读取、CRC 匹配以及主文档 XML 含正文。只解压包关系和内容类型清单（各 ≤ 1 MiB）与主文档（≤ 32 MiB）；扩展名 / MIME 一概不信（415 `ATTACHMENT_UNSUPPORTED_TYPE`）。单文件 ≤ 20 MB（413 `ATTACHMENT_TOO_LARGE`；app.ts 21 MB content-length 预检 + 路由流式计数——无 content-length 的 chunked 上传读到 21 MB 即停、不再整包进内存 + 服务层按实际字节兜底）。页数只在能从 PDF 读到时给（`/Type /Pages` 字典最大 `/Count`），否则 null，界面「已知时显示」。
- 可见性二选一：`students`（学生可查看和下载）/ `teacher_only`（仅教师可见）。学生能否列出 / 下载 = 课程访问权（`requireStudentCourseAccess`：成员 + 课程未归档 + 本人未归档）+ `visibility=students` + 未软删；看不到的一律 404 不暴露存在性。学生侧投影不下发 visibility / 课程归属 / 哈希（泄露测试锁定）。
- 上传幂等：前端每个队列条目生成 `uploadId`（重试复用），服务端按 `(teacher_id, upload_id)` 唯一，同键重放返回首次那行（新建 201 / 命中 200，响应形状相同）——回执丢失后重试不会多出一份资料；不带键的上传每次都是新的一行。
- 教师课程页新增「资料」页签：上传走 XHR 带进度（队列行：等待 / 上传中 n% / 已上传 / 上传失败 + 原因 + 重试 + 移除；按入队顺序、最多 2 个同时上传，成功后释放本地文件，本地预检失败的条目不提供重试；队列是模块级状态并记住入队时的课程——切页签 / 换课程不丢排队中的文件、也不会传进别的课程，#103-05）；本地先预检扩展名与 20 MB；文件名像含答案（答案 / 解析 / 参考 / answer / key / solution）且默认学生可见时，这一条按「仅教师可见」上传并在行内说明，上传后可在列表切换。列表显示格式徽标、文件名、大小、页数（已知时）、上传时间、可见性开关、下载、删除（Dialog 确认）。
- 学生课程页目录上方「资料（n）」区：有才渲染；条目即下载链接（`attachmentFileUrl("student", id)` + `download`），浏览器按 `Content-Disposition`（ASCII 回退名 + RFC 5987 中文名）处理；加载失败只给一行可重试提示，不影响目录。
- 还没做（下一刀）：个人账号从学习视角「添加资料」（本人空间上传入口）、在线预览（PDF 翻页 / docx 转 PDF 副本）、挂讲义 / 单元、Agent MCP 取件、blob GC。

## 随笔记录端：四形态、上下文锚、默认仅本人（2026-11-10，个人学习迭代模块 5 第一步）

- 实体：`memos` 一行 = 本人的一条原始随笔（`kind` = text / voice / image / ink），**只插入、软删，不更新**（计划 §8.3「原始随笔不可变」；转写、整理稿都是以后另起的派生条目）。媒体本体内容寻址存 `blobs/memos/<sha256>.<ext>`，软删不删 blob。`(student_id, client_id)` 唯一：前端生成 `clientId`，离线补传 / 重试重放同一条拿回同一行（新建 201、命中 200，响应形状相同）。
- 上下文锚自动：`anchor` = `question`（attemptId + questionId + label）/ `lecture`（lectureId + sectionId? + label）/ `none`。前端「我现在在哪」存储（`features/memos/learning-focus-store.ts`）由 AI 伴学 Dock 的宿主（作答 / 结果 / 讲练页的当前题）与讲义阅读页发布，随手记时自动带上、可一键去掉；页面记的锚服务端原样存（label 由前端给），Agent 转记的锚服务端核对本人可见（作答须本人；讲义走学生讲义详情同一谓词 `requireVisibleStudentLecture`——须在本人可见课程目录中、条目可见、已到发布时间、未软删）后生成 label，不可见一律 404 `MEMO_ANCHOR_NOT_FOUND`。另记 `tags`（≤ 5）、`source`（self / agent）、`device`（phone / tablet / desktop / agent / other）、`recordedAt`（设备时间，晚于服务端时间按服务端收口）与 `createdAt`。
- 可见性：**默认仅本人**——全部接口在 `/api/student/memos*`（学生会话 / 个人账号学习视角），教师侧没有任何路由或投影（e2e 与接口测试钉住 `/api/teacher/memos` 404、教师 Cookie 401）；「分享给教师 / 作为提问发给 Agent」归后续步骤。
- 媒体：格式只认内容（语音 webm / m4a / mp4 / ogg / wav / mp3，图片与手写 png / jpg / webp / gif；形态与内容不符 415 `MEMO_UNSUPPORTED_TYPE`）；语音 ≤ 20 MB、≤ 600 s（界面建议 ≤ 5 分钟，10 分钟自动停），图片 / 手写 ≤ 10 MB（413 `MEMO_TOO_LARGE`；app.ts 21 MB content-length 预检 + 路由流式计数（无 content-length 时读到 21 MB 即停）+ 服务层按实际字节）。语音按浏览器原格式存（Safari audio/mp4、Chrome webm/opus），平台不转码不转写；`GET /memos/:id/media` 直出 inline（`<audio>` / `<img>` 直接引用，private no-store）。手写只存 PaperEditor 渲染的 PNG 快照，矢量不上传。
- 离线：每条先落本机（IndexedDB `tutor-memos/outbox`，含媒体 Blob）再上传，本机写不进则立即上传、两边都没存下来才报错并恢复输入——文字放回输入框，录音 / 图片 / 手写留在本页给「重新保存」按钮（复用同一 clientId，服务端已落库只是响应丢失时不会成两条）（记录端「返回即有副本」，不把没有副本的内容当已保存关掉浮层）；暂态失败（网络 / 5xx / 401 / 408 / 429；401 = 会话过期，重新登录后自动补传）保留、`online` / 进页 / 新记一条时按入队顺序补传；业务拒绝（其余 4xx）标失败原因留在列表「上传失败」区由本人重试或丢弃，不静默删除未同步内容；本机待传条目不等云端查询、离线首次进页也可见；队列按账号隔离。文字和媒体写入请求均须带 `X-Tutor-Memo-Account`，服务端校验它与当前学生会话一致。账号切换或旧页面缺少绑定时返回 409 `MEMO_OUTBOX_ACCOUNT_CHANGED`，本机条目保留，更新页面并登录原账号后继续补传。仍在线时，暂态服务错误每 30 秒重试。
- 界面：顶栏导航「随笔」（`/s/memos`，个人账号同样有）= 常驻记录端 + 形态筛选（URL `?kind=`、`?tag=`）+ 记录时间倒序游标列表（待补传条目置顶）；普通页面右下角浮动「随手记」（随笔页不叠加）打开同一记录端，角标 = 待补传条数；工作区页面（作答 / 结果 / 讲练 / 讲义阅读，自带吸底操作条）不浮，入口在各自工具栏（作答页「练习更多」菜单项、其余顶栏图标按钮），避免压住「下一题」「交卷」。列表条目按形态渲染，带锚回链（作答页 `?q=` / 讲义页）、标签、相对时间、设备、「Agent 转记」标识与删除。
- MCP（学生 / 个人 token 同列）：`list_my_memos`（只读，文字正文 + 媒体元信息）、`add_memo`（Agent 转记一条文字随笔，source=agent，锚经核对）、`get_memo_media`（按 id 取语音 audio / 图片 image 内联，> 8 MB 返回 `MEMO_MEDIA_TOO_LARGE` 附元信息）。
- 还没做（模块 5 第二步起）：Agent 空闲整理稿（版本链 / 接受进档案）、语音转写派生条目的挂接、分享给教师、附件页码锚、考前易错点清单。
