# 讲练（kind: lesson）

本文件是讲练的专题 SSOT：讲练的定义、数据地基、卷的生命周期、作答与回看、做题记录与错题本口径，都以这里为准。
涉及讲练的任务必须在制定方案和修改前阅读。《学生作答与讲练.md》「讲练页约定」与《页面功能清单》§3.9 的讲练条目逐步迁入本文件，迁移期间两处不一致时以代码为准，并回到本文件订正。
全局开发规则见 [AGENTS.md](../../AGENTS.md)。

> 标注约定：**【现状】** = 已对照 v2 代码核实（基线 v2 d02f90ab）；**【待定】** = 需要产品拍板的口径；**【缺口】** = 现状与目标闭环之间缺的部分。

## 1. 定义

- 讲练是一篇 `kind: lesson` 的讲义：讲义段落与可作答题目原位交错，一篇文档就是「一件事」。
- 与配套练习（`practice` / `mixed` 讲义 + 独立单元）的区别：讲练的题属于随堂练习的**嵌入单元**，不单独布置、不进资源库单元列表与课程目录计数；配套练习单元是独立教学内容。
- 讲练卷 `attempts.sourceType = "lesson"`，与作业、课程练习、错题重练并列为四种作答来源之一。

## 2. 数据地基【现状】

- **嵌入单元**：判定统一走 `apps/server/src/services/lesson-embedded.ts`（`units.lectureId` 指向 kind='lesson' 讲义，含软删）。资源库、课程目录、各类计数、学情矩阵、D8 配套展开均排除嵌入单元。开卷 / 重开 / 落地页取嵌入单元走 `canonicalEmbeddedUnitOf` 单源（live 题 ∩ md 题槽交集最大，平局 updatedAt 最新）。
- **位置即 markdown**：题块在讲义原位，开围栏注入题目 id；改题走重导 / reparse 或题库单题编辑（`updateQuestion` 同事务回写讲义题块，缺块 422 `LESSON_QUESTION_BLOCK_MISSING`）。
- **防泄露根基**：讲义 markdown 原文对学生端恒不下发。学生只拿服务端 `splitLessonBlocks` 切出的 md 段 + 题目槽 + 冻结题公开投影；lesson 语境嵌套题块是 error `QUESTION_NESTED_IN_LESSON`。
- **冻结范围**：题目在开卷时冻结（依赖闭包、判分策略同普通卷）。**讲义正文不冻结**——`buildLessonStartData` 每次用当前 `lecture.markdown` 现切；老师重导后旧卷看到的是新讲义，不在当前 markdown 里的冻结题落到页尾「本次练习其余题目」。【缺口，见 §9 R3】

## 3. 卷的生命周期

```
          start（create-or-return）
 无卷 ─────────────────────────────▶ 进行中(draft)
                                       │  逐题提交：行级 submittedAt 写入，行锁定，当题释放
                                       │  最后一题提交：同事务自动收尾
                                       ▼
                                    已完成(submitted/graded)
                                       │  restart（显式「再做一次」，固定原卷 + 操作标识）
                                       ▼
                                    新的进行中卷（attemptNo+1，从空白开始）
```

- **开卷【现状】**：`POST /lectures/:id/lesson/start` 先返回进行中卷，没有就返回最新一份已完成卷，都没有才新建（`lesson-service.ts` `startLessonAttempt`）；刷新永不误开新卷。零题讲练 = 纯阅读。
- **逐题提交【现状】**：单题提交带题目版本与答案版本 CAS；当题释放对错 / 参考答案 / 详解（题级粒度，attempt 级 answerRelease 不适用）；已提交行锁定答案与笔迹。
- **收尾【现状】**：**只有「最后一题提交」这一条路**。前端没有「完成练习」整卷收尾入口（`use-lesson-attempt.ts`、`StudentLessonPage.tsx` 注释明确「无完成练习」），跳过题或中途离开的卷会一直是进行中。
  - 注：《页面功能清单》§3.9「进度与收尾」写的「未全部提交时『完成练习』」与代码不符，以本条为准，待同步订正。
- **重开【现状】**：「再做一次」只走 `restart`；单元页另有「清空并重新作答」，作废未交卷并开空白新卷，旧卷从历次与进度中移除。
- **不适用【现状】**：讲练不限时（限时测试只用于课程练习与作业）；讲练页不走 AttemptSession，未接入键盘快捷键（注册表为 `lesson.*` 预留）。

## 4. 作答视图【现状】

- 路由 `/s/lectures/:id/lesson/run`（`StudentLessonPage`）：md 段与题卡交错，目录在顶部工具栏，阅读位置按作答卷持久化。
- 题卡三态：作答态 / 已提交态（原地展开对错、参考答案、详解、已解锁提示）/ 待批态（填空、手写等不可自动判，详解已释放、对错「待老师批改」）。
- 草稿纸、正式手写、题面标画复用普通题卡；单题提交后只读。参考自评题按自评约定出现「对了 / 错了 / 暂不判断」。

## 5. 回看视图

- **完成视图【现状】**：run 页卷完成后切到完成视图（`LessonCompletedView`），讲义段与只读题卡交错，可看讲义，入口有「查看结果 / AI 复盘 / 再做一次」。只针对**最新一份卷**。
- **结果页【现状】**：`/s/attempts/:id` 只有题目，没有讲义；返回只回落地页。
- **落地页历次【现状】**：`StudentLessonLandingPage` 历次记录中进行中行进 run 页续作，已交行进 `/s/attempts/:id`。
- **我的记录【现状】**：`StudentRecordsPage` 进行中条目「继续作答」、已交条目「查看结果」都进 `/s/attempts/:id`，讲练卷同样如此。
- 结论：除了「最新一份卷的完成视图」，**所有回看路径都看不到讲义**；第 1、2 次等旧轮次没有带讲义的回看。【缺口，见 §9 R1】

## 6. 做题记录【现状】

- 讲练卷进「我的记录」（`GET /api/student/records`），来源徽章「讲练」，标题 = 讲练页标题；讲练作答**永不失权**（进行中草稿照常列出、可续作，`student-records.ts`）。
- 进行中卷携带行级进度 `practiceSubmittedCount / practiceQuestionCount`（「已做 X / N 题」），已提交行计入待批 / 待自评计数（行级提交事实口径）。
- 单元 / 讲练落地页的首次、最近、最佳表现用「做对 X / N 题」，未做进分母；最佳按答对比例、同率取最近，零题不参与。
- 本题历史（`/s/notebook/:questionId`）聚合四种来源，讲练的答案公布按题级 `submittedAt`。
- 【缺口】因为没有主动收尾，一张跳过了题的讲练卷在记录里永远是「进行中」，不进「已交卷」统计口径。

## 7. 错题本【现状】

- 错题本（`wrong-questions.ts`）取数**不按来源过滤**：条件是「卷已收尾 **或** 本行已单题提交」+ 有效判定非空 + 公布门。讲练逐题提交的行，**即使卷仍在进行中，也会进入轮次史**。
- 讲练行的公布门：`review-access.ts` 中行已提交且 `sourceType = "lesson"` 直接可见（题级释放）。
- 因此讲练判错题进错题本、可「重练全部 / 本组 / 选题重练」，重练卷 `sourceType = "wrong"`；订正、本题历史与普通题同一套。
- 【现状限制】
  - 未提交的题不进错题本（没有判定）。跳过的题既不算错也不算「未做轮」，因为卷不收尾就没有这一轮。
  - 错题卡与轮次只链接到 `/s/attempts/:attemptId` 结果页，回不到讲义里对应的知识点段。
  - 待批题（手写 / 无答案）教师批改前不进错题本，与普通卷一致。
  - 错题按题目归属单元分组，讲练题归在嵌入单元下；分组名是否显示成讲练页标题未核实。

## 8. 导入与重导【现状】

- 预览 / 统计 / 完成提示按「讲练页一件事」呈现；frontmatter `lecture` 只能写本篇标题，否则 warning `LESSON_LECTURE_TITLE_MISMATCH`。
- 重导同名讲练页时由本次导入**接管**嵌入单元（未挂载旧单元软删、挂载单元内不在文件里的题软删），预览亮 `LESSON_EMBEDDED_UNIT_SUPERSEDED` / `LESSON_EMBEDDED_QUESTIONS_SUPERSEDED`。
- 改名重导走 `replaceLectureId` 显式替换；批量导入不提供指认。
- 历史作答都是快照，不受重导影响；但讲义正文不冻结（见 §2）。

## 9. 待完善（迭代方向，详见讲练迭代方案）

| 编号 | 主题 | 现状 | 目标 |
|---|---|---|---|
| R1 | 回看能看讲义 | 只有最新卷完成视图有讲义 | 任一轮讲练卷都能以「讲练视图」回看；结果页可切「题目 / 讲练」 |
| R2 | 主动结束 | 只有最后一题自动收尾 | 有「结束本次讲练」，未提交题按未做收尾、进分母 |
| R3 | 讲义冻结 | 讲义每次现切当前版本 | 开卷记录讲义版本或冻结正文，回看讲义与题对得上 |
| R4 | 先做后看 | 只有先讲后练一种顺序 | 支持「先做后看」，模式记入卷 |
| R5 | 错题回到知识点 | 错题只链到结果页 | 错题卡可跳回讲义对应段 |
| R6 | 学习数据 | 题内用时与讲义事件分开 | 能对比两种顺序的效果 |
