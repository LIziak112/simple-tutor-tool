# 资料分析专项

::::material{id=mat-1 title="2025 年某省粮食生产情况"}
2025 年，某省粮食播种面积 $8{,}321.5$ 万亩，比上年增加 $42.6$ 万亩；粮食总产量 $3{,}096.2$ 万吨，比上年增加 $56.4$ 万吨，实现连续十二年增产。其中夏粮产量 $1{,}208.7$ 万吨，秋粮产量 $1{,}887.5$ 万吨。

:::seg{id=seg-1}
分品种看，稻谷产量 $1{,}542.3$ 万吨，小麦产量 $1{,}026.8$ 万吨，玉米产量 $435.6$ 万吨，豆类产量 $91.5$ 万吨。稻谷、小麦合计产量占粮食总产量的比重约为八成三。
:::

:::seg{id=seg-2}
全省高标准农田累计建成面积突破 $4{,}500$ 万亩，农业机械总动力达到 $7{,}860$ 万千瓦，比上年提高 $2.4\%$；耕种收综合机械化率 $74.6\%$，比上年提高 $1.1$ 个百分点。
:::

::::question{id=zl-1 type=choice difficulty=2 knowledge="增长率计算"}
2024 年该省粮食总产量比上年增长了约（　）。

- [ ] 1.6%
- [x] 3.0%
- [ ] 3.8%
- [ ] 5.6%

:::solution
增长量 $\div$ 基期量：$56.4 \div (3\,096.2 - 56.4) = 56.4 \div 3\,039.8 \approx 1.9\%$。注意题目问的是 2024 年比上年增长，应以 2023 年为基期：$(3\,039.8 - 2\,951.8) \div 2\,951.8 \approx 3.0\%$。
:::

::::question{id=zl-2 type=choice difficulty=3 knowledge="比重计算"}

- [ ] 43.8%
- [x] 49.8%
- [ ] 53.2%

::::question{id=zl-3 type=multi difficulty=3 knowledge="综合分析"}
根据资料，下列说法正确的有（　）。

- [x] 2025 年该省粮食产量实现连续十二年增产
- [ ] 2021—2025 年该省播种面积逐年下降
- [x] 2025 年耕种收综合机械化率比上年提高 1.1 个百分点
- [ ] 2025 年豆类产量超过 100 万吨

:::solution
播种面积逐年上升（8 104.2→8 321.5），B 错；豆类 $91.5$ 万吨不足 100 万吨，D 错。A、C 与资料一致。
:::
::::

::::question{id=zl-4 type=fill difficulty=2 knowledge="平均数计算"}
2021—2025 年五年间，该省粮食总产量平均每年约增产 [[60.0|60]] 万吨（保留一位小数）。

:::solution
五年跨度只有 4 个增长年份：$(3\,096.2 - 2\,856.3) \div 4 = 239.9 \div 4 \approx 60.0$ 万吨。「五年平均」误用 $\div 5$ 是常见陷阱。
:::

::::question{id=zl-5 type=choice difficulty=4 knowledge="增长贡献"}
按增量贡献从大到小排序，2025 年稻谷、小麦、玉米对粮食增产的贡献依次为（　）。

- [ ] 稻谷 > 玉米 > 小麦
- [x] 玉米 > 稻谷 > 小麦
- [ ] 小麦 > 稻谷 > 玉米
- [ ] 稻谷 > 小麦 > 玉米

:::solution
增量：稻谷 $1\,542.3-1\,528.4=13.9$，小麦 $1\,026.8-1\,012.9=13.9$，玉米 $435.6-421.3=14.3$。玉米 $14.3>$ 稻谷 $\approx$ 小麦 $13.9$，稻谷与小数点后第二位比较 $13.92>13.90$，故选 B。
:::
