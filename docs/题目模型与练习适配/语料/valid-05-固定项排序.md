# 语句排序专项

::::question{id=px-1 type=ordering difficulty=3 knowledge="语句排序"}
将下列段落排成一段语意连贯的文字。其中第 ○ 段位置已固定（已标注），有一段不属于本段文字，请勿选用。

:::item{id=it-1}
也就是说，批评的锋芒最终要指向作品本身，而不是借作品浇自己胸中的块垒。
:::

:::item{id=it-2 fixed=true}
如何对一部作品作出恰如其分的评价？
:::

:::item{id=it-3}
因此，批评家首先需要的不是立场，而是耐心——把作品读完、读透的耐心。
:::

:::item{id=it-4}
古人说「不以人废言」，评价作品同样不能因作者的声名与好恶而先存成见。
:::

:::item{id=it-5}
然而现实中，不少批评在作品开卷之前就已写好：喜欢作者的，赞其败笔为创新；厌恶作者的，讥其妙处为侥幸。
:::

:::item{id=it-6}
另外，豆浆与油条的搭配起源于南宋临安的早市，这一说法流传甚广。
:::

:::answer
it-2
it-4
it-5
it-1
it-3
:::

:::solution
正确顺序：设问（it-2，固定）→ 提出原则「不因人废言」（it-4）→ 指出现实反例（it-5）→ 「也就是说」回扣原则本身（it-1）→ 「因此」收束得出批评家的首要品质（it-3）。it-6（豆浆油条）为干扰段，与文段话题无关。
:::
::::

::::question{id=px-2 type=ordering difficulty=4 knowledge="实验步骤排序"}
Arrange the steps of a titration in the correct order. One item is a distractor.

:::item{id=it-1}
Record the initial reading of the burette.
:::

:::item{id=it-2}
Add the indicator to the flask containing the analyte solution.
:::

:::item{id=it-3 fixed=true}
Rinse the burette with the standard solution before filling it.
:::

:::item{id=it-4}
Titrate until the endpoint colour persists, then record the final reading.
:::

:::item{id=it-5}
Heat the flask to boiling for ten minutes before titration begins.
:::

:::answer
it-3
it-2
it-1
it-4
:::

:::solution
it-3 (fixed, first): rinse then fill the burette. Standard order: prepare burette → add indicator → take initial reading → titrate to endpoint and read final. it-5 (boiling) is the distractor — it belongs to other procedures, not acid-base titration.
:::
::::
