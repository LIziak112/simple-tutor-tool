## 归置规则

1. 新实施计划一律放 `superpowers/plans/`，按日期-主题命名；完成后保留，供 `审查报告/` 实施报告与进度表引用溯源。
2. 审查、验收与实测报告放 `审查报告/`，证据截图放报告同目录下的同名子目录。
3. 未决问题与技术债登记为 `待处理的问题/*待办.md`；解决后保留原文，验收结论写进 `审查报告/` 或进度表。
4. 文档移入 `archive/` 前，先全仓检索引用并修正活文档中的路径（archive 内部旧路径按其 README 口径冻结不改）。
5. 大型新功能开工时建自足目录（README + 规格 + 清单 + 验收），以 `学生端AI伴学/`、`题目模型与练习适配/` 为样板。
