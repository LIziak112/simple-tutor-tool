## 1. 目标模型

```
① 资源库（管"有什么"）        讲义库 + 题库（以练习单元为单位），一级文件夹组织
        │  引用（不复制）
② 课程（管"按什么顺序学"）    有序目录 course_items：分节标题 / 讲义 / 练习单元，每条可见性独立
        │  课程成员 course_students（教师管理）
③ 分发（管"谁在做什么"）
     ├─ 常规通道：学生是课程成员 → 自动看到课程内可见的讲义与练习 → 课程练习（可重做）
     └─ 作业通道：作业 = 若干练习单元 × 学生名单（布置时快照，可后续增删）× 截止时间
```

### 1.1 术语（界面文案与代码命名统一使用）

| 术语 | 含义 | 代码命名建议 |
| --- | --- | --- |
| 资源库 | 讲义库与题库的总称，导入内容的唯一落点 | library |
| 讲义库 / 题库 | 资源库中的讲义集合 / 练习单元集合 | lectures / units |
| 文件夹 | 资源库一级分组，默认「未归类」 | library_folders |
| 练习单元（单元） | 一组题目，DSL 中带 unit id | units |
| 课程 | 一份有序目录 + 成员 | courses |
| 课程目录 / 目录条目 | 课程里的有序条目（分节标题、讲义引用、单元引用） | course_items |
| 课程成员 | 加入课程的学生 | course_students |
| 课程练习 | 学生在课程中对某单元的作答，可重做 | attempts.sourceType='course' |
| 作业 | 教师显式布置的单元组合，有名单与截止 | assignments |
| 作答（一次） | 一份 attempt，无论来源 | attempts |
| 历次记录 | 同一学生同一课程同一单元的全部作答 | — |
| 回收站 | 资源库中被软删的讲义/单元 | deletedAt 非空 |

## 2. 设计决策（已定，实施时不得更改）

### 资源库

- **D1 引用而非复制**：课程目录条目只保存 `refId`；在资源库改讲义/题目，所有引用它的课程与未交卷作答立即看到新版本；**已交卷作答不受影响**（沿用 T2.6 交卷快照）。
- **D2 文件夹**：一级，不可嵌套；系统内置「未归类」（不可删、不可改名，`folderId = null` 即未归类）。删除文件夹时，其内容移入「未归类」（二次确认，显示将移动的讲义数/单元数）。文件夹可改名、拖拽排序。
- **D3 删除统一为软删 + 回收站**（讲义也改为软删，取消 T1.12 的物理删除）：
  - 资源库中删除讲义/单元 → `deletedAt` 置值，进入回收站，可恢复；回收站内可「彻底删除」——仅当该资源**没有任何作答记录与作业引用**时允许，否则按钮禁用并说明原因。
  - 删除前确认弹层必须列出**使用情况**：被哪些课程引用（课程名 + 当前是否对学生可见）、被哪些未删除作业使用（作业名 + 截止）。
  - 被软删的资源：在课程中对学生**自动不可见**，教师课程页该条目显示灰色「已删除」标记，可「恢复资源」或「从课程移除」；**作业不受资源删除影响**（作业是显式布置，照常可作答）。
  - 题目软删规则不变（T1.12）。
- **D4 课程删除与归档**：课程提供「归档」（学生端不可见，教师端可筛选查看、可恢复）与「删除」。删除仅在该课程**没有任何作答记录**（`attempts.courseId` 及关联作业）时允许，否则按钮禁用提示「请改用归档」。删除/归档课程**不影响资源库内容**。

### 课程与可见性

- **D5 学生可见规则**（唯一判定函数 `canStudentSeeItem`，所有学生端接口复用）：学生能看到某目录条目，当且仅当同时满足：
  1. 学生未归档，且是该课程成员；
  2. 课程未归档；
  3. 条目 `visible = true`，且 `publishAt` 为空或 `≤ 现在`；
  4. 被引用资源未软删；单元条目还要求该单元至少有 1 道未删除题目。
  学生可见的讲义 = 所在全部课程中可见讲义条目的并集（同一讲义出现在多个课程，讲义列表中只出现一次，但各课程目录中各自出现）。**不再有「全部讲义对所有学生可见」**。
- **D6 课程目录**：条目类型 `section`（分节标题，仅文字）/ `lecture` / `unit`；同一资源在同一课程中只能出现一次（唯一约束，重复添加返回 409 `DUPLICATE_COURSE_ITEM`，选择器中标记「已在本课程」）。新添加条目默认 `visible = true`（添加对话框中有「添加后对学生可见」开关，默认开）。
- **D7 课程成员**：只由教师添加/移出（课程页的成员页签与学生页两处入口，底层同一组接口）。移出成员：学生立即看不到该课程；其已交卷的课程练习记录**保留**，并在学生本人的记录中仍可查看；该课程下未交卷的草稿作答不再可访问（接口返回 403），数据保留不删。
- **D8 配套练习**：单元已有的 `lectureId` 解释为「配套讲义」。在课程中添加讲义时，若资源库中存在以它为配套讲义的单元，对话框提示并默认勾选「一并添加配套练习（N 个）」；学生阅读讲义页底部显示「本课配套练习」（仅显示同一课程中对该学生可见的配套单元）。

### 课程练习与作答

- **D9 作答来源**：`attempts` 增加 `sourceType: 'assignment' | 'course'`。`course` 作答记录 `courseId + unitId`；`assignment` 作答记录 `assignmentId`（`courseId` 可空，取作业所属课程）。hints / ink / events / 草稿同步 / 判分 / 快照全部按 attemptId 工作，**两种来源共用同一套作答接口与答题页**。
- **D10 课程练习可重做，历次保留**：
  - 同一 (学生, 课程, 单元) 同时最多 1 份未交卷作答；存在未交卷作答时入口为「继续作答」。
  - 已交卷后可「再做一次」，创建新 attempt（`attemptNo` 递增，从 1 起），**新一次从空白开始**，不预填上次答案与笔迹。
  - 历次记录全部保留，学生可逐次查看结果视图（快照 + 本人答案 + 参考答案 + 详解 + 笔迹 + 已解锁提示）。
  - 单元卡片显示：作答次数、**首次得分**、最近得分、最高得分、是否有待批题。首次得分最能反映真实掌握程度，教师侧统计优先使用它。
  - 同一单元在两个课程中各自独立计次；作业中的作答与课程练习互不计入对方次数。
- **D11 答案公布**：课程练习**交卷即公布**参考答案与详解（练习性质，允许重做正是为了对照订正）。作业默认同样交卷即公布；「截止后公布」为可选任务 T2A.8。

### 作业

- **D12 作业内容 = 有序的多个练习单元**：新表 `assignment_units(assignmentId, unitId, order)`。布置时从两个来源多选：「本课程练习」（所选课程目录中的单元，按目录顺序，含隐藏条目，并标注隐藏状态）与「资源库」（按文件夹/搜索筛选）。同一作业中单元不可重复（400 `DUPLICATE_UNIT`）。答题页按单元分节（节标题 = 单元标题），题号全卷连续；一个作业一人一份作答，得分按全卷计算。
- **D13 作业对象**：
  - 可选「所属课程」（可空）。选了课程时，名单默认带出**布置时刻的全部课程成员**（可逐个取消勾选），保存后即为独立快照，**之后课程成员变化不自动影响该作业**。
  - 名单可随时修改：新增学生立即可见；移出**未开始**的学生直接移除；移出**已开始或已交卷**的学生需二次确认——该作业从其待办中消失，已交卷结果保留在其记录中，教师侧数据保留。
  - 作业编辑页提供「补充课程新成员（N 人）」快捷按钮：列出当前课程中不在名单里的成员，可勾选加入。
  - 名单中每位学生显示状态徽章（未开始 / 进行中 / 已交卷 / 已批改）。
- **D14 作业内容锁定**：只要有任一学生创建了该作业的 attempt，作业的单元列表即锁定（编辑页显示锁定原因与已开始人数），`PATCH` 修改 `unitIds` 返回 409 `ASSIGNMENT_CONTENT_LOCKED`。标题、截止时间、名单始终可改。
- **D15 已做过提示**：布置作业选择内容与名单后，若名单中有学生**在课程练习中已交卷过**所选单元，在确认步骤中逐条提示「张三：已在〈课程〉中做过〈单元〉2 次（已看过答案）」。仅提示，不阻止。
- **D16 资源删除不影响作业**：作业引用的单元即使被软删，作业照常可作答；作业卡片显示「含已删除单元」提示。

### 导入

- **D17 导入只进资源库**：导入表单选择「目标文件夹」（默认未归类）；可选快捷项「同时加入课程 X」（追加到目录末尾，带「对学生可见」开关）——这只是快捷方式，归属仍在资源库。
- **D18 匹配规则**（重新导入即更新）：
  - 单元：按 DSL unit id 全局匹配（现状不变）。命中已有单元时**保留其原文件夹**，预览中标注「更新（位于文件夹 X）」。
  - 讲义：按 **(目标文件夹, 标题)** 匹配（替代原来的 (课程, 标题)）。命中则替换 markdown，否则新增。若其他文件夹已有同名讲义，预览给出 warning「资源库『Y』文件夹已有同名讲义，确认不是重复导入」。
  - 题目：同 id 更新 version+1（现状不变）；**文件中缺失的已有题目保留不删**，预览中明示「文件中未出现的 N 道已有题目将保留」。
  - 命中回收站中的资源时：自动恢复并更新，预览标注「将从回收站恢复」。
- **D19 预览必须展示「将发生什么」**：每个文件列出动作清单——新增单元 / 更新单元（其中新增题 n、更新题 n（version+1）、保留题 n）/ 新增讲义 / 更新讲义 / 从回收站恢复；若被更新的单元正被未截止作业使用，warning「该单元被 N 个未截止作业使用：已交卷学生不受影响，未交卷学生将看到新版本」。
- **D20 批量导入**：支持多选 .md 文件与选择文件夹（`webkitdirectory`；按特性检测降级——iPad Safari、桌面 Firefox 等不支持选文件夹的浏览器只显示多选文件，不报错）。可选「按子目录自动建文件夹」（文件夹名 = 文件所在的直接父目录名，已存在同名文件夹则复用）。
  - 预览：文件表格（相对路径、识别出的类型、单元数/题数/讲义数、error 数、warning 数、动作摘要），点击一行展开现有的单文件预览（CodeMirror 标红 + 渲染 + 统计）。
  - **跨文件冲突**（同一批次中两个文件定义同一 unit id，或同一目标文件夹下同名讲义）视为 error，两个文件都标红。
  - 提交：**每个文件独立事务**，有 error 的文件自动跳过、其余照常提交；结束后给出汇总报告（成功 n / 跳过 n / 失败 n，每行可展开原因），失败/跳过文件保留在列表中，修正后可「重新预览」再提交。
  - 上限：单批 ≤ 50 个文件、单文件 ≤ 1 MB、单批 markdown 原文合计 ≤ 10 MB；超限前端直接提示，服务端同样校验（413 `IMPORT_TOO_LARGE`，按原始 markdown 字节合计判定，不以 JSON body 体积为准）。`preview-batch` 以单个 JSON 传全部文件内容，转义后 body 体积约为原文 1.5–2 倍——须在该路由解析前加 content-length 粗防线（约 30 MB，超出直接 413，不进 parseBody），避免超限请求整包进内存后才被拒。
- **D21 「复制错误给 AI」新格式**（替换全文拼接）：
  - 内容 = 固定修正要求说明 + 逐文件：**相对路径**（粘贴内容则写「粘贴内容（无文件路径）」）+ 错误列表（行:列、CODE、中文说明、可选修复建议）+ 每个错误**前后各 3 行的带行号原文片段**（相邻片段合并），**不附全文**。
  - 修正要求说明中写明：「请按路径打开这些文件，只修正列出的问题，不要改动其他内容；若你无法访问文件，请让我提供完整文件」。
  - 批量预览页提供「复制全部错误给 AI」（仅含有 error 的文件）；单文件预览保留单文件复制。
  - 单文件规模控制：片段总行数超过 200 行时截断并注明「其余 N 处错误略」。

### 权限与错误码

- **D22** 学生访问课程资源：非成员或课程已归档 → 403 `COURSE_ACCESS_DENIED`；条目隐藏/未到发布时间/资源已删除/不在该课程目录中 → 404 `NOT_FOUND`（不暴露存在性）。作业相关维持现状（未被指派 403）。

### 数据迁移

- **D23 现有数据搬迁**（在 T2A.1 一次完成，幂等）：drizzle 迁移只做结构变更（DDL，经 `pnpm db:generate` 生成，不手改）；数据回填**不写进迁移文件**（db:generate 产不出 DML，手写会触碰禁改迁移红线），而是放在应用启动的迁移执行之后（migrate.ts 流程内）以代码执行，带完成标记防重跑，保证幂等可重复。搬迁步骤：
  1. 每个现有课程在资源库建同名文件夹；课程下的讲义/单元 `folderId` 指向该文件夹。
  2. 每个现有课程生成课程目录：按讲义原顺序，每篇讲义后紧跟其配套单元（按单元原顺序），剩余单元按原顺序追加在末尾。
  3. **讲义条目 `visible = true`；单元条目 `visible = false`**（课程练习本就交卷即公布答案（D11），「看到答案」不是风险；默认隐藏是为了避免学生端突然出现全部历史单元可自由刷题，由教师按教学节奏逐个开放）。
  4. 所有现有未归档学生加入所有现有课程（保持「学生能看到全部讲义」的现状不变），由教师后续调整。
  5. 现有作业：`assignment_units` 写入原 `unitId`（order=0）；`courseId` 取该单元原所属课程。
  6. 现有 attempts：`sourceType = 'assignment'`，`attemptNo = 1`。
  7. 「默认课程」按普通课程处理（教师可改名/归档）。

## 4. 教师端通用使用约定（所有页面任务都要遵守）

1. **影响先说清**：任何删除、移出、归档、锁定、覆盖更新，确认弹层必须写出具体影响（数量 + 名称列表，最多列 10 条，其余「等 N 项」）。
2. **批量操作**：资源库列表、课程成员、作业名单均支持多选 + 批量操作（全选当前筛选结果）。
3. **找得到**：资源库、课程选择器、作业内容选择器都有搜索（标题 / unit id / topic / 考点，前端即时过滤即可）与文件夹筛选；列表显示题数与题型分布，避免点进去才知道内容。
4. **状态一目了然**：课程目录条目显示「可见 / 隐藏 / 定时（9月30日 08:00 发布）/ 已删除 / 无题目」标签；作业名单显示每人状态；资源显示「被 N 个课程引用 · N 个作业使用」。
5. **不丢工作**：编辑抽屉与布置作业表单有未保存改动时，关闭/离开需确认；批量导入结果页不因单个文件失败而清空列表。
6. **可撤回**：资源删除进回收站；课程先归档；学生移出课程不删数据。成功操作用 toast 提示，删除类 toast 带「撤销」（调用恢复接口，5 秒内）。
7. **三态齐全**：加载 / 空态（带下一步引导按钮，如「资源库还没有内容 → 去导入」「课程还没有成员 → 添加学生」）/ 错误（中文说明 + 重试）。
8. **时间**：界面一律北京时间；定时发布、截止时间用同一个日期时间选择组件，显示「x 天后」相对提示。
9. **触控**：教师端也可能在 iPad 上使用，交互元素 ≥ 44px，拖拽排序提供「上移/下移」按钮作为触控兜底。
10. **学生视角核对**：课程页提供「学生可见预览」开关——只读地显示「该课程成员此刻能看到的目录」（按 D5 计算），便于教师确认可见性设置。

### T2A.7 作业改造（多单元内容 + 按课程布置 + 名单增删 + 内容锁定）
