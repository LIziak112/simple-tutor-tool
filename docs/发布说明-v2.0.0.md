这是 simple-tutor-tool 的第一个正式版本。

它是一个给线上一对一辅导老师用的自部署讲练工具，从我自己的真实教学场景里一点点长出来——每节课要发讲义、留练习、收手写作业、复盘学情，这些事原先散落在好几个工具里，索性自己写一个把它们串起来。很多地方仍在持续打磨，你大概会碰到不顺手的细节。感谢点进来的每一位；如果你也在做一对一辅导，欢迎试用、开 issue，任何反馈都有帮助。

## 这个工具做一件什么事

老师（借助 AI 或手写）产出符合 DSL 规范的 Markdown 文档，导入后自动渲染成可互动的讲义与练习；学生打开专属链接即可答题，iPad 上可用 Apple Pencil 手写；教师在后台查看逐题作答与笔迹原图、批改主观题；课程告一段落时，结构化的学情数据可以整包交回 AI 统计整理，服务于下一节课。内容从 AI 来，数据回 AI 去，中间的讲、练、批都在这一个工具里。

## 亮点

### 内容引擎：MD 进，互动页面出

- 讲义、练习或两者混合的 `.md` 一次导入，自动识别类型、解析、上架；练习自动拆成带题型、难度、考点的题库，讲义按「第 X 讲」自动分篇。
- Markdown DSL 提供折叠、提示、分步、函数图等教学排版指令；已发布指令只增不改，旧内容永远可用。
- 内置 linter：编辑器里实时诊断，`pnpm tutor-lint` 命令行校验，错误信息可以直接回喂给 AI 自行修正。
- 导入向导带 lint 门禁与 dry-run 预览，先看清会解析成什么样，再决定入库。

### 学生端：零负担使用

- 浏览器打开专属链接即用，免安装、免注册；iPad 可「添加到主屏幕」全屏使用（PWA）。
- 判断 / 选择 / 填空 / 手写四种作答方式，数学答案可选 MathLive 公式键盘输入。
- Apple Pencil 手写保留笔迹原图，批改与回放都基于原图。
- 错题本带轮次史与攻克标准，可一键错题重练。
- 作答草稿存本地，刷新或锁屏后自动恢复；答案与详解交卷后才对学生可见。

### 教师端：管理内容、获取数据

- 资源库把单元与讲义当作可维护的资产：预览、编辑、排序、归类、软删除，不是一次性导入物。
- 批改队列逐题批注对错、写评语，参考答案 LaTeX 渲染，手写笔迹可逐笔回放。
- 作答数据三视图（按课程 / 按作业 / 按学生）：逐题答案、判分结果、每题用时、手写原图。
- 学情分析提供掌握度矩阵、周趋势、重点考点与学生画像，为下节课讲什么给出直接依据。
- 一键备份 / 恢复（下载前自动拍数据库快照），提交记录可导出 CSV。

### AI 三层接入

- 制作端：DSL 规范 + 提示词模板 + linter(`/spec` 路由对外提供）——把规范交给任何 AI，它产出的 MD 即可直接导入。
- 数据端：一键导出「AI 学情数据包」（结构化作答数据 + 预置提示词），交给 AI 即得错误分布、薄弱考点与下节课建议。
- 实时接入：内置 MCP Server（教师 API Token 鉴权），Claude 等 AI 客户端可以直接列学生、取学情包、校验并导入内容。

## 工程质量

- 2300+ 单元测试；Playwright E2E 覆盖 Chromium 与 WebKit(iPad 模拟）。
- CI 上 lint、类型检查、单测、构建、E2E 与规范产物校验全绿才可合并。
- 全部数据结构以 `packages/contract` 的 Zod schema 为单一事实来源，前后端共用一份契约。
- 学生端接口强制附带防泄题测试：未交卷题目的答案、详解与提示永不下发。

## 快速上手

三种方式任选其一，都只需 Node.js 24（源码方式另需 pnpm):

**方式一：Docker Compose（推荐）**

```bash
git clone https://github.com/LIziak112/simple-tutor-tool.git && cd simple-tutor-tool
mkdir -p data && sudo chown -R 1000:1000 data    # 容器内以 uid 1000 运行，data/ 需可写
docker compose up -d --build                     # 浏览器打开 http://localhost
```

**方式二：Windows 一键脚本**

克隆仓库后双击根目录的「启动服务.cmd」：缺少构建产物时会自动执行 `pnpm build`（首次约 1–2 分钟），随后以生产模式启动，浏览器打开 `http://localhost:8787`。

**方式三：源码运行**

```bash
pnpm install
pnpm build
node apps/server/dist/index.js
```

想先看看效果再决定？：`pnpm install` 之后运行 `pnpm seed:demo`，可灌入一套演示数据（教师、学生、课程与作答记录），不用自己准备内容。

首次启动会进入教师端设置向导（设置登录名 + 密码，首位教师即管理员），之后建课、加学生、导入 `samples/` 里的样例文档即可走通全流程。公网部署建议在管理端关闭教师自助注册。

**TL;DR for English visitors:** simple-tutor-tool is a self-hosted, AI-native tool for building lectures and practice for 1-on-1 online tutoring, grown out of my own teaching workflow. Teachers import Markdown written to a small DSL, students answer through a personal link — including handwriting on iPad with Apple Pencil — and the teacher grades and reviews per-question results in one place. Three quick facts: it runs as a single Node process with SQLite and keeps all data in one directory you own; content is a Markdown DSL with a linter and a built-in MCP server, so AI clients can author and ingest it directly; grading happens server-side, and student-facing APIs are tested to never leak answers before submission. It is MIT licensed. If you tutor online, give it a try — feedback and issue reports are welcome.
