# 课程嵌套目录与查找实施计划

## 目标与范围

学生能按目录、名称和练习状态快速找到内容；教师能直接放进正确位置，也能让自己的 Agent 整理目录。此次仅扩展课程目录，资源库继续负责保存原件，不另建一套内容系统。延续现有发布、自评、提交、讲练和防泄露规则。

采用「嵌套文件夹 + 紧凑列表 + 名称搜索」这一套结构。首期不做拖拽树、全文索引、标签系统、智能推荐、权限继承编辑器或自动定时归类任务。

## 一、目录和名称

- 沿用 `course_items`，`section` 表示文件夹，新增可空 `parentId`：空为根目录，非空必须指向同课程文件夹。文件夹可以继续包含文件夹；内容只保留一个父级。
- 沿用条目 ID、资源引用 ID、顺序与发布字段。移动文件夹连同后代一起移动；同级上移/下移只调整顺序，不改变层级。
- **同一课程内所有目录名称唯一**，包括不同层级的文件夹、讲义和独立练习。不只检查同级，也不改变资源库原件或另一门课程中的名称。
- 新建、导入、批量添加及旧数据迁入统一自动去重：`基础`、`基础（2）`、`基础（3）`，忽略大小写。新文件夹名含后缀最多 100 字符；资源原有长标题完整保留，不因去重截断。手动改名若冲突则提示，让教师选择新名。
- 同一个资源仍只能加入同一课程一次，重试返回跳过结果，不因目标目录不同复制课程条目。需要调整位置时使用移动。
- 移动必须拒绝自己、后代、非文件夹和其他课程的条目。批量操作在事务内完成，失败不留半棵树。
- 移除文件夹默认「仅解散」：子内容升到上一级。取消此选项则移除整个子树的课程引用。两种操作都保留资源原件、作答和作业记录；普通内容条目只移除自身。

## 二、旧数据和迁移

- 先改 Zod 契约，再生成 Drizzle 迁移，增加 `parent_id` 和导入来源目录键 `import_path`；不手改线上数据库。
- 一次性回填将旧章节后的条目归入该章节，下一章节仍在根目录；首个章节之前的内容保留在根目录。旧条目 ID、顺序、可见性、发布时间均保留。
- 同次回填补齐课程内显示名并去重，记录迁移标记。之后启动不再次推断层级，避免覆盖教师整理结果。
- 不迁移讲练嵌入单元为独立练习；既有历史脏条目继续按原规则过滤。

## 三、教师操作

- 课程目录默认单栏占满可用宽度，只有打开「学生可见预览」才展示预览栏。
- 每行保留文件类型、名称、文件夹直接子项数、发布状态和操作。常用入口是搜索、新建文件夹、向指定文件夹添加；低频操作收在「更多」。
- 文件夹展开/折叠，支持全部折叠；搜索名称或完整路径时保留祖先并展开匹配路径。深层缩进设视觉上限，完整路径辅助说明，避免挤没标题。
- 「更多」支持新建子文件夹、添加内容、改名、移动、同级上/下移、隐藏/显示、定时和移除。复选框支持批量移动，目标选择排除已选文件夹及其后代。
- 从资源库添加的侧栏和资源库批量加入课程弹窗，都可选择根目录或任意嵌套文件夹。加载失败给重试入口，未确认目标有效前不能提交。
- 失败保留弹窗输入与选中项；保存中防止重复提交；成功刷新课程详情、列表、学生预览和内容树。

## 四、导入和 Agent 归类

- 导入页接收 `courseId`、`parentId`，打开时预选目标课程和文件夹。现有单文件、批量、目录和 ZIP 导入继续共用提交服务。
- 默认放入所选目录；勾选「保留来源目录层级」后，按相对路径逐层创建/复用课程文件夹，包含上传路径中的顶层文件夹。预览说明归档方式，并逐文件展示课程相对目标路径；资源库目标单独标识。
- `importPath` 保存来源路径键，同一来源目录在导入重试、课程目录改名后仍复用原目录。教师已移动的来源目录不会被重试强行搬回。路径中的 `.`、`..` 和伪造分隔符拒绝。
- 教师 MCP 增加四个工具：`get_course_catalog`、`get_library_catalog`、`manage_course_catalog`、`add_course_content`。Agent 先获取条目 ID、资源 ID 和父子关系，再提案，再显式 `confirm=true` 执行。
- 管理命令与 HTTP/UI 共用契约和服务：建文件夹、改名、移动、同级重排、可见性、移除。添加工具默认隐藏，缺省只预览，不暗中发布内容。
- 操作限制在 token 所属教师域；课程、目标和资源归属服务端重验。资源清单排除讲练嵌入单元。学生 MCP 不注册这些工具，不扩大普通学生出口。
- 现有 MCP 导入仍先写资源库，需要课程归档时接续调用添加工具；不必为此重做导入协议或 Agent 任务调度系统。

## 五、学生查找

- 展示相同目录结构，只有当前可访问的后代才展示祖先，空文件夹不占列表。
- 发布门逐层校验：文件夹隐藏或未到发布时间时，后代在目录、计数和直接访问入口都不可见。移动不改节点自身发布配置；显示文件夹保留既有定时设置。
- 搜索仅匹配当前可见内容的课程内名称与文件夹路径，前端即时过滤，不检索题干、答案或解析。输入法组合期间不反复改 URL。
- 类型筛选「全部 / 讲义 / 练习」；讲练继续显示讲义及讲练徽标，不把嵌入题作为独立练习。
- 仅独立练习显示状态筛选「全部练习 / 未开始 / 进行中 / 已交卷」。有草稿优先记为进行中，否则交过卷记为已交卷，其余未开始；三个状态互斥，不混淆交卷与待自评。
- 搜索/类型/状态写入白名单 URL 参数，便于分享和刷新；折叠与最后阅读条目 ID 使用学生角色内存缓存，账号切换沿用原有清理。阅读后回到课程时恢复筛选和定位；不复制草稿、答案或凭据到新存储。
- 匹配为空时说明原因并提供清除筛选。网络失败不假装没有课程内容。

## 六、紧凑 UI

- 教师课程列表改为紧凑行，桌面操作与信息并排，减少重复卡片留白；课程详情缩小头部、区块间距和内边距。
- 学生课程卡片减小间距和内边距；目录用连续分隔行替代大卡片。
- 常用触控目标至少 44px；通过减少留白提高密度，不靠缩小字体和点按区。搜索输入移动端保持 16px，标题换行，深层目录与长中文名称不撑破窄屏。
- 延续现有主题、组件、焦点样式和品牌，不新增依赖、CDN、视觉框架或无关动效。

## 八、验证和上线边界

先写核心行为失败测试，再接入实现。覆盖嵌套/全课程去重/循环/跨课程/越权/同资源重试/改名后导入重试/旧迁入只运行一次；新增学生投影同时断言契约和防泄露，隐藏祖先时直接访问失败。

组件测试覆盖文件夹搜索、折叠与筛选交互、草稿与已交卷互斥。端到端覆盖教师创建子目录、归档现有内容、学生搜索与阅读返回、390px 窄屏无横向溢出，并留截图供视觉检查。

运行 `pnpm gen:spec`、`pnpm lint:changed`、`pnpm typecheck:affected`、`pnpm test:affected`、`pnpm e2e:affected`；契约/迁移会触发选测脚本全量兜底，遵守其决策。全量构建由 PR CI 执行，实际结果另记验收记录，不预先宣称通过。真实 iPad/Pencil 和原生系统缩放不能由模拟设备替代。

基于最新 `origin/v2` 新建独立 worktree 和 `codex/nested-course-catalog` 分支，不改用户其他工作区。验证通过后提交 PR 到 `v2`，不自动合并或发布 `main`。
