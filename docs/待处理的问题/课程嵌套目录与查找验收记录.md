# 课程嵌套目录与查找验收记录

实施方案见 [课程嵌套目录与查找实施计划](课程嵌套目录与查找实施计划.md)。基线为 `origin/v2` 的 `340d4f19`，独立 worktree 分支为 `codex/nested-course-catalog`。

## 审查结论

按完整变更依次做了简化、正确性和学生数据安全审查；工作流技能未安装，使用仓库规定的等效人工审查与真实命令验证，未声称调用这些技能。

- 简化：目录管理共用一个契约与事务服务，HTTP 和教师 MCP 不另写一套操作；沿用章节类型和资源引用，不引入目录表、拖拽库或搜索服务。祖先检查与直接子项计数预建 Map，减少重复扫描。
- 正确性：补齐课程全域去重、同资源重试跳过、循环和跨课程目标校验；旧数据仅迁入一次；解散保留原件与记录。导入目录记录来源键，复用既有目录时也补键，改名后重试不重复建目录。长资源标题完整保留，文件夹才适用 100 字符限制。
- 安全：目录指令、资源和目标都在服务端校验教师归属；普通学生目录及直接读取共用祖先发布门；隐藏祖先后直接读取返回不可访问。新增投影测试同时验证公开契约和无答案字段。教师 MCP 只返回整理所需目录/资源元信息，学生 MCP 工具不增加，未修改既有答案公开和 AI 授权边界。
- UI：桌面默认单栏，课程列表与目录缩小留白；390px 下无横向溢出。复选框标签及常用操作保留至少 44px 点按区。学生阅读返回即时保存筛选与定位，角色切换沿用原查询缓存隔离。

## 手动复核与部署边界

1. 教师课程页新建文件夹，再通过「更多」新建子文件夹，将内容移动进去；搜索祖先名称应显示后代，同级上移/下移不得改变归属。
2. 从资源库添加、批量加入课程和导入时选择嵌套目标；重复添加同资源应跳过，重复名称自动加后缀。导入保留来源目录时，改名后再次导入不重复创建来源文件夹。
3. 隐藏父文件夹，以学生账号查看目录和直接访问其内容均不可见；显示父文件夹仍遵循原定时设置。学生搜索、类型与练习状态筛选后阅读再返回，应恢复筛选与阅读条目。
4. MCP 先调用 `get_course_catalog` / `get_library_catalog` 获取 ID，再调用管理或添加工具；缺省只预览，显式 `confirm=true` 执行。添加默认隐藏，不能操作其他教师课程。
5. 在 390px 窄屏核对长名称、深层目录和批量操作。自动化截图已检查，侧边栏本地预览也已检查。预览使用独立数据库备份，未迁移或改写用户原开发数据库。

数据库需部署生成的 0047、0048 迁移，并由启动回填旧章节关系。全量构建与 WebKit 回归交由 PR CI，本机没有重复执行全量构建。真实 iPad/Pencil 手感及原生系统缩放未做硬件验收；浏览器模拟与 Chromium 缩放回归不替代该项。PR 指向 `v2`，本次不自动合并或发布 `main`。
