# 结果回看页三处界面修正计划

日期：2026-10-11。基线：main / 726981c。状态：已确认并完成实施与验证，实施分支为 `codex/result-review-interface`。验收及手动验证见[验收记录](结果回看页三处界面修正验收.md)。仅合并到 `v2`。

## 范围与证据

用户标注的已批改学生结果页，共27题。现场浏览器确认定位栏没有手动收起入口；源码确认 ResultWorkspace 固定240px桌面侧栏，ResultQuestionTools 将三个工具组纵向堆叠，AnnotationView 闭合按钮默认拉满；得分说明和题量统计共处一条换行不稳定的横排。按照 better-interface 继续处理布局、文字层级和操作可达性。

## 实施顺序与文件清单

1. **题号栏手动折叠**：修改 `apps/web/src/features/attempt/ResultWorkspace.tsx` 与对应测试。桌面默认展开，顶部提供“收起题号栏”；收起为44px窄栏，保留“展开题号栏”按钮，正文获得释放的宽度。按钮带展开状态及受控区域关联，键盘可操作。开合保留定位范围、当前题号和正文实例，不清空订正状态；当前阅读题保持在可见位置。小屏继续使用原题号抽屉。
2. **题后工具紧凑布局**：修改 `ResultQuestionTools.tsx`、`AttemptResultView.tsx` 与相应测试；按需要给 `AnnotationView.tsx`、`NoteOriginalView.tsx`、`CorrectionSection.tsx`、`review-pack-panel.tsx` 增加可选紧凑布局属性，默认沿用现有调用方表现。保留“本次原稿 / 订正 / 更多”语义分组，分组标题与按钮同排，原稿和题干标注并排，订正标画、订正、历史并排，AI复习包保留明确入口。按钮自适应换行，去掉闭合态全宽标注按钮及标题独占行。展开内容使用完整可用宽度，编辑控制器不因排版切换而卸载；原稿与订正保持各自的数据和懒加载行为。详解仍在答案对照后、材料工具前。
3. **得分与题量重排**：修改 `AttemptResultView.tsx` 与对应测试，必要时提取局部汇总组件。得分独立呈现为大号数字与“/ 100”，最终/自动判分说明另起短行；课程、次数、时间归入次级信息行。题数统计使用对齐的标签和大号数字，明确区分总题数、服务端判定、未作答情况；答对/判错/待批兼有文字和颜色，未答采用中性色，保留未答与判错或待批重叠的说明。沿用现有字体和颜色体系，数字使用等宽数码，不改服务端口径。

## 测试与验收

- 行为改动先补失败测试：收起/展开后筛选与正文状态保留，键盘按钮展开状态正确；各工具入口及展开内容可达，闭合零请求，不丢订正反思；未公布时不出现得分、对错或参考答案。
- 纯布局、字号及颜色调整豁免行为TDD，使用浏览器实测尺寸和截图验收，不用仅验证类名的测试替代效果验证。
- 扩充 `e2e/student-review-workspace.spec.ts`：1024、1110、1440px桌面展开/折叠；工具闭合态显著压缩高度，展开不溢出；320/390px窄屏无横向滚动；统计0、待批、27题及大题数、长课程名可读。
- 跑相关单测与实际浏览器回归，再跑项目测试、类型检查、lint、build；对完整diff做简化检查和正确性审查。使用隔离测试数据库和8899/5199，不修改用户5173作业数据。
- 更新结果回看验收文档，保存桌面统计、工具区及折叠前后截图。独立 `codex/result-review-interface` 分支、小步绿灯提交；按用户后续明确要求，验证通过后仅本地合并 `v2`，不合并到 `main`。

汇总的标签与数字改为定义列表后，原E2E整句匹配需要同步更新：涉及 `teacher-mark-flow`、`student-records`、`student-course-practice`、`assignment-separate`、`main-flow`、`full-chain`、`multi-teacher-full-chain`、`phase3-full-chain`。`e2e/helpers.ts` 增加按统计标签验证可见性和数量的共享断言，避免重复选择器。教师页和作业列表的旧统计文案不受影响，保留其原断言。

## 边界

本轮为前端展示与本地展开状态调整，不新增依赖，不修改契约、API载荷、服务端判分、原稿封存与同步协议。不得为了紧凑把编辑器直接隐藏或重新挂载；若需要额外受控触发器，保持可选属性和现有默认行为。继续执行此前结果回看计划的公布门槛、材料只读与懒加载约束。
