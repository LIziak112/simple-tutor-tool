# 首页作业摘要与我的作业列表实施计划

## 目标与交互

首页作业区显示待完成总数及按布置时间倒序排列的最新两份待完成作业；已交卷与已批改作业不再占据首页。分区右侧常驻“查看全部”，进入独立的“我的作业”页面。没有待办时显示紧凑空态，避免占用大块阅读空间。

顶栏增加“我的作业”，顺序为：首页、我的作业、课程、错题本、我的记录。桌面保持既有导航风格；窄屏按内容空间调整为导航独立一行，保证五个入口的文字和点击区域可达。

新页面 `/s/assignments` 提供：

- 完成状态：待完成、已完成、全部，默认待完成。沿用服务端状态口径：未开始与进行中属于待完成，已交卷与已批改属于已完成。
- 布置时间：全部时间、最近 7 天、最近 30 天、自定义起止日期，默认全部时间，避免隐藏更早的未完成作业。按北京时间自然日解释日期边界，以 `createdAt` 为依据。
- 标题搜索；一行紧凑筛选栏，窄屏按合理阅读顺序换行。
- 布置时间倒序，每页 10 份，显示总数及上一页/下一页，避免长列表持续延伸。
- URL 保存筛选和页码；搜索或切换筛选回到第一页，空结果提供清除筛选入口。加载、错误、空数据分别处理。

从作业列表打开作业后，答题或结果页提供“返回我的作业”，保留筛选和页码；本题历史往返继续保留已有的来源上下文。

## 当前实现与根因

- `StudentHomePage.tsx` 的 `AssignmentList` 对全部待完成和已完成作业分别执行 `map`，没有数量限制；目前只有“无任何作业”时显示空态。
- `StudentLayout.tsx` 只有四个导航入口；`App.tsx` 只有 `/s/assignments/:id`，没有完整作业列表页面。
- 现有 `StudentAssignment` 契约包含 `title`、`createdAt`、`dueAt` 与 `status`，现有 `useStudentAssignments` 可供首页和列表共用，无需增加接口或契约字段。
- `StudentAssignmentAttemptPage.tsx` 的退出路径固定为首页，需要补充允许的作业列表返回上下文。

## 实施顺序

1. 确认方案后从 `v2` 创建独立 `codex/` 分支。
2. 先补失败测试：大量作业时首页只保留最新两份待办、已交卷移出、筛选日期边界、分页及来源返回。
3. 提取筛选与导航逻辑，新增完整列表；再收敛首页摘要并接入顶栏。纯视觉样式用真实浏览器验证，其余交互按 TDD 实现。
4. 对完整 diff 依次完成简化检查和正确性审查；核查学生端答案保护条件。确认的问题当场修复，不新增依赖。
5. 运行相关单测、全量单测、类型检查、lint、构建及 Chromium/WebKit 验证，记录真实输出。提交后延续本次会话的工作方式合并到 `v2`。

## 验证点

- 0、1、2、几十份作业，以及全待完成、全已完成、混合状态下：首页数量与文案正确，完整列表仍可访问所有作业。
- 交卷后返回首页，该作业不再显示在待办摘要；完整列表已完成视图可以找到并查看结果。
- 最近 7/30 天与自定义区间采用统一北京时间边界，无截止日期不影响布置时间筛选；输入无效日期或倒置区间时有明确处理。
- 搜索、状态、日期和分页联合工作；筛选变化重置页码，越界页码安全处理，刷新及浏览器前进后退保留筛选。
- 列表 → 作业/结果 → 本题历史 → 原结果 → 列表的上下文完整；外站、其他角色和路径穿越返回地址被拒绝。
- 中文长标题、大计数、320px、835px、桌面、200% 缩放及 RTL 下无重叠和不可达入口。
- 不修改学生端 API 数据载荷；沿用现有学生端泄露测试和历史样例回归。

## 实施与质量闸门

用户确认后，在 `codex/student-assignment-list` 分支实现。首页数量限制与新导航的失败测试先复现问题，来源返回测试也先失败，再接入实现；纯响应式样式用真实浏览器检查。筛选 helper 的边界用例随提取补充。

依次进行完整 diff 的简化检查与正确性审查：复用 `StudentAssignmentCard` 和 `useStudentAssignments`，统一待办判定及筛选 URL；没有重复 API 类型、新接口、新依赖或答案载荷变更。`/simplify`、`/code-review` 对应技能未安装，本次执行等价的逐文件人工审查，不将其报告为已调用技能。

审查修复：作业摘要骨架限制为两份；长标题所在首页 flex 子项增加 `min-w-0`；作业卡装饰使用逻辑方向；完整列表展示带年份的布置时间；输入增加明确 label/control 关联；返回地址拒绝详细页、路径穿越、反斜线和外站，丢弃未知查询字段。移动与桌面账户区共用同一展示定义，通过 `display:none` 切换；真实浏览器检查只有一份可访问的退出入口。

## 手动验证

1. 为学生布置至少 23 份作业，首页只出现最新两份待办，横幅和区块计数包含全部待办；交卷后回首页，该作业从摘要移除。
2. 顶栏点击「我的作业」，默认待完成、全部时间；翻页、搜索、切换已完成和自定义日期，检查计数及页码。日期按北京时间，允许只填一端，倒置区间提示错误。
3. 从第二页进入作业，点击返回，保留第二页；从已完成进入结果，再进本题历史，刷新后返回结果，最后返回仍保留已完成筛选。
4. 在 320、390、640、835、1024、1440、1920px 及 200% 缩放、RTL 下检查五个导航入口、筛选和长标题，没有页面横向溢出。
