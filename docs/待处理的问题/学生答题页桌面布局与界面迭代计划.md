# 学生答题页桌面布局与界面迭代计划

日期：2026-10-11。

状态：用户已确认「按照计划来实施把」；实现、质量闸门与验证完成。执行分支：`codex/student-desktop-interface`。最终截图、完整命令输出与未验收项见[迭代记录第十二轮](./学生作业体验迭代记录.md#第十二轮桌面答题布局与界面)。

## 目标与范围

按当前学生端 27 题错题重练页的 better-interface 评审推进，优先改善桌面显示和使用。以当前 Codex 侧栏约 1118px、普通桌面 1024px、1200px、1440px 为主要验收宽度，同时保证 320px、390px、768px 可用。

范围是未交卷答题工作区及其共用页头、题面、答题卡、保存详情和交卷确认。共享组件改动需检查结果回看和教师端弹层回归。沿用 React、Tailwind 4、Radix、Lucide 和现有设计令牌。

保留整卷题卡挂载、填写状态计算、阅读位置恢复、草稿同步与标画底图身份校验。布局改变后旧圈画由已有原底图查看机制处理，不把旧笔迹拉伸到重新排版的题面。本次不改题目原文、DSL、API 契约、数据库或判分，不新增依赖；组合陈述重新整理为列表不纳入本次实现。

## 第一阶段：桌面布局与视觉层级（最高优先级）

1. **页头压缩与对齐。** 将正常短标题页头从约 133px 压缩至约 80–96px。桌面将标题、保存状态、保存详情及练习信息组织为紧凑工具区；来源、次数和题数作为次级信息。窄屏按内容换行。保存入口和返回入口保留不小于 44px 的点击区，长标题仍可打开详情读全，页头高度继续由现有测量机制提供。
2. **当前侧栏宽度显示常驻题号导航。** 根据实际内容空间把答题页常驻答题卡断点从 1200px 调整到约 1024px；侧栏约 176–192px，正文使用 minmax(0,1fr)，保持居中限宽。768px 等窄屏沿用弹层。宽屏减少重复答题卡入口，同时保留进度与交卷的明确位置。
3. **题面阅读排版。** 修复公共 rich-markdown 样式覆盖 text-base 的根因，学生题面实际字号采用 1rem。文字题的常用阅读宽度以约 640–720px 为起点，通过真实中英文长题干验证；图形、公式、表格保持可用空间和滚动入口。避免仅限制题干宽度导致选项与题干边缘不一致。
4. **题头工具的桌面可发现性。** 空间允许时显示「圈画」「草稿」短标签，窄屏继续使用图标。保留题号、工具状态与原有 aria-label，已有笔迹状态不只依赖工具颜色。保持当前辅助稿下置方式。
5. **交卷弹层的稳定操作区。** 改成标题、可滚动内容、固定操作区的布局；未答题号和草稿状态在内容区内滚动，「继续作答」「确认交卷」始终在弹层可见区域。保留同步失败分支、忙碌期间关闭限制与遗漏题定位行为。

## 第二阶段：桌面使用效率与无障碍修正

1. 在共用答题卡内增加「下一道未答」入口，按现有完整填写口径寻找目标，覆盖部分填写和全部完成。沿用 jumpToQuestion 定位与焦点逻辑，不创建第二套填写状态。
2. 单选与多选控件优先由原生包裹 label 提供「字母＋选项正文」的完整名称，保留公式可访问语义；更新依赖旧精确名称的既有测试。
3. 对题号、选项和弹层关闭控件修正半透明焦点环；验证焦点与相邻背景至少 3:1，并保留高对比度模式可见性。范围优先限制在学生主题或相关控件，检查共享组件回归。
4. 在学生主题内加深次要文字，验证页头实际背景上的普通文字至少 4.5:1，不仅按白底计算。
5. 共用弹层缩放仅在允许动态效果时运行，减少动态效果时保留无位移的反馈。收敛相关 transition-all，保留既有交互所需的颜色反馈。
6. 填写计数采用 tabular-nums。保存与草稿提示保留已有业务口径，不用排版修正掩盖数据语义问题。

## 实现顺序与测试点

1. 用户确认后，从 v2 创建 codex/student-desktop-interface 独立分支。当前工作区仅有用户未跟踪文件，保留这些文件，不纳入提交。
2. 对行为改动先补失败测试：下一未答题的选择、全部完成状态、选项完整名称、长标题详情和交卷定位/忙碌分支。先记录失败，再改实现。
3. 纯样式调整按 AGENTS.md 的 TDD 豁免执行，以真实布局断言和截图验证，不新增只检查 className 的镜像测试。
4. 先完成第一阶段，再完成第二阶段；桌面排版定稿后复测旧标画在宽度改变时的原稿查看入口，确保答案和草稿不会丢失。
5. 真实浏览器验证 Chromium/WebKit：1024、当前约 1118、1200、1440px 常驻导航；320、390、768px 弹层导航；长标题与长题干；26 道遗漏题弹层按钮可见；最后一题不被底栏遮挡；题号跳转、键盘焦点与 Esc 返回；减少动态效果；实际 16px 字号和颜色对比度。
6. 200% 原生浏览器缩放若当前工具不支持，不把 CSS 放大或视口缩小当作等价验收，记录人工验收项。实体设备同样单独说明。
