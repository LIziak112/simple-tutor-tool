## 3. 界面结构与交互契约

### 3.1 结果工作区

- 显式申请StudentWorkspaceContext，仅结果页活跃时使用专用宽度；离开回看恢复普通学生导航。复用AttemptWorkspace的动态顶栏/底栏测量，不再把原学生导航和新的固定顶栏叠放。课程/作业页面外层返回条收敛进结果顶栏，不留重复返回入口。
- 顶栏：44px返回按钮、可换行标题、来源/第几次、明确“待公布/已交卷待批/已批改”，次级信息可展开。长标题不能靠title属性作为唯一完整内容出口。标题24px以内，正文16px，计数tabular-nums，letter-spacing为0。
- 汇总是无框全宽信息带，不是另一张大卡。得分显示服务端`scoreFinal ?? scoreAuto`、满分100及最终/自动判分口径。服务端判定显示对/错/待批；单独显示“未作答N题”，明确“未作答的客观题已计入判错”。截止前完全不显示分数、对错、待批数及相关筛选。
- `lg`（现有1024px断点）以上：240px题号栏 + `minmax(0,1fr)`正文；题号栏sticky位于动态顶栏下方，130题独立滚动，不能撑长整页。小屏不挤两列，底栏“题号”打开现有Radix弹层；抽屉max-height基于dvh，overscroll-contain。
- 底栏：题号入口、当前原卷题号/总题数、上一题/下一题图标按钮。重练本卷判错题保留现有组卷动作，放汇总操作区，默认只一个主要操作，不把“返回首页”作为主要复盘动作。
- 题号按钮44×44、数字位置固定、文字/图标冗余状态，aria-current=location；状态不能仅用颜色。使用独立结果导航模型，不把QuestionNavigator的“填写状态”冒充判定状态，可复用尺寸样式或小呈现函数，不塞大量模式布尔值。
- 提供“定位范围”选择：全部、判错、未作答、待批；这是题号与上一/下一定位范围，不声称“只看错题”。本期正文保留原序整卷，避免筛选卸载正在编辑的订正。判错与未作答可重叠；不更改原卷题号。范围为空显示原因及返回全部，不自动组卷。
- 点击题号：关闭移动抽屉、等待目标DOM、滚动到题卡标题并聚焦tabIndex=-1标题，动态scroll-margin避开顶栏。当前题通过IntersectionObserver维护，参考已实现阅读位置策略，不逐像素setState。
- `reviewQuestion`/`reviewScope` URL查询保存显式定位，自动阅读位置按学生+attempt存会话仓，不使用未交卷的last-read记录键、不保存答案。刷新恢复合法题；非法/不存在题退回首题。范围变更/上一下一使用replace，不制造大量后退历史。

### 3.2 本题阅读顺序

固定DOM顺序：题头（原题号/题型/判定）→题干/只读选项→本人答案与允许公布的参考答案→教师评语→详解→已打开提示→本题辅助操作及面板。主要阅读内容无需先穿过一组工具。

- 选项中你的选择总有文字标记；已公布且正确项与本人所选相同，标“正确项 · 你的选择”。未公布只标“你的选择”，用中性蓝/边框，无红绿正确项标记。题干仍沿RichMarkdown/displayStemMd投影，不回填带答案的底图。
- 逐题状态“未作答”与判定“判错/待批”可并存，服务端answer=null口径不改成客户端自行判分。部分填空可复用共享完整度函数辅助显示，但不能影响得分或server summary。
- 本人答案/参考答案区不使用卡片套卡片；填空按空号组织可读行，复用formatReferenceAnswers/Markdown，不用纯字符串吞掉公式。长式、表格、DSL与图片维持已有渲染能力。
- 题头只留明确常用图标/动作，详情/材料在下置辅助区。辅助区至少明确“本次原稿”“订正”“更多”；本次原稿内区分草稿、正式手写和题干标画，不让“圈画题干”被误认为原稿编辑。更多放本题历史/复习包等次要动作。
- 优先先移动并重新分组现有NoteOriginalView、AnnotationView、CorrectionSection、AnnotationLayer、ReviewPackPanel，不强行改底层接口。需要受控触发器时仅增加可选props和默认行为，既有调用方保持。封存/复制原稿/找回补充稿的行为不改。
- 收起过的订正编辑器保留同实例/持久仓；父容器收起必须先收笔落盘、解绑隐藏输入，失败保留原面板并提示重试。不能以CSS隐藏或卸载代替持久化。本期导航不强行关闭或卸载编辑中的稿件，失败/冲突状态仍有可见处理入口。
- 原稿、PNG与订正头只在明确展开后请求；不得为了“有稿徽章”对130题批量取头/图片。未知有无稿时入口用“查看本次原稿”，不臆断“无稿”。

### 3.3 我的记录

- 保留现有URL筛选/分页契约，页面标题下显示当前筛选后的总条数，不新增全账号假统计。
- 来源和状态为常见筛选；课程/作业/时间进入“更多筛选”可展开区域，已启用条件在折叠时仍有摘要和单项清除入口。必须保留旧query语义、重置offset和后退恢复。
- 桌面记录按标题/来源课程、时间、结果状态/得分、打开动作有固定阅读列；移动端同一DOM顺序换行。使用语义ol/li/link，不制造两个断点独立列表或在整卡link内嵌按钮。标题/课程允许完整换行；记录圆角≤8px，不再大面积卡片化筛选区。
- 得分0不能当缺省，未公布显示“待公布”，已公布score=null显示“待批”，draft不显示得分。待批数使用pendingCount，绝不自行补算；不把当前页条数当总条数。
- 进入详情携带白名单返回上下文：只接受同源`/s/records`路径及现有筛选字段，不能任意returnTo外链/协议跳转。返回入口明确“返回我的记录”，保留筛选/分页和列表阅读位置。直接访问无上下文按课程/作业/错题来源退回，标签与目标一致；浏览器新标签/刷新也能工作，不只依赖navigate(-1)。
- 全局滚动恢复仅限这条流程，不改其他学生页。没有记录/无筛选匹配/失败显示真实原因和清除条件或重试操作；越界offset有返回第一页入口。
