# 手写可靠性验收记录

日期：2026-10-13。分支：`codex/ink-reliability`；目标：仅合并到 `v2`。

## 最终行为

- 正式手写读取失败不降为空稿；跨设备编辑使用服务端修订号，冲突显式选择本机稿或云端稿，教师关闭手写入口时恢复操作仍可用。
- 幂等重试复用上传标识、矢量与图片；交卷等待在途请求并追平新版。旧上传回执不覆盖新版正文、切换后的账号或新读取的基线。
- PNG 由固定矢量重绘，兼容历史 Excalidraw；文件成对写完后才切换头指针。回收保护当前稿、备份引用及 24 小时安全窗口。
- 正式本机稿按部署、学生、attempt 隔离；旧键在服务端确认本人归属后迁入，原键保留。
- 正式纸面与草稿收起后保活 45 秒，落盘成功才释放；标画保留 PNG 笔迹层预览。重建恢复正文，撤销历史不跨引擎实例持久化。
- 讲练复用普通题卡的草稿、正式手写和标画，题级提交后切为只读。全屏参考题面仅在全屏时挂载。

## 质量闸门

依次完成以下审查；当前环境未提供计划中列出的斜杠技能文件，以下是实际执行的等价审查，未冒称调用技能或外部审查代理。

1. 复用与简化：提取共享纸面保活 hook；固定矢量 PNG 复用既有草稿渲染原语；移除上传控制器的活引擎依赖；讲练直接复用普通题卡并通过 footer 追加提交入口。
2. 正确性：修复旧稿回执覆盖新版正文、后台上传中提交误报失败、使用云端稿后旧 pending 继续补传、重读基线后的迟到回执、关闭辅助能力时恢复入口缺失。真实浏览器定位并修复题卡登记造成的重复题目标识。GC 在无 notes 目录的场景也运行。
3. 安全：学生公开题面投影保持原路径；版本与冲突响应无答案内容；新增请求元信息经 Zod 校验；服务端写事务重新检查整卷及题级提交状态。上传、取回、冲突响应的泄露测试与讲练页面/网络泄露监控通过。

不改的部分：标画尺寸、字体和内容签名核对继续保留。没有证据证明可以安全减少这些保护，不能为减少核对而让旧圈画映射到重排后的题面。未新增技术栈依赖。

## 手动验证

1. 同一题在两台设备编辑，先保存一台，再保存另一台：看到冲突而非静默覆盖；分别验证保留本机稿、使用云端稿。
2. 换设备断网进入已有手写题：看到重试入口，不能从未知状态覆盖云端稿；恢复网络后旧稿回显。
3. 连续写几笔，后台上传中立即交卷：等待最新稿上传；核对图片与矢量回放一致，没有下一笔未结束的片段。
4. 逐题打开纸面与标画，收起超过 45 秒后重开：正文恢复；模拟本机磁盘写入失败时纸面保留。
5. 在讲练页使用草稿与标画后提交本题：当题反馈正常，编辑入口消失；整卷完成与显式再做一次仍正常。
6. iPad / Pencil 验证手掌误触、手指滚动、旋转与边缘系统手势。真机条件未提供，本次自动化不替代这些验收。
