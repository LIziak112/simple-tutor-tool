# 手写命名配置与设置页实施计划

日期：2026-10-13。分支：`codex/ink-profile-settings`。状态：用户已确认，实现与自动化验收进行中。

## 用户目标

删除没有实际用途的 `/dev/ink` 手写开发页，保留 `/dev/ink-feel`，将其改为面向用户的「手写手感」设置与试写页面。用户调整后保存为有名字的配置，可在其他设备选择已有配置，也可根据设备重新调整并另存。草稿、正式手写作答及订正沿用当前设备选择的配置。

## 行为约定

- 页面只呈现配置选择、实时试写、必要的手感控制和保存操作，去除引擎泳道、采样 HUD、合成数据注入、预算测试、渲染验证等开发信息。
- 提供内置手感起点（跟手硬笔、自然压感、等宽标画），界面不要求用户理解引擎名称、采样 API 或技术参数术语。
- 用户配置具有独立 id、名称、参数、版本和更新时间。名称例如「iPad 日常作答」「手机手指书写」。每个账号最多 20 份，名称最多 40 字。
- 「保存修改」更新选中的配置；「另存为新配置」创建新的命名配置。只有服务端确认成功才显示已保存，不将本机暂存伪称账号同步完成。
- 配置按账号同步；本设备当前选择按部署实例、身份类型、账号保存，其他设备不会因当前设备切换配置而自动切换。
- 服务端更新采用版本比较，跨端同时编辑陈旧版本返回冲突，不静默覆盖。另存不影响原配置；删除当前配置后本设备回落内置默认值，保留笔迹正文。
- 未登录可以调整、试写；保存到账号需要登录。学生与教师会话明确区分，双身份同时登录时按入口所属身份处理，禁止串账号或混用 Cookie。
- 页面改动为暂存，保存成功后配置生效；重取配置列表不覆盖正在编辑的参数。切配置或离开页面时，如有未保存改动提供保存/放弃路径。
- 全屏试写保留同一纸面，收起、切配置、切输入方式时先收笔；账号变化清理当前配置缓存。配置变化不得绕过交卷及讲练题级锁定。
- 不建立旧笔感版本兼容层；仍保证新笔迹的编辑画面、PNG 与教师回放采用一致的绘制参数。临时预测永不进入正文、撤销历史或导出。
- 标画共享输入偏好，默认采用等宽笔刷；草稿、正式作答及订正共享用户选定的作答笔感。

## 文件范围

### 契约与账号同步

- `packages/contract/src/ink-profile.ts` 及测试：配置参数、命名记录、创建/修改/列表响应、版本冲突与限额的 Zod schema，前后端仅使用推断类型。
- `packages/contract/src/ink.ts`、`note.ts` 及测试：按实现需要为矢量载荷增加可选且有默认值的渲染配置，使草稿派生图、正式笔迹快照和回放能采用同一口径，不保存预测。
- `packages/contract/src/index.ts`、schema 导出脚本：注册新契约；执行 `pnpm schema:export`、`pnpm gen:spec` 并提交生成物。
- `apps/server/src/db/schema.ts`：增加手写配置表，按身份类型与账号归属隔离。迁移仅通过 `pnpm db:generate` 生成；同步迁移和备份/恢复回归，不手改数据库。
- `apps/server/src/services/ink-profile-service.ts`、`routes/ink-profiles.ts` 及测试，`app.ts`：账号配置 CRUD、版本比较、限额与域隔离，复用师生现有鉴权守卫。

### 用户页面与共享引擎

- `apps/web/src/pages/dev/InkFeelPage.tsx`：改为单一手感配置页面，保留原 URL；增加正式学生/教师入口或别名，避免用户从开发导航进入。
- `apps/web/src/features/ink/ink-profile-*`：API、按账号读取、配置列表和本设备选择；共享消费入口供所有手写面使用。
- `features/ink/InkPad.tsx`、`engine/index.ts`、实验绘制适配器：将已验证的自然笔感能力提取到共享引擎，统一参数下发与生命周期，正式默认值保持明确。
- `features/notes/use-note-editor.ts`、`NoteLayer.tsx`、`CorrectionPanel.tsx`、正式手写 `HandwrittenControls.tsx`：去除互相覆盖的默认值，接入配置；输入模式不再只是刷新即丢的会话值。
- `features/notes/render-note.ts`、`features/ink/replay/` 与正式 PNG 生成：绘制口径一致。标画在独立坐标域内复用输入偏好，不改变固定底图绑定规则。
- `pages/student/StudentLayout.tsx`、教师账号/设置入口：提供简洁的「手写手感」链接与当前配置选择，不扩张主导航。

### 删除开发页与回归迁移

- `App.tsx`：移除 `/dev/ink` 路由；`InkDevPage.tsx`、仅服务该页的开发面板及 UI 测试删除。保留仍被正式功能或测试使用的纯绘制/测量工具，按引用检查删除死代码。
- `e2e/ink-lifecycle.spec.ts`、`ink-feel.spec.ts`：迁移至手感设置页和实际作答面。
- `e2e/note-render.spec.ts`：保留真实 canvas/PNG 的内容验证，改为测试直接调用绘制检查函数，不在用户页面增加调试面板。
- `AGENTS.md`、`docs/页面功能清单.md`、原实验页说明及本计划：同步入口、配置归属、设备选择与手动验证说明。

## 实施顺序与 TDD

1. 先补契约失败测试，再定义配置及渲染参数 schema，导出类型与默认值。
2. 先补未登录、师生隔离、账号隔离、另存/修改、版本冲突、限额及学生接口泄露测试；再生成数据库迁移、实现服务端 CRUD。
3. 先补本设备选择、刷新恢复、换账号隔离、配置删除回落及重取不覆盖编辑测试；再实现客户端配置仓和精简设置页。
4. 先补草稿/作答/订正沿用参数、切换收笔、撤销与笔迹不丢、PNG/回放一致、已提交题禁止写入测试；再接入共享引擎与实际页面。
5. 删除开发页，迁移仍有意义的浏览器像素回归；验证旧链接不再呈现开发页，保留的 `/dev/ink-feel` 完成完整设置流程。
6. 对完整 diff 依次做复用简化、正确性和学生载荷安全审查，修复确认发现。运行全量测试、lint、typecheck、build 与相关 Chromium/WebKit E2E；生成物二次生成无 diff，现存 samples 回归通过。
7. 分支全绿后合并本地 `v2`，再推进本地 `main`；不夹带其他任务未提交内容，远端发布按现有授权执行。

## 手动验收

同一账号在平板保存「平板硬笔」，在手机读取并选用；手机调整后另存「手机手指」，平板仍保留自己的当前选择。两设备同时修改同一配置时出现冲突提示。检查离线保存失败、账号切换、未保存离开、配置删除、全屏与旋转。最后在真实草稿、正式手写题、讲练单题作答及订正中验证参数沿用、行级锁定、交卷和教师 PNG/回放一致。真实 Pencil 舒适程度由用户试写确认，自动化只验证功能与数据。
