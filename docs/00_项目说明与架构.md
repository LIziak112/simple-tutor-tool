# 线上答题系统 — 项目说明与架构

> 版本：v0.1（2026-09-24 立项）
> 一句话目标：学生用 iPad/电脑网页**看讲义、做题（支持手写）**；老师**直接查看每个学生的做题情况与做题痕迹**。

## 1. 背景与功能目标

《有理数打磨/01_线上格式规范.md》已定义了练习册的结构化书写格式（题号/题型/考点/ANSWER 注释/折叠详解）。本工具把符合该规范的 MD（或题库 JSON）变成可答题、可判分、可回看笔迹的系统。

功能目标：

1. **导入**：讲义 MD + 练习册 MD（按 01 规范书写）或题库 JSON；
2. **学生端**：网页（iPad Safari / 电脑浏览器 / 微信内置浏览器），选姓名免登录，看讲义、逐题作答；判断/选择/填空即时判分；计算/应用/找错题**手写作答**（Apple Pencil 流畅、防手掌误触）；
3. **做题痕迹**：每题保留 文本答案 + 手写笔迹 PNG + 该题用时 + 提交时间 + 总用时；
4. **教师端**：按学生查看提交明细、每题对错、手写原图；可人工批注对错；导出 CSV；
5. **部署形态（M1）**：局域网零依赖——一台电脑跑 `server.py`，iPad 同 WiFi 浏览器访问 `http://<电脑IP>:8787`。

## 2. 架构（M1：局域网版）

```text
┌─────────────┐   ┌─────────────┐
│ iPad Safari │   │ 电脑浏览器   │
│ 学生答题     │   │ 教师/学生    │
└──────┬──────┘   └──────┬──────┘
       │  HTTP (同 WiFi 局域网)
       ▼
┌──────────────────────────────┐
│ server.py (Python 3 标准库)   │
│  · 静态文件 public/           │
│  · /api/* JSON 接口           │
│  · MD→题库解析 parser.py      │
└──────────────┬───────────────┘
               ▼
      data/content.json      （讲义 + 题库）
      data/submissions/*.json（学生提交，含手写 PNG base64）
```

技术选型：

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 原生 HTML/CSS/JS，无构建 | 双击可改，无工具链 |
| 公式渲染 | KaTeX（CDN，可降级为纯文本） | `$...$` / `$$...$$` |
| MD 渲染 | marked（CDN，可降级） | 讲义与题干 |
| 手写 | Pointer Events + perfect-freehand（CDN，可降级为折线） | 防手掌误触、压感平滑 |
| 后端 | Python 3.12 标准库 http.server | 本机无 Node.js，Python 3.12.10 可用 |
| 存储 | JSON 文件 | 无数据库，人类可读可直接备份 |

- **M1（已完成）**：局域网全流程可用——导入 MD/JSON、看讲义、答题、手写、提交、教师查看与批注、CSV 导出。
- **M2（已完成 2026-09-24，单机公网版）**：部署至阿里云 ECS（47.116.99.166:8787，systemd 服务 quiz-system），学生/教师通过公网访问，提交存服务器。见 [../deploy/README.md](../deploy/README.md)。飞书多维表格同步等托管化改造未做。

## 6. 运行方式（验收通过后）

```bash
cd 线上答题系统
python server.py            # 默认 0.0.0.0:8787，Ctrl+C 停止
# 学生/老师浏览器访问 http://<本机局域网IP>:8787
# 教师: http://<本机局域网IP>:8787/teacher.html
```
