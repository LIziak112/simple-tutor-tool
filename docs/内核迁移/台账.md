## 验收证据怎么填

「验收证据」一列只认三样：测试文件、用例名、提交号（或固定到提交的链接），写成 `tests/文件.test.ts`「用例名」@提交号，一行有多条证据用「；」隔开。进度回填照这一列对账，不靠描述；没有这三样的行不能改成「已验收」。一行内所有契约项都有证据、且对应 PR 已合入才改「已验收」；证据还在未合入的 PR 上时写「契约已补（待 PR 合入后记验收）」。沿用旧台账的行写「沿用旧台账」，不重跑。
