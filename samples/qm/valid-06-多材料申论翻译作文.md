# 申论与写作专项

<!-- 验证结构点：response 题型、一题多材料 ::ref 引用（mat-1 segs 区间 + mat-2 全文）、seg 片段引用翻译源文、:::variant 多种参考表达、word-min/word-max 字数提示、参考答案为 Markdown（含列表与格式） -->

::::material{id=mat-1 title="给定资料一"}
:::seg{id=seg-1}
S 市的老旧小区改造起初推进缓慢。主管部门发现，图纸上的「统一改造」到了基层处处碰壁：加梯的楼栋里低层住户反对，改绿化的地块边停车刚需集中，适老化改造的申请者却不了解政策。一位社区书记坦言：「方案是专家画的，不是居民一起定的。」
:::

:::seg{id=seg-2}
转机出现在试点社区。街道把改造清单拆成三十七个小项，逐楼栋开议事会，居民代表对每个小项投票排序；预算明细张贴在单元门口，谁都可以查。半年后，该社区改造项目一次性通过验收，居民自发组成的「改造监督小组」又跟进了两年维护。
:::

:::seg{id=seg-3}
S 市随后出台文件，把「先协商、后改造」写入流程：未经过议事协商的小区改造项目不予立项。文件同时要求，社区议事会成员中普通居民比例不得低于三分之二。
:::
::::

::::material{id=mat-2 title="给定资料二"}
「议事协商不是开会走过场。」某大学基层治理研究中心的跟踪调查显示，改造满意度高的小区有一个共同点：协商过程产生了真实的分歧，且分歧被摆到了桌面上处理。研究负责人指出，分歧不是治理的失败，而是治理的起点——「绕开分歧的改造，问题只是被埋进了新墙面里。」

调查同时提醒了另一面：部分小区把议事协商办成了「表决仪式」，方案早已内定，居民投票只剩鼓掌。这类小区的后期维护纠纷率反而最高。
::::

::::question{id=sl-1 type=response difficulty=3 knowledge="归纳概括" word-min=150 word-max=250}
::ref{material=mat-1 segs=seg-1..seg-2}
::ref{material=mat-2}
根据给定资料，概括 S 市老旧小区改造中「议事协商」做法的主要特点。

要求：概括准确、条理清楚；不超过 250 字。

:::answer
S 市议事协商做法的主要特点：

1. **化整为零、逐项协商**：把改造清单拆分为三十七个小项，逐楼栋议事，居民对每个小项投票排序，协商颗粒度下沉到具体事项。
2. **公开透明、全程可查**：预算明细张贴公示，接受居民随时查询，并为协商结果配备两年期的居民自发监督。
3. **以分歧为起点**：不回避真实分歧，把分歧摆上桌面处理，而非内定后走表决流程。
4. **制度化固化**：将「先协商、后改造」写入立项前置条件，并以居民占比不低于三分之二的成员结构保证议事代表性。
:::

:::variant
若按「协商前—协商中—协商后」时序作答亦可：协商前拆分项目、公开预算；协商中逐楼栋议事、投票排序、直面分歧；协商后居民自发监督两年、制度化写入立项条件（居民代表占比 ≥ 2/3）。
:::

::::question{id=fy-1 type=response difficulty=2 knowledge="英译中" word-min=40 word-max=80}
::ref{material=mat-3 segs=seg-1..seg-2}
将材料中划定的两个句子译成中文。

:::answer
读书只能为心灵提供知识的材料；唯有思考，才能把我们读到的东西变成自己的。记忆尤须着力锻炼，因为强健的记忆力与鲜活、原创的想象力密不可分。
:::

:::variant
第一种译法（拆分句式）：书籍只为头脑提供知识的原料；使所读内容真正属于我们的，是思考。我们应特别锻炼记忆力，因为牢固的记忆无法与新颖而富于原创性的想象相分离。
:::

:::variant
第二种译法（更口语）：光靠读书只能得到知识的原料，想真正消化还得靠自己思考。记忆力尤其要多练——记不牢的人，想象力也很难出新。
:::

::::question{id=zw-1 type=response difficulty=4 knowledge="议论文写作" word-min=800 word-max=1000}
结合给定资料，以「分歧是治理的起点」为题，写一篇议论文。

要求：观点鲜明，论据充分；不少于 800 字，不多于 1000 字。

:::answer
**审题立意**：抓住「分歧—协商—共识」的递进关系；反面「表决仪式」是重要的对比论证材料。

**结构示范**：

- 开头：由 S 市改造转机切入，点出「绕开分歧的改造，把问题埋进新墙面」。
- 第一层（是什么）：分歧是利益与诉求的真实呈现，不是治理的失败（资料二研究结论）。
- 第二层（为什么）：化整为零的协商让分歧转化为方案颗粒度（三十七个小项、逐楼栋议事、投票排序）。
- 第三层（怎么办）：以制度固化协商成果（先协商后改造、居民占比三分之二、公开预算与长期监督）。
- 结尾：回应「表决仪式」的反例，强调真分歧才有真共识。

**范文开头段**：老旧小区的墙面可以刷新，埋在墙里的分歧刷不掉。S 市的试点给出相反的答案：把分歧摆上桌面，三十七个小项逐一议过，改造反而一次通过……（下略，800 字以上范文按此展开）
