本讲练「先给依据、再定顺序」的两种衔接题：七选五先看选项与空位前后句的关系，排序题先找首句与代词回指。做完后回到本页核对解析，再进入下一讲的整卷训练。

::::material{id=lesson-mat-1 title="Cohesion in English Paragraphs — Excerpt"}
A paragraph holds together by more than grammar. Each sentence leaves a {{lslot-1}} for the next to fill: a demonstrative, a repeated noun, or a question raised and then answered. Readers rarely notice this machinery until it breaks.

Consider the classic five-sentence gap item. {{lslot-2}} The sentence before a gap usually sets up a need — a contrast, a definition, a result — and the correct option is the one that pays it off. Distractors stay on topic but answer a question nobody asked.

The same logic orders a Chinese paragraph. {{lslot-3}} Fixed openings announce the theme; the middle sentences must then follow the order in which the theme unfolds, not the order in which thoughts happened to occur to the writer. {{lslot-4}} When a sentence cannot point forward or back, it is usually an intruder.
::::

:::::question{id=lq-1 type=matching difficulty=3 knowledge="七选五"}
从下方 5 个选项中为文中 3 个空白处选择最合适的内容（每空限选一项，不可重复），选项中有两项为多余选项。

::ref{material=lesson-mat-1 slots=lslot-1..lslot-3}

::::options
:::option{id=lopt-1}
a small, half-hidden signal
:::
:::option{id=lopt-2}
Winter arrived early that year, and the lake froze.
:::
:::option{id=lopt-3}
The examiner is not testing memory but the ability to repair a broken chain of reasoning.
:::
:::option{id=lopt-4}
A repeated noun works the same way: it promises the reader that the topic has not changed.
:::
:::option{id=lopt-5}
An intruder is easy to spot once you ask what the surrounding sentences are doing together.
:::
::::

:::answer
lslot-1 = lopt-1
lslot-2 = lopt-3
lslot-3 = lopt-4
:::

:::solution
多余项分析：lopt-2（季节叙述与衔接话题无关，answer a question nobody asked）、lopt-5（是对第 5 段结论的复述，不承接第 3 空前的「同样的逻辑」）。三个空位分别承接「留出信号→half-hidden signal」「设问→pay it off 的考官视角」「中文段落同理→代词/名词回指」。
:::
:::::

::::question{id=lq-2 type=choice difficulty=2 knowledge="段落衔接"}
第 4 空。::ref{material=lesson-mat-1 slot=lslot-4}

- [ ] therefore
- [x] when
- [ ] although
- [ ] unless

:::solution
第 4 空前句说明「句子无法前后呼应时多半是插入句」，后句正是「无法指向前后」的条件句式；when 引导该条件，与全文「设问—回应」的衔接观一致。
:::
::::

:::::question{id=lq-3 type=ordering difficulty=3 knowledge="语句排序"}
将下列段落排成一段语意连贯的文字。其中一段位置已固定（已标注），另有一段不属于本段文字，请勿选用。

:::item{id=lit-1}
也就是说，衔接练习的终点不是背熟套话，而是能在任何话题下找到那句「承接前文、开启后文」的句子。
:::

:::item{id=lit-2 fixed=true}
为什么七选五与排序题总被放在同一讲？
:::

:::item{id=lit-3}
因为两者考察的是同一种能力：识别句子之间的逻辑契约。
:::

:::item{id=lit-4}
七选五把契约撕开一个缺口让你补上；排序题则把整份契约拆散让你重装。
:::

:::item{id=lit-5}
另外，橄榄油凉拌与热炒的风味差异，主要来自多酚类物质对温度的敏感程度。
:::

:::answer
lit-2
lit-3
lit-4
lit-1
:::

:::solution
首句设问已固定；lit-3 直接回答设问（「因为……」）；lit-4 将两种题型并置展开；lit-1 的「也就是说」收束全段。lit-5 谈橄榄油风味，与本段话题无关，是干扰项。
:::
