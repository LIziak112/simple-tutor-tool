# 第1讲 有理数

## 一、正数与负数

$0$ 既不是正数也不是负数；$+7$、$\dfrac{2}{3}$ 是正数，$-3.5$、$-\dfrac{1}{6}$ 是负数。整数与分数统称有理数。

::::example{title="例 1：$-a$ 一定是负数吗"}
$-a$ 一定是负数吗？举例说明。

:::solution
不一定：当 $a=3$ 时，$-a=-3$ 是负数；当 $a=-3$ 时，$-a=3$ 是正数。$-a$ 表示 $a$ 的相反数，符号由 $a$ 本身决定。
:::
::::

::::question{type=judge difficulty=1 knowledge="有理数的概念"}
$0$ 是最小的正整数。[[错误]]

:::solution
$0$ 既不是正数也不是负数；最小的正整数是 $1$。
:::
::::

# 第2讲 数轴

## 一、数轴与大小比较

规定了原点、正方向和单位长度的直线叫作数轴；数轴上右边的数总比左边的数大，例如 $-2<-1.5<0<2$。

:::tip{title="小技巧"}
比较大小先在数轴上找点，再从左到右读序。
:::

::::question{type=choice difficulty=2 knowledge="数轴"}
比 $-1.5$ 大的数是（　）

- [ ] $-2$
- [x] $0$
- [ ] $-1.6$
- [ ] $-\dfrac{7}{4}$

:::solution
$-2<-1.5$，$-1.6<-1.5$，$-\dfrac{7}{4}=-1.75<-1.5$，只有 $0>-1.5$。故选 B。
:::
::::

## 二、相反数与绝对值

绝对值表示数轴上的点到原点的距离，不会是负数：$|-3|=3$，且 $|a|\geq 0$ 恒成立。

::::question{type=fill difficulty=2 knowledge="绝对值"}
计算：$|-5|=$ [[5]]；$-|-7|=$ [[-7]]。

:::solution
$|-5|=5$；先求绝对值再取相反数，$-|-7|=-7$。
:::
::::

:::fold{title="拓展：绝对值的几何意义"}
$|a|$ 是数轴上表示 $a$ 的点到原点的距离，因此 $|a|\geq 0$；互为相反数的两个点到原点的距离相等。
:::
