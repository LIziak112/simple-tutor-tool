$-5$ 的相反数是（　）

- [ ] $-5$
- [x] $5$

- [ ] $-\frac{1}{5}$

:::hint
只有符号不同的两个数互为相反数；$a$ 的相反数是 $-a$。
:::

$-5$ 的相反数是 $5$，故选 B。
:::

::::question{type=multi difficulty=2 knowledge="有理数加法"}
下列运算结果为正数的有（　）

- [x] $(-3)+7$
- [ ] $(-2)+(-5)$
- [x] $0+4.8$
- [ ] $|-9|+(-10)$

:::solution
异号相加取绝对值较大的加数的符号：$(-3)+7=4>0$，$0+4.8=4.8>0$；同号相加取相同的符号：$(-2)+(-5)=-7<0$，$|-9|+(-10)=9-10=-1<0$。故选 AC。
:::
::::

::::question{type=fill difficulty=2 knowledge="有理数加法"}
计算：$(-3)+7=$ [[4]]；$(-2)+(-5)=$ [[-7]]。

写等价形式：$0.5=$ [[0.5|1/2]]（填小数或分数均可）。

:::hint
同号相加，取相同的符号，并把绝对值相加；异号相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值。
:::

:::solution
$(-3)+7=4$；$(-2)+(-5)=-7$；$0.5=\dfrac{1}{2}$。
:::

:::solution

::::question{type=solve difficulty=3 knowledge="有理数混合运算" id=p4-q7}
计算 $-2^2+(-3)\times\left(-\frac{1}{3}\right)$，写出过程。

:::answer
-3
:::

:::solution
先算乘方：$-2^2=-4$（注意不是 $(-2)^2=4$）；再算乘法：$(-3)\times\left(-\frac{1}{3}\right)=1$；最后相加：$-4+1=-3$。
:::
::::

::::question{type=apply difficulty=3 knowledge="有理数加减混合应用"}
水箱水位初始高度为 $1.2$ 米，上午上升 $0.4$ 米，下午下降 $0.7$ 米，晚间又上升 $0.5$ 米。请用有理数的加减混合运算求最终水位，并列式说明每一步的含义。

:::answer
1.4
:::

:::hint
规定上升为正、下降为负，把各次变化依次写成有理数的和。
:::

:::solution
$1.2+(+0.4)+(-0.7)+(+0.5)=1.4$（米）。答：最终水位为 $1.4$ 米。
:::

::::question{type=find-error difficulty=2 knowledge="有理数加法"}
下面是小明的解答，其中有一处错误：

> 计算 $(-8)+(+3)+(+5)$。
> 第一步：$(-8)+(+3)=11$（同号相加，取相同的符号，绝对值相加）。
> 第二步：$11+(+5)=16$。

请指出从哪一步开始出错，说明理由，并写出正确的过程。

:::hint
先回顾异号两数相加的法则。
:::

:::hint
逐项检查每一步的符号与绝对值是怎样得来的。
:::

:::answer
第一步开始出错：$-8$ 与 $+3$ 是异号相加，应取绝对值较大的加数（$8$）的符号，并用 $8-3=5$，得 $-5$。
:::

:::solution
$(-8)+(+3)=-5$，$-5+(+5)=0$。异号相加不能把绝对值相加。
:::
