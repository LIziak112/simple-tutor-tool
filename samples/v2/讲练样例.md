# 第1讲 有理数

## 一、正数与负数

$0$ 既不是正数也不是负数；$+7$、$\dfrac{2}{3}$ 是正数，$-3.5$、$-\dfrac{1}{6}$ 是负数。整数与分数统称有理数。

:::warning{title="易错点：$-a$ 不一定是负数"}
$-a$ 表示 $a$ 的相反数：当 $a=3$ 时，$-a=-3$ 是负数；当 $a=-3$ 时，$-a=3$ 是正数。一个数的符号由数本身决定，不能只看前面有没有「负号」。
:::

::::question{type=judge difficulty=1 knowledge="有理数的概念" id=lesson-q1}
$0$ 是最小的正整数。[[错误]]

:::solution
$0$ 既不是正数也不是负数；最小的正整数是 $1$。
:::
::::

::::example{title="例 1：识别正数与负数"}
指出下列各数中的正数与负数：$+7$，$-3.5$，$0$，$\dfrac{2}{3}$，$-\dfrac{1}{6}$。

:::solution
正数：$+7$，$\dfrac{2}{3}$；负数：$-3.5$，$-\dfrac{1}{6}$；$0$ 既不是正数也不是负数。
:::
::::

::::question{type=choice difficulty=1 knowledge="有理数的分类"}
$\dfrac{2}{3}$ 是（　）

- [ ] 正整数
- [x] 正分数
- [ ] 负分数
- [ ] 非有理数

:::hint
整数与分数统称有理数；先看符号定正负，再看形式判断是整数还是分数。
:::

:::solution
$\dfrac{2}{3}$ 大于 $0$ 且是分数，故它是正分数，选 B。
:::
::::

# 第2讲 数轴

## 一、数轴与大小比较

规定了:mark[原点]{color=blue}、正方向和单位长度的直线叫作数轴；数轴上右边的数总比左边的数大，例如 $-2<-1.5<0<2$。

用数轴比较大小可以分两步进行：

::::steps
:::step{title="第 1 步：找点"}
把每个数在数轴上标出来，例如比较 $-2$，$-1.5$，$0$，$2$。
:::

:::step{title="第 2 步：定向"}
从左到右依次读取各点，得到从小到大的顺序，用「$<$」连接。
:::
::::

::::question{type=fill difficulty=2 knowledge="绝对值"}
计算：$|-5|=$ [[5]]；$-|-7|=$ [[-7]]。

:::hint
绝对值表示数轴上的点到原点的距离，不会是负数；先算绝对值，再取相反数。
:::

:::solution
$|-5|=5$；先求绝对值再取相反数，$-|-7|=-7$。
:::
::::

## 二、相反数与绝对值

只有符号不同的两个数互为相反数，如 $3$ 与 $-3$；互为相反数的两个点关于原点对称。

:::fold{title="拓展：绝对值的几何意义"}
$|a|$ 是数轴上表示 $a$ 的点到原点的距离，因此 $|a|\geq 0$；互为相反数的两个点到原点的距离相等，相加得 $0$。
:::
