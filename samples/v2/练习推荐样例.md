::::question{type=judge difficulty=1 knowledge="相反数"}
$-2$ 的相反数是 $2$。[[]]

:::solution
只有符号不同的两个数互为相反数，$-2$ 的相反数是 $2$。
:::
::::

::::question{type=choice difficulty=2 knowledge="有理数乘法"}
下列运算结果为负数的是（　）

- [ ] $(-2)\times(-3)$
- [x] $(-4)\times 5$
- [ ] $0\times(-7)$
- [ ] $|-3|\times 2$

:::hint
先算绝对值，再按「同号得正、异号得负」确定符号；$0$ 与任何数相乘都得 $0$。
:::

:::solution
$(-2)\times(-3)=6$，$(-4)\times 5=-20$，$0\times(-7)=0$，$|-3|\times 2=6$；只有第二个结果是负数，故选 B。
:::
::::

::::question{type=fill difficulty=2 knowledge="有理数减法"}
计算：$5-(-3)=$ [[8]]；$(-6)-4=$ [[-10]]。

:::solution
减去一个数等于加上它的相反数：$5-(-3)=5+3=8$；$(-6)-4=(-6)+(-4)=-10$。
:::
